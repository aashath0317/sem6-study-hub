1What is a function?

Function என்றால் என்ன?

ஒவ்வொரு input-க்கும் ஒரே ஒரு output ஒதுக்க வேண்டும். இரண்டு inputs ஒரே output-க்கு வரலாம்; ஆனால் ஒரு input இரண்டு outputs-க்கு போனால் function அல்ல. Domain, codomain இரண்டையும் கவனியுங்கள்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Domain அனுமதித்த inputs; codomain அறிவிக்கப்பட்ட outputs set; range உண்மையில் கிடைக்கும் outputs. Range codomain-இன் subset. f(x)=1/(x−2) என்றால் x≠2. √(x−1) real-valued என்றால் x≥1. ln(g(x))-க்கு g(x)>0. இவற்றைச் சேர்த்து domain restriction அமைக்க வேண்டும்.

முழுப் படிகளுடன் புரிந்துகொள்ள

Function f:A→B-இல் ஒவ்வொரு input-க்கும் exactly one output. Many inputs ஒரே output தரலாம். DomainA;codomainB;rangef(A)⊆B. ℤ→ℤ,x²-க்கு range nonnegative perfect squares மட்டும். √(x−1) real domain[1,∞);1/(x²−4) domainℝ{−2,2}. Formula மட்டும் இல்லாமல் declared sets-உம் function-இன் பகுதி.

Many questions ask how one quantity depends on another: a company's profit vs production level, bacteria population vs time, vocabulary learned vs learning time. Functions describe these relationships.

Definition

A function f from A to B is a rule that assigns to each element of A one and only one element of B. We write f : A → B. Functions are also called mappings or transformations.

Term Meaning
Domain The set A: the inputs
Codomain The set B: where the outputs are allowed to land
Image If f(a) = b, then b is the image of a (and a is a preimage of b)
Range The set of all images, f(A) ⊆ B. The range can be smaller than the codomain
"f maps A to B" Another way of saying f : A → B
Two conditions for a function
  1. Every element of A has an image (nothing in A is left out).
  2. Each element of A has exactly one image (no element goes to two places).

Many elements of A may share the same image, and some elements of B may have no preimage. That's still a function.

Example 3.1 — f : ℤ → ℤ, f(x) = x²
  • Domain: all integers
  • Codomain: all integers
  • Range: the perfect squares {0, 1, 4, 9, …}

The range is not the whole codomain.

Finding the domain of a real function

Exclude anything that makes the formula undefined:

  • Square root of a negative number is not allowed: need inside ≥ 0.
  • Division by zero is not allowed: need denominator ≠ 0.
Find the domain

(a) f(x) = √(x − 1)

Need x − 1 ≥ 0, so x ≥ 1. Domain = [1, ∞).

(b) f(x) = 1 / (x² − 4)

Need x² − 4 ≠ 0, so x ≠ ±2. Domain = (−∞, −2) ∪ (−2, 2) ∪ (2, ∞).

ஒரு அளவு மற்றொன்றை எவ்வாறு சார்ந்துள்ளது எனப் பல கேள்விகள் கேட்கின்றன: நிறுவன இலாபமும் உற்பத்தி நிலையும், பக்டீரியாத் தொகையும் காலமும், கற்ற சொற்களும் கற்றல் நேரமும். சார்புகள் இத்தொடர்புகளை விவரிக்கின்றன.

A-இன் பல மூலகங்கள் ஒரே படிமத்தைப் பகிர முடியும்; B-இன் சில மூலகங்களுக்கு முன்படிமம் இல்லாமலும் இருக்கலாம். இருந்தாலும் அது சார்பே.

  • துணை ஆட்களம்: அனைத்து முழு எண்களும்

வீச்சு முழுத் துணை ஆட்களமும் அல்ல.

மெய்ச் சார்பின் ஆட்களத்தைக் கண்டறிதல்

சூத்திரத்தை வரையறுக்கப்படாததாக்கும் அனைத்தையும் விலக்கவும்:

  • எதிர்மறை எண்ணின் வர்க்கமூலம் அனுமதிக்கப்படுவதில்லை: உள்ளே உள்ள பெறுமதி ≥ 0 தேவை.
  • பூச்சியத்தால் வகுத்தல் அனுமதிக்கப்படுவதில்லை: பகுதி ≠ 0 தேவை.
ஆட்களத்தைக் கண்டறியவும்

(a) f(x) = √(x − 1)

(b) f(x) = 1 / (x² − 4)

2One-to-one (injective)

வெவ்வேறு உள்ளீடுகளுக்கு வெவ்வேறு வெளியீடு

வெவ்வேறு inputs ஒரே output-ஐத் தரக்கூடாது. f(x)=x², real domain-இல் f(2)=f(−2), அதனால் injective அல்ல. நிரூபிக்க f(a)=f(b) எனத் தொடங்கி a=b கிடைக்கிறதா பாருங்கள்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Proof method: f(a)=f(b) எனக் கொண்டு algebra செய்து a=b கிடைக்கிறதா பாருங்கள். Counterexample-க்கு a≠b இருந்தும் same output ஒரு ஜோடி போதும். x² negative மற்றும் positive inputs-இல் one-to-one அல்ல. ஆனால் domain [0,∞) என்றால் one-to-one. Function formula மட்டும் பார்த்து classification சொல்லக்கூடாது.

முழுப் படிகளுடன் புரிந்துகொள்ள

Injective proof:f(a)=f(b) assume செய்து a=b derive. 3a−5=3b−5→a=b. x² onℝ not injective:1,−1 same1. Domain[0,∞) restriction-இல் x² injective ஆகலாம். Disproof-க்கு distinct inputs same image என்ற ஒரு witness pair போதும்;different inputs சிலவற்றுக்கு different outputs என்பது proof அல்ல.

Definition

f is one-to-one (injective) if and only if f(a) = f(b) implies a = b for all a, b in the domain.

  • Lemma 3.2.1: equivalently, a ≠ b ⇒ f(a) ≠ f(b). Different inputs always give different outputs.
  • With quantifiers: ∀a ∀b (f(a) = f(b) → a = b)
Proving / disproving one-to-one

f(x) = 3x − 5 is one-to-one.

Let f(x₁) = f(x₂). Then 3x₁ − 5 = 3x₂ − 5, so 3x₁ = 3x₂, so x₁ = x₂. ∎

f(x) = x² is not one-to-one.

f(1) = f(−1) = 1, but 1 ≠ −1. One counterexample is enough.

வரையறை

ஆட்களத்திலுள்ள அனைத்து a, b-க்கும் f(a) = f(b) எனில் a = b என்றால் மட்டுமே f ஒன்றுக்கொன்றானது (உட்சார்பு).

  • துணைத்தேற்றம் 3.2.1: அதற்குச் சமமாக a ≠ b ⇒ f(a) ≠ f(b). வெவ்வேறு உள்ளீடுகள் எப்போதும் வெவ்வேறு வெளியீடுகளை வழங்குகின்றன.
  • அளவைக்குறிகளுடன்: ∀a ∀b (f(a) = f(b) → a = b)
ஒன்றுக்கொன்றானதா என நிறுவுதல் / மறுத்தல்

f(x) = 3x − 5 ஒன்றுக்கொன்றானது.

f(x₁) = f(x₂) என்க. அப்போது 3x₁ − 5 = 3x₂ − 5; எனவே 3x₁ = 3x₂; எனவே x₁ = x₂. ∎

f(x) = x² ஒன்றுக்கொன்றானதல்ல.

f(1) = f(−1) = 1; ஆனால் 1 ≠ −1. ஓர் எதிர் எடுத்துக்காட்டு போதும்.

3Onto (surjective) & bijection

Surjective மற்றும் Bijection

Codomain-இன் ஒவ்வொரு உறுப்புக்கும் குறைந்தது ஒரு input இருந்தால் Surjective. Injective-உம் surjective-உம் இரண்டும் இருந்தால் Bijective. Codomain மாறினால் surjectivity-யும் மாறலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Onto proof: arbitrary y∈codomain எடுத்துக் கொண்டு f(x)=y தீர்த்து, கிடைத்த x domain-இல் இருக்கிறதா நிரூபியுங்கள். f(x)=2x+1, ℝ→ℝ என்றால் x=(y−1)/2 எப்போதும் real; onto. Injective+onto → bijection → inverse function A↔B. ஒரு codomain value-க்கு preimage இல்லாவிட்டால் onto அல்ல; இரண்டு preimages இருந்தால் injective அல்ல.

முழுப் படிகளுடன் புரிந்துகொள்ள

Surjective:arbitrary y∈codomain எடுத்துப் f(x)=y solve செய்து x∈domain என்பதை நிரூபி. 3x−5 y-க்கு x=(y+5)/3∈ℝ;ontoℝ. x² ontoℝ இல்லை:y−1 counterexample;onto[0,∞) என்றால் x√y witness. Bijection=injective+onto. Finite sets-இல் bijection இருந்தால் sizes சமம்;size சமம் என்பதால் எந்த mapping-உம் bijection ஆகிவிடாது.

Onto

f : A → B is onto (surjective) if for every b ∈ B there is an a ∈ A with f(a) = b. In other words, range = codomain: nothing in B is missed.

Example 3.2

f : ℝ → ℝ, f(x) = 3x − 5 is onto.

Given any y, solve 3x − 5 = y to get x = (y + 5)/3, which is a real number. So every y is hit. ✓

f : ℝ → ℝ, f(x) = x² is not onto.

ℝ contains negative numbers, and no real x has x² = −1. ✗

Bijection (one-to-one correspondence)

f is a bijection if it is both one-to-one and onto.

Example: the identity function ι_A : A → A, ι_A(x) = x, sends each element to itself. It is one-to-one and onto, so it's a bijection.

4Inverse functions

வெளியீட்டிலிருந்து உள்ளீட்டிற்குத் திரும்புதல்

Output-இலிருந்து input-க்கு திரும்பும் விதி Inverse. இரு திசையிலும் ஒரே பதில் வேண்டுமென்றால் பொருத்தமான domain, codomain-இல் bijection வேண்டும். x²-க்கு real domain முழுவதிலும் தனித்த inverse இல்லை.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

f(x)=(x−1)/2 என்றால் y=(x−1)/2 → x=2y+1; ஆகவே f⁻¹(x)=2x+1. f⁻¹(x) என்பது 1/f(x) அல்ல. Check: f⁻¹(f(x))=x, f(f⁻¹(y))=y உரிய domains-இல். Domain restriction இல்லாமல் square root-இல் ± விடையை ஒரே inverse function என்று சொல்ல முடியாது.

முழுப் படிகளுடன் புரிந்துகொள்ள

Inverse இருபக்கமும் undo செய்யும் function ஆக A↔B இருக்க f bijection வேண்டும். y=3x−5→x=(y+5)/3→f⁻¹(y). f⁻¹ என்பது reciprocal1/f அல்ல. Domain/range swap;f⁻¹∘f=idA,f∘f⁻¹=idB. Noninjective function-ஐ appropriate restricted domain-இல் invert செய்யலாம்;inverse image of a set வேறு கருத்து.

Definition

Let f be a bijection from A to B. The inverse function f⁻¹ assigns to each b ∈ B the unique a ∈ A with f(a) = b:

f⁻¹(b) = a ⇔ f(a) = b

  • Only bijections have inverses. If f isn't one-to-one, some b would need two outputs. If f isn't onto, some b would have none.
  • ⚠️ Don't confuse f⁻¹ with 1/f. f⁻¹ "undoes" f; 1/f is the reciprocal.
Example — f : ℝ → ℝ, f(x) = 3x − 5

f is a bijection (shown above), so it is invertible.

Let y = 3x − 5 and solve for x: x = (y + 5)/3.

So f⁻¹(y) = (y + 5)/3.

Check: f(f⁻¹(y)) = 3·(y + 5)/3 − 5 = y ✓

Note on the PDF

The lesson PDF works this example as "y = x + 1, so f⁻¹ = y − 1". That's the textbook example for f(x) = x + 1, pasted under the wrong function. For f(x) = x + 1 the inverse is indeed f⁻¹(y) = y − 1. For f(x) = 3x − 5 it is (y + 5)/3.

Recipe for an inverse: 1. Write y = f(x). 2. Solve for x in terms of y. 3. Swap the names if needed: f⁻¹(y) = …

5Composition of functions

ஒரு Function-க்குப் பிறகு மற்றொன்று

(f∘g)(x)=f(g(x)). முதலில் உள்ளே உள்ள g; பிறகு f. வரிசை முக்கியம்: துணியைத் துவைத்துப் பிறகு உலர்த்துவது போல, வரிசை மாற்றினால் முடிவு பொதுவாக மாறும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

f(x)=x+1, g(x)=2x என்றால் f∘g=2x+1; g∘f=2x+2. இவை வேறுபடும். f(g(x)) வரையறுக்க g(x) output f-இன் domain-இல் இருக்க வேண்டும். Inverse composition-இல் (f∘g)⁻¹=g⁻¹∘f⁻¹; வரிசை திரும்புகிறது.

முழுப் படிகளுடன் புரிந்துகொள்ள

f∘g:g முதலில். f=x²−1,g=√x+1: f∘g=x+2√x,domainx≥0;g∘f=√(x²−1)+1,domainx≤−1 அல்லதுx≥1. Formula simplify செய்தபின் original domain restrictions மறக்காதீர்கள். Whole domain-இல் composition வேண்டுமெனில் inner function image outer domain-க்குள் இருக்கவேண்டும்;இல்லையெனில் restricted composite domain குறிப்பிடவும்.

Definition

Let g : A → B and f : B → C. The composition f ∘ g is defined by (f ∘ g)(a) = f(g(a)).

Apply g first, then f. f ∘ g is only defined when the range of g is a subset of the domain of f.

   A ──g──▶ B ──f──▶ C
   a  ↦  g(a)  ↦  f(g(a))      (f∘g)(a) = f(g(a))
Example — f(x) = x² − 1, g(x) = √x + 1

(a) g ∘ f. Put f(x) into g:

(g ∘ f)(x) = g(f(x)) = √(f(x)) + 1 = √(x² − 1) + 1

Over the reals, g ∘ f has domain (−∞, −1] ∪ [1, ∞) because x² − 1 ≥ 0.

(b) f ∘ g. Put g(x) into f:

(f ∘ g)(x) = f(g(x)) = (g(x))² − 1 = (√x + 1)² − 1 = x + 2√x + 1 − 1 = x + 2√x

f ∘ g has domain [0, ∞) inherited from g(x) = √x + 1. Simplifying the formula does not remove its original domain restrictions.

Order matters

In general f ∘ g ≠ g ∘ f, as the example shows.

For a bijection f : A → B:
(f⁻¹ ∘ f)(a) = f⁻¹(f(a)) = f⁻¹(b) = a and (f ∘ f⁻¹)(b) = f(f⁻¹(b)) = f(a) = b

So composing a function with its inverse gives the identity.

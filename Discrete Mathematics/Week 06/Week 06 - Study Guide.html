Number theory ("higher arithmetic") studies integers and their properties. This lesson covers divisibility, modular arithmetic, primes and a cryptography application.

Definition 1

Let a and b be integers with a ≠ 0. If there is an integer c with b = ac, then a divides b, written a | b.

  • a is a factor of b; b is a multiple of a.
  • If a does not divide b, write a ∤ b.
Example 6.1.1
  • 20/4 = 5 is an integer, so 4 | 20.
  • 17/6 is not an integer, so 6 ∤ 17.
Don't confuse the notations

a | b is a statement (true or false): "a divides b". a / b is a number: a divided by b.

3 | 12 is true; 12/3 = 4.

Theorem 1 — properties of divisibility

For integers a, b, c:

  1. If a | b and a | c, then a | (b + c).
  2. If a | b, then a | bc for every integer c.
  3. If a | b and b | c, then a | c (transitivity).
Proofs (direct, using the definition)

(i) a | b and a | c, so b = as and c = at for integers s and t. Then b + c = as + at = a(s + t), so a | (b + c). ∎

(ii) a | b, so b = as. Then bc = asc = a(sc), so a | bc. ∎

(iii) b = as and c = bt, so c = (as)t = a(st), so a | c. ∎

Corollary

If a | b and a | c, then a | (mb + nc) for any integers m and n.

Proof: by (ii), a | mb and a | nc. Then by (i), a | mb + nc. ∎

Exam favourites: divisibility proofs

If 7 | 4n, then 7 | n (January and July 2023)
  1. 7 | 4n, so 4n = 7k for some integer k.
  2. The trick: 2 × 4 = 8 = 7 + 1, so n = 8n − 7n.
  3. n = 2(4n) − 7n = 2(7k) − 7n = 7(2k − n).
  4. 2k − n is an integer, so 7 | n. ∎

This works because 4 and 7 share no common factor. In general, find a multiple of the coefficient that is 1 more than a multiple of the divisor.

If a | b and c | d, then ac | bd (January 2023)

b = ak and d = cm for integers k and m. Then bd = (ak)(cm) = (ac)(km), so ac | bd. ∎

2The division algorithm

ஈவும் மீதியும்

Theorem 2 (the division algorithm)

Let a be an integer and d a positive integer. Then there are unique integers q and r with 0 ≤ r < d such that

a = dq + r

Name Symbol Notation
Dividend a —
Divisor d —
Quotient q q = a div d
Remainder r r = a mod d
Examples 6.2.1 and 6.2.2
  • 27 ÷ 4: 27 = 4·6 + 3, so 6 = 27 div 4 and 3 = 27 mod 4.
  • −23 ÷ 5: −23 = 5·(−5) + 2, so −5 = −23 div 5 and 2 = −23 mod 5.
The remainder is never negative

For −23 ÷ 5 the answer is not q = −4, r = −3. The remainder must satisfy 0 ≤ r < d. So go one step further down: q = −5, and r = −23 − (−25) = 2.

If the remainder is zero, then x is divisible by y (y | x).

Proof by cases using remainders

The division algorithm says every integer has exactly one remainder when divided by m. So you can prove a statement by checking each possible remainder as a separate case.

January 2023 Q2(c): a² has the form 3k or 3k + 1, never 3k + 2

Divide a by 3: a = 3q + r with r = 0, 1 or 2.

Case a² Form
r = 0 9q² = 3(3q²) 3k
r = 1 9q² + 6q + 1 = 3(3q² + 2q) + 1 3k + 1
r = 2 9q² + 12q + 4 = 3(3q² + 4q + 1) + 1 3k + 1

Every case gives 3k or 3k + 1, so a² is never 3k + 2. ∎

Model Q1(b): n odd ⇒ 4 | n² − 5, but 8 ∤ n² − 5

Write n = 2k + 1. Then n² − 5 = 4k² + 4k − 4 = 4(k² + k − 1), so 4 divides it.

k² + k = k(k + 1) is a product of consecutive integers, so it is even. Then k² + k − 1 is odd, and 4 × (odd) is never divisible by 8. ∎

Template for a cases proof

State the cases from the division algorithm, work out each case in a table or list, and finish with "every case gives …, so …". Missing one case loses the marks.

3Modular arithmetic & congruence

மீதியை அடிப்படையாகக் கொண்ட கணக்கு

Clock-இல் 12-க்குப் பிறகு மீண்டும் 1 வருவது போல ஒரு modulus-க்குள் எண்ணுகிறோம். a≡b (mod m) என்றால் m, a−b-ஐ வகுக்கும். இரண்டுக்கும் ஒரே remainder என்பதும் அதே பொருள்.

Definition 2 — congruence

Let m be a positive integer. a is congruent to b modulo m, written a ≡ b (mod m), if m divides a − b. If not, write a ≢ b (mod m).

Theorem 3

a ≡ b (mod m) if and only if a mod m = b mod m: a and b leave the same remainder.

Example 6.3.1
  • Is 17 ≡ 3 (mod 7)? 17 − 3 = 14, and 7 | 14. Yes, 17 ≡ 3 (mod 7).
  • Is 21 ≡ 6 (mod 8)? 21 − 6 = 15, and 8 ∤ 15. No, 21 ≢ 6 (mod 8).
Theorem 4 — you can add and multiply congruences

If a ≡ b (mod m) and c ≡ d (mod m), then:

  • a + c ≡ b + d (mod m)
  • ac ≡ bd (mod m)
Example 6.3.2

12 ≡ 2 (mod 5) and 16 ≡ 1 (mod 5). So:

  • 28 = 12 + 16 ≡ 2 + 1 = 3 (mod 5)
  • 192 = 12·16 ≡ 2·1 = 2 (mod 5)

Congruence classes (Definition 3)

The congruence class of a modulo n is the set of all integers with the same remainder as a when divided by n.

Example 6.3.3

… ≡ −40 ≡ −33 ≡ −26 ≡ −19 ≡ −12 ≡ −5 ≡ 2 ≡ 9 ≡ 16 ≡ 23 ≡ 30 ≡ 37 ≡ … ≡ 2 (mod 7)

So the congruence class of 2 modulo 7 is {…, −40, −33, −26, −19, −12, −5, 2, 9, 16, 23, 30, 37, …}. Start at 2 and keep adding or subtracting 7.

4Primes

Every positive integer greater than 1 is divisible by at least 1 and itself.

Definition 4
  • A positive integer p > 1 is prime if its only positive factors are 1 and p.
  • An integer > 1 that is not prime is composite.
  • Equivalently, a prime is a natural number > 1 that can't be written as a product of two smaller natural numbers.
  • Remark: n is composite ⇔ there is an integer a with a | n and 1 < a < n.
Example Reasoning
7 is prime (6.4.1) The only products are 1 × 7 and 7 × 1
6 is composite (6.4.2) 6 = 2 × 3, both smaller than 6
Every even integer > 2 is composite (6.4.3) x = 2 × (x/2), and x/2 is an integer
Theorem 5 (Euclid)

There are infinitely many primes. If p₁, …, pₙ are the n smallest primes, there is always a larger prime not in that list.

Theorem 6 — the fundamental theorem of arithmetic

Every positive integer greater than 1 can be written uniquely as a prime or as a product of two or more primes, with the prime factors in non-decreasing order.

Cryptography is the study of secret messages. It has two parts:

  • Encryption: making a message secret.
  • Decryption: recovering the original message.

Caesar's cipher (used by Julius Caesar) shifts each letter three places forward. So C → F and Y → B (it wraps around).

Number the letters A = 0, B = 1, …, Z = 25. Then:

Encrypt: f(p) = (p + 3) mod 26
Decrypt: f⁻¹(p) = (p − 3) mod 26

f is one-to-one (in fact a bijection) on {0, …, 25}, so f⁻¹ exists. Both domain and codomain are {0, 1, …, 25}.

Example 6.5.1 — encrypt YARD
Letter Y A R D
p 24 0 17 3
(p + 3) mod 26 27 ≡ 1 3 20 6
Cipher B D U G

YARD → BDUG

Decrypt CHVW
Letter C H V W
p 2 7 21 22
(p − 3) mod 26 −1 ≡ 25 4 18 19
Plain Z E S T

CHVW → ZEST. (Note −1 = 26 × (−1) + 25, so −1 mod 26 = 25.)

Q1. a, b, c are integers. Which statement is incorrect?

(a) If a|b and b|c, then a|c. (b) If a|b, then a|bc for all integers c. (c) a + b + c is not an integer. (d) If a|b and a|c, then a|(b + c).

Answer: (c) “a + b + c is not an integer”

Adding integers always gives an integer, so (c) is wrong. The others are the three divisibility rules to memorise (a|b means “a divides b”, b = a × something):

  • a|b and b|c ⇒ a|c (e.g. 2|4, 4|12 ⇒ 2|12)
  • a|b ⇒ a|bc (e.g. 3|6 ⇒ 3|6×5)
  • a|b and a|c ⇒ a|(b + c) (e.g. 5|10, 5|15 ⇒ 5|25)

Q2. Quotient and remainder when 34 is divided by 5?

(a) 6 and 4 (b) 6 and 5 (c) 3 and 4 (d) 4 and 6

Answer: (a) quotient 6, remainder 4

34 = 5 × 6 + 4. (Write a = d × q + r with 0 ≤ r < d.) The remainder must be smaller than 5, so (b) is impossible. In notation: 34 div 5 = 6, 34 mod 5 = 4.

Q3. True or false: “a is congruent to b modulo m if m divides a + b.”

Answer: False

Correct definition: a ≡ b (mod m) if m divides a − b (the difference), i.e. a and b leave the same remainder when divided by m.

Q4. Which is incorrect?

(a) 2 ≡ 37 mod 5 (b) 4 ≡ 29 mod 5 (c) 7 ≡ 62 mod 9 (d) 2 ≡ 42 mod 4

Answer: (c) 7 ≡ 62 mod 9

Test: subtract, then check if m divides the difference.

  • (a) 37 − 2 = 35, 5 | 35 ✓ (b) 29 − 4 = 25, 5 | 25 ✓ (d) 42 − 2 = 40, 4 | 40 ✓
  • (c) 62 − 7 = 55, and 9 does not divide 55 (9 × 6 = 54) → incorrect.

Q5. True or false: a prime is a natural number greater than 1 that cannot be written as the product of two smaller natural numbers.

Answer: True

That is the definition. Equivalently: its only positive divisors are 1 and itself. 1 is not prime; 2 is the only even prime.

Q6. Which set contains only primes?

(a) {13, 29, 41} (b) {55, 37, 99} (c) {32, 45, 16} (d) {7, 89, 17}

Answer marked by the quiz: (a) {13, 29, 41}
  • (b) 55 = 5 × 11 and 99 = 9 × 11 → not prime. (c) all even or divisible by 5 → not prime.
  • (a) 13, 29, 41 are all prime ✓.
  • Note: (d) 7, 89, 17 are also all prime, so the question has two correct sets. The quiz accepted (a).

How to test if n is prime: try dividing by the primes 2, 3, 5, 7, … up to √n. If none divides it, n is prime. (89: √89 ≈ 9.4; 2, 3, 5, 7 don't divide 89 → prime.)

Q7. Encrypt CART with Caesar's cipher.

(a) PBQR (b) FDUW (c) LIJT (d) SKNW

Answer: (b) FDUW

Caesar cipher: shift every letter 3 forward. f(p) = (p + 3) mod 26, with A = 0, …, Z = 25. C → F, A → D, R → U, T → W → FDUW. (After Z, wrap round: X → A, Y → B, Z → C.)

Q8. Decrypt ERRN with Caesar's cipher.

(a) BOOK (b) ROOM (c) KEEN (d) REEL

Answer: (a) BOOK

Decrypt = shift 3 back. f⁻¹(c) = (c − 3) mod 26. E → B, R → O, R → O, N → K → BOOK.

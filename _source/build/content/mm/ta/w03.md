## Text-இன் பங்கும் அடிப்படை elements-உம்

Text பெயர்கள், instructions, facts, நேரடியாகப் படம் காட்ட முடியாத ideas ஆகியவற்றைச் சொல்லுகிறது. Multimedia-வில் page titles, picture labels, button menus, navigation, main content ஆகியவற்றில் வருகிறது. Photo bus-ஐக் காட்டலாம்; ஆனால் destination, fare condition அல்லது abstract concept-ஐ text விளக்கலாம்.

Developers இரண்டு பார்வையில் text-ஐப் பார்க்கிறார்கள். **Presentation:** typeface, size, colour, arrangement மூலம் எப்படி தெரிகிறது? **Content/behaviour:** என்ன அர்த்தம், user interact செய்தால் என்ன நடக்கிறது? Hyperlink அழகாக இருந்தாலும் destination புரியாத label இருந்தால் குழப்பமாக இருக்கும்.

PDF basic characters-ஐ alphabetic, numbers, special characters என்று பிரிக்கிறது. Alphabetic-இல் uppercase/lowercase letters; numbers-இல் digits; special-இல் punctuation, mathematical symbols, signs உள்ளன. Icons/drawing symbols/Greek letters-உம் repertoire-இல் இருக்கலாம். Characters சேர்ந்து words, sentences, paragraphs, பெரிய நூல்கள் உருவாகின்றன.

**Linear organisation** வரிசையாக வாசிக்கச் செய்கிறது. **Nonlinear organisation** links மூலம் வேண்டிய இடத்திற்குச் செல்லச் செய்கிறது. **Glyph** என்பது character-ஐக் காட்டும் visible shape. Character meaning வேறு; glyph தோற்றம் வேறு. அதே letter வெவ்வேறு typeface-இல் வேறு வடிவில் இருக்கலாம்.

:::example Railway information screen
Title service-ஐ அடையாளம் காட்டுகிறது. Short instruction destination தேர்ந்தெடுக்க உதவுகிறது. Labels controls-க்குப் பெயர் கொடுக்கின்றன. “Fare conditions” link கூடுதல் தகவலுக்குச் செல்கிறது. Meaning, appearance, interaction மூன்றும் பயணியின் வேலையை எளிதாக்குகின்றன.
:::

## Typeface, font மற்றும் appearance effects

:::key வேறுபடுத்த வேண்டிய இரண்டு சொற்கள்
**Typeface** என்பது letters/numbers/symbols-இன் visual design family. Lesson-இன் traditional definition-இல் **font** என்பது அந்த family-இன் ஒரு size/style characters தொகுப்பு. Digital usage-இல் glyph shapes மற்றும் rendering தகவல் தரும் software resource-ஐயும் font என்கிறோம்.
:::

ஒரு typeface family-இல் regular/bold/italic styles இருக்கலாம். Family visual design-ஐத் தீர்மானிக்கிறது; style/size heading அல்லது paragraph-இல் அதன் பயன்பாட்டைத் தீர்மானிக்கிறது. அன்றாடப் பேச்சில் இரண்டும் கலந்தாலும் exam-இல் வேறுபாட்டைச் சொல்லுங்கள்.

Type size **points**-இல் அளக்கப்படுகிறது. **One point = 1/72 inch**. PDF capital top முதல் descender வரை என்று விளக்குகிறது. துல்லியமாகப் பார்த்தால் point size font-இன் design/em size; visible letter height typeface-க்கு ஏற்ப மாறும். அதே point size-இல் இரண்டு fonts வேறு உயரமாகத் தெரியலாம்.

| Effect | பயன்பாடும் கவனிக்க வேண்டியதும் |
|---|---|
| UPPERCASE/lowercase | Tone/hierarchy காட்டும்; நீண்ட uppercase paragraph வாசிக்கக் கடினமாகலாம் |
| Bold | முக்கிய word/heading-க்கு வலிமை |
| Italic | Family மாற்றாமல் வேறுபாடு/emphasis |
| Underline | Emphasis; website-இல் link என்று தோன்றலாம் |
| Superscript/subscript | Normal line-க்கு மேல்/கீழ் characters; powers/chemical notation |
| Emboss/shadow | Depth/decorative effect; readability குறையக்கூடாது |
| Colour | Attention/meaning organisation; background-உடன் test செய்யுங்கள் |
| Strikethrough | பழைய அல்லது நீக்கிய text-ஐக் காட்டும் |

Effect தெளிவான message கொடுத்தால்தான் பயன். எல்லா effects-ஐயும் ஒரே phrase-இல் வைத்தால் hierarchy/readability கெடும். ஒரே purpose-க்கு ஒரே effect-ஐச் சீராகப் பயன்படுத்துங்கள்.

## Serif, sans serif மற்றும் spacing anatomy

**Serif** typeface-இல் main strokes முடிவில் finishing strokes/tips இருக்கும்; Times New Roman உதாரணம். **Sans serif**-இல் அவை இல்லை; Arial உதாரணம். Figures 3.1 மற்றும் 3.2 ஒரே words-ஐ இந்த இரண்டு வகைகளில் காட்டுகின்றன.

PDF நீண்ட document-க்கு serif, display-க்கு sans serif பரிந்துரைக்கிறது. இது guidance; கட்டாய rule இல்லை. Size, spacing, contrast, rendering, reader needs-உம் முக்கியம். உண்மையான screen/print-இல் test செய்யுங்கள்.

| Term | அடையாளம் காண வேண்டியது |
|---|---|
| Baseline | பெரும்பாலான letters உட்காரும் reference line |
| Cap height | Baseline-க்கு மேல் capital letter உயரம் |
| x-height | x போன்ற lowercase body உயரம் |
| Ascender | h/b/d-இல் lowercase body-க்கு மேலே வரும் stroke |
| Descender | p/q/y-இல் baseline-க்குக் கீழே வரும் stroke |
| Leading | Text lines இடையிலான இடைவெளி |
| Tracking | Characters தொகுப்பு முழுவதற்குமான spacing |
| Kerning | குறிப்பிட்ட character pair-க்கான spacing adjustment |

## Bitmap fonts, vector fonts மற்றும் rasterization

**Bitmap font** character தோற்றத்தை pixel patterns-ஆகச் சேமிக்கிறது. அது குறிப்பிட்ட pixel size-உடன் தொடர்புடையது. பெரிதாக்கும்போது stored pixels பெரிதாகத் தெரியும். அதிக characters/size variants சேமிக்க கூடுதல் data வேண்டும்.

**Vector/outline font** glyph outline-ஐ mathematical description-ஆகச் சேமிக்கிறது. Renderer அதை வேண்டிய size-க்கு scale செய்து வரைகிறது. TrueType/PostScript source examples. பல sizes-க்கு outline reuse செய்வது வசதி. ஆனால் எல்லா vector-font files-உம் மிகவும் சிறியது என்ற PDF கூற்று universal guarantee இல்லை.

| Bitmap font | Vector/outline font |
|---|---|
| Pixel patterns சேமிக்கும் | Mathematical outlines சேமிக்கும் |
| குறிப்பிட்ட pixel dimensions-க்கு design | பல sizes-க்கு scale செய்யலாம் |
| Enlargement-இல் pixels தெரியும் | Renderer தேர்ந்த size-க்கான pixels உருவாக்கும் |
| பல stored sizes-க்கு கூடுதல் data தேவைப்படலாம் | ஒரே outline design பல sizes-க்கு உதவும் |

**Rasterization** glyph outline-ஐ screen pixels-ஆக மாற்றுகிறது. Grid discrete என்பதால் diagonal edge படிக்கட்டு போலத் தெரியும்; இதுவே **aliasing**. **Anti-aliasing** edge-இல் intermediate intensities பயன்படுத்தி foreground/background கலப்பதன் மூலம் smooth-ஆகத் தெரியச் செய்கிறது. Appearance மேம்படும்; physical resolution முடிவில்லாமல் அதிகரிக்காது.

:::flow Outline-இலிருந்து visible text வரை
Character code glyph-ஐத் தேர்ந்தெடுக்கும்
Font glyph outline தரும்
Renderer scale/position செய்யும்
Rasterization pixel coverage தீர்மானிக்கும்
Anti-aliasing edge intensities சரிசெய்யும்
Screen காட்டும்
:::

Figure 3.4 diagonal stroke, circle, stepped raster edge-ஐ smoother versions-உடன் ஒப்பிடுகிறது. Outline → pixel grid → jagged edge வாய்ப்பு → intensity blending என்பதே முக்கியத் தொடர்பு.

## Plain text, rich text மற்றும் hypertext

**Plain text** bold/centred paragraph போன்ற presentation formatting இல்லாமல் characters சேமிக்கிறது. **Rich text** formatting instructions/control structures சேர்க்கிறது. **Hypertext** related sections/documents/media-க்கு செல்ல links கொடுக்கிறது. இவை text organisation/presentation பற்றியவை; encoding characters data-ஆக மாறுவதை விளக்குகிறது.

PDF plain-text example-ஆக ASCII பயன்படுத்துகிறது. Plain text ASCII மட்டும் அல்ல; UTF-8 Tamil file-உம் plain text. Rich formatting மற்றும் hyperlinks ஒரே document-இல் சேரலாம்.

Text-ஐச் சுருக்கமாக எழுதுங்கள்; ஆனால் முக்கிய தகவலைப் பல clicks-க்குப் பின்னால் மறைக்க வேண்டாம். சிறிய size-இல் decorative font தவிருங்கள். குறைந்த, சீரான typefaces மற்றும் தேவையான bold/italic variations பயன்படுத்துங்கள். Leading படிக்க வசதியாக இருக்கட்டும்; முக்கிய content-க்கு பொருத்தமான size/weight கொடுங்கள்; headline spacing சரிசெய்யுங்கள். Text/background colours test செய்யுங்கள். ஒரே வகை content-க்கு ஒரே style. Keyboard access, controls, choices, தெளிவான interaction labels-உம் text design-இன் பகுதிகள்.

:::example Instruction-ஐ மேம்படுத்துதல்
“Click here” destination சொல்லாது. “Route map-ஐத் திறக்கவும்” action/result இரண்டையும் சொல்கிறது. Relevant control அருகே instruction வையுங்கள். Ornate font/animated heading-ஐவிட தெளிவான sentence பயனுள்ளதாக இருக்கும்.

## Character encoding மற்றும் font mapping

**Character set** characters repertoire-ஐ வரையறுக்கிறது. **Code point** character-க்கு numerical identity கொடுக்கிறது. **Character encoding** அதை stored/transmitted code units/bytes-ஆக மாற்றுகிறது. PDF ASCII, “EBCD”, Unicode என்று சொல்கிறது; “EBCD” என்பது **EBCDIC**-ஐக் குறிக்கலாம்.

**ASCII** basic English letters/digits/punctuation/control codes-க்கான சிறிய repertoire. Tamil/Sinhala scripts-ஐக் காட்ட முடியாது. **Unicode** பல writing systems-க்கு shared repertoire தருகிறது. UTF encodings Unicode data-ஐ bytes-இல் சேமிக்கின்றன. Unicode என்ற சொல்லும் குறிப்பிட்ட UTF-உம் ஒரே பொருள் அல்ல.

கொடுக்கப்பட்ட [encoding article](https://medium.com/jspoint/introduction-to-character-encoding-3b9735f265a6) binary/hex notation, code points, byte encodings விளக்குகிறது. Character identity-யும் அதைச் சேமிக்கும் bytes-உம் வேறு. Endianness multi-byte value-இல் byte order; byte-order mark encoding convention-ஐக் காட்டலாம். தவறான encoding மூலம் படித்தால் text குழம்பலாம்.

:::warn Source correction: variable-length encodings
ஒவ்வொரு symbol-க்கும் fixed bits என்று PDF பொதுவாகச் சொல்வது சரியல்ல. UTF-8 ஒரு Unicode scalar value-க்கு **1–4 bytes**; UTF-16 **1 அல்லது 2 code units**; UTF-32 ஒரு code unit பயன்படுத்தும். [Unicode FAQ](https://www.unicode.org/faq/utf_bom.html) பார்க்கவும். ஒரு displayed character பல code points-ஆகவும் இருக்கலாம்.
:::

**Font mapping** தேவைப்பட்ட font இல்லாதபோது பயன்படுத்தும் substitute-ஐக் குறிப்பிடுகிறது. Available system fonts அல்லது சரியான licence உடைய packaged fonts பயன்படுத்துங்கள். Substitute layout-ஐ மாற்றலாம் அல்லது glyphs இல்லாமல் இருக்கலாம். Special text-ஐ image-ஆக மாற்ற PDF பரிந்துரைக்கிறது; appearance இருக்கும், ஆனால் ordinary editability/selectable text போகும்; enlargement sharpness-உம் குறையலாம். Audience device-இல் test செய்யுங்கள்.

**PostScript** page-description language; mathematical outline fonts மற்றும் தரமான printing-உடன் தொடர்புடையது. Source பழைய display-support தேவைகளை **TrueType**-உடன் ஒப்பிடுகிறது. TrueType Apple/Microsoft-உடன் தொடர்புடைய outline-font technology; operating-system renderer support செய்கிறது. “No licensing needed” என்ற PDF கூற்று தவறு: பயன்படுத்த/விநியோகிக்க font licence-ஐப் பார்க்க வேண்டும். Format பெயர் permission கொடுக்காது.

## PDF-இன் ஐந்து review questions

**1. Typeface என்றால்?** Letters/numbers/symbols family-இன் வடிவமைக்கப்பட்ட தோற்றம். Traditional usage-இல் font குறிப்பிட்ட style/size; digital usage-இல் அந்த shapes தரும் resource.

**2. இரண்டு முக்கிய font வகைகளும் உதாரணமும்?** Serif-இல் finishing strokes உண்டு; Times New Roman உதாரணம். Sans serif-இல் இல்லை; Arial உதாரணம். Context/size/spacing/readability பார்த்து actual output test செய்யுங்கள்.

**3. Bitmap/vector font வேறுபாடு?** Bitmap pixel patterns சேமித்து designed pixel size-உடன் இணைகிறது. Vector mathematical outlines சேமிக்கிறது; screen-க்கு rasterize செய்ய வேண்டும். தனித்தனி bitmap sizes சேமிக்காமல் ஒரே outline பல sizes-க்கு உதவும்.

**4. Anti-aliasing என்றால்?** Rasterized text/graphic edge pixels intensities-ஐ மாற்றி foreground/background கலக்கிறது; இதனால் jagged boundary smooth-ஆகத் தெரியும்.

**5. ASCII/Unicode ஒப்பீடு?** இரண்டும் text-க்கு numerical representation உதவுகின்றன. ASCII சிறிய basic repertoire; Tamil/Sinhala முடியாது. Unicode பல scripts-ஐக் கொண்டது; UTF-8 போன்ற encoding-இலிருந்து character identity-ஐப் பிரிக்கிறது. Encoded text வரைய பொருத்தமான font-உம் வேண்டும்; Unicode மட்டும் visual design-ஐத் தேர்ந்தெடுக்காது.

:::exam English answer frame
“Readable multimedia text needs a suitable typeface, size, contrast and spacing. Serif and sans serif describe stroke design; bitmap and vector describe representation. Outline fonts are rasterized for the display, and anti-aliasing smooths perceived pixel edges. Use a suitable character encoding and test font availability or mapping on the target device.”
:::

## Assets-ஐ application-ஆக மாற்றும் authoring

:::key Authoring
**Multimedia authoring** என்பது text, graphics, sound, video, animation ஆகியவற்றைத் திட்டமிட்ட title-ஆக இணைத்து ஒருங்கிணைப்பது. Title interactive, partly interactive அல்லது non-interactive ஆக இருக்கலாம். Structure, timing, controls ஆகியவை message மற்றும் audience தேவைக்குப் பொருந்த வேண்டும்.
:::

Sound file அல்லது drawing உருவாக்குவது asset production. Assets-ஐ ஓர் ஒழுங்கான அனுபவத்தில் அமைப்பது authoring. Narration எப்போது தொடங்கும், எந்த picture-ஐ விளக்கும், button என்ன செய்யும், question-க்கு answer கொடுத்தபின் என்ன நடக்கும் என developer முடிவு செய்கிறார். Files-ஐச் சேகரிப்பது மட்டும் போதாது; அவற்றின் தொடர்புகளை ஒருங்கிணைக்க வேண்டும்.

**Authoring system** pre-programmed elements மற்றும் வசதிகளைத் தருகிறது. Templates, components, wizards, APIs ஆகியவை low-level programming-ஐக் குறைக்கலாம். **Authoring paradigm/metaphor** system பயன்படுத்தும் organisation அணுகுமுறை. Content மற்றும் interaction தேவைக்கேற்ப அணுகுமுறை மாறும்.

PDF Flash, Animate, Dreamweaver, Captivate, Composica ஆகியவற்றைக் குறிப்பிடுகிறது. பழைய Authorware, Director, மேலும் authoring தொடர்பான வசதிகள் கொண்ட PowerPoint, Keynote, Moodle, Joomla ஆகியவையும் உள்ளன. இவை lesson examples. எல்லாம் தற்போது கிடைக்கும், ஒரே நோக்கம் கொண்டவை, எல்லா project-க்கும் பொருந்தும் என்று கருதக்கூடாது. ஒரே system பல paradigms இணைக்கலாம்.

ஒவ்வொரு feature-ஐயும் புதிதாக code செய்வதைவிட computer-based training உருவாக்க authoring வேகமளிக்கலாம். ஆனால் research, asset preparation, design, testing, technical judgement தேவைதான். Output compatibility, supported media, interaction model, team skills ஆகியவற்றின் அடிப்படையில் tool தேருங்கள்.

## Storyboards மற்றும் navigation

**Storyboard** screen-by-screen அல்லது shot-by-shot plan. Layout, content, media, timing, narration, effects, interaction ஆகியவற்றை விளக்கும். **Navigation** content units இடையிலான routes. அழகான screen drawing மட்டும் போதாது; controls என்ன செய்யும் என்பது developer-க்கு தெரிய வேண்டும்.

ஒவ்வொரு screen-க்கும் identifier, purpose, visual layout, assets, written/spoken text, controls, destinations எழுதுங்கள். Entry conditions மற்றும் action முடிந்தபின் நடப்பதையும் குறியுங்கள். Readable text, captions, keyboard operation போன்ற accessibility தேவைகள் சேருங்கள். Authored result இந்த plan-ஐ consistent-ஆகச் செயல்படுத்த வேண்டும்.

Home menu-க்கு அழைக்கும். Storyboard எல்லா screens மற்றும் feedback paths-ஐ விளக்க வேண்டும்.

## நான்கு authoring paradigms மற்றும் Activity 14.1

| Paradigm | வேலை ஒழுங்குபடுத்தும் முறை | உதவும் சூழல் | Course example |
|---|---|---|---|
| Structure-based | Hierarchy, network, associations மூலம் content grouping | Linked information title | Dreamweaver |
| Timeline-based | Time axis மற்றும் tracks-இல் media அமைத்தல் | Synchronised animated presentation | Flash/Animate |
| Scripting-language-based | Media, events, conditions, timing-க்கு instructions | Custom interactive behaviour | ActionScript |
| Flow-control-based | Action/interaction icons-ஐ flow line மூலம் இணைத்தல் | Rapid e-learning prototypes | Authorware அல்லது IconAuthor |

**Structure-based:** concepts-ஐ groups/subgroups-ஆக அமைக்கும். Higher-level concept பல media items-க்கு link ஆகலாம். Hierarchical, network, associative structures title-இல் வெவ்வேறு routes தரலாம். கட்டாய playback duration-ஐவிட information organisation முக்கியம்.

**Timeline-based:** item-க்கு start, end, track கொடுக்கப்படுகிறது. Parallel tracks ஒரே நேரத்தில் என்ன play ஆகிறது என்பதைக் காட்டும். ஒரு item's duration மாறினால் மற்ற item's timing தானாக மாறாமல் இருக்கலாம்; sync பாருங்கள். Timeline title-இலும் navigation மற்றும் interactive control சேர்க்கலாம்.

**Scripting-language-based:** positions, events, hotspots, sequencing, sync ஆகியவற்றை language-இல் எழுதலாம். Conditions, variables, functions சிக்கலான interaction தரலாம். Conventional programming-க்கு நெருக்கமானது; அதிக effort தேவைப்படலாம், control flexible ஆகும். Source interpreted/object-oriented features கூறுகிறது. எல்லா languages/runtimes ஒரே விதமாக execute ஆகும் எனக் கருதாதீர்கள்.

**Flow control:** icon palette-இலிருந்து operations தேர்ந்து program flow காட்ட இணைக்கலாம். Prototype அல்லது short development cycle-க்கு உதவலாம். Visual branch இருந்தாலும் sensible condition, முழு feedback paths, testing தேவை. PDF இதை வேகமான style என்கிறது; உண்மையான வேகம் project மற்றும் developer-ஐப் பொறுத்தது.

**Activity 14.1 கேள்வி:** நான்கு categories காட்டும் tools கண்டறிந்து விளக்கவும்.

**Model answer:** Dreamweaver மூலம் linked web content-ஐ organise செய்யலாம்; structure/links தகவல் உறவுகளைச் செயல்படுத்தும். Animate timeline media எப்போது வரவேண்டும் என அமைக்கும். பொருத்தமான environment-இல் ActionScript event-driven actions மற்றும் conditional navigation எழுத உதவும். பழைய Authorware/IconAuthor presentation மற்றும் interaction icons-ஐ flow-ஆக இணைக்கும். இவை source examples மூலம் features-ஐ விளக்குகின்றன; modern application பல features இணைக்கலாம்.

## Multimedia script writing

Multimedia script presentation-ஐத் துல்லியமாக விளக்கும். Visual, narrative, action, expression தகவல்கள் இருக்கலாம். Drawings இல்லாமலும் script இருக்கலாம்; storyboard visual planning சேர்க்கும். ஒரு idea-ஐ graphic/action போன்ற concrete வடிவில் எப்படி காட்டலாம் என முதலில் சிந்தியுங்கள். Mind map relationships ஆராய உதவும்; final production-க்கு clear sequence மற்றும் usable directions வேண்டும்.

PDF script-writing process-இன் stages:

1. **Program idea:** message, insight, அதை வெளிப்படுத்தும் வழி பற்றி பேசுதல்.
2. **Program brief:** title, audience, objectives, content outline; தேவையான rationale மற்றும் beneficiaries சேர்த்தல்.
3. **Research:** topic மற்றும் audience பற்றி ஆராய்ந்து accuracy/suitability பார்ப்பது.
4. **Identify and select content elements:** assets தேர்ந்து organisation/navigation திட்டமிடுதல்.
5. **Interface design and layout:** appearance மற்றும் actions idea/audience-க்கு பொருந்தச் செய்தல்.
6. **Prepare the storyboard:** production செய்யும் அளவுக்கு ஒவ்வொரு shot/screen-ஐ விளக்குதல்.

“சுவாரசியமான ஒன்றைக் காட்டு” போன்ற vague script முக்கிய முடிவுகளைத் தெளிவுபடுத்தாது. பயனுள்ள instruction என்ன தெரியும், என்ன கேட்கும், என்ன மாறும், எது next step-ஐ trigger செய்யும் எனச் சொல்லும். Narration-க்கு பொருத்தமான image காட்டி புரிந்துகொள்ள நேரம் கொடுங்கள். Narration-ஐச் சத்தமாக வாசித்து இயல்பற்ற wording திருத்துங்கள்.

## Activity 14.2: script வகைகள் மற்றும் model answer

**கேள்வி:** இணைத்த video-scripting tutorial பார்த்து வெவ்வேறு video-script types-க்கு உரிய activities பட்டியலிடவும்.

கொடுக்கப்பட்ட [Biteable tutorial link](https://biteable.com/blog/tips/video-script/) தயாரிப்பின்போது திறக்கவில்லை. கீழே PDF-இன் visual, narrative, action, expression categories-ஐப் பயன்படுத்தும் முழு model answer உள்ளது. பார்க்காத tutorial-இன் summary என்று இது கூறப்படவில்லை.

| Script தகவல் | Road-safety video-இன் activity | Production team பெறுவது |
|---|---|---|
| Visual | Road view, crossing position, readable labels திட்டமிடல் | Framing மற்றும் displayed content |
| Narrative | Crossing-க்கு முன் பார்க்கும் முறையை எழுதுதல் | பேசவேண்டிய exact wording |
| Action | நிற்பது, பார்ப்பது, கடப்பது எப்போது எனக் கூறுதல் | தெரியும் movement மற்றும் order |
| Expression | Calm, clear delivery மற்றும் attentive behaviour குறித்தல் | Tone மற்றும் performance |

Brief-ஐ script-ஆக மாற்றி storyboard panels-இல் தகவலை அமைக்கவும். Spoken instruction-ஐ picture உண்மையில் காட்டுகிறதா பார்க்கவும். Safe action-க்கு முரணான expression பயன்படுத்த வேண்டாம். Interactive version-இல் ஒவ்வொரு event trigger, user choices, ஒவ்வொரு outcome feedback சேர்க்கவும்.

## Asset orchestration மற்றும் libraries

**Orchestration** imported assets-ஐக் கதைக்கேற்ப ஒருங்கிணைக்கும். Library reusable symbols, bitmaps, video, sound வைத்திருக்கும். Asset-இன் **instance** தேவைப்படும் இடத்தில் வைத்து position, timing, behaviour அமைக்கவும். பொருளுள்ள பெயர்கள் மற்றும் related groups team-க்கு assets கண்டுபிடிக்கவும் திருத்தவும் உதவும்.

இணைக்கப்பட்ட [Adobe library guide](https://helpx.adobe.com/animate/using/library.html) Animate libraries created/imported assets மற்றும் reusable symbols வைத்திருப்பதைக் கூறுகிறது. Folders, previews organisation-க்கு உதவும். Reusable item மற்றும் scene-இல் உள்ள instance வேறு. Shared source மாறினால் அதன் uses பாதிக்கலாம். Replacement மற்றும் naming conflicts கவனமாகப் பாருங்கள்.

பயனுள்ள inventory-இல் filename, purpose, source, permitted use, format, பயன்படுத்தும் screens இருக்கும். Project move/package செய்தபின் external links மற்றும் referenced media பாருங்கள். Editor working copy-இன் local absolute paths மற்ற device-இல் இயங்காமல் போகலாம். தேவையான media-ஐ package செய்து published output-இல் பொருத்தமான references பயன்படுத்துங்கள்.

பழைய [Premiere importing tutorial](https://helpx.adobe.com/premiere-pro/atv/cs6-tutorials/importing-files-and-folders.html) மற்றும் [asset-management video](https://www.youtube.com/watch?v=a3dxCd4Gvw0) தயாரிப்பின்போது fetch ஆகவில்லை. பார்க்காத content verified teaching material ஆகக் காட்டப்படவில்லை.

## Distribution மற்றும் Activity 14.3

**Distribution** பொருத்தமான medium வழியாக title-ஐ share/publish/promote செய்கிறது. Audience-க்கு route தேர்ந்து supported output உருவாக்குங்கள். Development முழுவதும் மற்றும் actual target hardware/software/playback mode-இல் test செய்யுங்கள். Authoring preview சரியாக இருப்பது மட்டும் packaged title வேறிடத்தில் இயங்கும் சான்றல்ல.

Assets, navigation, event paths, timing, audio/video sync, readable text, media formats, installation instructions ஆகியவை முழுமையா பாருங்கள். Editor-only resources இல்லாமல் புதிய package copy test செய்யுங்கள். பிறகு final files மற்றும் documentation தயாரியுங்கள். PDF optical disks, ZIP disks, servers, networks, broadcasts, social media, web pages கூறுகிறது; சில பழைய examples.

**Activity 14.3 கேள்வி:** web/social media, CD/DVD, intranet, VPN, television distribution constraints ஆராயவும்.

| Medium | முழு model answer: முக்கிய constraints |
|---|---|
| Web மற்றும் social media | Network rate, accepted codecs/containers, file-size/duration limits, aspect ratio, phone readability, captions, platform processing |
| CD அல்லது DVD | Fixed capacity, disk/file formats, drive availability, player compatibility, update/replacement process |
| Intranet | Organisation network capacity, internal server setup, authentication, approved browsers, access permissions |
| VPN | Remote access configuration, authentication, encryption overhead, reliable connection, effective bandwidth; VPN access route, multimedia file format அல்ல |
| Television broadcast | Broadcaster கூறும் picture, frame/scanning, colour, sound, caption, delivery requirements; exact specifications broadcaster-இலிருந்து பெற வேண்டும் |

இந்த constraints packaging-ஐ வழிநடத்தும். Local training disk தேவையான assets கொண்டிருக்க வேண்டும். Network title-க்கு server paths இயங்க வேண்டும்.

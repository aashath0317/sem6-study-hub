## வகுபடுதன்மை

**எண் கோட்பாடு** ("உயர் எண்கணிதம்"), **முழு எண்களையும் அவற்றின் பண்புகளையும்** ஆய்கிறது. இந்தப் பாடம் வகுபடுதன்மை, மட்டு எண்கணிதம், பகா எண்கள், மறையியல் பயன்பாடு ஆகியவற்றை உள்ளடக்குகிறது.

:::key வரையறை 1
a, b முழு எண்களாகவும் **a ≠ 0** ஆகவும் இருக்கட்டும். **b = ac** ஆகும் முழு எண் c இருந்தால் **a, b-ஐ வகுக்கிறது**; **a | b** என எழுதப்படுகிறது.

- a என்பது b-இன் **காரணி**; b என்பது a-இன் **மடங்கு**.
- a, b-ஐ வகுக்காவிட்டால் **a ∤ b** எழுதவும்.
:::

:::example எடுத்துக்காட்டு 6.1.1
- 20/4 = 5 முழு எண்; எனவே **4 | 20**.
- 17/6 முழு எண் அல்ல; எனவே **6 ∤ 17**.
:::

:::warn குறியீடுகளைக் குழப்ப வேண்டாம்
**a | b** ஒரு **வாக்கியம்** (உண்மை அல்லது பொய்): "a, b-ஐ வகுக்கிறது".
**a / b** ஓர் **எண்**: a-ஐ b-ஆல் வகுத்தது.

3 | 12 *உண்மை*; 12/3 = 4.
:::

### தேற்றம் 1 — வகுபடுதன்மைப் பண்புகள்
முழு எண்கள் a, b, c-க்கு:

1. **a | b, a | c எனில் a | (b + c)**.
2. **a | b எனில்**, ஒவ்வொரு முழு எண் c-க்கும் **a | bc**.
3. **a | b, b | c எனில் a | c** (கடத்தற்பண்பு).

:::example நிறுவல்கள் (வரையறையைப் பயன்படுத்தி நேரடியாக)
**(i)** a | b, a | c; எனவே முழு எண்கள் s, t-க்கு b = as, c = at.
அப்போது b + c = as + at = **a(s + t)**; எனவே a | (b + c). ∎

**(ii)** a | b; எனவே b = as. அப்போது bc = asc = **a(sc)**; எனவே a | bc. ∎

**(iii)** b = as, c = bt; எனவே c = (as)t = **a(st)**; எனவே a | c. ∎
:::

:::key பெறுபேறு
a | b, a | c எனில் எந்த முழு எண்கள் m, n-க்கும் **a | (mb + nc)**.

*நிறுவல்:* (ii)-ஆல் a | mb, a | nc. பின்னர் (i)-ஆல் a | mb + nc. ∎
:::

**கீழுள்ள பகுதி இன்னும் தமிழில் மொழிபெயர்க்கப்படவில்லை; தற்போது ஆங்கிலத்தில் மட்டும் உள்ளது.**

### Exam favourites: divisibility proofs

:::example If 7 | 4n, then 7 | n (January and July 2023)
1. 7 | 4n, so **4n = 7k** for some integer k.
2. The trick: 2 × 4 = 8 = 7 + 1, so **n = 8n − 7n**.
3. n = 2(4n) − 7n = 2(7k) − 7n = **7(2k − n)**.
4. 2k − n is an integer, so **7 | n**. ∎

This works because 4 and 7 share no common factor. In general, find a multiple of the coefficient that is **1 more than a multiple of the divisor**.
:::

:::example If a | b and c | d, then ac | bd (January 2023)
b = ak and d = cm for integers k and m. Then bd = (ak)(cm) = **(ac)(km)**, so ac | bd. ∎
:::

## வகுத்தல் படிமுறை

:::key தேற்றம் 2 (வகுத்தல் படிமுறை)
a முழு எண்ணாகவும் d **நேர்மறை** முழு எண்ணாகவும் இருக்கட்டும். அப்போது **0 ≤ r < d** ஆகுமாறு **தனித்துவமான** முழு எண்கள் q, r உள்ளன:

**a = dq + r**
:::

| பெயர் | குறியீடு | குறியீட்டு முறை |
|---|---|---|
| **வகுபடும் எண்** | a | — |
| **வகுக்கும் எண்** | d | — |
| **ஈவு** | q | **q = a div d** |
| **மீதி** | r | **r = a mod d** |

:::example எடுத்துக்காட்டுகள் 6.2.1, 6.2.2
- **27 ÷ 4:** 27 = 4·6 + 3; எனவே 6 = 27 div 4, **3 = 27 mod 4**.
- **−23 ÷ 5:** −23 = 5·(−5) + 2; எனவே −5 = −23 div 5, **2 = −23 mod 5**.
:::

:::warn மீதி ஒருபோதும் எதிர்மறையல்ல
−23 ÷ 5-க்கு விடை q = −4, r = −3 **அல்ல**. மீதி 0 ≤ r < d நிறைவேற்ற வேண்டும். எனவே மேலும் ஒரு படி **கீழே** செல்லவும்: q = −5; r = −23 − (−25) = **2**.
:::

மீதி **பூச்சியம்** எனில் x, y-ஆல் **வகுபடும்** (y | x).

{{tool:dv}}

**கீழுள்ள பகுதி இன்னும் தமிழில் மொழிபெயர்க்கப்படவில்லை; தற்போது ஆங்கிலத்தில் மட்டும் உள்ளது.**

### Proof by cases using remainders

The division algorithm says every integer has **exactly one** remainder when divided by m. So you can prove a statement by checking **each possible remainder as a separate case**.

:::example January 2023 Q2(c): a² has the form 3k or 3k + 1, never 3k + 2
Divide a by 3: a = 3q + r with r = 0, 1 or 2.

| Case | a² | Form |
|---|---|---|
| r = 0 | 9q² = 3(3q²) | **3k** |
| r = 1 | 9q² + 6q + 1 = 3(3q² + 2q) + 1 | **3k + 1** |
| r = 2 | 9q² + 12q + 4 = 3(3q² + 4q + 1) + 1 | **3k + 1** |

Every case gives 3k or 3k + 1, so a² is **never 3k + 2**. ∎
:::

:::example Model Q1(b): n odd ⇒ 4 | n² − 5, but 8 ∤ n² − 5
Write n = 2k + 1. Then n² − 5 = 4k² + 4k − 4 = **4(k² + k − 1)**, so 4 divides it.

k² + k = k(k + 1) is a product of consecutive integers, so it is **even**. Then k² + k − 1 is **odd**, and 4 × (odd) is never divisible by 8. ∎
:::

:::tip Template for a cases proof
State the cases from the division algorithm, work out each case in a table or list, and finish with "every case gives …, so …". Missing one case loses the marks.
:::

## மட்டு எண்கணிதமும் சமானமும்

:::key வரையறை 2 — சமானம்
m நேர்மறை முழு எண்ணாக இருக்கட்டும். **m, a − b-ஐ வகுத்தால்**, **a, b-க்கு மட்டு m-இல் சமானம்**; **a ≡ b (mod m)** என எழுதப்படுகிறது. இல்லாவிட்டால் a ≢ b (mod m).
:::

:::key தேற்றம் 3
**a mod m = b mod m என்றால் மட்டுமே a ≡ b (mod m)**: a, b **ஒரே மீதியை** விடுகின்றன.
:::

:::example எடுத்துக்காட்டு 6.3.1
- 17 ≡ 3 (mod 7) ஆகுமா? 17 − 3 = 14; 7 | 14. **ஆம்**, 17 ≡ 3 (mod 7).
- 21 ≡ 6 (mod 8) ஆகுமா? 21 − 6 = 15; 8 ∤ 15. **இல்லை**, 21 ≢ 6 (mod 8).
:::

:::key தேற்றம் 4 — சமானங்களைக் கூட்டவும் பெருக்கவும் முடியும்
**a ≡ b (mod m)**, **c ≡ d (mod m)** எனில்:

- **a + c ≡ b + d (mod m)**
- **ac ≡ bd (mod m)**
:::

:::example எடுத்துக்காட்டு 6.3.2
12 ≡ 2 (mod 5), 16 ≡ 1 (mod 5). எனவே:

- 28 = 12 + 16 ≡ 2 + 1 = **3 (mod 5)**
- 192 = 12·16 ≡ 2·1 = **2 (mod 5)**
:::

### சமான வகுப்புகள் (வரையறை 3)
**a-இன் மட்டு n சமான வகுப்பு**, n-ஆல் வகுக்கும்போது **a-இன் அதே மீதியை விடும் அனைத்து முழு எண்களினதும்** கணம்.

:::example எடுத்துக்காட்டு 6.3.3
… ≡ −40 ≡ −33 ≡ −26 ≡ −19 ≡ −12 ≡ −5 ≡ 2 ≡ 9 ≡ 16 ≡ 23 ≡ 30 ≡ 37 ≡ … ≡ 2 (mod 7)

எனவே **2-இன் மட்டு 7 சமான வகுப்பு** {…, −40, −33, −26, −19, −12, −5, 2, 9, 16, 23, 30, 37, …}. 2-இல் தொடங்கி 7-ஐச் சேர்த்தோ கழித்தோ செல்லவும்.
:::

## பகா எண்கள்

1-ஐவிடப் பெரிய ஒவ்வொரு நேர்மறை முழு எண்ணும் குறைந்தது 1-ஆலும் அதனாலுமே வகுபடும்.

:::key வரையறை 4
- **1, p மட்டுமே நேர்மறைக் காரணிகளாக** இருந்தால் நேர்மறை முழு எண் **p > 1**, **பகா எண்**.
- **பகா எண் அல்லாத > 1 முழு எண்**, **பகு எண்**.
- அதற்குச் சமமாக, பகா எண் என்பது **இரு சிறிய இயல் எண்களின் பெருக்கலாக எழுத முடியாத**, > 1 இயல் எண்.
- **குறிப்பு:** **a | n, 1 < a < n** ஆகும் முழு எண் a இருந்தால் மட்டுமே n பகு எண்.
:::

| எடுத்துக்காட்டு | காரணம் |
|---|---|
| **7 பகா எண்** (6.4.1) | 1 × 7, 7 × 1 மட்டுமே பெருக்கல்கள் |
| **6 பகு எண்** (6.4.2) | 6 = 2 × 3; இரண்டும் 6-ஐவிடச் சிறியவை |
| **ஒவ்வொரு இரட்டை முழு எண் > 2-உம் பகு எண்** (6.4.3) | x = 2 × (x/2); x/2 முழு எண் |

:::key தேற்றம் 5 (யூக்ளிட்)
**முடிவற்ற பகா எண்கள் உள்ளன.** p₁, …, pₙ என்பவை n மிகச்சிறிய பகா எண்கள் எனில், பட்டியலில் இல்லாத பெரிய பகா எண் எப்போதும் உள்ளது.
:::

:::key தேற்றம் 6 — எண்கணிதத்தின் அடிப்படைத் தேற்றம்
1-ஐவிடப் பெரிய ஒவ்வொரு நேர்மறை முழு எண்ணையும் **பகா எண்ணாகவோ**, **இரண்டு அல்லது அதிகமான பகா எண்களின் பெருக்கலாகவோ**, காரணிகளை **குறையாத வரிசையில்** அமைத்து **தனித்துவமாக** எழுதலாம்.
:::

:::example எடுத்துக்காட்டு 6.4.4 — A = {4, 5, 12, 49, 748}
| n | பகா அல்லது பகு | பகாக் காரணிப்படுத்தல் |
|---|---|---|
| 4 | பகு | 2² |
| 5 | **பகா** | 5 |
| 12 | பகு | 2² × 3 |
| 49 | பகு | 7² |
| 748 | பகு | 2² × 11 × 17 |
:::

:::tip விரைவான பகாத்தன்மைச் சோதனை
n-ஐச் சோதிக்க **√n வரையான** வகுப்பான்களை மட்டும் முயன்றால் போதும். n = ab; a, b இரண்டும் √n-ஐவிடப் பெரியவை எனில் ab > n; அது இயலாது.
:::

## மறையியல் — சீசரின் மறையீடு

**மறையியல்**, **இரகசியச் செய்திகளின்** ஆய்வு. அதற்கு இரு பகுதிகள்:

- **மறைகுறியாக்கம்**: செய்தியை இரகசியமாக்குதல்.
- **மறைவிலக்கல்**: மூலச் செய்தியை மீட்டெடுத்தல்.

**சீசரின் மறையீடு** (Julius Caesar பயன்படுத்தியது), **ஒவ்வொரு எழுத்தையும் மூன்று இடங்கள் முன்னோக்கி நகர்த்துகிறது**. எனவே C → F, Y → B (மீண்டும் தொடக்கத்துக்கு வருகிறது).

எழுத்துகளுக்கு A = 0, B = 1, …, Z = 25 என எண்களிடவும். அப்போது:

:::formula
**மறைகுறியாக்கு:** f(p) = (p + 3) mod 26
**மறைவிலக்கு:** f⁻¹(p) = (p − 3) mod 26
:::

{0, …, 25}-இல் f **ஒன்றுக்கொன்றானது** (உண்மையில் இருவழிச் சார்பு); எனவே **f⁻¹ உள்ளது**. ஆட்களம், துணை ஆட்களம் இரண்டும் {0, 1, …, 25}.

:::example எடுத்துக்காட்டு 6.5.1 — YARD-ஐ மறைகுறியாக்குதல்
| எழுத்து | Y | A | R | D |
|---|---|---|---|---|
| p | 24 | 0 | 17 | 3 |
| (p + 3) mod 26 | 27 ≡ **1** | **3** | **20** | **6** |
| மறையீடு | **B** | **D** | **U** | **G** |

YARD → **BDUG**
:::

:::example CHVW-ஐ மறைவிலக்குதல்
| எழுத்து | C | H | V | W |
|---|---|---|---|---|
| p | 2 | 7 | 21 | 22 |
| (p − 3) mod 26 | −1 ≡ **25** | **4** | **18** | **19** |
| மூல எழுத்து | **Z** | **E** | **S** | **T** |

CHVW → **ZEST**. (குறிப்பு −1 = 26 × (−1) + 25; எனவே −1 mod 26 = 25.)
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- a | b தீர்மானித்தல்
- **வகுபடுதன்மைப் பண்புகளை நிறுவுதல்** (b = as பயன்படுத்தி நேரடி நிறுவல்கள்)
- **எதிர்மறைகளுடனும் ஈவும் மீதியும்**
- a mod m
- சமானங்களைச் சரிபார்த்தல்
- சமான வகுப்புகளைப் பட்டியலிடுதல்
- பகா அல்லது பகு + **பகாக் காரணிப்படுத்தல்**
- **செய்முறை அட்டவணையுடன் சீசர் மறைகுறியாக்கமும் மறைவிலக்கலும்**
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|
| a \| b | ஏதாவது முழு எண் c-க்கு b = ac (a ≠ 0); இல்லாவிட்டால் a ∤ b |
| தேற்றம் 1 | a\|b, a\|c ⇒ a\|(b+c); a\|b ⇒ a\|bc; a\|b, b\|c ⇒ a\|c |
| பெறுபேறு | a\|b, a\|c ⇒ a\|(mb + nc) |
| வகுத்தல் படிமுறை | a = dq + r, 0 ≤ r < d; q = a div d, r = a mod d |
| எதிர்மறை a | −23 = 5(−5) + 2; எனவே r = 2 (ஒருபோதும் எதிர்மறையல்ல) |
| a ≡ b (mod m) | m \| (a − b) ⇔ ஒரே மீதி |

**Q1.** a, b, c are integers. Which statement is **incorrect**?

(a) If a|b and b|c, then a|c. (b) If a|b, then a|bc for all integers c. (c) a + b + c is not an integer. (d) If a|b and a|c, then a|(b + c).

**✅ Answer: (c) “a + b + c is not an integer”**

Adding integers always gives an integer, so (c) is wrong. The others are the three **divisibility rules** to memorise (a|b means “a divides b”, b = a × something):

- a|b and b|c ⇒ a|c (e.g. 2|4, 4|12 ⇒ 2|12)
- a|b ⇒ a|bc (e.g. 3|6 ⇒ 3|6×5)
- a|b and a|c ⇒ a|(b + c) (e.g. 5|10, 5|15 ⇒ 5|25)


**Q2.** Quotient and remainder when 34 is divided by 5?

(a) 6 and 4 (b) 6 and 5 (c) 3 and 4 (d) 4 and 6

**✅ Answer: (a) quotient 6, remainder 4**

34 = 5 × **6** + **4**. (Write a = d × q + r with 0 ≤ r < d.) The remainder must be smaller than 5, so (b) is impossible.
In notation: 34 div 5 = 6, 34 mod 5 = 4.


**Q3.** True or false: “a is congruent to b modulo m if m divides **a + b**.”

**✅ Answer: False**

Correct definition: **a ≡ b (mod m) if m divides a − b** (the **difference**), i.e. a and b leave the same remainder when divided by m.


**Q4.** Which is **incorrect**?

(a) 2 ≡ 37 mod 5 (b) 4 ≡ 29 mod 5 (c) 7 ≡ 62 mod 9 (d) 2 ≡ 42 mod 4

**✅ Answer: (c) 7 ≡ 62 mod 9**

**Test: subtract, then check if m divides the difference.**

- (a) 37 − 2 = 35, 5 | 35 ✓ (b) 29 − 4 = 25, 5 | 25 ✓ (d) 42 − 2 = 40, 4 | 40 ✓
- (c) 62 − 7 = 55, and 9 does **not** divide 55 (9 × 6 = 54) → incorrect.


**Q5.** True or false: a prime is a natural number greater than 1 that cannot be written as the product of two smaller natural numbers.

**✅ Answer: True**

That is the definition. Equivalently: its only positive divisors are 1 and itself. 1 is **not** prime; 2 is the only even prime.


**Q6.** Which set contains only primes?

(a) {13, 29, 41} (b) {55, 37, 99} (c) {32, 45, 16} (d) {7, 89, 17}

**✅ Answer marked by the quiz: (a) {13, 29, 41}**

- (b) 55 = 5 × 11 and 99 = 9 × 11 → not prime. (c) all even or divisible by 5 → not prime.
- (a) 13, 29, 41 are all prime ✓.
- Note: (d) 7, 89, 17 are **also** all prime, so the question has two correct sets. The quiz accepted (a).

**How to test if n is prime:** try dividing by the primes 2, 3, 5, 7, … up to √n. If none divides it, n is prime. (89: √89 ≈ 9.4; 2, 3, 5, 7 don't divide 89 → prime.)


**Q7.** Encrypt **CART** with Caesar's cipher.

(a) PBQR (b) FDUW (c) LIJT (d) SKNW

**✅ Answer: (b) FDUW**

**Caesar cipher: shift every letter 3 forward.** f(p) = (p + 3) mod 26, with A = 0, …, Z = 25.
C → F, A → D, R → U, T → W → **FDUW**. (After Z, wrap round: X → A, Y → B, Z → C.)


**Q8.** Decrypt **ERRN** with Caesar's cipher.

(a) BOOK (b) ROOM (c) KEEN (d) REEL

**✅ Answer: (a) BOOK**

**Decrypt = shift 3 back.** f⁻¹(c) = (c − 3) mod 26.
E → B, R → O, R → O, N → K → **BOOK**.

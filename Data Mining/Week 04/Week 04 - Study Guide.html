1Why reduce data at all?

குறைந்த தரவில் அதே பயன்

முழுத் தரவும் மிகப் பெரியதாக இருந்தால் கணக்கிட நேரம் அதிகம். முக்கியத் தகவலை அதிகமாக இழக்காமல் அளவைக் குறைப்பதே Data reduction. சுருக்கம் பயனுள்ள முடிவை வைத்திருக்கிறதா என்று பார்க்க வேண்டும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

பெரிய data-வைச் சிறு representation-ஆக மாற்றியும் analysis-க்கு தேவையான தகவலைப் பாதுகாப்பதே reduction. ஐந்து strategies: cube aggregation; attribute subset; dimensionality reduction; numerosity reduction; discretisation/concept hierarchy. அளவு குறைந்தது மட்டும் வெற்றி அல்ல; original data-இன் task result-க்கு போதுமான ஒற்றுமை இருக்கிறதா சோதிக்கவேண்டும்.

Real datasets are huge — millions of rows and hundreds of columns. Mining algorithms on such data are slow and need a lot of memory. Data reduction produces a much smaller version of the dataset that still gives the same (or almost the same) analytical results.

The one-sentence definition

Data reduction = obtaining a reduced representation of the dataset that is much smaller in volume but keeps the integrity of the original data, so mining it is more efficient and the results barely change.

Two benefits are named in the notes:

  1. Less time and memory needed by data-mining algorithms.
  2. Data becomes easier to visualise.

Where this fits — the four preprocessing tasks

This lesson is the third member of the data-preprocessing family introduced in Week 3:

Task What it does Example
Data cleaning Removes noise, fixes inconsistencies Filling missing ages, smoothing noisy prices
Data integration Merges data from multiple sources into one coherent store Combining branch databases into a data warehouse
Data transformation Converts data into a suitable form Normalisation (helps distance-based algorithms)
Data reduction ← this week Shrinks the data size Aggregating, dropping redundant features, clustering

The five data-reduction strategies

Memorise these five — they are the outline of the whole lesson:

Data cube aggregationAttribute subset selectionDimensionality reductionNumerosity reductionDiscretization & concept hierarchies
Strategy Idea in plain words
Data cube aggregation Apply aggregation (sum, count…) while building a data cube — store summaries, not every transaction.
Attribute subset selection Detect and remove irrelevant, weakly relevant or redundant attributes (columns).
Dimensionality reduction Use encoding mechanisms to compress the data (e.g. wavelets, PCA).
Numerosity reduction Replace the data by a smaller representation — a model (parametric) or histograms / clusters / samples (non-parametric).
Discretization & concept hierarchy generation Replace raw values by ranges or higher-level concepts (e.g. age 23 → "youth").
Exam focus

"List and briefly explain the strategies for data reduction" is a classic question. Write all five with one line each — exactly the table above.

2Data cube aggregation

விவரங்களை மொத்தங்களாகச் சுருக்குதல்

தினசரி விற்பனையை மாத மொத்தமாகச் சேர்த்தால் குறைந்த பதிவுகளில் போக்கைக் காணலாம். இதுதான் Aggregation. ஆனால் மாத மொத்தத்தில் எந்த நாளில் திடீர் விற்பனை நடந்தது என்ற நுணுக்கம் மறையலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

ஒவ்வொரு sale row-க்கு பதில் item×branch×year totals வைத்தால் cube aggregation. Branch→region அல்லது month→year roll-up செய்யலாம். Annual total கேள்விக்கு transaction detail தேவையில்லாமல் வேகம் கிடைக்கலாம்; ஆனால் individual sale fraud தேட அதே summary போதாது. “No loss” என்பது அந்த குறிப்பிட்ட task-க்கு மட்டுமே, எல்லாப் புதிய கேள்விகளுக்கும் அல்ல.

A data cube stores multidimensional aggregated information. (Cubes are covered in detail in Week 5 – Data Warehousing; here you only need the idea.)

Picture sales data with three dimensions — item type, branch and year. Instead of storing every single sale, each cell of the cube holds an aggregate value (e.g. total sales of computers at Branch B in 2008).

Branch A Branch B Branch C
Home entertainment 568 750 150
Computer 680 952 31
Phone 1,000 512 290
Security 38 580 7

One "slice" of a sales cube: annual sales per item type for each branch (values illustrative).

  • Each attribute can have a concept hierarchy — e.g. branches can be grouped into regions based on their address — so you can analyse at multiple levels of abstraction.
  • Cubes give fast access to pre-computed, summarised data, which benefits both OLAP (on-line analytical processing) and data mining.
Why it reduces data

If the analysis only needs annual totals per branch, keeping quarterly or per-transaction rows is waste. Aggregating to the level you need shrinks the data massively with no loss for that task.

3Attribute subset selection

முக்கிய Attributes தேர்வு

எல்லா columns-மும் prediction-க்கு உதவாது. தேவையற்ற அல்லது ஒரே தகவலைத் திரும்பக் கூறும் attributes-ஐ நீக்குவது Subset selection. சரியான subset வேகத்தையும் பொதுமைப்படுத்தலையும் மேம்படுத்தலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Forward selection காலி subset-இலிருந்து பயனுள்ள attributes சேர்க்கும்; backward elimination அனைத்திலிருந்து தேவையற்றதை நீக்கும்; combined முறை இரண்டையும் செய்கிறது. Decision tree தேர்ந்த split attributes-உம் relevance காட்டலாம். Target prediction-க்கு உதவாத ID போன்ற column-ஐ வைத்தால் noise அல்லது leakage அதிகரிக்கலாம். Feature selection-ஐ evaluation fold-க்கு வெளியே முழுத் dataset-இல் செய்ய வேண்டாம்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

n attributes-க்கு 2ⁿ subsets; exhaustive search செலவு அதிகம். Forward empty-இலிருந்து best add; backward full-இலிருந்து worst remove; combined add/remove; tree பயன்படுத்திய attributes subset ஆகலாம். Greedy local choice global optimum உத்தரவாதமில்லை. Phone number CD taste-க்கு நேரடி predictor அல்ல என்ற பாட உதாரணம்; IDs leakage/overfitting தரலாம். Feature selection-ஐ training folds-க்குள் fit செய்து evaluation leakage தவிர்க்கவும்.

Datasets may contain hundreds of attributes, many irrelevant or redundant.

The notes' example

Task: predict whether a customer will buy a new CD when told about a sale. - Relevant: age, music taste - Irrelevant: telephone number

Why not keep everything? Leaving out relevant attributes or keeping irrelevant ones confuses the mining algorithm → poor-quality patterns. A domain expert could pick attributes by hand, but that is slow and hard when the data's behaviour is not well known.

Goal

Find the minimum set of attributes such that the probability distribution of the data classes is as close as possible to the distribution obtained using all attributes.

Extra benefit: fewer attributes in the discovered patterns → patterns are easier to understand.

Heuristic (greedy) methods

Trying every subset of n attributes means 2n possibilities — impossible for large n. So we use greedy heuristics: at each step make the choice that looks best right now (a locally optimal choice) hoping it leads to a globally optimal solution. They can work well, but do not guarantee the globally optimal subset.

The four basic methods (Figure 3-2 in the notes):

Method How it works Example with
Stepwise forward selection Start with an empty set. Repeatedly add the best remaining attribute. {} → {A1} → {A1, A4} → {A1, A4, A6}
Stepwise backward elimination Start with all attributes. Repeatedly remove the worst one. {A1…A6} → {A1, A3, A4, A5, A6} → {A1, A4, A5, A6} → {A1, A4, A6}
Combined forward + backward Each step adds the best and removes the worst. —
Decision tree induction Build a decision tree; attributes that appear in the tree form the reduced set; those that never appear are irrelevant. Tree tests A4, A1, A6 → {A1, A4, A6}
How to remember

Forward = grow from nothing. Backward = shrink from everything. Decision tree = "whatever the tree bothered to use".

4Dimensionality reduction

பரிமாணங்களைக் குறைத்தல்

பல அளவுகளை சில புதிய அளவுகளால் பிரதிநிதித்துவப்படுத்தலாம். PCA போன்ற முறைகள் முக்கிய variation-ஐ வைத்திருக்க முயல்கின்றன. இது சில original columns-ஐ மட்டும் தேர்ந்தெடுப்பதிலிருந்து வேறுபடும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Feature selection original columns-ஐத் தேர்வு செய்யும்; PCA original attributes-இன் புதிய linear combinations உருவாக்கும். குறைந்த components அதிக variance வைத்திருக்க முயலும்; interpretation கடினமாகலாம். Scale மிக வேறுபட்டால் PCA முடிவைப் பாதிக்கும். புதிய components குறைந்தவை என்பதால் அவை தானாக அதிக classification accuracy தரும் என்று உறுதி இல்லை.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Feature selection பழைய columns சிலவற்றைத் தேர்வு செய்கிறது; PCA பழைய columns-இன் combinations மூலம் புதிய axes உருவாக்குகிறது. Lossless exact reconstruction; reduced PCA/selected wavelet coefficients பொதுவாக approximate (lossy). Full invertible transform செய்தது மட்டும் loss அல்ல; components/coefficients கைவிடுவதால் தகவல் இழப்பு. PCA அதிக variance capture செய்கிறது; அதுவே target class-க்கு மிகப் பயன்படும் direction என்று உறுதி இல்லை.

Here data encoding or transformations are applied to get a compressed representation of the original data.

Lossless

The original data can be reconstructed exactly from the compressed data — no information lost.

Example: string compression algorithms (like ZIP).

Lossy

Only an approximation of the original can be reconstructed.

Two popular, effective methods: - Wavelet transforms - Principal Components Analysis (PCA)

  • Wavelet transform – converts the data vector into a vector of wavelet coefficients; keeping only the strongest coefficients gives a compressed approximation.
  • PCA – finds a small number of new axes (principal components) that capture most of the variation in the data, then represents each record using only those few components.
Exam focus

Be able to define lossless vs lossy and name wavelet transforms and PCA as the two popular lossy methods — that's what the notes emphasise.

5Numerosity reduction

பதிவுகளுக்குப் பதில் சுருக்கம்

முழுப் பதிவுகளுக்குப் பதில் sampling, regression, histogram, clustering போன்ற சுருக்கங்களைப் பயன்படுத்துவது Numerosity reduction. சுருக்கத்தின் அளவும் தகவல் இழப்பும் இடையே சமநிலை வேண்டும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Parametric regression போன்ற model parameters வைத்துத் தரவைச் சுருக்கும். Non-parametric histogram, clustering, sampling போன்ற சுருக்கங்களைப் பயன்படுத்தலாம். Histogram strategies: equal-width — அகலம் சமம்; equal-frequency — பதிவுகளின் எண்ணிக்கை சமம்; V-optimal bucket உள்ள variation குறையப் பிரிக்கும்; MaxDiff அடுத்தடுத்த frequency வேறுபாடு அதிகமான இடங்களில் பிரிக்கும். Random sample representative ஆகிறதா சோதிக்க வேண்டும்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Parametric: y=wx+b regression coefficients அல்லது log-linear model சேமி. Non-parametric summaries: histogram, cluster representative, sample. Full records reconstruct ஆகும் என்று உத்தரவாதமில்லை. Histogram rules: equal-width range; equal-depth count; V-optimal within-bin squared error குறைப்பு; MaxDiff பெரிய adjacent gaps. Sampling-இல் random, stratified, cluster samples வேறுபடும்; சிறிய sample representative தானா பார்க்கவும்.

Replace the data with an alternative, smaller representation. Two families:

Parametric methods

A model estimates the data, so you store only the model parameters (plus maybe outliers) instead of the data.

  • Regression
  • Log-linear models (estimate discrete multidimensional probability distributions)

Non-parametric methods

No model is assumed; store a reduced version of the data itself.

  • Histograms
  • Clustering
  • Sampling

Regression

In linear regression the data are modelled to fit a straight line:

y = w x + b
  • y = response variable, x = predictor variable
  • w (slope) and b (intercept) are the regression coefficients.

So instead of storing 10,000 (x, y) pairs you store just two numbers, w and b. That's the reduction.

Histograms

Histograms use binning to approximate the data distribution — a very popular form of data reduction. A histogram for attribute A splits A's values into disjoint subsets called buckets.

  • Singleton bucket – a bucket holding just one attribute-value/frequency pair.
  • Usually buckets represent continuous ranges of the attribute.

Partitioning rules — know all four:

Rule How buckets are formed
Equal-width Every bucket has the same range width.
Equal-frequency (equi-depth) Every bucket holds roughly the same number of (contiguous) values.
V-Optimal Of all possible histograms with the given number of buckets, the one minimising total within-bucket squared deviation from the bucket means (equivalently, the sum of bucket-size × within-bucket variance for a consistent variance definition).
MaxDiff Look at the difference between each pair of adjacent sorted values. Put a bucket boundary at the β − 1 largest differences, where β = number of buckets wanted.

We work through all of these with numbers in section 7.

Clustering and sampling (for completeness)

  • Clustering – group similar records into clusters; store only the cluster representations (e.g. centre + diameter) instead of every record.
  • Sampling – represent a large dataset by a much smaller random sample (e.g. simple random sample without/with replacement, cluster sample, stratified sample).

6Discretization & concept hierarchies

எண்களை வகைகளாக மாற்றுதல்

வயது 21, 22, 23 என்பதை இளைஞர் என்ற interval-ஆக மாற்றுவது Discretization. நகரம் → மாவட்டம் → நாடு போன்ற படிநிலையே Concept hierarchy. நுணுக்கத்தை விட்டுப் பொதுப் பார்வைக்குச் செல்ல உதவும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Supervised discretization class labels பயன்படுத்தும்; unsupervised அவற்றைப் பயன்படுத்தாது. Top-down splitting பெரிய interval-ஐப் பிரிக்கும்; bottom-up merging சிறிய intervals-ஐ இணைக்கும். Concept hierarchy numeric intervals-ஆகவோ city→country போன்ற semantic levels-ஆகவோ இருக்கலாம். Label “young” எந்த வயது range என்பதைத் தெளிவாக வரையறுத்தால்தான் மற்றவர் அதே முடிவை மீண்டும் பெற முடியும்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Continuous age→interval labels என்பது discretisation; youth/middle-aged/senior போன்ற உயர்நிலை concepts generalisation. Supervised class labels பயன்படும்; unsupervised பயன்படாது. Top-down split; bottom-up adjacent merge. Hierarchy street<city<province<country மூலம் abstraction levels. Preprocessing-இலும் query-time generalisation-இலும் பயன்படுத்தலாம்; “mining-இன் போது ஒருபோதும் நடக்காது” என பொதுவிதி இல்லை.

Discretization reduces the number of values of a continuous attribute by dividing its range into intervals. Interval labels then replace the actual values.

Worked example

Ages 13, 15, 16, 19, 22, 25, 33, 35, 46, 52 → replace with labels "10–19", "20–29", "30–39", "40+". Ten distinct values become four labels — the data is simpler and the mining results become a concise, knowledge-level representation.

Ways to classify discretization methods

Basis Type Meaning
Uses class information? Supervised Yes — uses the class labels to choose intervals
Unsupervised No class information used (e.g. plain binning)
Direction Top-down (splitting) Find one or a few split points (cut points) to split the whole range, then repeat recursively on each interval
Bottom-up (merging) Start with all values as potential split points, remove some by merging neighbouring values into intervals, repeat recursively

Concept hierarchies

Doing discretization recursively on an attribute gives a hierarchical (multiresolution) partitioning — a concept hierarchy. It lets you mine at multiple levels of abstraction.

A concept hierarchy replaces low-level concepts (numeric age values) with higher-level concepts (youth, middle-aged, senior).

Figure 3-3 — a concept hierarchy for price:

                        ($0 … $1000]
      ┌──────────┬───────────┼───────────┬────────────┐
 ($0…$200]  ($200…$400]  ($400…$600]  ($600…$800]  ($800…$1000]
  ┌───┴───┐   ┌───┴───┐     …            …            …
($0…$100] ($100…$200] ($200…$300] ($300…$400] …

Why bother, if detail is lost?

  • Generalised data is more meaningful and easier to interpret.
  • Gives a consistent representation of results across multiple mining tasks.
  • Mining a reduced dataset needs fewer I/O operations → more efficient.
Important

Discretization and concept hierarchies often support preprocessing. Generalisation can also be task/query-oriented (see AOI in Week 8); it is not a universal rule that hierarchy use never happens during analysis. More than one hierarchy can be defined for the same attribute to suit different users.

Link

Discretization is itself a form of numerosity reduction, and it is very useful for automatically generating concept hierarchies.

7Binning: equal-width vs equal-depth

இரண்டு Binning முறைகள்

Equal-width ஒவ்வொரு bin-க்கும் ஒரே அகலம்; Equal-depth ஒவ்வொரு bin-க்கும் சுமார் ஒரே எண்ணிக்கையான பதிவுகள். தரவு சமமாகப் பரவவில்லை என்றால் இவ்விரு முறைகளின் bins மிகவும் வேறுபடலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Equal-width width=(max−min)/k. Equal-depth-இல் sorted N records-ஐ ஒவ்வொரு bin-க்கும் சுமார் N/k records-ஆகப் பிரிப்போம். Duplicate values இருப்பதால் எல்லைகளில் policy தேவைப்படலாம். “3 bins” என்பது ஒவ்வொரு bin-இலும் 3 values என்றில்லை. Count=27, k=3 என்றால் 9 values/bin. Outlier ஒன்று equal-width-இன் பெரும்பாலான range-ஐப் பிடித்துக்கொள்ளலாம்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Equal-width: W=(B−A)/N. 64…85,7 bins→W=3; [64,67),[67,70),…last bin85 உட்பட. Counts 2,2,4,2,0,2,2; empty bin சாத்தியம். Equal-depth: 12 values/3→4 per bin: 4,8,9,15 |21,21,24,25 |26,28,29,34. Ties/மீதியை எப்படிப் பகிர்ந்தோம் குறிப்பிடுங்கள். Equal-depth ஒரே count தர முயலும்; equal-width ஒரே range.

The lecture video opens with why: data mining looks for hidden frequent patterns. If an attribute has a very large range of values, the same exact value rarely repeats, so patterns are hard to find. Breaking the range into bins (partitions) makes values "collide" so frequent patterns appear 00:00.

Equal-width partitioning (uniform grid) 00:37

Divide the range into N intervals of equal size. If A is the lowest value and B is the highest:

Width W = (B − A) / N

Bins: [A, A+W), [A+W, A+2W), … up to B. Simple and straightforward.

Weakness — outliers 01:18

If B is an outlier (one huge value), B − A becomes huge, so W becomes huge, and almost all normal data falls into one or two bins. Skewed data is not handled well.

Equal-depth (equal-frequency) partitioning 01:44

Divide into N intervals each containing approximately the same number of samples. Good data scaling; but managing categorical attributes can be tricky.

Bin-களால் Noise குறைத்தல்

Exam focus

This exact style of question (sort → partition into equal-depth bins → smooth by means / boundaries) is very common. Always show the sorted data, the depth calculation, each bin, and the replaced values. If a value is exactly in the middle, state which boundary you chose.

10Also asked in self-assessments: entropy-based discretization and the 3-4-5 rule

Entropy மற்றும் 3-4-5 விதி

Entropy split class-கள் தெளிவாகப் பிரியும் எல்லையைத் தேர்வு செய்யும். குறைந்த weighted entropy நல்ல split. 3-4-5 rule முக்கிய இலக்கங்களின் பரப்பைப் பார்த்து புரியக்கூடிய வட்டமான intervals உருவாக்கும் வேறு முறை.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Entropy split: I(S,T)=(|S₁|/|S|)Ent(S₁)+(|S₂|/|S|)Ent(S₂); Ent=−Σp log₂p. குறைந்த I, அதிக information gain தரும். Class pure என்றால் entropy 0. 3–4–5 rule: distinct most-significant-digit values எண்ணிக்கை 3/6/7/9 என்றால் 3 intervals (7-க்கு 2–3–2); 2/4/8 என்றால் 4; 1/5/10 என்றால் 5. எல்லா datasets-க்கும் 3, பிறகு 4, பிறகு 5 bins என்று பொருள் அல்ல.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Entropy discretisation: labels21N,25N,30Y,35Y,40Y,45N; parent entropy1. Threshold27.5→left2N pure; right3Y1N entropy≈0.8113; weighted entropy4/6×0.8113≈0.5409; gain≈0.4591. Best candidate-ஐத் தேர்ந்து stopping criterion வரை recurse.

3-4-5 rule: most-significant-digit interval count3/6/7/9→3 parts (7க்கு2–3–2 widths); 2/4/8→4;1/5/10→5. இது entropy/class-based split அல்ல; human-readable natural partitioning heuristic. Outlier percentile range, outward rounded bounds, actual min/max coverage, recursive subdivision ஆகிய steps-ஐக் குறிப்பிடவும்.

These two methods aren't in this week's PDF, but the 2024 cohort's Self-Assessment 4 asked about them (they're from the Han & Kamber textbook). Learn the idea and one example of each.

Entropy-based discretization (supervised)

Idea

Use the class labels to choose the split point T that makes the two intervals as pure as possible, i.e. the one with the lowest expected information (equivalently, the highest information gain):

I(S, T) = (|S₁| / |S|)·Ent(S₁) + (|S₂| / |S|)·Ent(S₂), where Ent(S) = −Σ pᵢ log₂ pᵢ

Then split each interval again recursively until the gain is too small (below a threshold).

Ages with class "buys"

Data: 21 N · 25 N · 30 Y · 35 Y · 40 Y · 45 N. The whole set has Ent(S) = 1.000 (3 Y and 3 N).

Candidate T (midpoint) Left / right I(S, T) Gain
23 {N} / 0.809 0.191
27.5 {N, N} / {Y, Y, Y, N} 0.541 0.459 ← best
32.5 {N, N, Y} / 0.918 0.082
37.5 {N, N, Y, Y} / 1.000 0
42.5 {N, N, Y, Y, Y} / 0.809 0.191

So the first split is age ≤ 27.5 vs age > 27.5.

The 3-4-5 rule (natural partitioning)

Rule

Look at the most significant digit (msd) of the range, and count how many distinct msd values the range covers:

Distinct msd values covered Split into
3, 6, 7 or 9 3 intervals (equal width for 3, 6 or 9; 7 uses 2-3-2 widths)
2, 4 or 8 4 intervals
1, 5 or 10 5 intervals

Apply it recursively to each interval. This gives "natural", rounded boundaries that people find easy to read.

Profit from −Rs. 351,976 to Rs. 4,700,896 (textbook example)
  1. Use the 5th to 95th percentile range (−159,876 to 1,838,761) to avoid outliers. The msd is 1,000,000, so round outwards to Low = −1,000,000 and High = 2,000,000.
  2. That covers 3 distinct msd values (−1, 0, 1 million), so make 3 intervals: (−1M, 0], (0, 1M], (1M, 2M].
  3. Adjust to the real min and max: the first interval shrinks to (−400,000, 0], and a new interval (2M, 5M] is added to cover the maximum.
  4. Repeat inside each interval. For example, at the 100,000s digit, (0, 1M] covers 10 distinct values, so split it into 5 intervals of 200,000: (0, 200k], (200k, 400k], …, (800k, 1M].

12Quick revision sheet

விரைவாக நினைவுபடுத்திக்கொள்ள

குறைந்த தரவில் அதே பயன்

முழுத் தரவும் மிகப் பெரியதாக இருந்தால் கணக்கிட நேரம் அதிகம். முக்கியத் தகவலை அதிகமாக இழக்காமல் அளவைக் குறைப்பதே Data reduction. சுருக்கம் பயனுள்ள முடிவை வைத்திருக்கிறதா என்று பார்க்க வேண்டும்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

பெரிய data-வைச் சிறு representation-ஆக மாற்றியும் analysis-க்கு தேவையான தகவலைப் பாதுகாப்பதே reduction. ஐந்து strategies: cube aggregation; attribute subset; dimensionality reduction; numerosity reduction; discretisation/concept hierarchy. அளவு குறைந்தது மட்டும் வெற்றி அல்ல; original data-இன் task result-க்கு போதுமான ஒற்றுமை இருக்கிறதா சோதிக்கவேண்டும்.

விவரங்களை மொத்தங்களாகச் சுருக்குதல்

தினசரி விற்பனையை மாத மொத்தமாகச் சேர்த்தால் குறைந்த பதிவுகளில் போக்கைக் காணலாம். இதுதான் Aggregation. ஆனால் மாத மொத்தத்தில் எந்த நாளில் திடீர் விற்பனை நடந்தது என்ற நுணுக்கம் மறையலாம்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

முக்கிய Attributes தேர்வு

எல்லா columns-மும் prediction-க்கு உதவாது. தேவையற்ற அல்லது ஒரே தகவலைத் திரும்பக் கூறும் attributes-ஐ நீக்குவது Subset selection. சரியான subset வேகத்தையும் பொதுமைப்படுத்தலையும் மேம்படுத்தலாம்.

Forward selection காலி subset-இலிருந்து பயனுள்ள attributes சேர்க்கும்; backward elimination அனைத்திலிருந்து தேவையற்றதை நீக்கும்; combined முறை இரண்டையும் செய்கிறது. Decision tree தேர்ந்த split attributes-உம் relevance காட்டலாம். Target prediction-க்கு உதவாத ID போன்ற column-ஐ வைத்தால் noise அல்லது leakage அதிகரிக்கலாம். Feature selection-ஐ evaluation fold-க்கு வெளியே முழுத் dataset-இல் செய்ய வேண்டாம்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

n attributes-க்கு 2ⁿ subsets; exhaustive search செலவு அதிகம். Forward empty-இலிருந்து best add; backward full-இலிருந்து worst remove; combined add/remove; tree பயன்படுத்திய attributes subset ஆகலாம். Greedy local choice global optimum உத்தரவாதமில்லை. Phone number CD taste-க்கு நேரடி predictor அல்ல என்ற பாட உதாரணம்; IDs leakage/overfitting தரலாம். Feature selection-ஐ training folds-க்குள் fit செய்து evaluation leakage தவிர்க்கவும்.

பரிமாணங்களைக் குறைத்தல்

பல அளவுகளை சில புதிய அளவுகளால் பிரதிநிதித்துவப்படுத்தலாம். PCA போன்ற முறைகள் முக்கிய variation-ஐ வைத்திருக்க முயல்கின்றன. இது சில original columns-ஐ மட்டும் தேர்ந்தெடுப்பதிலிருந்து வேறுபடும்.

Feature selection original columns-ஐத் தேர்வு செய்யும்; PCA original attributes-இன் புதிய linear combinations உருவாக்கும். குறைந்த components அதிக variance வைத்திருக்க முயலும்; interpretation கடினமாகலாம். Scale மிக வேறுபட்டால் PCA முடிவைப் பாதிக்கும். புதிய components குறைந்தவை என்பதால் அவை தானாக அதிக classification accuracy தரும் என்று உறுதி இல்லை.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Feature selection பழைய columns சிலவற்றைத் தேர்வு செய்கிறது; PCA பழைய columns-இன் combinations மூலம் புதிய axes உருவாக்குகிறது. Lossless exact reconstruction; reduced PCA/selected wavelet coefficients பொதுவாக approximate (lossy). Full invertible transform செய்தது மட்டும் loss அல்ல; components/coefficients கைவிடுவதால் தகவல் இழப்பு. PCA அதிக variance capture செய்கிறது; அதுவே target class-க்கு மிகப் பயன்படும் direction என்று உறுதி இல்லை.

பதிவுகளுக்குப் பதில் சுருக்கம்

முழுப் பதிவுகளுக்குப் பதில் sampling, regression, histogram, clustering போன்ற சுருக்கங்களைப் பயன்படுத்துவது Numerosity reduction. சுருக்கத்தின் அளவும் தகவல் இழப்பும் இடையே சமநிலை வேண்டும்.

Parametric regression போன்ற model parameters வைத்துத் தரவைச் சுருக்கும். Non-parametric histogram, clustering, sampling போன்ற சுருக்கங்களைப் பயன்படுத்தலாம். Histogram strategies: equal-width — அகலம் சமம்; equal-frequency — பதிவுகளின் எண்ணிக்கை சமம்; V-optimal bucket உள்ள variation குறையப் பிரிக்கும்; MaxDiff அடுத்தடுத்த frequency வேறுபாடு அதிகமான இடங்களில் பிரிக்கும். Random sample representative ஆகிறதா சோதிக்க வேண்டும்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Parametric: y=wx+b regression coefficients அல்லது log-linear model சேமி. Non-parametric summaries: histogram, cluster representative, sample. Full records reconstruct ஆகும் என்று உத்தரவாதமில்லை. Histogram rules: equal-width range; equal-depth count; V-optimal within-bin squared error குறைப்பு; MaxDiff பெரிய adjacent gaps. Sampling-இல் random, stratified, cluster samples வேறுபடும்; சிறிய sample representative தானா பார்க்கவும்.

Supervised discretization class labels பயன்படுத்தும்; unsupervised அவற்றைப் பயன்படுத்தாது. Top-down splitting பெரிய interval-ஐப் பிரிக்கும்; bottom-up merging சிறிய intervals-ஐ இணைக்கும். விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

இரண்டு Binning முறைகள்

Equal-width ஒவ்வொரு bin-க்கும் ஒரே அகலம்; Equal-depth ஒவ்வொரு bin-க்கும் சுமார் ஒரே எண்ணிக்கையான பதிவுகள். தரவு சமமாகப் பரவவில்லை என்றால் இவ்விரு முறைகளின் bins மிகவும் வேறுபடலாம்.

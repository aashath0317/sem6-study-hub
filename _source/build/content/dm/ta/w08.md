## கனசதுரங்களை ஏன் திறம்படக் கணக்கிட வேண்டும்?

- கிடங்கைச் செயல்படுத்துவதில் **தரவுக் கனசதுரக் கணக்கீடு** ஓர் **இன்றியமையாத** பணி.
- கனசதுரத்தின் முழுவதையோ பகுதியையோ **முன்கணக்கிடுவது பதில் நேரத்தைப் பெரிதும் குறைத்து**, OLAP செயல்திறனை மேம்படுத்துகிறது.
- **சவால்:** இதற்கு **கணிசமான கணக்கீட்டு நேரமும் சேமிப்பிடமும்** தேவைப்படலாம்.

## கனசதுரப் பொருளாக்கம்: கலங்களும் கனச்செவ்வகங்களும்

தரவுக் கனசதுரம் என்பது **கனச்செவ்வகங்களின் பின்னல்**; **ஒவ்வொரு கனச்செவ்வகமும் ஒரு group-by**. A, B, C பரிமாணங்களுக்கு:

```
                 all            ← உச்சிக் கனச்செவ்வகம் (0-D): மிகவும் பொதுமைப்படுத்தப்பட்டது, ஒரு பெறுமதி
           A      B      C      ← 1-D கனச்செவ்வகங்கள்
          AB     AC     BC      ← 2-D கனச்செவ்வகங்கள்
                ABC             ← அடிப்படைக் கனச்செவ்வகம் (3-D): மிகக்குறைவாகப் பொதுமைப்படுத்தப்பட்டது
```

- **கீழ்விரிப்பு**: உச்சியிலிருந்து **கீழே** அடிப்படையை நோக்கிச் செல்லுதல்.
- **மேல்சுருக்கம்**: அடிப்படையிலிருந்து **மேலே** உச்சியை நோக்கிச் செல்லுதல்.

### அடிப்படைக் கலங்களும் திரட்டுக் கலங்களும்
- **அடிப்படைக் கனச்செவ்வகத்திலுள்ள** கலம் **அடிப்படைக் கலம்**. **அடிப்படையல்லாத** கனச்செவ்வகத்திலுள்ள எந்தக் கலமும் **திரட்டுக் கலம்**.
- திரட்டுக் கலத்தில், திரட்டப்பட்ட ஒவ்வொரு பரிமாணமும் **\*** என எழுதப்படுகிறது.
- a = (a₁, …, aₙ, அளவைகள்) என்ற கலத்தில் **துல்லியமாக m பெறுமதிகள் "\*" அல்லாதவையாக** இருந்தால் அது **m-பரிமாணக் கலம்**.
  - **m = n** → அடிப்படைக் கலம்
  - **m < n** → திரட்டுக் கலம்

:::example மாதம் × நகரம் × வாடிக்கையாளர் குழு; அளவை = விலை
| கலம் | வகை |
|---|---|
| (Jan, \*, \*, 2800) | **1-D** திரட்டுக் கலம் |
| (\*, Toronto, \*, 1200) | **1-D** திரட்டுக் கலம் |
| (Jan, \*, Business, 150) | **2-D** திரட்டுக் கலம் |
| (Jan, Toronto, Business, 45) | **3-D அடிப்படைக் கலம்** |
:::

### மூதாதைகளும் வழித்தோன்றல்களும்
**i-D கலம் a**, **j-D கலம் b**-இன் **மூதாதையாக** (b அதன் **வழித்தோன்றலாக**) இருப்பதற்கான அவசியமானதும் போதுமானதுமான நிபந்தனைகள்:

1. **i < j**, மேலும்
2. **a-இல் "\*" அல்லாத ஒவ்வொரு பரிமாணத்திலும் a, b ஒத்திருக்க வேண்டும்**.

கூடுதலாக **j = i + 1** எனில் a **பெற்றோர்**, b **பிள்ளை**.

*எடுத்துக்காட்டு:* (Jan, \*, \*) என்பது (Jan, Toronto, Business)-இன் மூதாதையும் (Jan, Toronto, \*)-இன் **பெற்றோரும்** ஆகும்.

## முழுக் கனசதுரமும் பனிப்பாறைக் கனசதுரமும்

### முழுக் கனசதுரம்
**அனைத்துக் கனச்செவ்வகங்களின் அனைத்துக் கலங்களையும் முன்கணக்கிடுவது**, மிக வேகமான OLAP-ஐ வழங்குகிறது; ஆனால்:

- அது **பரிமாண எண்ணிக்கையுடன் அடுக்குக்குறியாக அதிகரிக்கிறது**: n பரிமாணங்கள் → **2ⁿ கனச்செவ்வகங்கள்**. கருத்துப் படிநிலைகள் இருந்தால் **இன்னும் அதிகம்**:

:::formula
மொத்தக் கனச்செவ்வகங்கள் = Π<sub>i=1..n</sub> (L<sub>i</sub> + 1)   (L<sub>i</sub> = i பரிமாணத்தின் படிநிலையிலுள்ள நிலைகளின் எண்ணிக்கை; "all"-க்காக +1)
:::

- ஒவ்வொரு கனச்செவ்வகத்தின் அளவும் அதன் பரிமாணங்களின் **தனித்த பெறுமதி எண்ணிக்கையைச்** சார்ந்தது.
- எனவே முழுக் கனசதுரத்துக்கு **மிகப்பெரிய, அளவுக்கதிகமான நினைவகம்** தேவைப்படலாம்.

### பனிப்பாறைக் கனசதுரம்
- கனசதுரக் கலங்கள் பொதுவாக **அரிதானவை**. வாடிக்கையாளர் சில பொருட்களையே வாங்குவதால் பெரும்பாலான கலங்கள் **வெற்றாகவோ மிகச்சிறிய பெறுமதிகளுடனோ** உள்ளன.
- அதற்குப் பதிலாக, **அளவை குறைந்தபட்ச வரம்பைக் கடக்கும் கலங்களை மட்டும் பொருளாக்கவும்** (**பனிப்பாறை நிபந்தனை**); எ.கா. **எண்ணிக்கை ≥ 10** அல்லது **விற்பனை ≥ $100**.

:::key பனிப்பாறைக் கனசதுரம்
பனிப்பாறை நிபந்தனையை நிறைவேற்றும் கலங்களை மட்டும் சேமிக்கும் **பகுதியளவு பொருளாக்கப்பட்ட** கனசதுரம். இது **செயலாக்க நேரத்தையும் வட்டிடத்தையும் சேமித்து**, **மேலும் குவிக்கப்பட்ட பகுப்பாய்வை** வழங்குகிறது. வரம்புக்குக் கீழுள்ள கலங்கள் பொதுவாகப் பகுப்பாய்வு செய்ய **மிக அற்பமானவை**.
:::

:::example படிநிலைகளுடன் கனச்செவ்வக எண்ணிக்கை
காலத்தில் நாள் < மாதம் < காலாண்டு < ஆண்டு நிலைகள் உள்ளன (L = 4); பொருளுக்கு 2 நிலைகள்; இடத்துக்கு 3.

கனச்செவ்வகங்கள் = (4+1)(2+1)(3+1) = **60**; படிநிலைகளின்றி 2³ = 8 மட்டுமே.
:::

## MultiWay அணித் திரட்டல்

**தரவுக் கட்டமைப்புகள்:** **ROLAP**, கனச்செவ்வகங்களை **தொடர்புநிலை அட்டவணைகளில்** சேமிக்கிறது. **MOLAP**, **பல்பரிமாண அணிகளைப்** பயன்படுத்துகிறது. **முழுக் கனசதுரங்களைக்** கணக்கிடும் இரு முறைகள் இடம்பெறுகின்றன: **MultiWay** (அணி அடிப்படையிலானது), **BUC**.

### துண்டாக்கப்பட்ட அணி
- A, B, C-க்கான 3-D அணியை எடுத்து **சிறிய நினைவகத் துண்டுகளாகப் பிரிக்கவும்**.
- ஒவ்வொரு பரிமாணமும் **4 சம பிரிவுகளாகப்** பிரிக்கப்படுவதால் 4 × 4 × 4 = **64 துண்டுகள்** (துண்டு 1 = a0b0c0, துண்டு 2 = a1b0c0, …, துண்டு 64 = a3b3c3).
- தனித்த பெறுமதி எண்ணிக்கைகள் **A = 40, B = 400, C = 4000** → பிரிவு அளவுகள் **10, 100, 1000**.

முழுக் கனசதுரத்துக்குக் **கணக்கிட வேண்டிய கனச்செவ்வகங்கள்**:

- **ABC**: அடிப்படைக் கனச்செவ்வகம், ஏற்கெனவே 3-D அணியாக வழங்கப்பட்டுள்ளது. மற்ற அனைத்தும் அதிலிருந்து நேரடியாகவோ மறைமுகமாகவோ கணக்கிடப்படுகின்றன.
- **AB, AC, BC**: 2-D கனச்செவ்வகங்கள்
- **A, B, C**: 1-D கனச்செவ்வகங்கள்
- **all**: உச்சி, group-by (); ஒரு பெறுமதி; எ.கா. மொத்த எண்ணிக்கை

### ஒரேநேரத் திரட்டல்
அடிப்படைக் கலத்தை வாசிக்கும்போது, **அது சார்ந்த அனைத்துத் திரட்டுக் கலங்களும் ஒரே நேரத்தில் புதுப்பிக்கப்படுவதே** முக்கிய கருத்து. எனவே கனச்செவ்வகத்துக்கு ஒருமுறை என்றில்லாமல் அணி **ஒருமுறை** ஸ்கேன் செய்யப்படுகிறது.

:::example குறிப்புகளிலிருந்து: தயாரிப்பு, நகரம், வாடிக்கையாளர்
**{P1, Calgary, Vance}** என்ற அடிப்படை வரிசையை (எண்ணிக்கை 2) வாசிப்பது, பின்வரும் அனைத்திலும் ஒரேநேரத்தில் **2** சேர்க்கிறது:

- **2-D:** {P1, Calgary, \*}, {P1, \*, Vance}, {\*, Calgary, Vance}
- **1-D:** {P1, \*, \*}, {\*, Calgary, \*}, {\*, \*, Vance}
- **உச்சி:** {\*, \*, \*}

ஒவ்வொரு வரிசைக்கும் இதைச் செய்தால் முழுக் கனசதுரமும் நிரம்பும். மேலுள்ள கருவி இதைக் காட்டுகிறது.
:::

:::tip துண்டு வரிசை முக்கியம்
MultiWay, **நினைவகத்தைக் குறைக்கும்** வரிசையில் துண்டுகளை அணுகுகிறது: நினைவகத்தில் வைத்திருக்கும் 2-D தளங்கள் **மிகச்சிறிய பரிமாணங்களுக்கானவையாக** இருக்க வேண்டும் (இங்கு **AB**; A = 40, B = 400 மிகச்சிறியவை). மிகப்பெரிய தளத்துக்கு (BC) ஒரே நேரத்தில் நினைவகத்தில் ஒரு துண்டு மட்டுமே தேவை.
:::

## BUC — கீழிருந்து மேல் கணக்கீடு

- **BUC**, MultiWay-க்கு எதிர்த்திசையில் **உச்சிக் கனச்செவ்வகத்திலிருந்து அடிப்படைக் கனச்செவ்வகத்தை நோக்கிக்** கனசதுரத்தை உருவாக்குகிறது.
- வழக்கமான பின்னல் வரைபடம் **உச்சியை (all) மேலேயும்**, **அடிப்படையை (ABC) கீழேயும்** வைக்கிறது.

:::warn பெயரிடல் குழப்பம் (தேர்வில் சிக்கலாக வரலாம்)
BUC என்பது **"Bottom-Up Construction"** (கீழிருந்து மேல் உருவாக்கம்); ஆனால் வழக்கமான பின்னல் வரைபடத்தில் (உச்சி மேலே) அதன் செயலாக்க வரிசை உண்மையில் **மேலிருந்து கீழ்**: *all*-இல் தொடங்கி ABC நோக்கிக் கீழ்விரிகிறது. உச்சியை அடியில் வரையும் பார்வையிலிருந்து பெயர் வந்தது.
:::

**3-D கனசதுரத்தில் BUC-இன் ஆராய்வு வரிசை (படம் 8-4):**

```
all → A → AB → ABC → AC → B → BC → C
```

அது A-இல் பிரித்து, ஒவ்வொரு A பிரிவுக்குள்ளும் B-இல் மறுசுழற்சியாகப் பிரித்து, இவ்வாறே ஆழம்-முதல் செல்கிறது. **BUC-இன் வலிமை: பனிப்பாறைக் கிளை வெட்டல்.** **எண்ணிக்கை சார்ந்த குறைந்தபட்ச ஆதரவுக்கு**, ஒரு பிரிவு தோல்வியுற்றால் அதன் எந்த வழித்தோன்றலும் தேர்ச்சி பெற முடியாது; எனவே BUC **அந்தக் கிளையை ஆராய்வதை நிறுத்துகிறது**. சராசரிகளுக்கோ எதிர்மறைப் பெறுமதிகள் உள்ள கூட்டுத்தொகைகளுக்கோ இதைக் கண்மூடித்தனமாகப் பயன்படுத்த வேண்டாம்.

## நட்சத்திரப் பண்புக்கூறுகள், நட்சத்திரக் கணுக்கள், நட்சத்திர மரங்கள்

- பண்புக்கூறுப் பெறுமதி p-இன் **ஒற்றைப் பரிமாணத் திரட்டல்**, **பனிப்பாறை நிபந்தனையில் தோல்வியுற்றால்**, p-ஐத் தனியாகக் கையாள்வதில் பயனில்லை.
- p-ஐ **\*** கொண்டு மாற்றவும். அப்போது p ஒரு **நட்சத்திரக் கணுவால்** பிரதிநிதித்துவப்படுத்தப்படுகிறது; தேர்ச்சி பெறுபவை **நட்சத்திரமல்லாத கணுக்கள்**. இரண்டும் * என அச்சிடப்பட்டாலும், இந்தச் சுருக்கப்பட்ட-பெறுமதி இடநிரப்பி, கனசதுரத்தின் **all** பொதுக்குறியிலிருந்து கருத்தளவில் வேறுபட்டது.
- இவ்வாறு சுருக்கப்பட்ட கனச்செவ்வக மரம் **நட்சத்திர மரம்**. **நட்சத்திர அட்டவணை** நட்சத்திரக் கணுக்களைப் பட்டியலிடுகிறது.

{{tool:star}}

:::example குறிப்புகளின் எடுத்துக்காட்டு (min_sup = 2)

- நட்சத்திரக் கணுக்களை \* கொண்டு மாற்றி இணைத்தபின் குறைக்கப்பட்ட அட்டவணை:

| A | B | C | D | எண்ணிக்கை |
|---|---|---|---|---|

## பண்புக்கூறு நோக்கிய தூண்டல் (AOI)

**தரவுப் பொதுமைப்படுத்தல்**, கீழ்நிலைப் பெறுமதிகளை (எண் வயது) **உயர்நிலைக் கருத்துகளால்** (இளைஞர், நடுத்தர வயது, முதியவர்) மாற்றுவதால், பெருமளவு தரவை **பல அருவாக்க நிலைகளில் சுருக்கமாக** விவரிக்கலாம்.

:::grid
**தரவுக் கனசதுர அணுகுமுறை**

- கிடங்கில் முன்கணக்கிடப்பட்ட **பொருளாக்கப்பட்ட பார்வைகளை** அடிப்படையாகக் கொண்டது
- வினவல் வருவதற்கு *முன்* **இணையமற்ற திரட்டல்**
+++
**பண்புக்கூறு நோக்கிய தூண்டல் (1989)**

- **வினவல் நோக்கிய**, பொதுமைப்படுத்தல் சார்ந்த, **நிகழ்நிலைப்** பகுப்பாய்வு
- தரவுக் கனசதுர அணுகுமுறைக்கு **சில ஆண்டுகளுக்கு முன்** முன்மொழியப்பட்டது
:::

### AOI கருத்து
1. தரவுத்தள வினவலால் **பணிக்குப் பொருத்தமான தரவைச் சேகரிக்கவும்**.
2. ஒவ்வொரு பண்புக்கூறின் **வேறுபட்ட பெறுமதிகளின் எண்ணிக்கையைப்** பார்த்து **பொதுமைப்படுத்தவும்**: **பண்புக்கூறு நீக்கம்** அல்லது **பண்புக்கூறுப் பொதுமைப்படுத்தல்**.
3. **ஒரே மாதிரியான பொதுமைப்படுத்தப்பட்ட வரிசைகளை இணைத்து**, **அவற்றின் எண்ணிக்கைகளைக் கூட்டுவதன்** மூலம் **திரட்டவும்**.
4. விளக்கப்படங்கள், குறுக்கு அட்டவணைகள் அல்லது விதிகளாக முடிவை **வழங்கவும்**.

### இரு விதிகள்

:::grid
**பண்புக்கூறு நீக்கம்**

பண்புக்கூறுக்கு **பல வேறுபட்ட பெறுமதிகள்** இருந்து, பின்வருவனவற்றில் ஒன்று உண்மையானால்:

1. **பொதுமைப்படுத்தல் செயற்குறி இல்லை** (கருத்துப் படிநிலை இல்லை), அல்லது
2. அதன் உயர்நிலைக் கருத்துகள் **பிற பண்புக்கூறுகளால் வெளிப்படுத்தப்படுகின்றன**

→ **அதை நீக்கவும்**.
+++
**பண்புக்கூறுப் பொதுமைப்படுத்தல்**

பண்புக்கூறுக்கு **பல வேறுபட்ட பெறுமதிகளும்**, **பொதுமைப்படுத்தல் செயற்குறியும் இருந்தால்**

→ வேறுபட்ட பெறுமதிகளின் எண்ணிக்கை ≤ **பண்புக்கூறுப் பொதுமைப்படுத்தல் வரம்பு** ஆகும்வரை **அதைப் பயன்படுத்தவும்** (படிநிலையில் ஏறவும்).
:::

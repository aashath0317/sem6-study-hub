## வகைப்படுத்தலும் முன்னறிவிப்பும்

இரண்டும் தரவு வகுப்புகளை விவரிக்க அல்லது **எதிர்காலப் போக்குகளை முன்னறிவிக்க**, **தரவிலிருந்து மாதிரியை உருவாக்குகின்றன**.

:::grid
**வகைப்படுத்தல்**

**வகைசார் (தனித்த, வரிசையற்ற) வகுப்பு அடையாளங்களை** முன்னறிவிக்கிறது.

- வங்கி: கடன் விண்ணப்பதாரர் **"பாதுகாப்பானவரா" அல்லது "இடருள்ளவரா"**?
- மருத்துவம்: நோயாளிக்கு **சிகிச்சை A, B அல்லது C** வழங்க வேண்டுமா?
+++
**முன்னறிவிப்பு (எண்ணியல்)**

**தொடர்ச்சியான பெறுமதியுள்ள (வரிசைப்படுத்தப்பட்ட)** பண்புக்கூற்றை முன்னறிவிக்கிறது.

- வங்கி: இந்த விண்ணப்பதாரருக்கு எந்த **கடன் தொகை ($-இல்)** பாதுகாப்பானது?

இங்கு "வகுப்பு அடையாளம்" இல்லை. அதை **முன்னறிவிக்கப்படும் பண்புக்கூறு** என அழைத்து **முன்னறிவிப்பியை** உருவாக்குகிறோம்.
:::

### முக்கிய சொற்கள்

| சொல் | பொருள் |
|---|---|
| **வரிசை X** | A₁ … Aₙ பண்புக்கூறுகளுக்கான பெறுமதிகளுள்ள **n-பரிமாணப் பண்புக்கூறு வெக்டர்** X = (x₁, x₂, …, xₙ) |
| **வகுப்பு அடையாளப் பண்புக்கூறு** | ஒவ்வொரு வரிசையின் **முன்வரையறுக்கப்பட்ட வகுப்பையும்** வழங்கும் பண்புக்கூறு; தனித்ததும் வரிசையற்றதும் |
| **பயிற்சி வரிசைகள்** | மாதிரியை உருவாக்கப் பயன்படும் வரிசைகள். **மாதிரிகள், எடுத்துக்காட்டுகள், நிகழ்வுகள், தரவுப் புள்ளிகள், பொருட்கள்** என்றும் அழைக்கப்படுகின்றன |
| **மேற்பார்வைக் கற்றல்** | ஒவ்வொரு பயிற்சி வரிசையின் வகுப்பு அடையாளமும் **வழங்கப்பட்டுள்ளது**. வகைப்படுத்தல் இவ்வாறு செயல்படுகிறது |
| **மேற்பார்வையற்ற கற்றல் (குழுமமாக்கல்)** | வகுப்பு அடையாளங்கள் **தெரியாது**; பெரும்பாலும் வகுப்புகளின் எண்ணிக்கையும் தெரியாது. எ.கா. இடர்க் குழுக்களாக இருக்கக்கூடிய "ஒத்த வரிசைகளின் குழுக்களைக்" கண்டறிதல் |

## இரு-படி வகைப்படுத்தல் செயல்முறை

:::flow
படி 1 – கற்றல்: பயிற்சித் தரவு → வகைப்படுத்தல் படிமுறை → வகைப்படுத்தி (எ.கா. விதிகள்)
படி 2 – வகைப்படுத்தல்: சோதனைத் தரவு → துல்லியத்தை மதிப்பிடு → புதிய தரவை வகைப்படுத்து
:::

**படி 1: கற்றல் (பயிற்சிக் கட்டம்).** படிமுறை வகுப்பு அடையாளங்களுடனான **பயிற்சி வரிசைத் தொகுப்பைப் பகுப்பாய்வு செய்து**, **வகைப்படுத்தியை** உருவாக்குகிறது. கடன் எடுத்துக்காட்டில் வகைப்படுத்தி **வகைப்படுத்தல் விதிகளின்** தொகுப்பு:

```
வயது = இளைஞர் எனில் கடன்_முடிவு = இடருள்ளது
வருமானம் = அதிகம் எனில் கடன்_முடிவு = பாதுகாப்பானது
வயது = நடுத்தர_வயது மற்றும் வருமானம் = குறைவு எனில் கடன்_முடிவு = இடருள்ளது
```

**படி 2: வகைப்படுத்தல்.** முதலில் **சோதனைத் தொகுப்பில் முன்னறிவிப்புத் துல்லியத்தை மதிப்பிடவும்**.

:::warn பயிற்சித் தரவிலேயே ஏன் சோதிக்கக்கூடாது?
அந்த மதிப்பீடு **மிகையான நம்பிக்கையுள்ளதாக** இருக்கும்; ஏனெனில் வகைப்படுத்தி **மிகைப்பொருத்தமடைகிறது**: பொதுவான தரவில் இல்லாத பயிற்சித் தரவின் குறிப்பிட்ட **ஒழுங்கின்மைகளைக்** கற்கிறது. எனவே **சோதனைத் தொகுப்பு சீரற்ற முறையில் தேர்ந்தெடுக்கப்பட்டு**, பயிற்சி வரிசைகளிலிருந்து **சுயாதீனமாக** இருக்க வேண்டும்.
:::

:::formula
**துல்லியம்** = **சரியாக வகைப்படுத்தப்பட்ட** சோதனைத் தொகுப்பு வரிசைகளின் %
:::

துல்லியம் ஏற்கத்தக்கதாக இருந்தால், **எதிர்கால ("தெரியாத", "முன்னர் காணப்படாத") வரிசைகளுக்கு** வகைப்படுத்தி அடையாளமிடுகிறது; எ.கா. புதிய கடன் விண்ணப்பதாரர்களை ஏற்றல் அல்லது நிராகரித்தல்.

## தரவைத் தயார்படுத்தலும் முறைகளை ஒப்பிடுதலும்

### வகைப்படுத்தலுக்கான முன்செயலாக்கம்
| படி | என்ன, ஏன் |
|---|---|
| **தரவுத் தூய்மைப்படுத்தல்** | **இரைச்சலைக்** குறைத்து (சீராக்கல்), **விடுபட்ட பெறுமதிகளைக்** கையாளுதல் (அதிகம் நிகழும் அல்லது அதிக சாத்தியமுள்ள பெறுமதி). கற்றலின்போது குழப்பத்தைக் குறைக்கிறது |
| **பொருத்தப்பாட்டுப் பகுப்பாய்வு** | **ஒட்டுறவுப் பகுப்பாய்வு** மிகையான பண்புக்கூறுகளை நீக்குகிறது (A1, A2 வலுவாக ஒட்டுறவுடையவை எனில் ஒன்றை நீக்கவும்). **பண்புக்கூறுப் பொருத்தப்பாட்டுப் பகுப்பாய்வு**, கற்றலை **மெதுவாக்கித் தவறாக வழிநடத்தும்** பொருத்தமற்றவற்றை நீக்குகிறது |
| **உருமாற்றமும் குறைப்பும்** | நரம்பியல் வலையமைப்புகளுக்கும் **தொலைவு அடிப்படையிலான** முறைகளுக்கும் **இயல்பாக்கம்**; பெரிய வீச்சுப் பண்புக்கூறுகள் (வருமானம்), சிறிய வீச்சுள்ளவற்றை (இருமம்) **மிஞ்சி ஆதிக்கம் செலுத்தாதிருக்க**. கருத்துப் படிநிலைகளால் **பொதுமைப்படுத்தல்** (வருமானம் → குறைவு/நடுத்தரம்/அதிகம், தெரு → நகரம்) தரவைச் சுருக்குவதால் **குறைந்த உள்ளீடு/வெளியீடு** |

### வகைப்படுத்திகளையும் முன்னறிவிப்பிகளையும் ஒப்பிடும் அளவுகோல்கள்

| அளவுகோல் | பொருள் |
|---|---|
| **துல்லியம்** | **புதிய, காணப்படாத** தரவின் வகுப்பை (அல்லது பெறுமதியை) சரியாக முன்னறிவிக்கும் திறன். இது மதிப்பீடு என்பதால் **நம்பிக்கை எல்லைகளைக்** கணக்கிடலாம் |
| **வேகம்** | மாதிரியை உருவாக்கிப் பயன்படுத்துவதற்கான **கணக்கீட்டுச் செலவு** |
| **உறுதித்தன்மை** | **இரைச்சலுள்ள** அல்லது **விடுபட்ட பெறுமதிகளுள்ள** தரவில் சரியான முன்னறிவிப்புகள் |
| **அளவீட்டுத்திறன்** | **பெருமளவு** தரவிலிருந்து திறம்பட உருவாக்குதல் |
| **விளக்கத்தன்மை** | மாதிரி வழங்கும் **புரிதலும் நுண்ணறிவும்**. **அகநிலையானது** என்பதால் மதிப்பிடுவது கடினம் (எ.கா. "கருப்புப் பெட்டி" பின்னோக்குப் பரப்பல் நரம்பியல் வலையமைப்பிலிருந்து விதிகளைப் பிரித்தெடுத்தல்) |

:::tip நினைவுக்குறிப்பு: "A-S-R-S-I"
**A**ccuracy — துல்லியம் · **S**peed — வேகம் · **R**obustness — உறுதித்தன்மை · **S**calability — அளவீட்டுத்திறன் · **I**nterpretability — விளக்கத்தன்மை
:::

## முடிவெடுக்கும் மரங்களும் அவற்றின் வரலாறும்

**முடிவெடுக்கும் மரம்** ஒரு **பாய்வுப்படம் போன்ற மரம்**:

- **உட்புற (இலையல்லாத) கணு** = **பண்புக்கூறின் மீதான சோதனை**
- **கிளை** = சோதனையின் **விளைவு**
- **இலை (இறுதி) கணு** = **வகுப்பு அடையாளம்**
- மேலுள்ள கணு **வேர்**

```
                    வயது?
          ┌──────────┼──────────────┐
        இளைஞர்    நடுத்தர_வயது      முதியவர்
          │          │               │
      மாணவரா?      ஆம்        கடன்_மதிப்பீடு?
       ┌──┴──┐                  ┌────┴─────┐
    இல்லை   ஆம்               நியாயம்   மிகச்சிறப்பு
      │      │                 │          │
    இல்லை   ஆம்               ஆம்       இல்லை
```
*"buys_computer" என்ற கருத்து. செய்முறை எடுத்துக்காட்டின் இறுதி மரம்.*

ID3, C4.5, CART அனைத்தும் **பேராசை (பின்செல்லாத)**, **மேலிருந்து கீழ் மறுசுழற்சிப் பிரித்தாளும்** அணுகுமுறையைப் பயன்படுத்துகின்றன. மரம் வளரும்போது பயிற்சித் தொகுப்பு சிறிய உட்கணங்களாக **மறுசுழற்சியாகப் பிரிக்கப்படுகிறது**.

### அடிப்படைப் படிமுறை (படம் 11-4) எளிய சொற்களில்

1. N கணுவை உருவாக்கவும்.
2. D-இன் அனைத்து வரிசைகளும் **ஒரே வகுப்பில்** இருந்தால் → N அந்த வகுப்புடைய **இலையாகிறது**.
3. **பண்புக்கூறுகள் எதுவும் மீதமில்லை** எனில் → **பெரும்பான்மை வகுப்பு** அடையாளத்துடன் இலை.
4. இல்லாவிட்டால் **பண்புக்கூறுத் தேர்வு அளவையால் சிறந்த பிரிப்பளவுகோலைக்** கண்டறிந்து, N-க்கு அதையே அடையாளமிடவும்; பல்வழிப் பிரிப்புகளுள்ள தனித்த பண்புக்கூறாக இருந்தால் **பண்புக்கூற்றை நீக்கவும்**.
5. ஒவ்வொரு விளைவு j-க்கும் Dⱼ பிரிவை உருவாக்கவும். **Dⱼ வெற்றாக** இருந்தால் → **D-இன் பெரும்பான்மை வகுப்புடன்** இலையை இணைக்கவும். இல்லாவிட்டால் Dⱼ-இல் **மறுசுழற்சி செய்யவும்**.

## பண்புக்கூறுத் தேர்வு அளவைகள்

**பண்புக்கூறுத் தேர்வு அளவை** (அல்லது **பிரிப்பு விதி**) என்பது D-ஐ வகுப்புகளாக **மிகச்சிறப்பாகப் பிரிக்கும்** பிரிவைத் தேர்ந்தெடுக்கும் அனுபவவழி. ஒவ்வொரு பிரிவும் **தூய்மையாக** (ஒரு வகுப்பு) இருப்பது இலட்சியம். அளவை **பண்புக்கூறுகளைத் தரவரிசைப்படுத்துகிறது**; சிறந்தது **பிரிப்புப் பண்புக்கூறு**. தொடர்ச்சியான பண்புக்கூறுகளுக்கு **பிரிப்புப் புள்ளியும்** தேவை; இரும மரங்களுக்கு **பிரிக்கும் உட்கணமும்** தேவை.

### தகவல் ஆதாயம் (ID3)
**Claude Shannon-இன் தகவல் கோட்பாட்டை** அடிப்படையாகக் கொண்டது. **அதிக ஆதாயமுள்ள** பண்புக்கூற்றைத் தேர்ந்தெடுக்கவும்: அது **இன்னும் தேவைப்படும் தகவலைக் குறைத்து** (குறைந்த தூய்மையின்மை), எதிர்பார்க்கப்படும் சோதனை எண்ணிக்கையையும் குறைக்கிறது.

:::formula
**Info(D)** = − Σ<sub>i=1..m</sub> p<sub>i</sub> log₂(p<sub>i</sub>)    (D-இன் என்ட்ரோப்பி)
**Info<sub>A</sub>(D)** = Σ<sub>j=1..v</sub> ( |D<sub>j</sub>| / |D| ) × Info(D<sub>j</sub>)
**Gain(A)** = Info(D) − Info<sub>A</sub>(D)
:::

- p<sub>i</sub> = |C<sub>i,D</sub>| / |D| = வரிசை C<sub>i</sub> வகுப்பைச் சாரும் நிகழ்தகவு.
- |Dⱼ|/|D| என்பது j பிரிவின் **நிறை**.

### ஆதாய விகிதம் (C4.5)

அது **பல பெறுமதிகளுள்ள பண்புக்கூறுகளை விரும்புகிறது**. தனித்துவமான **product_ID**-இல் பிரிப்பது வரிசைக்கு ஒரு தூய பிரிவை வழங்குவதால் Info = 0; ஆதாயம் **அதிகபட்சம்**; இருப்பினும் வகைப்படுத்தலுக்கு அந்தப் பிரிப்பு **பயனற்றது**.

**பிரிப்புத் தகவலால்** C4.5 ஆதாயத்தை **இயல்பாக்குகிறது**: வகுப்பைப் பொருட்படுத்தாமல் D-ஐ v பிரிவுகளாகப் பிரிப்பதால் கிடைக்கும் சாத்தியத் தகவல்.

**அதிகபட்ச ஆதாய விகிதமுள்ள** பண்புக்கூற்றைத் தேர்ந்தெடுக்கவும்.

### ஜினி சுட்டெண் (CART)

:::formula
**Gini(D)** = 1 − Σ<sub>i=1..m</sub> p<sub>i</sub>²
**Gini<sub>A</sub>(D)** = ( |D₁| / |D| ) Gini(D₁) + ( |D₂| / |D| ) Gini(D₂)     (இருமப் பிரிப்பு)
**ΔGini(A)** = Gini(D) − Gini<sub>A</sub>(D)
:::

- **இந்தப் பாடத்தின் CART**, இருமப் பிரிப்புகளைக் கருதுகிறது; ஜினி தூய்மையின்மையை வேறு கிளை எண்ணிக்கையுள்ள பிரிவுகளையும் மதிப்பிடப் பயன்படுத்தலாம். v பெறுமதிகளுள்ள தனித்த பண்புக்கூறுக்கு 2ᵛ உட்கணங்கள் உள்ளன. முழுக் கணத்தையும் வெற்றுக் கணத்தையும் நீக்கினால் **2ᵛ − 2** உட்கணங்கள். ஒவ்வொரு பிரிப்பும் இருமுறை வருகிறது ({low} மற்றும் {medium, high} என்பது அதே பிரிப்பு); எனவே **(2ᵛ − 2)/2 வேறுபட்ட இருமப் பிரிப்புகள்** உள்ளன.
- தொடர்ச்சியான பண்புக்கூறுகளுக்கு **வரிசைப்படுத்தப்பட்ட அடுத்தடுத்த ஒவ்வொரு பெறுமதிச் சோடியின் நடுப்புள்ளியையும்** பிரிப்புப் புள்ளியாக முயலவும்: D₁ = A ≤ பிரிப்பு, D₂ = A > பிரிப்பு.
- **குறைந்தபட்ச Gini<sub>A</sub>(D)**, அதாவது **தூய்மையின்மையில் அதிகபட்சக் குறைப்பு**, உள்ள பண்புக்கூறையும் பிரிப்பையும் தேர்ந்தெடுக்கவும்.

| காணொளி | முக்கிய கற்றல்கள் |
|---|---|
| **1.4 வகைப்படுத்தியை உருவாக்குதல்** | Classify தாவல் → **J48** (Weka-வின் **C4.5**) தேர்வு → இயல்புநிலை **10-மடங்கு குறுக்கு உறுதிப்படுத்தலுடன்** இயக்குதல். **துல்லியம்**, **குழப்ப அணி**, அச்சிடப்பட்ட **மரம்** ஆகியவற்றை வாசிக்கவும். கிளை வெட்டல் விருப்பங்கள் மரத்தின் அளவை மாற்றுகின்றன |
| **1.5 வடிகட்டியைப் பயன்படுத்துதல்** | **வடிகட்டிகள்** (Preprocess-இல்) தரவை உருமாற்றுகின்றன. எ.கா. **Remove** வடிகட்டி பண்புக்கூறுகளை நீக்குகிறது. ஒரு பண்புக்கூற்றை நீக்குவது மரத்தை மாற்றலாம்; மேம்படுத்தவும் முடியும் |
| **1.6 தரவைக் காட்சிப்படுத்துதல்** | **Visualize** பலகம் வகுப்பின்படி நிறமிட்டுப் பண்புக்கூறுச் சோடிகளை வரைகிறது. **வகைப்படுத்திப் பிழைகளையும் காட்சிப்படுத்தலாம்**: தவறாக வகைப்படுத்தப்பட்ட நிகழ்வுகள் சதுரங்களாகக் காட்டப்படுகின்றன |

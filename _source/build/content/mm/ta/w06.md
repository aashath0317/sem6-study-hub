
## Matrix வடிவமும் coordinate முறையும்

ஒரு raster object என்பது 2D Cartesian coordinate அமைப்பில் இருக்கும் நிறமுள்ள pixels தொகுப்பு. ஒரு point-ஐ **column vector** P = [[m: x; y]] என்று எழுதலாம். முழு object-ஐ மாற்ற அதன் எல்லா defining points-ஐயும் மாற்ற வேண்டும். PDF column vectors பயன்படுத்துகிறது. எனவே matrix இடப்புறம் வரும்: **P′ = MP**. கீழே positive angle என்பது y மேல்நோக்கி இருக்கும் Cartesian அமைப்பில் counterclockwise திருப்பம். Screen-இல் y கீழ்நோக்கி இருக்கலாம்; இரண்டு முறைகளையும் கலக்க வேண்டாம்.

Transformation என்பது position, orientation அல்லது size-ஐ மாற்றுவது. Translation நகர்த்தும். Rotation ஒரு pivot-ஐச் சுற்றித் திருப்பும். Scaling dimensions-ஐ மாற்றும். Raster application-இன் Free Transform மூலம் move, rotate, skew, scale போன்றவற்றை இணைக்கலாம். Options bar-இல் parameters-ஐப் பார்க்கலாம்.

:::example PDF-இன் தொடக்க நகர்த்தல்
ஒவ்வொரு vertex-க்கும் (2,2) சேர்க்கவும்: (2,3) → (4,5), (4,5) → (6,7), (6,8) → (8,10). எல்லா vertices-உம் ஒரே தூரமும் திசையும் நகரும். Shape-உம் size-உம் மாறாது.
:::

## Translation, rotation, scaling: formula-வும் செய்முறையும்

:::formula
Translation: x′ = x + tx; y′ = y + ty; P′ = P + T.
Rotation: x′ = x cos θ − y sin θ; y′ = x sin θ + y cos θ.
R = [[m: cosθ −sinθ; sinθ cosθ]].
Scaling: x′ = sx·x; y′ = sy·y; S = [[m: sx 0; 0 sy]].
:::

Rotation-ஐ angle-sum identities மூலம் பெறலாம். x = r cos α, y = r sin α என்றால் புதிய angle α + θ; r மாறாது. r cos(α + θ), r sin(α + θ) ஆகியவற்றை விரித்தால் மேலுள்ள equations வரும். இரண்டு scaling factors சமமெனில் uniform scaling. சமமில்லையெனில் proportions மாறும். Negative factor அந்த coordinate திசையில் reflection செய்யும். வேறு pivot குறிப்பிடாவிட்டால் இங்கே rotation-உம் scaling-உம் origin-ஐ மையமாகக் கொள்கின்றன.

:::example Translation கணக்கு 1
**Formula:** P′ = P + T. **Substitution-உம் working-உம்:** (2+(4), 3+(-1)). **விடை:** P′ = (6, 2) coordinate units.
:::

:::example Translation கணக்கு 2
**Formula:** P′ = P + T. **Substitution-உம் working-உம்:** (-2+(3), 5+(2)). **விடை:** P′ = (1, 7) coordinate units.
:::

:::example Translation கணக்கு 3
**Formula:** P′ = P + T. **Substitution-உம் working-உம்:** (0+(-3), -4+(6)). **விடை:** P′ = (-3, 2) coordinate units.
:::

:::example Scaling கணக்கு 1
**Formula:** P′ = SP. **Substitution-உம் working-உம்:** (2×(2), 3×(3)). **விடை:** P′ = (4, 9) coordinate units.
:::

:::example Scaling கணக்கு 2
**Formula:** P′ = SP. **Substitution-உம் working-உம்:** (0.5×(-4), 2×(6)). **விடை:** P′ = (-2.0, 12) coordinate units.
:::

:::example Scaling கணக்கு 3
**Formula:** P′ = SP. **Substitution-உம் working-உம்:** (-1×(5), 0.5×(-2)). **விடை:** P′ = (-5, -1.0) coordinate units.
:::

:::example Rotation கணக்கு 1
**Formula:** P′ = RP. **Substitution-உம் working-உம்:** (2×(0.0) − (3)×(1.0), 2×(1.0) + (3)×(0.0)). **விடை:** P′ = (-3.0, 2.0) coordinate units.
:::

**Formula:** P′ = RP. **Substitution-உம் working-உம்:** (4×(-1.0) − (0)×(0.0), 4×(0.0) + (0)×(-1.0)). **விடை:** P′ = (-4.0, 0.0) coordinate units.
:::

## Homogeneous coordinates-உம் composite transformations-உம்

சாதாரண translation addition-ஐப் பயன்படுத்துகிறது. Rotation-உம் scaling-உம் multiplication பயன்படுத்துகின்றன. Homogeneous coordinates மூலம் மூன்றையும் matrix multiplication ஆக எழுதலாம். Point-க்கு கடைசியாக **h = 1** சேர்க்கவும்: P = [[m: x; y; 1]].

:::warn Source திருத்தம்
Page 6-இல் xh = x/h, yh = y/h என்று உள்ளது. Homogeneous triple (xh,yh,h)-க்கு Cartesian coordinates x = xh/h, y = yh/h ஆகும். அதாவது xh = h·x, yh = h·y. பாடத்தில் h = 1 என்பதால் இந்தத் தலைகீழ் எழுத்து முடிவை மாற்றவில்லை. காட்டப்பட்ட transformation matrices வழக்கமான h = 1 முறையையே பயன்படுத்துகின்றன.
:::

:::formula
T = [[m: 1 0 tx; 0 1 ty; 0 0 1]].
R = [[m: cosθ −sinθ 0; sinθ cosθ 0; 0 0 1]].
S = [[m: sx 0 0; 0 sy 0; 0 0 1]].
P′ = MP. கடைசி row இறுதி coordinate-ஐ 1 ஆக வைத்திருக்கும்.
:::

ஒரு sequence-இல் முதலில் செய்யும் operation point-க்கு அருகில் வரும். “Translate, then scale” என்றால் P′ = STP. “Scale, then translate” என்றால் P′ = TSP. Matrix multiplication பொதுவாக commutative அல்ல. Multiply செய்வதற்கு முன்பு order-ஐ எழுதவும். சரியான matrix-ஐத் தவறான வரிசையில் பயன்படுத்துவதை இது தடுக்கும்.

:::example Homogeneous கணக்கு 1
Formula: (x,y) = (xh/h,yh/h). (2/1,3/1) என substitute செய்யவும். Working-இல் **(2,3) coordinate units** கிடைக்கும். அதன் h = 1 column [[m: 2; 3; 1]].
:::

:::example Homogeneous கணக்கு 2
Formula: (x,y) = (xh/h,yh/h). (4/2,6/2) என substitute செய்யவும். Working-இல் **(2,3) coordinate units** கிடைக்கும். அதன் h = 1 column [[m: 2; 3; 1]].
:::

:::example Homogeneous கணக்கு 3
Formula: (x,y) = (xh/h,yh/h). (-6/3,9/3) என substitute செய்யவும். Working-இல் **(-2,3) coordinate units** கிடைக்கும். அதன் h = 1 column [[m: -2; 3; 1]].
:::

:::example Composite கணக்கு 1: translate செய்து scale செய்யவும்
Formula: P′ = STP. P = (1,2), T = (3,1), S factors = (2,3) என substitute செய்யவும். முதலில் (1+(3), 2+(1)) = (4,3). அடுத்து multiply செய்யவும்: (2×(4), 3×(3)). **விடை: (8,9) coordinate units**.
:::

:::example Composite கணக்கு 2: translate செய்து scale செய்யவும்
Formula: P′ = STP. P = (2,1), T = (-1,2), S factors = (3,2) என substitute செய்யவும். முதலில் (2+(-1), 1+(2)) = (1,3). அடுத்து multiply செய்யவும்: (3×(1), 2×(3)). **விடை: (3,6) coordinate units**.
:::

:::example Composite கணக்கு 3: translate செய்து scale செய்யவும்
Formula: P′ = STP. P = (-1,3), T = (2,-1), S factors = (2,0.5) என substitute செய்யவும். முதலில் (-1+(2), 3+(-1)) = (1,2). அடுத்து multiply செய்யவும்: (2×(1), 0.5×(2)). **விடை: (2,1) coordinate units**.
:::

## குறிப்பிட்ட pivot-உம் Activity 6.1-உம்

C = (xc,yc)-ஐச் சுற்றி rotate செய்ய, C-ஐ origin-க்கு translate செய்து rotate செய்யவும்; பிறகு திரும்ப translate செய்யவும். Pivot அதே இடத்தில் இருக்கும். Scaling-க்கும் இதே construction பொருந்தும்.

:::formula
C-ஐச் சுற்றிய rotation: M = T(xc,yc) R(θ) T(−xc,−yc).
x′ = xc + (x−xc)cosθ − (y−yc)sinθ.
y′ = yc + (x−xc)sinθ + (y−yc)cosθ.
C-ஐ மையமாகக் கொண்ட scaling: M = T(xc,yc) S T(−xc,−yc).
x′ = xc + sx(x−xc); y′ = yc + sy(y−yc).
:::

Figures 6.4, 6.5-இன் கருத்தை இந்த equations காட்டுகின்றன. C-இலிருந்து P வரையிலான vector-ஐ rotate அல்லது stretch செய்து மீண்டும் C-இல் பொருத்துகிறோம். Scaling homogeneous matrix-இன் final-column entries xc(1−sx), yc(1−sy). Rotation-க்கு அவை xc(1−cosθ)+yc sinθ, yc(1−cosθ)−xc sinθ.

:::example Activity 6.1(i)
**கேள்வி:** P(4,3)-ஐ C(2,1) சுற்றி 60° rotate செய்யவும். **Formula:** P′ = T(C)RT(−C)P. **Substitute:** relative point = (4−(2),3−(1)) = (2,2). **Working:** x′ = 2+(2)×0.500000−(2)×0.866025; y′ = 1+(2)×0.866025+(2)×0.500000. **விடை:** (1.267949,3.732051) coordinate units.
:::

:::example Pivot rotation கணக்கு 2
**கேள்வி:** P(3,2)-ஐ C(1,1) சுற்றி 90° rotate செய்யவும். **Formula:** P′ = T(C)RT(−C)P. **Substitute:** relative point = (3−(1),2−(1)) = (2,1). **Working:** x′ = 1+(2)×0.000000−(1)×1.000000; y′ = 1+(2)×1.000000+(1)×0.000000. **விடை:** (0.000000,3.000000) coordinate units.
:::

:::example Pivot rotation கணக்கு 3
**கேள்வி:** P(0,1)-ஐ C(1,1) சுற்றி 180° rotate செய்யவும். **Formula:** P′ = T(C)RT(−C)P. **Substitute:** relative point = (0−(1),1−(1)) = (-1,0). **Working:** x′ = 1+(-1)×-1.000000−(0)×0.000000; y′ = 1+(-1)×0.000000+(0)×-1.000000. **விடை:** (2.000000,1.000000) coordinate units.
:::

:::example Activity 6.1(ii)
**கேள்வி:** P(6,4)-ஐ C(2,3) மையமாக வைத்து (2.5,1.5) factors-இல் scale செய்யவும். Formula: P′ = T(C)ST(−C)P. Substitute செய்து கணக்கிடவும்: x′ = 2+2.5×(6−(2)) = 12; y′ = 3+1.5×(4−(3)) = 4.5. **விடை: (12,4.5) coordinate units.**
:::

:::example Pivot scaling கணக்கு 2
**கேள்வி:** P(4,3)-ஐ C(2,1) மையமாக வைத்து (2,3) factors-இல் scale செய்யவும். Formula: P′ = T(C)ST(−C)P. Substitute செய்து கணக்கிடவும்: x′ = 2+2×(4−(2)) = 6; y′ = 1+3×(3−(1)) = 7. **விடை: (6,7) coordinate units.**
:::

:::example Pivot scaling கணக்கு 3
**கேள்வி:** P(-1,5)-ஐ C(1,1) மையமாக வைத்து (0.5,2) factors-இல் scale செய்யவும். Formula: P′ = T(C)ST(−C)P. Substitute செய்து கணக்கிடவும்: x′ = 1+0.5×(-1−(1)) = 0; y′ = 1+2×(5−(1)) = 9. **விடை: (0,9) coordinate units.**
:::

## Digital image-ஐ அமைத்தலும் workspace-ஐ அறிதலும்

வரைவதற்கு முன் physical width, height, pixel dimensions அல்லது resolution, colour depth, colour mode ஆகியவற்றை அமைக்கவும். Physical size அதேபடி இருக்கும்போது pixels per inch அதிகரித்தால் pixel dimensions-உம் memory-உம் அதிகரிக்கும். Pixel dimensions அதேபடி இருந்தால் print resolution-ஐ மாற்றுவது physical print size-ஐ மாற்றும். PDF resolution-ஐ “pixels per square inch” என்கிறது. வழக்கமான linear unit **pixels per inch**; width, height இரண்டிலும் தனித்தனியாக அளவிடுகிறோம். ஓரிடத்தில் CMYK என்பதை CYMK எனவும் எழுதியுள்ளது.

ஒளி வெளியிடும் screen-க்கு **RGB** தேர்வு செய்யவும். அது additive colour. Ink மூலம் print செய்யத் தகுந்த **CMYK** workflow பயன்படுத்தவும். அது subtractive colour. Grayscale தனித்தனி colour channels இல்லாமல் சாம்பல் shades காட்டும். Photoshop-இல் File → New setup dialog-ஐத் திறக்கும். Figure 6.6 உதாரணத்தில் width, height, resolution, colour mode, background அமைக்கப்படுகின்றன.

Figure 6.7 workspace-இல் task அடிப்படையில் commands கொண்ட **menu bar**, active tool-க்கான **options bar**, **toolbox**, **active image area**, palettes-ஐ ஒழுங்குபடுத்தும் **palette well**, image-ஐப் பார்வையிட்டு மாற்றும் **palettes/panels** உள்ளன. Source பழைய Photoshop version-ஐக் காட்டுகிறது. வேறு version-இல் panel பெயரும் இடமும் மாறலாம்.

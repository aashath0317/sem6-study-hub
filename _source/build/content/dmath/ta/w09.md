## இருமத் தொடர்புகள்

கண மூலகங்களுக்கிடையிலான தொடர்புகள் எங்கும் உள்ளன. தொடர்புடைய மூலகங்களின் **வரிசைச் சோடிகளாக** அவை வெளிப்படுத்தப்படுவதால், வரிசைச் சோடிகளின் கணம் ஓர் **இருமத் தொடர்பு**.

:::key வரையறை 1
**A-இலிருந்து B-க்கான இருமத் தொடர்பு**, **A × B-இன் உட்கணம்**. **a ∈ A**, **b ∈ B** உடைய (a, b) வரிசைச் சோடிகளின் கணம் R.

- **a R b** என்பது (a, b) ∈ R: "R-ஆல் a, b-உடன் தொடர்புடையது".
- **a R̸ b** என்பது (a, b) ∉ R.
:::

:::example எடுத்துக்காட்டு 9.1.1 — நண்பர்களும் நகரங்களும்
- A = உங்கள் நண்பர்கள்; B = இலங்கையின் முக்கிய நகரங்கள்.
- நண்பர் a, நகரம் b-க்குச் சென்றிருந்தால் (a, b) ∈ R.
- Kolitha, Sneha காலிக்குச் சென்றிருந்தால் (Kolitha, Galle), (Sneha, Galle) ஆகியவை R-இல் உள்ளன. Sneha கண்டிக்குச் செல்லாவிட்டால் (Sneha, Kandy) ∉ R.
- **எந்த** நகரத்துக்கும் செல்லாத நண்பர் **எந்தச்** சோடியிலும் தோன்றுவதில்லை. யாரும் செல்லாத நகரம் ஒருபோதும் இரண்டாவது மூலகமாக வராது.
:::

:::example எடுத்துக்காட்டு 9.1.2 — பட்டப்படிப்புகளும் பல்கலைக்கழகங்களும்
பல்கலைக்கழகம் b, படிப்பு a-ஐ வழங்கினால் (a, b) ∈ R.

- **R-இல் உள்ளவை:** (மருத்துவம், கொழும்பு), (பொறியியல், மொரட்டுவை), (முகாமைத்துவம், ஸ்ரீ ஜயவர்த்தனபுர), (கலை, ருஹுணு), (பௌதிக அறிவியல்கள், களனி)
- **R-இல் இல்லாதவை:** (பொறியியல், களனி), (கட்டடக் கலை, பேராதனை)
:::

## தொடர்புகளாகச் சார்புகள்

- **f : A → B சார்பு** ஒரு தொடர்பு: அதன் வரைபு {(a, b) | b = f(a)} ⊆ A × B.
- **A-இன் ஒவ்வொரு மூலகமும் துல்லியமாக ஒரு சோடியின் முதல் மூலகமாக** இருக்கும் சிறப்புத் தொடர்பு.
- மாறாக, அந்தப் பண்புள்ள எந்தத் தொடர்பும் சார்பை வரையறுக்கிறது.

:::example எடுத்துக்காட்டுகள் 9.2.1, 9.2.2
- A = {1, 2, 3, 4}, B = {1, 4, 9, 16}; b = a² எனில் (a, b) ∈ R. அப்போது R = {(1, 1), (2, 4), (3, 9), (4, 16)}. இது **சார்பு** (உண்மையில் ஒன்றுக்கொன்றானது).
- A = {a, b, c, d}, B = {1, 2, 3, 4, 5}, R = {(a, 2), (b, 3), (c, 4), (d, 5)}. A-இன் ஒவ்வொரு மூலகமும் துல்லியமாக ஒருமுறை தோன்றுவதால் இது **சார்பு**.
:::

:::key தொடர்புகள் சார்புகளைப் பொதுமைப்படுத்துகின்றன
தொடர்பு **ஒன்றுக்குப் பலவாக** இருக்கலாம்: A-இன் ஒரு மூலகம் B-இன் **பல** மூலகங்களுடன் தொடர்புடையதாக இருக்கலாம். சார்புகளால் அவ்வாறு முடியாது.
:::

## ஒரு கணத்தின் மீதான தொடர்புகள்

:::key வரையறை 2
**A கணத்தின் மீதான தொடர்பு**, A-இலிருந்து A-க்கான தொடர்பு: **A × A-இன்** உட்கணம்.
:::

:::example எடுத்துக்காட்டு 9.3.1 — A = {1, 2, 3, 4}-இல் "வகுக்கிறது"
R = {(a, b) | a, b-ஐ வகுக்கிறது} = {(1, 1), (1, 2), (1, 3), (1, 4), (2, 2), (2, 4), (3, 3), (4, 4)}
:::

:::example எடுத்துக்காட்டு 9.3.2 — முழு எண்களில் தொடர்புகள்
| தொடர்பு | விதி | (1,1) | (1,2) | (2,1) | (1,−1) | (2,2) |
|---|---|---|---|---|---|---|
| R₁ | a ≤ b | ✓ | ✓ | | | ✓ |
| R₂ | a > b | | | ✓ | ✓ | |
| R₃ | a = b அல்லது a = −b | ✓ | | | ✓ | ✓ |
| R₄ | a = b | ✓ | | | | ✓ |
| R₅ | a = b + 1 | | | ✓ | | |
| R₆ | a + b ≤ 3 | ✓ | ✓ | ✓ | ✓ | |
:::

## பண்புகள்: தற்சுட்டு, சமச்சீர், கடத்தல்

| பண்பு | வரையறை | சொற்களில் | திசைவரைபுக் காட்சி |
|---|---|---|---|
| **தற்சுட்டு** (வரையறை 3) | **ஒவ்வொரு** a ∈ A-க்கும் (a, a) ∈ R | ஒவ்வொரு மூலகமும் அதனுடன் தொடர்புடையது | **ஒவ்வொரு** கணுவிலும் **வளையம்** |
| **சமச்சீர்** (வரையறை 4) | (a, b) ∈ R ⇒ (b, a) ∈ R | ஒவ்வொரு தொடர்பும் இரு திசைகளிலும் செல்கிறது | ஒவ்வொரு அம்புக்கும் **திரும்பும் அம்பு** |
| **கடத்தல்** (வரையறை 5) | (a, b) ∈ R, (b, c) ∈ R ⇒ (a, c) ∈ R | இரு படிப் பாதை நேரடி இணைப்பைக் குறிக்கிறது | ஒவ்வொரு 2-படிப் பாதைக்கும் **குறுக்குவழி** |

:::example தற்சுட்டு — {1, 2, 3, 4}-இல் எடுத்துக்காட்டு 9.4.2
- R₁ = {(1,1), (1,2), (2,1), (2,2), (3,4), (4,1), (4,4)}
- R₂ = {(1,1), (1,2), (2,1)}
- R₃ = {(1,1), (1,2), (1,4), (2,1), (2,2), (3,3), (4,1), (4,4)}
- R₄ = {(2,1), (3,1), (3,2), (4,1), (4,2), (4,3)}
- R₅ = {(1,1), (1,2), (1,3), (1,4), (2,2), (2,3), (2,4), (3,3), (3,4), (4,4)}
- R₆ = {(3,4)}

**R₃, R₅ தற்சுட்டானவை**: (1,1), (2,2), (3,3), (4,4) அனைத்தையும் கொண்டுள்ளன. மற்றவை **அல்ல**: R₁, R₂, R₄, R₆ எதிலும் (3,3) இல்லை.

*மேலும் (9.4.1):* "x, y ஒரே தாயையும் தந்தையையும் கொண்டவர்கள்" என்பது தற்சுட்டு; ஏனெனில் ஒவ்வொருவரும் தம்முடன் தொடர்புடையவர்.
:::

:::example சமச்சீர்
- "a, b-இன் நண்பர்" (9.4.3): x, y-இன் நண்பர் எனில் y, x-இன் நண்பர். **சமச்சீர்.**
- {1, 3, 5}-இல் R = {(1,1), (1,3), (3,1), (5,3), (3,5), (3,3)} (9.4.4): ஒவ்வொரு சோடிக்கும் அதன் எதிர் உள்ளது. **சமச்சீர்.**
- ℕ-இல் a < b (9.4.5): 1 < 2; ஆனால் 2 < 1 அல்ல. **சமச்சீரல்ல.**
:::

:::example கடத்தல்
- "ஒரே சொந்த ஊர்" (9.4.6): x, y ஒரே சொந்த ஊரையும் y, z ஒரே சொந்த ஊரையும் கொண்டால் x, z-உம் அவ்வாறே. **கடத்தல்.**
- {p, q, r}-இல் R = {(p, q), (q, r), (p, r)} (9.4.7): p→q→r; p→r உள்ளது. **கடத்தல்.**
:::

{{tool:rl2}}

:::tip விரைவான சரிபார்ப்பு முறை
- **தற்சுட்டு:** ஒவ்வொரு (a, a)-ஐயும் தேடவும். ஒரு வளையம் விடுபட்டால் தற்சுட்டல்ல.
- **சமச்சீர்:** ஒவ்வொரு (a, b)-க்கும் (b, a)-ஐத் தேடவும்.
- **கடத்தல்:** ஒவ்வொரு (a, b)-க்கும் b-இல் தொடங்கும் ஒவ்வொரு சோடியையும், எ.கா. (b, c), பார்க்கவும். அப்போது (a, c) இருக்க வேண்டும்.
- ஒரு பண்பு தோல்வியுறுகிறது எனக் காட்ட **ஓர் எதிர் எடுத்துக்காட்டு போதும்**. எந்தச் சோடி மீறுகிறது எனக் கூறவும்.
:::

## சமானத் தொடர்புகள்

:::key வரையறை
A-இன் மீதான தொடர்பு **தற்சுட்டு, சமச்சீர், கடத்தல்** ஆகிய மூன்றும் உடையதெனில் அது **சமானத் தொடர்பு**.
:::

:::example எடுத்துக்காட்டு 9.4.8
{1, 2, 3}-இல் R = {(1,1), (2,2), (3,3), (1,2), (2,1), (2,3), (3,2), (1,3), (3,1)} தற்சுட்டு, சமச்சீர், கடத்தல் உடையதால் **சமானத் தொடர்பு**.
:::

:::example எடுத்துக்காட்டு 9.4.9 — ℤ-இல் 7 | (a − b) எனில் a R b
- **தற்சுட்டு:** a − a = 0, இது 7-ஆல் வகுபடும். எனவே a R a. ✓
- **சமச்சீர்:** 7 | (a − b) எனில் b − a = −(a − b)-உம் 7-ஆல் வகுபடும். எனவே a R b ⇒ b R a. ✓
- **கடத்தல்:** 7 | (a − b), 7 | (b − c) எனில் a − c = (a − b) + (b − c), 7-ஆல் வகுபடும். எனவே a R b, b R c ⇒ a R c. ✓

எனவே R **சமானத் தொடர்பு**. இது வாரம் 6-இன் **மட்டு 7 சமானம்**. அதன் "வகுப்புகள்" சமான வகுப்புகள்.
:::

:::tip சமானத் தொடர்புகளை அடையாளம் காணுதல்
**"ஒரே ___ கொண்டது"** என்ற வடிவிலுள்ள தொடர்புகள் பொதுவாகச் சமானத் தொடர்புகள்: ஒரே சொந்த ஊர், ஒரே பிறந்தநாள், ஒரே பெற்றோர், ஒரே மட்டு m மீதி. கோடுகளுக்குத் தற்சுட்டு தேவைப்பட்டால், **சமாந்தரக் கோடுகளுடன் ஒன்றன்மேல் ஒன்று பொருந்தும் கோடுகளையும்** சேர்க்கவும்; வெவ்வேறு கோடுகளின் சமாந்தரத்தன்மை மட்டும் தற்சுட்டல்ல.

**≤, <, வகுக்கிறது, "இவரைவிட உயரமானவர்"** போன்றவை **அல்ல**: சமச்சீரில் தோல்வியுறுகின்றன.
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- தொடர்பின் சோடிகளைப் பட்டியலிடுதல் (எ.கா. கொடுக்கப்பட்ட கணங்களில் a > b, a + b = 4, a | b)
- அம்பு வரைபடத்தையும் அட்டவணையையும் வரைதல்
- கொடுக்கப்பட்ட சோடிக் கணங்களுக்கு **காரணங்களுடன் தற்சுட்டு / சமச்சீர் / கடத்தல்** தீர்மானித்தல்
- நிஜவாழ்க்கைத் தொடர்புகளுக்கு இந்தப் பண்புகளைத் தீர்மானித்தல் ("உயரமானவர்", "ஒரே பிறந்தநாள்", "பொதுவான பாட்டன் அல்லது பாட்டி")
- எடுத்துக்காட்டு 9.4.9 போல, தொடர்பு சமானத் தொடர்பு என **நிறுவுதல்** (சமாந்தரக் கோடுகள்; m | (a − b))
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|
| இருமத் தொடர்பு | A × B-இன் உட்கணம்; a R b ⇔ (a, b) ∈ R |
| பிரதிநிதித்துவங்கள் | வரிசைச் சோடிகள் · அம்பு வரைபடம் · அட்டவணை / 0–1 அணி |
| சார்பு | ஒவ்வொரு a-உம் முதல் மூலகமாகத் துல்லியமாக ஒருமுறை தோன்றும் தொடர்பு |
| A-இன் மீதான தொடர்பு | A × A-இன் உட்கணம் |
| தற்சுட்டு | அனைத்து a-க்கும் (a, a): எங்கும் வளையங்கள் |
| சமச்சீர் | (a, b) ⇒ (b, a) |

**Q1.** A binary relation from A to B is a subset of:

(a) A − B (b) A ∪ B (c) A ∩ B (d) A × B

**✅ Answer: (d) A × B**

A × B (Cartesian product) = **all ordered pairs (a, b)** with a from A and b from B. A relation just picks some of those pairs.


**Q2.** A = {1, 2, 3, 4}, B = {x, y, z}. Which is **not** a relation from A to B?

(a) {(3, x), (4, x)} (b) {(1, x), (2, y), (4, z)} (c) {(1, x), (1, y), (1, z), (4, z)} (d) {(2, y), (3, z), (y, 4)}

**✅ Answer: (d) — the pair (y, 4) is backwards**

In a relation **from A to B**, every pair must be **(something from A, something from B)**.
(y, 4) has a letter first and a number second, so it is not in A × B.
One element of A may appear many times (option c is fine).


**Q3.** Which relation (on integers) contains the pair (1, 2)?

(a) a = b (b) a ≤ b (c) a > b (d) a = b or a = −b

**✅ Answer: (b) {(a, b) | a ≤ b}**

Put a = 1, b = 2 into each rule: 1 = 2 ✗; **1 ≤ 2 ✓**; 1 > 2 ✗; 1 = ±2 ✗.


**Q4.** True or false: R on A is **reflexive** if (a, a) ∈ R for every a ∈ A.

**✅ Answer: True**

**The four properties (memorise):**

- **Reflexive:** every element is related to itself — (a, a) for **every** a.
- **Symmetric:** if (a, b) is in, then (b, a) is in.
- **Antisymmetric:** (a, b) and (b, a) both in only when a = b.
- **Transitive:** if (a, b) and (b, c) are in, then (a, c) is in.


**Q5.** Which relation on {1, 3, 5} is **reflexive**?

(a) {(1,1), (1,5), (5,3)} (b) {(1,1), (1,3), (3,1), (3,3)} (c) {(1,3), (1,5), (3,1), (3,3), (5,3), (5,5)} (d) {(1,1), (1,5), (3,1), (3,3), (5,5)}

**✅ Answer: (d)**

**Checklist:** reflexive needs **all** of (1,1), (3,3), (5,5).

- (a) missing (3,3), (5,5) (b) missing (5,5) (c) missing (1,1)
- (d) has (1,1), (3,3), (5,5) ✓ (extra pairs are allowed).


**Q6.** R = {(a, b) | a < b} on the natural numbers. Which is true?

(a) R is transitive (b) R is symmetric (c) none (d) neither symmetric nor transitive

**✅ Answer: (a) R is transitive**

- **Transitive?** If a < b and b < c then a < c ✓.
- **Symmetric?** 1 < 2 is true but 2 < 1 is false ✗.
- (Also not reflexive: 1 < 1 is false.)


**Q7.** Which relation on {1, 2, 3, 4} is an **equivalence relation**?

(a) {(2,4), (4,2)} (b) {(1,1), (1,2), (2,1), (2,2), (3,3), (4,4)} (c) {(2,2), (2,3), (2,4), (3,2), (3,3), (3,4)}

**✅ Answer: (b)**

**Equivalence relation = Reflexive + Symmetric + Transitive (R-S-T).**

- (b) Reflexive: (1,1), (2,2), (3,3), (4,4) all there ✓. Symmetric: (1,2) and (2,1) ✓. Transitive: (1,2),(2,1) → (1,1) ✓ and (2,1),(1,2) → (2,2) ✓.
- (a) not reflexive (no (1,1)). (c) not reflexive (no (1,1)) and not symmetric ((2,4) without (4,2)).

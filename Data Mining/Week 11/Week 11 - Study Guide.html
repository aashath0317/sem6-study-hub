1Classification vs prediction

Class மற்றும் எண்ணை கணிப்பது

Spam அல்லது not spam போன்ற label கணிப்பது Classification. அடுத்த மாத விற்பனைத் தொகை போன்ற தொடர்ச்சியான எண்ணைக் கணிப்பது இப்பாடத்தில் Prediction. Output வகை முறைத் தேர்வை மாற்றும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

பாடத்தில் classification categorical label(yes/no/class); numeric prediction/regression continuous value. இரண்டும் labelled examples-இலிருந்து learn செய்யலாம். Modern usage-இல் “prediction” class prediction-ஐயும் உள்ளடக்கும் broader word; course comparison-இல் numeric prediction என்று தெளிவாக்குங்கள். Clustering label இல்லாமல் groups தேடும் வேறு task.

Both build a model from data to describe data classes or predict future trends.

Classification

Predicts categorical (discrete, unordered) class labels.

  • Bank: is a loan applicant "safe" or "risky"?
  • Medical: should a patient get treatment A, B or C?

Prediction (numeric)

Predicts a continuous-valued (ordered) attribute.

  • Bank: what loan amount (in $) is safe for this applicant?

There's no "class label" here. We call it the predicted attribute and build a predictor.

Key terms

Term Meaning
Tuple X An n-dimensional attribute vector X = (x₁, x₂, …, xₙ), with values for attributes A₁ … Aₙ
Class label attribute The attribute giving each tuple's predefined class; discrete and unordered
Training tuples Tuples used to build the model. Also called samples, examples, instances, data points, objects
Supervised learning The class label of each training tuple is given. Classification works this way
Unsupervised learning (clustering) Class labels are not known, and often the number of classes isn't either. E.g. find "groups of like tuples" that might be risk groups

இரண்டும் தரவு வகுப்புகளை விவரிக்க அல்லது எதிர்காலப் போக்குகளை முன்னறிவிக்க, தரவிலிருந்து மாதிரியை உருவாக்குகின்றன.

வகைப்படுத்தல்

வகைசார் (தனித்த, வரிசையற்ற) வகுப்பு அடையாளங்களை முன்னறிவிக்கிறது.

  • வங்கி: கடன் விண்ணப்பதாரர் "பாதுகாப்பானவரா" அல்லது "இடருள்ளவரா"?
  • மருத்துவம்: நோயாளிக்கு சிகிச்சை A, B அல்லது C வழங்க வேண்டுமா?

முன்னறிவிப்பு (எண்ணியல்)

தொடர்ச்சியான பெறுமதியுள்ள (வரிசைப்படுத்தப்பட்ட) பண்புக்கூற்றை முன்னறிவிக்கிறது.

  • வங்கி: இந்த விண்ணப்பதாரருக்கு எந்த கடன் தொகை ($-இல்) பாதுகாப்பானது?

இங்கு "வகுப்பு அடையாளம்" இல்லை. அதை முன்னறிவிக்கப்படும் பண்புக்கூறு என அழைத்து முன்னறிவிப்பியை உருவாக்குகிறோம்.

மேற்பார்வைக் கற்றல் ஒவ்வொரு பயிற்சி வரிசையின் வகுப்பு அடையாளமும் வழங்கப்பட்டுள்ளது. வகைப்படுத்தல் இவ்வாறு செயல்படுகிறது

2The two-step classification process

Classification இரண்டு படிகள்

Label தெரிந்த training examples-இலிருந்து model கற்போம். பின்னர் தெரியாத examples-இல் சோதிப்போம். Train செய்த அதே records-இல் மட்டும் accuracy பார்த்தால் திறனை அதிகமாக மதிப்பிடலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

இரண்டு stages: training labelled data மூலம் model construction; unseen independent test data மூலம் model usage/evaluation. Train-set accuracy மட்டும் generalisation estimate அல்ல; memorisation/overfitting அதிக score தரலாம். Test set-ஐ repeatedly tune செய்ய பயன்படுத்தினால் அதுவும் leakage; validation/CV பயன்படுத்தி final test தனியே வைத்திருக்கவும்.

Step 1 – Learning: training data → classification algorithm → classifier (e.g. rules)Step 2 – Classification: test data → estimate accuracy → classify new data

Step 1: learning (training phase). The algorithm analyses a training set of tuples with their class labels and builds a classifier. In the loan example the classifier is a set of classification rules:

IF age = youth THEN loan_decision = risky
IF income = high THEN loan_decision = safe
IF age = middle_aged AND income = low THEN loan_decision = risky

Step 2: classification. First estimate predictive accuracy on a test set.

Why not test on the training data?

That estimate would be optimistic, because the classifier overfits: it learns particular anomalies of the training data that aren't in the general data. So the test set must be randomly selected and independent of the training tuples.

Accuracy = % of test-set tuples correctly classified

If the accuracy is acceptable, the classifier labels future ("unknown", "previously unseen") tuples, e.g. approving or rejecting new loan applicants.

படி 1 – கற்றல்: பயிற்சித் தரவு → வகைப்படுத்தல் படிமுறை → வகைப்படுத்தி (எ.கா. விதிகள்)படி 2 – வகைப்படுத்தல்: சோதனைத் தரவு → துல்லியத்தை மதிப்பிடு → புதிய தரவை வகைப்படுத்து

படி 1: கற்றல் (பயிற்சிக் கட்டம்). படிமுறை வகுப்பு அடையாளங்களுடனான பயிற்சி வரிசைத் தொகுப்பைப் பகுப்பாய்வு செய்து, வகைப்படுத்தியை உருவாக்குகிறது. கடன் எடுத்துக்காட்டில் வகைப்படுத்தி வகைப்படுத்தல் விதிகளின் தொகுப்பு:

வயது = இளைஞர் எனில் கடன்_முடிவு = இடருள்ளது
வருமானம் = அதிகம் எனில் கடன்_முடிவு = பாதுகாப்பானது
வயது = நடுத்தர_வயது மற்றும் வருமானம் = குறைவு எனில் கடன்_முடிவு = இடருள்ளது

படி 2: வகைப்படுத்தல். முதலில் சோதனைத் தொகுப்பில் முன்னறிவிப்புத் துல்லியத்தை மதிப்பிடவும்.

பயிற்சித் தரவிலேயே ஏன் சோதிக்கக்கூடாது?

அந்த மதிப்பீடு மிகையான நம்பிக்கையுள்ளதாக இருக்கும்; ஏனெனில் வகைப்படுத்தி மிகைப்பொருத்தமடைகிறது: பொதுவான தரவில் இல்லாத பயிற்சித் தரவின் குறிப்பிட்ட ஒழுங்கின்மைகளைக் கற்கிறது. எனவே சோதனைத் தொகுப்பு சீரற்ற முறையில் தேர்ந்தெடுக்கப்பட்டு, பயிற்சி வரிசைகளிலிருந்து சுயாதீனமாக இருக்க வேண்டும்.

துல்லியம் = சரியாக வகைப்படுத்தப்பட்ட சோதனைத் தொகுப்பு வரிசைகளின் %

துல்லியம் ஏற்கத்தக்கதாக இருந்தால், எதிர்கால ("தெரியாத", "முன்னர் காணப்படாத") வரிசைகளுக்கு வகைப்படுத்தி அடையாளமிடுகிறது; எ.கா. புதிய கடன் விண்ணப்பதாரர்களை ஏற்றல் அல்லது நிராகரித்தல்.

Preprocessing for classification

Step What and why
Data cleaning Reduce noise (smoothing) and treat missing values (most common value or most probable value). Reduces confusion during learning
Relevance analysis Correlation analysis removes redundant attributes (if A1 and A2 are strongly correlated, drop one). Attribute relevance analysis removes irrelevant ones, which would slow down and mislead learning
Transformation and reduction Normalization for neural networks and distance-based methods, so large-range attributes (income) don't outweigh small-range ones (binary). Generalization via concept hierarchies (income → low/medium/high, street → city) compresses data, so there is less I/O

Criteria to compare classifiers and predictors

Criterion Meaning
Accuracy Ability to correctly predict the class (or value) of new, unseen data. It's an estimate, so confidence limits can be computed
Speed Computational cost of building and using the model
Robustness Correct predictions on noisy data or data with missing values
Scalability Builds efficiently from large amounts of data
Interpretability Understanding and insight the model gives. Subjective, so harder to assess (e.g. extracting rules from a "black box" backpropagation neural network)

ID3, C4.5 and CART all use a greedy (non-backtracking), top-down recursive divide-and-conquer approach. The training set is recursively partitioned into smaller subsets as the tree grows.

Basic algorithm (Figure 11-4) in plain words

  1. Create node N.
  2. If all tuples in D are in the same class → N becomes a leaf with that class.
  3. If there are no attributes left → leaf labelled with the majority class.
  4. Otherwise, use an attribute selection measure to find the best splitting criterion, label N with it, and remove the attribute if it was discrete with multiway splits.
  5. For each outcome j, form partition Dⱼ. If Dⱼ is empty → attach a leaf with the majority class of D. Otherwise recurse on Dⱼ.

ID3, C4.5, CART அனைத்தும் பேராசை (பின்செல்லாத), மேலிருந்து கீழ் மறுசுழற்சிப் பிரித்தாளும் அணுகுமுறையைப் பயன்படுத்துகின்றன. மரம் வளரும்போது பயிற்சித் தொகுப்பு சிறிய உட்கணங்களாக மறுசுழற்சியாகப் பிரிக்கப்படுகிறது.

அடிப்படைப் படிமுறை (படம் 11-4) எளிய சொற்களில்

  1. N கணுவை உருவாக்கவும்.
  2. D-இன் அனைத்து வரிசைகளும் ஒரே வகுப்பில் இருந்தால் → N அந்த வகுப்புடைய இலையாகிறது.
  3. பண்புக்கூறுகள் எதுவும் மீதமில்லை எனில் → பெரும்பான்மை வகுப்பு அடையாளத்துடன் இலை.
  4. இல்லாவிட்டால் பண்புக்கூறுத் தேர்வு அளவையால் சிறந்த பிரிப்பளவுகோலைக் கண்டறிந்து, N-க்கு அதையே அடையாளமிடவும்; பல்வழிப் பிரிப்புகளுள்ள தனித்த பண்புக்கூறாக இருந்தால் பண்புக்கூற்றை நீக்கவும்.
  5. ஒவ்வொரு விளைவு j-க்கும் Dⱼ பிரிவை உருவாக்கவும். Dⱼ வெற்றாக இருந்தால் → D-இன் பெரும்பான்மை வகுப்புடன் இலையை இணைக்கவும். இல்லாவிட்டால் Dⱼ-இல் மறுசுழற்சி செய்யவும்.

5Attribute selection measures

சிறந்த split எது?

Class-களைச் சுத்தமாகப் பிரிக்கும் attribute-ஐத் தேர்ந்தெடுக்க Information gain, gain ratio, Gini போன்ற அளவுகள் பயன்படும். Pure group-இல் எல்லாரும் ஒரே class; uncertainty குறைவு.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Entropy(S)=−Σpᵢlog₂pᵢ; Gain=parent entropy−weighted child entropy. ID3 அதிக gain தேர்வு செய்யும்; பல distinct values கொண்ட attribute-க்கு bias இருக்கலாம். Gain ratio=Gain/SplitInfo, C4.5 அந்த bias-ஐக் குறைக்க முயலும். Gini=1−Σpᵢ²; split பிறகு weighted Gini குறைவாக இருப்பது நல்லது. Gain-இல் பெரியது, impurity-இல் சிறியது என்று திசையை மாற்றிப் புரியாதீர்கள்.

விரிவான விளக்கம் · கணக்கும் தேர்வுப் புள்ளிகளும்

Entropy H=−Σp log₂p; Gain=H(parent)−Σweight×H(child). 0log0=0 convention. SplitInfo partition-size entropy; gain ratio=Gain/SplitInfo (denominator0 என்றால் அந்த split செல்லாது). பல values/unique ID-க்கு information-gain bias உண்டு. Gini=1−Σp², weighted child Gini குறைந்த split. v categorical values-க்கு distinct unordered binary splits (2ᵛ−2)/2. Gini impurity தானாக binary-only அல்ல; CART இந்தப் பாடத்தில் binary trees பயன்படுத்துகிறது.

An attribute selection measure (or splitting rule) is a heuristic for choosing the split that best separates D into classes. Ideally every partition is pure (one class). The measure ranks the attributes, and the best one is the splitting attribute. For continuous attributes we also need a split point; for binary trees, a splitting subset.

Measure Used by Split type
Information gain ID3 Multiway
Gain ratio C4.5 Multiway
Gini index CART Binary

Information gain (ID3)

Based on Claude Shannon's information theory. Choose the attribute with the highest gain: it minimises the information still needed (least impurity) and so the expected number of tests.

Info(D) = − Σi=1..m pi log₂(pi) (entropy of D)
InfoA(D) = Σj=1..v ( |Dj| / |D| ) × Info(Dj)
Gain(A) = Info(D) − InfoA(D)
  • pi = |Ci,D| / |D| = probability that a tuple belongs to class Ci.
  • |Dⱼ|/|D| is the weight of partition j.

Gain ratio (C4.5)

Information gain is biased

It prefers attributes with many values. Splitting on a unique product_ID gives one pure partition per tuple, so Info = 0 and the gain is maximal, yet the split is useless for classification.

C4.5 normalises gain using split information: the potential information from splitting D into v partitions, regardless of class.

SplitInfoA(D) = − Σj=1..v ( |Dj| / |D| ) × log₂( |Dj| / |D| )
GainRatio(A) = Gain(A) / SplitInfoA(D)

Pick the attribute with the maximum gain ratio.

Gini index (CART)

Gini(D) = 1 − Σi=1..m pi²
GiniA(D) = ( |D₁| / |D| ) Gini(D₁) + ( |D₂| / |D| ) Gini(D₂) (binary split)
ΔGini(A) = Gini(D) − GiniA(D)
  • CART in this course considers binary splits; the Gini impurity itself can also be used to score partitions with other arities. For a discrete attribute with v values there are 2ᵛ subsets. Excluding the full set and the empty set leaves 2ᵛ − 2 subsets. Each split appears twice ({low} vs {medium, high} is the same split), so there are (2ᵛ − 2)/2 distinct binary splits.
  • For continuous attributes, try the midpoint between each pair of adjacent sorted values as the split point: D₁ = A ≤ split, D₂ = A > split.
  • Choose the attribute and split with the minimum GiniA(D), i.e. the maximum reduction in impurity.

பண்புக்கூறுத் தேர்வு அளவை (அல்லது பிரிப்பு விதி) என்பது D-ஐ வகுப்புகளாக மிகச்சிறப்பாகப் பிரிக்கும் பிரிவைத் தேர்ந்தெடுக்கும் அனுபவவழி. ஒவ்வொரு பிரிவும் தூய்மையாக (ஒரு வகுப்பு) இருப்பது இலட்சியம். அளவை பண்புக்கூறுகளைத் தரவரிசைப்படுத்துகிறது; சிறந்தது பிரிப்புப் பண்புக்கூறு. தொடர்ச்சியான பண்புக்கூறுகளுக்கு பிரிப்புப் புள்ளியும் தேவை; இரும மரங்களுக்கு பிரிக்கும் உட்கணமும் தேவை.

தகவல் ஆதாயம் (ID3)

Claude Shannon-இன் தகவல் கோட்பாட்டை அடிப்படையாகக் கொண்டது. அதிக ஆதாயமுள்ள பண்புக்கூற்றைத் தேர்ந்தெடுக்கவும்: அது இன்னும் தேவைப்படும் தகவலைக் குறைத்து (குறைந்த தூய்மையின்மை), எதிர்பார்க்கப்படும் சோதனை எண்ணிக்கையையும் குறைக்கிறது.

Info(D) = − Σi=1..m pi log₂(pi) (D-இன் என்ட்ரோப்பி)
InfoA(D) = Σj=1..v ( |Dj| / |D| ) × Info(Dj)
Gain(A) = Info(D) − InfoA(D)
  • pi = |Ci,D| / |D| = வரிசை Ci வகுப்பைச் சாரும் நிகழ்தகவு.
  • |Dⱼ|/|D| என்பது j பிரிவின் நிறை.

ஆதாய விகிதம் (C4.5)

தகவல் ஆதாயம் சார்புடையது

அது பல பெறுமதிகளுள்ள பண்புக்கூறுகளை விரும்புகிறது. தனித்துவமான product_ID-இல் பிரிப்பது வரிசைக்கு ஒரு தூய பிரிவை வழங்குவதால் Info = 0; ஆதாயம் அதிகபட்சம்; இருப்பினும் வகைப்படுத்தலுக்கு அந்தப் பிரிப்பு பயனற்றது.

பிரிப்புத் தகவலால் C4.5 ஆதாயத்தை இயல்பாக்குகிறது: வகுப்பைப் பொருட்படுத்தாமல் D-ஐ v பிரிவுகளாகப் பிரிப்பதால் கிடைக்கும் சாத்தியத் தகவல்.

SplitInfoA(D) = − Σj=1..v ( |Dj| / |D| ) × log₂( |Dj| / |D| )
GainRatio(A) = Gain(A) / SplitInfoA(D)

அதிகபட்ச ஆதாய விகிதமுள்ள பண்புக்கூற்றைத் தேர்ந்தெடுக்கவும்.

ஜினி சுட்டெண் (CART)

Gini(D) = 1 − Σi=1..m pi²
GiniA(D) = ( |D₁| / |D| ) Gini(D₁) + ( |D₂| / |D| ) Gini(D₂) (இருமப் பிரிப்பு)
ΔGini(A) = Gini(D) − GiniA(D)
  • இந்தப் பாடத்தின் CART, இருமப் பிரிப்புகளைக் கருதுகிறது; ஜினி தூய்மையின்மையை வேறு கிளை எண்ணிக்கையுள்ள பிரிவுகளையும் மதிப்பிடப் பயன்படுத்தலாம். v பெறுமதிகளுள்ள தனித்த பண்புக்கூறுக்கு 2ᵛ உட்கணங்கள் உள்ளன. முழுக் கணத்தையும் வெற்றுக் கணத்தையும் நீக்கினால் 2ᵛ − 2 உட்கணங்கள். ஒவ்வொரு பிரிப்பும் இருமுறை வருகிறது ({low} மற்றும் {medium, high} என்பது அதே பிரிப்பு); எனவே (2ᵛ − 2)/2 வேறுபட்ட இருமப் பிரிப்புகள் உள்ளன.
  • தொடர்ச்சியான பண்புக்கூறுகளுக்கு வரிசைப்படுத்தப்பட்ட அடுத்தடுத்த ஒவ்வொரு பெறுமதிச் சோடியின் நடுப்புள்ளியையும் பிரிப்புப் புள்ளியாக முயலவும்: D₁ = A ≤ பிரிப்பு, D₂ = A > பிரிப்பு.
  • குறைந்தபட்ச GiniA(D), அதாவது தூய்மையின்மையில் அதிகபட்சக் குறைப்பு, உள்ள பண்புக்கூறையும் பிரிப்பையும் தேர்ந்தெடுக்கவும்.

சிறந்த split எது?

Class-களைச் சுத்தமாகப் பிரிக்கும் attribute-ஐத் தேர்ந்தெடுக்க Information gain, gain ratio, Gini போன்ற அளவுகள் பயன்படும். Pure group-இல் எல்லாரும் ஒரே class; uncertainty குறைவு.

Entropy(S)=−Σpᵢlog₂pᵢ; Gain=parent entropy−weighted child entropy. ID3 அதிக gain தேர்வு செய்யும்; பல distinct values கொண்ட attribute-க்கு bias இருக்கலாம். Gain ratio=Gain/SplitInfo, C4.5 அந்த bias-ஐக் குறைக்க முயலும். Gini=1−Σpᵢ²; split பிறகு weighted Gini குறைவாக இருப்பது நல்லது. Gain-இல் பெரியது, impurity-இல் சிறியது என்று திசையை மாற்றிப் புரியாதீர்கள்.

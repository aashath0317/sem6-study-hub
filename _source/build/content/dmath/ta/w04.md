## தொடரிகள்

**தொடரிகள்**, **வரிசைப்படுத்தப்பட்ட மூலகப் பட்டியல்கள்**. எண்ணல் பிரச்சினைகளைத் தீர்க்கப் பயன்படும் **தனித்த கட்டமைப்பும்**, கணினி அறிவியலில் முக்கிய **தரவுக் கட்டமைப்பும்** ஆகும்.

- 1, 3, 5, 7, 9 என்பது ஐந்து உறுப்புகளுள்ள **முடிவுள்ள** தொடரி.
- 1, 3, 9, 27, 81, …, 3ⁿ, … என்பது **முடிவற்ற** தொடரி.

:::formula
குறியீடு: {a₁, a₂, a₃, …},  {aₙ},  அல்லது  {aₙ}<sub>n=1</sub><sup>∞</sup>
:::

:::example எடுத்துக்காட்டு 4.1.1
aₙ = n / (n + 1), 1/2, 2/3, 3/4, …, n/(n+1), … உறுப்புகளை வழங்குகிறது.
:::

## பெருக்குத் தொடரிகளும் கூட்டுத் தொடரிகளும்

:::grid
**பெருக்குத் தொடரி**

a, ar, ar², …, arⁿ, …

- **a** = ஆரம்ப உறுப்பு
- **r** = **பொது விகிதம்** (ஒவ்வொருமுறையும் r-ஆல் பெருக்கவும்)

*எடுத்துக்காட்டுகள்:*
- {(−1)ⁿ}: a = 1, r = −1 → 1, −1, 1, −1, …
- {6·(1/3)ⁿ}: a = 6, r = 1/3 → 6, 2, 2/3, …
+++
**கூட்டுத் தொடரி**

a, a + d, a + 2d, …, a + nd, …

- **a** = ஆரம்ப உறுப்பு
- **d** = **பொது வித்தியாசம்** (ஒவ்வொருமுறையும் d சேர்க்கவும்)

*எடுத்துக்காட்டு:*
- {sₙ = −1 + 4n}: a = −1, d = 4 → −1, 3, 7, 11, …
:::

:::key குறிப்பு 4.1 — சரங்கள்
**முடிவுள்ள தொடரி** a₁, a₂, …, aₙ, **சரம்** என்றும் அழைக்கப்படுகிறது. சரத்தின் **நீளம்** அதன் உறுப்பு எண்ணிக்கை. *எடுத்துக்காட்டு:* "abcd" நீளம் 4 உடைய சரம்.
:::

### தொடரிக்கான சூத்திரத்தைக் கண்டறிதல் (எடுத்துக்காட்டு 4.1.2)

| உறுப்புகள் | வடிவம் | சூத்திரம் | வகை |
|---|---|---|---|
| 1, 1/2, 1/4, 1/8, 1/16 | ஒவ்வொரு உறுப்பும் முந்தையதன் பாதி | aₙ = (1/2)ⁿ, n = 0, 1, 2, … | **பெருக்குத் தொடரி**, a = 1, r = 1/2 |
| 1, 3, 5, 7, 9 | ஒவ்வொருமுறையும் 2 சேர் | aₙ = 2n + 1, n = 0, 1, 2, … | **கூட்டுத் தொடரி**, a = 1, d = 2 |
| 1, −1, 1, −1, 1 | மாறிமாறி வருகிறது | aₙ = (−1)ⁿ, n = 0, 1, 2, … | **பெருக்குத் தொடரி**, a = 1, r = −1 |

:::tip வடிவத்தைக் கண்டறிவது எப்படி
- உறுப்புகளுக்கிடையிலான **வித்தியாசங்களைச்** சரிபார்க்கவும். மாறிலி → கூட்டுத் தொடரி.
- **விகிதங்களைச்** சரிபார்க்கவும். மாறிலி → பெருக்குத் தொடரி.
- இல்லாவிட்டால் கீழுள்ள பயனுள்ள தொடரிகளுடன் ஒப்பிடவும் (வர்க்கங்கள், கனங்கள், 2ⁿ, n!); அல்லது "முந்தைய உறுப்பு(கள்) + ஏதாவது" என முயலவும்.
:::

## கூட்டுத்தொகைக் குறியீடு (Σ)

:::formula
Σ<sub>j=m</sub><sup>n</sup> a<sub>j</sub> = a<sub>m</sub> + a<sub>m+1</sub> + … + a<sub>n</sub>
:::

- **j**, **கூட்டுத்தொகைச் சுட்டெண்**. **கீழ் எல்லை m** முதல் **மேல் எல்லை n** வரையான ஒவ்வொரு முழு எண்ணிலும் செல்கிறது.
- **Σ**, கிரேக்க எழுத்தான **சிக்மாவின்** பெரிய எழுத்து.

:::key குறிப்பு 4.2 — வழக்கமான எண்கணித விதிகள் பொருந்தும்
Σ<sub>j=1</sub><sup>n</sup> (a·x<sub>j</sub> + b·y<sub>j</sub>) = a·Σ<sub>j=1</sub><sup>n</sup> x<sub>j</sub> + b·Σ<sub>j=1</sub><sup>n</sup> y<sub>j</sub>

எனவே **கூட்டுத்தொகைகளைப் பிரிக்கவும்**, **மாறிலிகளை வெளியே எடுக்கவும்** முடியும்.
:::

:::example எடுத்துக்காட்டு 4.1.2 — {1/n}-இன் முதல் 100 உறுப்புகள்
கீழ் எல்லை 1, மேல் எல்லை 100; எனவே கூட்டுத்தொகை **Σ<sub>j=1</sub><sup>100</sup> 1/j**.
:::

## பெருக்குத் தொடர் (தேற்றம் 1)

:::formula
a, r மெய்யெண்களாகவும் r ≠ 0 ஆகவும் இருந்தால்:
Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j</sup> = **(a·r<sup>n+1</sup> − a) / (r − 1)**  r ≠ 1 எனில்; **(n + 1)·a**  r = 1 எனில்
:::

**நிறுவல் வரைவு:**

1. S = Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j</sup> என்க.
2. r-ஆல் பெருக்கவும்: rS = Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j+1</sup> = Σ<sub>k=1</sub><sup>n+1</sup> a·r<sup>k</sup>.
3. k = n+1 உறுப்பை நீக்கி k = 0 உறுப்பைச் சேர்க்கவும்: rS = (Σ<sub>k=0</sub><sup>n</sup> a·r<sup>k</sup>) + (a·r<sup>n+1</sup> − a) = S + (a·r<sup>n+1</sup> − a).
4. r ≠ 1 எனில் S-க்குத் தீர்க்கவும்: **S = (a·r<sup>n+1</sup> − a)/(r − 1)**.
5. r = 1 எனில் ஒவ்வொரு உறுப்பும் a-க்குச் சமம்; எனவே S = (n + 1)a.

:::example எடுத்துக்காட்டு 4.2.1 — Σ<sub>j=0</sub><sup>8</sup> (3·2<sup>j</sup> + 2·3<sup>j</sup>)
குறிப்பு 4.2-ஆல் பிரிக்கவும்: S₁ + S₂.

- **S₁ = Σ 3·2<sup>j</sup>**; a = 3, r = 2: (3·2⁹ − 3)/(2 − 1) = 1536 − 3 = **1,533**
- **S₂ = Σ 2·3<sup>j</sup>**; a = 2, r = 3: (2·3⁹ − 2)/(3 − 1) = (39,366 − 2)/2 = **19,682**

**மொத்தம் = 1,533 + 19,682 = 21,215**
:::

## முடிவற்ற தொடர்கள் (தேற்றம் 2)

:::formula
|x| < 1 எனில்:  Σ<sub>n=0</sub><sup>∞</sup> xⁿ = **1 / (1 − x)**
:::

**நிறுவல்:** தேற்றம் 1-இல் a = 1, r = x எனில் பகுதிக் கூட்டுத்தொகை Σ<sub>n=0</sub><sup>k</sup> xⁿ = (x<sup>k+1</sup> − 1)/(x − 1). |x| < 1 என்பதால் k → ∞ எனில் x<sup>k+1</sup> → 0. எனவே கூட்டுத்தொகை → (−1)/(x − 1) = 1/(1 − x). ∎

மேலும் பொதுவாக |r| < 1 எனில் **Σ a·rⁿ = a/(1 − r)**.

:::example எடுத்துக்காட்டு 4.2.2 — Σ<sub>n=0</sub><sup>∞</sup> 2<sup>−2n</sup>·3<sup>1+n</sup>
ஒவ்வொரு உறுப்பையும் மீளெழுதவும்: 2<sup>−2n</sup>·3<sup>1+n</sup> = (1/4ⁿ)·3·3ⁿ = **3·(3/4)ⁿ**.

a = 3, r = 3/4 < 1 உடைய பெருக்குத் தொடர்; எனவே S = 3/(1 − 3/4) = 3/(1/4) = **12**.
:::

## இரட்டைக் கூட்டுத்தொகைகள்

**முதலில் உட்கூட்டுத்தொகையை**, பின்னர் வெளிக்கூட்டுத்தொகையை மதிப்பிடவும்.

:::example எடுத்துக்காட்டு 4.2.3 — Σ<sub>i=0</sub><sup>2</sup> Σ<sub>j=0</sub><sup>3</sup> i·j
- j = 0, 1, 2, 3-இல் **உட்கூட்டுத்தொகை**: i·0 + i·1 + i·2 + i·3 = 6i
- **வெளிக்கூட்டுத்தொகை**: Σ<sub>i=0</sub><sup>2</sup> 6i = 0 + 6 + 12 = **18**
:::

## பயனுள்ள மூடிய வடிவங்கள் (அட்டவணை 2)

| கூட்டுத்தொகை | மூடிய வடிவம் |
|---|---|
| Σ<sub>k=0</sub><sup>n</sup> a·r<sup>k</sup> (r ≠ 0) | (a·r<sup>n+1</sup> − a)/(r − 1), r ≠ 1 |
| Σ<sub>k=1</sub><sup>n</sup> k | **n(n + 1)/2** |
| Σ<sub>k=1</sub><sup>n</sup> k² | **n(n + 1)(2n + 1)/6** |
| Σ<sub>k=1</sub><sup>n</sup> k³ | **n²(n + 1)²/4** |
| Σ<sub>k=0</sub><sup>∞</sup> x<sup>k</sup>, \|x\| < 1 | **1/(1 − x)** |
| Σ<sub>k=1</sub><sup>∞</sup> k·x<sup>k−1</sup>, \|x\| < 1 | **1/(1 − x)²** |

:::example எடுத்துக்காட்டு 4.2.4 — Σ<sub>k=100</sub><sup>200</sup> k
"200 வரையான கூட்டுத்தொகை கழித்தல் 99 வரையான கூட்டுத்தொகை" பயன்படுத்தவும்:

Σ<sub>k=100</sub><sup>200</sup> k = Σ<sub>k=1</sub><sup>200</sup> k − Σ<sub>k=1</sub><sup>99</sup> k = (200)(201)/2 − (99)(100)/2 = 20,100 − 4,950 = **15,150**
:::

:::warn PDF பற்றிய குறிப்பு
PDF, (200)(201)/2-ஐ "201,000" என எழுதி **196,050** பெறுகிறது. அது எண்கணிதப் பிழை: 200 × 201 / 2 = **20,100**; எனவே சரியான விடை **15,150**. Σ கணிப்பானின் முதல் பொத்தானால் சரிபார்க்கவும்.
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- aₙ உறுப்புகளைக் கண்டறிதல்
- கூட்டுத் தொடரி அல்லது பெருக்குத் தொடரியையும் அதன் a, d, r-ஐயும் அடையாளம் காணுதல்
- உறுப்பு பட்டியலுக்குச் சூத்திரம் எழுதுதல்
- கூட்டுத்தொகைகளை Σ குறியீட்டில் எழுதுதல்
- **பிரித்தல் + பெருக்குத் தொடர் சூத்திரம்**, **மூடிய வடிவங்கள்**, **"n வரையான கூட்டுத்தொகை கழித்தல் m − 1 வரையான கூட்டுத்தொகை"** உத்தி ஆகியவற்றால் கூட்டுத்தொகைகளை மதிப்பிடுதல்
- முடிவற்ற பெருக்குத் தொடர்கள் (முதலில் a·rⁿ என மீளெழுதவும்)
:::

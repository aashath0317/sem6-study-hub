:::example a) முழு எண்கள் மீதான உண்மை மதிப்புகள்
| கூற்று | மதிப்பு | காரணம் |
|---|---|---|
| (∀x)(∃y)(x + y = x) | **மெய்** | y = 0 என எடுக்கவும் |
| (∃y)(∀x)(x + y = 0) | **பொய்** | ஒரே y, **ஒவ்வொரு** x இற்கும் −x ஆக இருக்க முடியாது (x = 1 இற்கு y = −1 தேவை; x = 2 இற்கு y = −2 தேவை) |

| (∃x)(∃y)(x² = y) | **மெய்** | x = 2, y = 4 |

ஒப்படை 1 உடன் ஒப்பிடவும்: ∀ மற்றும் ∃ ஐ இடமாற்றுவது பொருளை மாற்றுகிறது. ∀x∃y இல் y, x ஐச் சார்ந்திருக்கலாம்; ∃y∀x இற்கு எல்லா x இற்கும் பொருந்தும் **ஒரே** y தேவை.
:::

:::example b) f : ℤ → ℤ, f(x) = 2x − 1
**(i) உட்சார்பா: ஆம்.** f(a) = f(b) எனில், 2a − 1 = 2b − 1; ஆகவே a = b.

**(ii) மேல் சார்பா: இல்லை.** f(x) எப்போதும் **ஒற்றை எண்ணாகும்**. எடுத்துக்காட்டாக, 0 = 2x − 1 என்பது x = ½ ஐத் தருகிறது; இது முழு எண் அல்ல. எனவே 0 இற்கு முன்படிமம் இல்லை.
:::

:::example c) aRb ⇔ 3a − 7b இரட்டை எண்: ஒரு சமானத் தொடர்பு
- **தற்சுட்டு:** 3a − 7a = −4a இரட்டை எண் ✓
- **சமச்சீர்:** 3a − 7b இரட்டை எண் எனில், 3b − 7a = −(3a − 7b) − 4a − 4b இரட்டை எண் ✓
- **கடத்தல்:** 3a − 7b மற்றும் 3b − 7c இரட்டை எண்கள் எனில், அவற்றின் கூட்டுத்தொகை 3a − 4b − 7c இரட்டை எண்; எனவே 3a − 7c = (கூட்டுத்தொகை) + 4b இரட்டை எண் ✓

ஆகவே **R ஒரு சமானத் தொடர்பாகும்**. உண்மையில், **a மற்றும் b ஒரே இரட்டை/ஒற்றைத் தன்மையைக் கொண்டிருக்கும்போது மட்டுமே** aRb.
:::

## ஜனவரி 2023 — வினா 4 (வரைபுகள்)

:::example a) n ≥ 2 முனைகளைக் கொண்ட ஒவ்வொரு முடிவுறு எளிய திசையற்ற வரைபிலும் சம படியுடைய இரண்டு முனைகள் உள்ளன
- படிகள் {0, 1, …, n − 1} இல் உள்ளன; இவை n மதிப்புகள்.
- ஆனால் **0 மற்றும் n − 1 இரண்டும் இருக்க முடியாது**: மற்ற எல்லா முனைகளுடனும் இணைந்த முனை இருந்தால், தனித்த முனை எதுவும் இருக்காது.
- எனவே n முனைகளின் படிகள் அதிகபட்சம் **n − 1 வெவ்வேறு மதிப்புகளை** எடுக்கும்.
- **புறாக்கூட்டுக் கொள்கையின்படி**, இரண்டு முனைகள் ஒரே படியைப் பகிர்கின்றன. ∎
:::

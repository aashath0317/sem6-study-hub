## Sequences

**Sequences** are **ordered lists of elements**. They're a **discrete structure** used to solve counting problems, and an important **data structure** in computer science.

- 1, 3, 5, 7, 9 is a **finite** sequence with five terms.
- 1, 3, 9, 27, 81, …, 3ⁿ, … is an **infinite** sequence.

:::formula
Notation: {a₁, a₂, a₃, …},  {aₙ},  or  {aₙ}<sub>n=1</sub><sup>∞</sup>
:::

:::example Example 4.1.1
aₙ = n / (n + 1) gives the terms 1/2, 2/3, 3/4, …, n/(n+1), …
:::

## Geometric & arithmetic progressions

:::grid
**Geometric progression**

a, ar, ar², …, arⁿ, …

- **a** = initial term
- **r** = **common ratio** (multiply by r each time)

*Examples:*
- {(−1)ⁿ}: a = 1, r = −1 → 1, −1, 1, −1, …
- {6·(1/3)ⁿ}: a = 6, r = 1/3 → 6, 2, 2/3, …
+++
**Arithmetic progression**

a, a + d, a + 2d, …, a + nd, …

- **a** = initial term
- **d** = **common difference** (add d each time)

*Example:*
- {sₙ = −1 + 4n}: a = −1, d = 4 → −1, 3, 7, 11, …
:::

:::key Remark 4.1 — strings
A **finite sequence** a₁, a₂, …, aₙ is also called a **string**. The **length** of the string is its number of terms. *Example:* "abcd" is a string of length 4.
:::

### Finding a formula for a sequence (Example 4.1.2)

| Terms | Pattern | Formula | Type |
|---|---|---|---|
| 1, 1/2, 1/4, 1/8, 1/16 | Each term is half the previous one | aₙ = (1/2)ⁿ, n = 0, 1, 2, … | **Geometric**, a = 1, r = 1/2 |
| 1, 3, 5, 7, 9 | Add 2 each time | aₙ = 2n + 1, n = 0, 1, 2, … | **Arithmetic**, a = 1, d = 2 |
| 1, −1, 1, −1, 1 | Alternating | aₙ = (−1)ⁿ, n = 0, 1, 2, … | **Geometric**, a = 1, r = −1 |

:::tip How to spot the pattern
- Check the **differences** between terms. Constant → arithmetic.
- Check the **ratios**. Constant → geometric.
- Otherwise compare with the useful sequences below (squares, cubes, 2ⁿ, n!), or try "previous term(s) + something".
:::

## Summation notation (Σ)

:::formula
Σ<sub>j=m</sub><sup>n</sup> a<sub>j</sub> = a<sub>m</sub> + a<sub>m+1</sub> + … + a<sub>n</sub>
:::

- **j** is the **index of summation**. It runs through every integer from the **lower limit m** to the **upper limit n**.
- **Σ** is the upper-case Greek letter **sigma**.

:::key Remark 4.2 — the usual laws of arithmetic apply
Σ<sub>j=1</sub><sup>n</sup> (a·x<sub>j</sub> + b·y<sub>j</sub>) = a·Σ<sub>j=1</sub><sup>n</sup> x<sub>j</sub> + b·Σ<sub>j=1</sub><sup>n</sup> y<sub>j</sub>

So you can **split sums** and **pull constants out**.
:::

:::example Example 4.1.2 — first 100 terms of {1/n}
Lower limit 1, upper limit 100, so the sum is **Σ<sub>j=1</sub><sup>100</sup> 1/j**.
:::

## Geometric series (Theorem 1)

:::formula
If a and r are real and r ≠ 0:
Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j</sup> = **(a·r<sup>n+1</sup> − a) / (r − 1)**  if r ≠ 1,  and  **(n + 1)·a**  if r = 1
:::

**Proof sketch:**

1. Let S = Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j</sup>.
2. Multiply by r: rS = Σ<sub>j=0</sub><sup>n</sup> a·r<sup>j+1</sup> = Σ<sub>k=1</sub><sup>n+1</sup> a·r<sup>k</sup>.
3. Remove the k = n+1 term and add the k = 0 term: rS = (Σ<sub>k=0</sub><sup>n</sup> a·r<sup>k</sup>) + (a·r<sup>n+1</sup> − a) = S + (a·r<sup>n+1</sup> − a).
4. If r ≠ 1, solve for S: **S = (a·r<sup>n+1</sup> − a)/(r − 1)**.
5. If r = 1, every term equals a, so S = (n + 1)a.

:::example Example 4.2.1 — Σ<sub>j=0</sub><sup>8</sup> (3·2<sup>j</sup> + 2·3<sup>j</sup>)
Split using Remark 4.2: S₁ + S₂.

- **S₁ = Σ 3·2<sup>j</sup>** with a = 3, r = 2: (3·2⁹ − 3)/(2 − 1) = 1536 − 3 = **1,533**
- **S₂ = Σ 2·3<sup>j</sup>** with a = 2, r = 3: (2·3⁹ − 2)/(3 − 1) = (39,366 − 2)/2 = **19,682**

**Total = 1,533 + 19,682 = 21,215**
:::

## Infinite series (Theorem 2)

:::formula
If |x| < 1:  Σ<sub>n=0</sub><sup>∞</sup> xⁿ = **1 / (1 − x)**
:::

**Proof:** by Theorem 1 with a = 1, r = x, the partial sum is Σ<sub>n=0</sub><sup>k</sup> xⁿ = (x<sup>k+1</sup> − 1)/(x − 1). Because |x| < 1, x<sup>k+1</sup> → 0 as k → ∞. So the sum → (−1)/(x − 1) = 1/(1 − x). ∎

More generally, **Σ a·rⁿ = a/(1 − r)** when |r| < 1.

:::example Example 4.2.2 — Σ<sub>n=0</sub><sup>∞</sup> 2<sup>−2n</sup>·3<sup>1+n</sup>
Rewrite each term: 2<sup>−2n</sup>·3<sup>1+n</sup> = (1/4ⁿ)·3·3ⁿ = **3·(3/4)ⁿ**.

This is geometric with a = 3 and r = 3/4 < 1, so S = 3/(1 − 3/4) = 3/(1/4) = **12**.
:::

## Double sums

Evaluate the **inner sum first**, then the outer sum.

:::example Example 4.2.3 — Σ<sub>i=0</sub><sup>2</sup> Σ<sub>j=0</sub><sup>3</sup> i·j
- **Inner sum** over j = 0, 1, 2, 3: i·0 + i·1 + i·2 + i·3 = 6i
- **Outer sum**: Σ<sub>i=0</sub><sup>2</sup> 6i = 0 + 6 + 12 = **18**
:::

## Useful closed forms (Table 2)

| Sum | Closed form |
|---|---|
| Σ<sub>k=0</sub><sup>n</sup> a·r<sup>k</sup> (r ≠ 0) | (a·r<sup>n+1</sup> − a)/(r − 1), r ≠ 1 |
| Σ<sub>k=1</sub><sup>n</sup> k | **n(n + 1)/2** |
| Σ<sub>k=1</sub><sup>n</sup> k² | **n(n + 1)(2n + 1)/6** |
| Σ<sub>k=1</sub><sup>n</sup> k³ | **n²(n + 1)²/4** |
| Σ<sub>k=0</sub><sup>∞</sup> x<sup>k</sup>, \|x\| < 1 | **1/(1 − x)** |
| Σ<sub>k=1</sub><sup>∞</sup> k·x<sup>k−1</sup>, \|x\| < 1 | **1/(1 − x)²** |

:::example Example 4.2.4 — Σ<sub>k=100</sub><sup>200</sup> k
Use "sum up to 200 minus sum up to 99":

Σ<sub>k=100</sub><sup>200</sup> k = Σ<sub>k=1</sub><sup>200</sup> k − Σ<sub>k=1</sub><sup>99</sup> k = (200)(201)/2 − (99)(100)/2 = 20,100 − 4,950 = **15,150**
:::

### Telescoping sums (examined: 2019 and model paper)

When each term is a **difference of two consecutive values**, almost everything cancels and only the **first and last pieces** remain.

:::formula
Σ<sub>k=1</sub><sup>n</sup> [f(k) − f(k − 1)] = **f(n) − f(0)**
:::

:::example 2019 Q2(b): Σ<sub>k=1</sub><sup>n</sup> [k² − (k − 1)²]
Write out the terms: (1² − 0²) + (2² − 1²) + (3² − 2²) + ⋯ + (n² − (n − 1)²).

Each square cancels with the next bracket, leaving **n² − 0² = n²**.

*Check:* k² − (k − 1)² = 2k − 1, so this also shows 1 + 3 + 5 + ⋯ + (2n − 1) = n².
:::

:::example Model Q2(a): Σ<sub>i=0</sub><sup>n</sup> 1/((i + 1)(i + 2))
**Step 1, split the fraction** (partial fractions): 1/((i + 1)(i + 2)) = 1/(i + 1) − 1/(i + 2).

**Step 2, write out the terms:** (1 − 1/2) + (1/2 − 1/3) + ⋯ + (1/(n + 1) − 1/(n + 2)).

**Step 3, cancel:** only the first and last pieces remain: 1 − 1/(n + 2) = **(n + 1)/(n + 2)**.

*Check with n = 1:* 1/2 + 1/6 = 2/3, and (1 + 1)/(1 + 2) = 2/3 ✓
:::

:::tip Spot a telescoping sum
Look for a **difference** inside the sum, or a fraction 1/(k(k + 1)) that splits into 1/k − 1/(k + 1). Always **write the first three terms and the last one** in the exam: that is where the marks for "show the cancellation" are.
:::

:::warn Note on the PDF
The PDF writes (200)(201)/2 as "201,000" and gets **196,050**. That's an arithmetic slip: 200 × 201 / 2 = **20,100**, so the correct answer is **15,150**. Check it with the Σ calculator's first button.
:::

## Quick revision sheet

| Concept | Remember it as |
|---|---|
| Sequence | Ordered list: {aₙ} |
| Geometric | a, ar, ar², …: multiply by r |
| Arithmetic | a, a+d, a+2d, …: add d |
| String | Finite sequence; length = number of terms |
| Σ | Index j from lower m to upper n; linear, so split and factor |
| Geometric sum | (a·r<sup>n+1</sup> − a)/(r − 1); if r = 1, (n+1)a |
| Infinite geometric | a/(1 − r), \|r\| < 1 |
| Σk, Σk², Σk³ | n(n+1)/2, n(n+1)(2n+1)/6, n²(n+1)²/4 |
| Partial range | Σ<sub>m</sub><sup>n</sup> = Σ<sub>1</sub><sup>n</sup> − Σ<sub>1</sub><sup>m−1</sup> |
| Double sum | Inner first |
| Telescoping | Σ[f(k) − f(k−1)] = f(n) − f(0); split 1/((i+1)(i+2)) = 1/(i+1) − 1/(i+2) |

## Official quiz 4 — every question explained

**Q1.** Fifth term of a(n) = 2n + 3?

(a) 13 (b) −7 (c) −13 (d) 7

<details class="beginner-answer" markdown="1"><summary>Answer: (a) 13</summary>

“Fifth term” means put **n = 5**: a(5) = 2(5) + 3 = 10 + 3 = **13**.
</details>

**Q2.** Sum of the infinite series 1 + 1/3 + 1/3² + …

(a) 3/2 (b) 4/3 (c) 10/9 (d) 2

<details class="beginner-answer" markdown="1"><summary>Answer: (a) 3/2</summary>

It is **geometric**: each term is the one before × 1/3.

- First term a = 1, common ratio r = 1/3.
- **Infinite geometric sum: S = a / (1 − r)** (only when −1 < r < 1).
- S = 1 / (1 − 1/3) = 1 / (2/3) = **3/2**.
</details>

**Q3.** Sum of the first six terms of 1 + 7 + 13 + …

(a) 12 (b) 48 (c) 96 (d) 24

<details class="beginner-answer" markdown="1"><summary>Answer: (c) 96</summary>

It is **arithmetic**: add 6 each time (a = 1, d = 6).

- Quick way: list them: 1 + 7 + 13 + 19 + 25 + 31 = **96**.
- Formula: **Sₙ = n/2 × (2a + (n − 1)d)** = 6/2 × (2 + 5×6) = 3 × 32 = **96**.
</details>

**Q4.** An infinite geometric series has a sum only if the common ratio r satisfies:

(a) −1 ≤ r ≤ 1 (b) −1 < r < 1 (c) r < −1 or r > 1 (d) r ≤ −1 or r ≥ 1

<details class="beginner-answer" markdown="1"><summary>Answer: (b) −1 < r < 1 (that is, |r| < 1)</summary>

The terms must shrink towards 0. If r = 1 the terms stay the same (1 + 1 + 1 + … grows forever), so the ends are **not** included — strict “<”.
</details>

**Q5.** A simple formula for 1, 7, 25, 79, 241, 727, …

(a) 3ⁿ⁺¹ − 2 (b) 3ⁿ − 2 (c) (−3)ⁿ + 4 (d) n² − 2

<details class="beginner-answer" markdown="1"><summary>Answer: (b) aₙ = 3ⁿ − 2</summary>

**Fast method: test each option with n = 1, 2, 3.**

- (b) n = 1: 3 − 2 = 1 ✓, n = 2: 9 − 2 = 7 ✓, n = 3: 27 − 2 = 25 ✓, n = 4: 81 − 2 = 79 ✓.
- (a) n = 1: 9 − 2 = 7 ✗ (the first term must be 1).
Hint you can spot: the terms are close to powers of 3 (3, 9, 27, 81) minus 2.
</details>

**Q6.** Value of Σ (k = 50 to 100) k²

(a) 297,925 (b) 297,900 (c) 338,350 (d) 290,025

<details class="beginner-answer" markdown="1"><summary>Answer: (a) 297,925</summary>

**Formula: 1² + 2² + … + n² = n(n + 1)(2n + 1) / 6.**
A sum that starts at 50 = (sum from 1 to 100) − (sum from 1 to **49**).

- 1 to 100: 100 × 101 × 201 / 6 = 338,350
- 1 to 49: 49 × 50 × 99 / 6 = 40,425
- 338,350 − 40,425 = **297,925**

Trap: (c) 338,350 is the sum from 1 to 100. Subtract up to **49**, not 50, because 50² must stay in.
</details>

**Q7.** Which sequence is arithmetic with common difference 3?

(a) 2n² + 3n (b) 5 + 3n (c) 3n² + 3n (d) 2n² + 3

<details class="beginner-answer" markdown="1"><summary>Answer: (b) aₙ = 5 + 3n</summary>

**Arithmetic = a straight-line formula a + dn (no n²).** The number in front of n is the common difference.
5 + 3n → 8, 11, 14, … (add 3 each time) ✓. Anything with n² is not arithmetic.
</details>

**Q8.** Which sequence is geometric with common ratio 3?

(a) 3n² + 3n (b) 2n² + 3 (c) 6(3ⁿ⁻¹) (d) 2n² + 3n

<details class="beginner-answer" markdown="1"><summary>Answer: (c) gₙ = 6(3ⁿ⁻¹)</summary>

**Geometric = a × rⁿ⁻¹** (n in the power). Here a = 6, r = 3 → 6, 18, 54, … (× 3 each time) ✓.
</details>

**Q9.** 2¹ + 2² + 2³ + … + 2ⁿ =

(a) 2(2ⁿ − 1) (b) 2(2ⁿ⁻¹ − 1) (c) 2(2ⁿ⁺¹ − 1) (d) none

<details class="beginner-answer" markdown="1"><summary>Answer: (a) 2(2ⁿ − 1)</summary>

**Finite geometric sum: Sₙ = a(rⁿ − 1)/(r − 1).** Here a = 2, r = 2:
Sₙ = 2(2ⁿ − 1)/(2 − 1) = **2(2ⁿ − 1)**.
Check with n = 2: 2 + 4 = 6, and 2(4 − 1) = 6 ✓.
</details>

**Q10.** Third term of aₙ = (−1)ⁿ(n − 7)

(a) 8 (b) 4 (c) 8 (d) −4

<details class="beginner-answer" markdown="1"><summary>Answer: (b) 4</summary>

Put n = 3: (−1)³ × (3 − 7) = (−1) × (−4) = **4**.
Remember: (−1) to an **odd** power = −1, to an **even** power = +1; and negative × negative = positive.
</details>

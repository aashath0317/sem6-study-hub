
## Animation, frames, உணரப்படும் அசைவு

:::key வரையறை
Animation என்பது தொடர்ச்சியாக வேகமாகக் காட்டப்படும் still images அல்லது model poses மூலம் மாற்றம் அல்லது அசைவு தெரியும் முறை. **Frame** என்பது அந்தத் தொடரில் ஒரு image. **Frame rate** என்பது ஒரு second-இல் காட்டப்படும் frames எண்ணிக்கை; unit fps.
:::

பாடம் animation-ஐ 2D Cartesian plane-இல் pixel positions, colours மாறுவதாக விளக்குகிறது. Figure 7.1 அதே சிவப்பு ball-ஐ அடுத்தடுத்த heights-இல் காட்டுகிறது. ஒவ்வொரு படமும் அசையாதது. வரிசையாகக் காட்டும்போது bounce புரிகிறது. PDF-இன் **12–30 fps** ஓர் உதாரண range; கட்டாய வரம்பு அல்ல. Style, medium, device-க்கு ஏற்ப அதிகமான அல்லது குறைந்த rate தேர்வு செய்யலாம்.

Source இந்தத் தோற்றத்தை **persistence of vision**, **phi phenomenon** மூலம் விளக்குகிறது. Course-க்கு முதலாவது visual impression சிறிது நேரம் நீடிப்பது; இரண்டாவது மாறும் stimuli மூலம் அசைவு உணரப்படுவது என்று நினைவில் வைக்கவும். Retina-இல் chemical image, mind action-ஐ “complete” செய்வது என்ற விளக்கம் எளிமைப்படுத்தப்பட்ட கற்பித்தல் விளக்கம்; visual perception-இன் முழு அறிவியல் விளக்கம் அல்ல.

## அடிப்படை animation முறைகளும் parameters-உம்

| முறை | செயல்படும் விதம் | முக்கிய விளைவு |
|---|---|---|
| முழு image-frame மாற்றம் | காட்டப்படும் படத்தை அடுத்த படத்தால் மாற்றும் | புரிவது எளிது; ஒவ்வொரு படமும் அதிக data கொண்டிருக்கலாம் |
| Delta-frame animation | Initial frame-க்குப் பிறகு மாற்றங்களை மட்டும் store/update செய்யும் | மீண்டும் வரும் data-ஐக் குறைக்கலாம் |
| Palette animation | Colour-table entries அல்லது pixels-இன் colours மாற்றும் | Geometry நகராமல் மாற்றம் காட்டலாம் |
| Visual effects (VFX) | Artificial imagery-ஐ captured scene-உடன் சேர்க்கும் | சேர்த்த content live scene-க்கு பொருந்த வேண்டும் |
| Character animation | உணர்வு காட்டும் character-ஐ animate செய்யும் | Poses, movement, timing மூலம் mood, physical effects தெரியும் |

PDF **bit-blitting** என்பதையும் குறிப்பிடுகிறது. அது foreground, background போன்ற bitmap regions-ஐ transfer அல்லது combine செய்வது. Pixel positions மாற்றுவதையும் palette colours மாற்றுவதையும் வேறுபடுத்தவும். இரண்டாலும் display animated போலத் தோன்றலாம்.

| Parameter வகை | உதாரணங்கள் | Design முடிவு |
|---|---|---|
| Visual | Stage size, colour, bitmap/vector representation | பார்வையாளர் என்ன, எந்த size-இல் பார்க்கிறார்? |
| Timing | Frame rate, duration, playback/flow control | எப்போது, எவ்வளவு நேரம் நடக்கும்? |
| Motion | Path, position, shape, scale, colour change | Frames இடையில் எந்த property மாறுகிறது? |

Default-ஐ அப்படியே பயன்படுத்தாமல் parameters-ஐத் தேர்வு செய்யவும். அகல stage desktop demonstration-க்கு பொருந்தலாம்; phone-க்கு மாற்றம் தேவைப்படலாம். மெதுவான அசைவு diagram-ஐப் புரிய உதவும். வேகமான impact weight-ஐக் காட்டலாம். Timing என்பது action எவ்வளவு நேரம் எடுக்கும் என்பது. Spacing என்பது காட்டப்படும் poses இடையில் object எவ்வளவு தூரம் நகரும் என்பது.

## Bitmap, vector, keyframes, tweening

பாடத்தின் **bitmap animation** முறையில் frame bitmaps memory-இல் preload செய்யப்பட்டு வரிசையாகக் காட்டப்படுகின்றன. நிறைய pixel colours store செய்யப்படுவதால் memory அதிகமாகலாம். **Vector animation** முறையில் mathematical descriptions மூலம் frames கணக்கிடப்படுகின்றன. எளிய graphics குறைந்த stored data-வில் அமையலாம்; rendering-க்கு computation தேவை. இவை trade-offs. எல்லா vector files-உம் சிறியது என்றோ, எல்லா bitmap players-உம் முழு movie-ஐ preload செய்ய வேண்டும் என்றோ இல்லை. Complexity, caching, compression, implementation ஆகியவை முக்கியம்.

**Keyframe** முக்கிய state-ஐப் பதிவு செய்யும். உதாரணம் bounce-இன் மேல் அல்லது கீழ் இருக்கும் ball. **Tweening** இடைப்பட்ட states-ஐ உருவாக்கும். Animator முக்கிய poses-ஐ அமைப்பார்; software இடைவெளியை interpolate செய்யும். Frame-by-frame முறையில் ஒவ்வொரு pose-உம் தனியாக வரையப்படும். நுணுக்கமான control கிடைக்கும்; drawing வேலை அதிகம்.

:::example Position tween
Start x = 20, end x = 220 எனத் தேர்வு செய்யவும். Progress t = 0.25 என்றால் linear interpolation x = 20 + 0.25(220−20) = 70. t = 0.5 என்றால் x = 120. Path நேராகவும் progress சீராகவும் இருக்கும். Easing endpoints-ஐ வைத்துக்கொண்டு speed distribution-ஐ மாற்றும்.
:::

Tween இருந்தாலே அசைவு நம்பும்படி இருக்கும் என்று இல்லை. Acceleration, contact poses, object weight பார்க்கவும். Direction மாற்றம் அல்லது குறிப்பிட்ட pose முக்கியமெனில் கூடுதல் keyframes பயன்படுத்தவும். இடை frames தவறான வழியில் சென்றால் path, pivot, rotation direction, easing பார்க்கவும்.

## Cel, path, shape animation

**Cel animation** மாறும் drawings-ஐ மீண்டும் பயன்படுத்தும் background-இலிருந்து பிரிக்கிறது. பழைய முறையில் transparent cels-இல் drawings வைத்து அடுக்கி photograph எடுத்தனர். இணைக்கப்பட்ட [cel-animation விளக்கம்](https://conceptartempire.com/cel-animation/) script, storyboard மூலம் planning தொடங்குவது, key poses action அமைப்பது, in-between drawings மென்மையாக்குவது, photographed layers sequence உருவாக்குவது ஆகியவற்றைக் கூறுகிறது. Digital layers-இலும் moving objects, background தனித்தனியாக வைத்திருப்பது பயனுள்ளது. Article-இன் embedded demonstration இங்கே பார்க்கப்படவில்லை; எழுத்து விளக்கம் கிடைத்தது.

**Path animation** ஒரு object-ஐ முன்பே நிர்ணயித்த straight அல்லது curved path-இல் நகர்த்தும். Shape மாற வேண்டியதில்லை. Bitmap bird அதே image-உடன் curve-இல் செல்லலாம் அல்லது தனியான wing-flap animation இருக்கலாம். Motion tween அந்த route-உடன் position, rotation, scale மாற்றத்தையும் இணைக்கலாம்.

**Shape animation** ஒரு vector shape-ஐ இன்னொன்றாக morph செய்யும். Software key shapes இடையில் geometry-ஐ interpolate செய்யும். Elements சரியாகப் பொருந்தினால் நடுவிலுள்ள வடிவங்கள் சிக்கலாகாது. Position, colour-உம் மாறலாம். Bitmap photograph நகர்வதால் மட்டும் அது shape tween ஆகாது.

PDF-இன் பழைய PowerPoint link திறக்கவில்லை. ஆனால் [தற்போதைய Microsoft guide](https://support.microsoft.com/en-us/powerpoint/add-a-motion-path-animation-effect) கிடைத்தது. Object-ஐத் தேர்வு செய்து animation motion path கொடுத்து, route மாற்றி preview செய்வதே முறை. Custom route வரையலாம். Animation controls மூலம் start behaviour, duration அமைக்கலாம். Lesson-இல் process arrow காட்ட இது உதவும்; path சரியான sequence-ஐச் சொல்ல வேண்டும்.

## Principles, timing, sound, layers, backgrounds

PDF இந்தத் topics-ஐக் குறிப்பிடுகிறது; விரிவான பாடத்துக்கு வெளிப்புற tutorials கூறுகிறது. அவை தனி files ஆக வழங்கப்படவில்லை. Outline முழுமையடைய கீழேயுள்ள practical விளக்கங்களைப் பயன்படுத்தவும். [Adobe animation-principles guide](https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html) கூடுதல் reference.

Actions-ஐ timeline-இல் திட்டமிடவும். Dialogue, music, sound effects தனித்தனி tracks-இல் இருந்தால் align, adjust செய்வது எளிது. Impact sound contact frame-உடன் பொருந்த வேண்டும். Music இருந்தாலும் speech தெளிவாக இருக்க வேண்டும். Background, shadow, ball, sound போன்ற layer names கொடுக்கவும். மாறாத background-ஐ lock செய்தால் தவறான edit தவிர்க்கலாம். Effects scene-இன் light, perspective, style-க்கு பொருந்த வேண்டும். தனி keyframes மட்டும் பார்க்காமல் intended size, frame rate-இல் preview செய்யவும்.

## Web, CSS animation

Web-இல் [CSS animation](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Animations/Using) property values கூறும் keyframes-ஐ duration, timing, repetition கூறும் rule-உடன் இணைக்கிறது. Movement, scale-க்கு transform, fade-க்கு opacity பயன்படுத்தலாம். Animation ஒருமுறை நடக்கலாம் அல்லது repeat ஆகலாம். States இடையில் property மாறும்போது transition உதவும்; keyframes பல stages கூறலாம்.

```css
@keyframes mmBall {
  from { transform: translateY(0); }
  to { transform: translateY(-80px); }
}
.ball { animation: mmBall 1s ease-in-out 2 alternate; }
@media (prefers-reduced-motion: reduce) {
  .ball { animation: none; }
}
```

இந்த உதாரணம் alternate direction மூலம் element-ஐ மேலே நகர்த்தி மீண்டும் திரும்பச் செய்கிறது. Reduced-motion rule குறைந்த அசைவு விரும்பும் பயனாளருக்கு animation-ஐ நீக்கும். Instructional motion-க்கு pause அல்லது step control கொடுக்கவும். முக்கிய தகவல் நகரும்போது மட்டும் கிடைக்கக்கூடாது. Phone, keyboard controls-இல் இறுதி அனுபவத்தைச் சோதிக்கவும். CSS motion interface feedback, எளிய teaching diagrams-க்கு பொருந்தும். சிக்கலான character scene-க்கு animation package அல்லது வேறு rendering முறை தேவைப்படலாம்.

### (i) Tweening மூலம் shadow-உடன் bouncing ball உருவாக்கவும்

Ground line கொண்ட stage உருவாக்கவும். Ball, shadow தனித்தனி layers-இல் இருக்கட்டும். Pivots பொருத்தமாக அமைக்கவும். Contact, upward motion, apex, return contact ஆகியவற்றுக்கு keyframes அமைக்கவும். அவற்றுக்கு இடையில் tween செய்யவும். Apex அருகே மெதுவாகவும் impact நோக்கி வேகமாகவும் இருக்க easing மாற்றவும். Contact-இல் squash, வேகமான அசைவில் stretch செய்யவும்; volume திடீரென மாறக்கூடாது. Shadow ball-க்குக் கீழே இருக்கட்டும். Ball உயரும்போது shadow சிறியதாகவும் மங்கலாகவும், ground அருகே அகலமாகவும் கருமையாகவும் இருக்கட்டும். முழு loop preview செய்து எல்லையில் திடீர் jump உள்ளதா பார்க்கவும். Editable file சேமித்து தனி playback copy export செய்யவும்.

### (ii) Bitmap bird-ஐ path-இல் animate செய்யவும்

Bird bitmap import செய்து தேவையற்ற background-ஐ remove அல்லது mask செய்யவும். பயன்படுத்தும் package-க்குத் தேவையான symbol type-ஆக reusable object-ஐ மாற்றவும். Start, end keyframes வைத்து curved path வரையவும் அல்லது தேர்வு செய்யவும். Motion tween மூலம் object-ஐ அதில் இணைக்கவும். Duration அமைத்து registration point ஒரே விதமாக இருக்கட்டும். Orientation-to-path பயன்படுத்தினால் sharp bends-இல் திடீர் rotation உள்ளதா பார்க்கவும். Still bird image path-இல் நகரலாம். Wing-flapping-க்கு கூடுதல் frames அல்லது nested animation தேவை. தொடக்கத்திலிருந்து முடிவுவரை preview செய்து image stage-க்கு வெளியே crop ஆகிறதா பார்க்கவும்.

### (iii) Circle-ஐ triangle-ஆக deform செய்யவும்

தனி layer-இல் vector circle வரையவும். பின்னால் ஒரு keyframe-இல் triangle உருவாக்கவும். Raw vector shapes அல்லது package ஆதரிக்கும் morph representation கொண்டு shape tween செய்யவும். நடுவிலுள்ள frames-ஐ scrub செய்து பார்க்கவும். Shape twist ஆனால் complexity குறைக்கவும் அல்லது shape hints/corresponding control points பயன்படுத்தவும். Timing, வேண்டுமெனில் colour change அமைக்கவும். Circle-ஐ நகர்த்தும் motion tween தேவையான deformation அல்ல. Circle outline தொடர்ச்சியாக triangle outline-ஆக மாறுவதே model result.

## Matrices represent data

Matrices are used throughout discrete maths to express **relationships between elements of sets**. For example, they're used to model **communication networks** and **transportation systems**. Later they represent **relations** (Week 9) and **graphs** (Week 11).

:::key Definition 1
- A **matrix** is a **rectangular array of numbers**.
- A matrix with **m rows** and **n columns** is an **m × n matrix** (rows first).
- A matrix with the same number of rows and columns is a **square matrix**.
- Two matrices are **equal** if they have the **same size** and **equal entries in every position**.
:::

:::example Example 5.1.1
[[m: 1 0 1; 1 2 3]] is a **2 × 3** matrix: 2 rows, 3 columns.
:::

### Rows, columns, entries (Definition 2)

- A = [aᵢⱼ] is the general notation.
- The **i-th row** is the 1 × n matrix [aᵢ₁ aᵢ₂ … aᵢₙ].
- The **j-th column** is an **m × 1** matrix (a₁ⱼ, a₂ⱼ, …, aₘⱼ written vertically).
- The **(i, j)-th entry** is **aᵢⱼ**: row i, column j.

## Matrix addition

If A = [aᵢⱼ] and B = [bᵢⱼ] are **both m × n**, then **A + B = [aᵢⱼ + bᵢⱼ]**. Add entries in the same position.

:::example Example 5.2.1
A = [[m: 1 0 4; −1 2 2; 0 −2 −3]] B = [[m: −1 3 5; 2 −2 −3; 2 −3 0]]

A + B = [[m: 0 3 9; 1 0 −1; 2 −5 −3]]
:::

:::warn
You can only add matrices of the **same size**.
:::

## Matrix multiplication

Let **A be m × k** and **B be k × n**. The product **AB is m × n**, and its (i, j) entry is the **sum of products of row i of A with column j of B**:

:::formula
c<sub>ij</sub> = a<sub>i1</sub>b<sub>1j</sub> + a<sub>i2</sub>b<sub>2j</sub> + … + a<sub>ik</sub>b<sub>kj</sub>
:::

:::key Size rule
(m × **k**) · (**k** × n) = **m × n**. The **inner sizes must match**; the **outer sizes give the result's size**.
:::

:::example Example 5.2.2
A = [[m: 3 1 4; −1 2 3]] (2 × 3), B = [[m: 1 3 −3; 4 −1 2; 2 4 1]] (3 × 3), so AB is **2 × 3**.

| Entry | Row of A · column of B | Value |
|---|---|---|
| c₁₁ | (3)(1) + (1)(4) + (4)(2) | **15** |
| c₁₂ | (3)(3) + (1)(−1) + (4)(4) | **24** |
| c₁₃ | (3)(−3) + (1)(2) + (4)(1) | **−3** |
| c₂₁ | (−1)(1) + (2)(4) + (3)(2) | **13** |
| c₂₂ | (−1)(3) + (2)(−1) + (3)(4) | **7** |
| c₂₃ | (−1)(−3) + (2)(2) + (3)(1) | **10** |

AB = [[m: 15 24 −3; 13 7 10]]
:::

:::warn Matrix multiplication is NOT commutative (Example 5.2.3)
A = [[m: 1 1; 2 1]], B = [[m: 2 1; 1 1]]

AB = [[m: 3 2; 5 3]] but BA = [[m: 4 3; 3 2]]

So **AB ≠ BA**. Also, AB may exist while BA doesn't (when the sizes don't match).
:::

### Algorithm 1: matrix multiplication

```
procedure matrix multiplication (A: m×k, B: k×n)
for i := 1 to m
    for j := 1 to n
    begin
        c[i][j] := 0
        for q := 1 to k
            c[i][j] := c[i][j] + a[i][q] * b[q][j]
    end
{C = [c[i][j]] is the product of A and B}
```

:::example Example 5.2.4 — cost of multiplying two n × n matrices
- The product has **n²** entries.
- Each entry needs **n multiplications** and **n − 1 additions**.

Total: **n³ multiplications** and **n²(n − 1) additions**. That's O(n³).
:::

## Identity, powers, transpose & symmetric

### Identity matrix (Definition 3)

**Iₙ** is the **n × n matrix with 1s on the main diagonal and 0s everywhere else**. E.g. I₃ = [[m: 1 0 0; 0 1 0; 0 0 1]]

:::formula
If A is n × n:   **IₙA = AIₙ = A**
:::

### Powers of matrices
For a **square** n × n matrix A:

:::formula
**A⁰ = Iₙ**,   **Aʳ = A·A·…·A**  (r times)
:::

### Transpose (Definition 3)
The **transpose Aᵗ** of an m × n matrix is the **n × m** matrix you get by **swapping rows and columns**.

*Example:* A = [[m: 1 2 3; 4 5 6]], so Aᵗ = [[m: 1 4; 2 5; 3 6]]

### Symmetric matrix (Definition 3)
A **square** matrix A is **symmetric** if **A = Aᵗ**. It is a mirror image across the main diagonal: aᵢⱼ = aⱼᵢ.

*Example:* [[m: 1 1 −1; 1 2 0; −1 0 5]] is symmetric.

:::tip Useful transpose facts
(A + B)ᵗ = Aᵗ + Bᵗ  ·  **(AB)ᵗ = Bᵗ Aᵗ** (the order reverses)  ·  (Aᵗ)ᵗ = A
:::

### Determinant and inverse of a matrix (examined: January 2023)

The lesson PDF stops at transposes, but the **January 2023 paper asked for a 3 × 3 inverse**. Learn this method.

:::key 2 × 2 matrices
For A = [[m: a b; c d]]:

- **det A = ad − bc**
- If det A ≠ 0, **A⁻¹ = (1/det A) · [[m: d −b; −c a]]**: swap the diagonal, change the signs of the other two, divide by the determinant.
- If det A = 0 the matrix has **no inverse** (it is *singular*).
:::

*Example:* A = [[m: 4 7; 2 6]]. det A = 4·6 − 7·2 = **10**, so A⁻¹ = (1/10)·[[m: 6 −7; −2 4]].

:::key 3 × 3 matrices: the four-step method
1. **Determinant:** expand along row 1 with the signs **+ − +**: det A = a₁₁·M₁₁ − a₁₂·M₁₂ + a₁₃·M₁₃, where M is the 2 × 2 determinant left after deleting that entry's row and column.
2. **Cofactors:** for every entry, Cᵢⱼ = (sign) × (its 2 × 2 minor), using the chessboard of signs [[m: + − +; − + −; + − +]].
3. **Adjugate:** adj A = the **transpose** of the cofactor matrix (rows become columns).
4. **Inverse:** **A⁻¹ = (1/det A) · adj A**. Check by multiplying: A·A⁻¹ must give I₃.
:::

:::example January 2023 Q3(c): A = [[m: 1 2 3; 2 1 3; 3 2 1]]
**Step 1, determinant (row 1, signs + − +):**

det A = 1·(1·1 − 3·2) − 2·(2·1 − 3·3) + 3·(2·2 − 1·3) = 1·(−5) − 2·(−7) + 3·(1) = −5 + 14 + 3 = **12**

**Step 2, cofactors:**

| Entry | Minor (delete its row and column) | Sign | Cofactor |
|---|---|---|---|
| a₁₁ | 1·1 − 3·2 = −5 | + | **−5** |
| a₁₂ | 2·1 − 3·3 = −7 | − | **7** |
| a₁₃ | 2·2 − 1·3 = 1 | + | **1** |
| a₂₁ | 2·1 − 3·2 = −4 | − | **4** |
| a₂₂ | 1·1 − 3·3 = −8 | + | **−8** |
| a₂₃ | 1·2 − 2·3 = −4 | − | **4** |
| a₃₁ | 2·3 − 3·1 = 3 | + | **3** |
| a₃₂ | 1·3 − 3·2 = −3 | − | **3** |
| a₃₃ | 1·1 − 2·2 = −3 | + | **−3** |

Cofactor matrix C = [[m: −5 7 1; 4 −8 4; 3 3 −3]]

**Step 3, adjugate (transpose of C):** adj A = [[m: −5 4 3; 7 −8 3; 1 4 −3]]

**Step 4, inverse:** A⁻¹ = (1/12)·[[m: −5 4 3; 7 −8 3; 1 4 −3]]

*Check one entry of A·A⁻¹:* row 1 of A · column 1 of adj A = 1(−5) + 2(7) + 3(1) = 12, and 12/12 = **1** ✓
:::

:::warn Solving matrix equations: keep X on the right
To solve **BX = 2X + C**, move the X terms together: BX − 2X = C. Factor X out **on the right**: **(B − 2I)X = C**. Write 2I, not 2, because you can't subtract a number from a matrix. Then multiply by the inverse **on the left**: **X = (B − 2I)⁻¹C**. Since matrix multiplication isn't commutative, CA⁻¹ is wrong here.
:::

## Zero–one matrices: join and meet

A **zero–one matrix** has entries that are **only 0 or 1**. Its arithmetic uses the **Boolean operations ∧ and ∨**:

| b₁ ∧ b₂ | = 1 if b₁ = b₂ = 1, otherwise 0 |
|---|---|
| **b₁ ∨ b₂** | **= 1 if b₁ = 1 or b₂ = 1, otherwise 0** |

For m × n zero–one matrices A = [aᵢⱼ] and B = [bᵢⱼ]:

| Operation | Notation | (i, j) entry |
|---|---|---|
| **Join** | **A ∨ B** | aᵢⱼ ∨ bᵢⱼ (OR) |
| **Meet** | **A ∧ B** | aᵢⱼ ∧ bᵢⱼ (AND) |

:::example Example 5.2.4 (join and meet)
A = [[m: 1 0 1; 0 1 0]], B = [[m: 0 1 0; 1 1 0]]

A ∨ B = [[m: 1∨0 0∨1 1∨0; 0∨1 1∨1 0∨0]] = [[m: 1 1 1; 1 1 0]]

A ∧ B = [[m: 1∧0 0∧1 1∧0; 0∧1 1∧1 0∧0]] = [[m: 0 0 0; 0 1 0]]
:::

| Concept | Remember it as |
|---|---|
| m × n | Rows × columns; square if m = n |
| aᵢⱼ | Row i, column j |

| AB | (m×k)(k×n) = m×n; c<sub>ij</sub> = row i · column j |

## Official quiz 5 — every question explained

These are all **7 questions from the official CODL Quiz 5 — Matrices**. Cover the answer, try the question yourself, then click **Answer** to check. Each answer gives the quick method in a few short steps — the same steps you can write in the written exam.

**Q1.** A and B are matrices of the same order. True or false: AB = BA?

<details class="beginner-answer" markdown="1"><summary>Answer: False</summary>

Matrix multiplication is **not commutative** — order matters. In general AB ≠ BA.
Tiny example: A = [[1, 1], [0, 0]], B = [[1, 0], [1, 0]] → AB = [[2, 0], [0, 0]] but BA = [[1, 1], [1, 1]].
</details>

**Q2.** (Aᵀ)ᵀ equals:

(a) none (b) Aᵀ (c) can't say (d) A

<details class="beginner-answer" markdown="1"><summary>Answer: (d) A</summary>

**Transpose = swap rows and columns.** Doing it twice swaps them back, so you get A again.
</details>

**Q3.** A and B are symmetric. Then AB = BA if and only if:

(a) AB is a null matrix (b) AB is anti-symmetric (c) AB is symmetric (d) none

<details class="beginner-answer" markdown="1"><summary>Answer: (c) AB is symmetric</summary>

Why: (AB)ᵀ = BᵀAᵀ = BA (because Aᵀ = A and Bᵀ = B).
So AB is symmetric ((AB)ᵀ = AB) exactly when BA = AB.
**Rule to remember: (AB)ᵀ = BᵀAᵀ** — the order reverses.
</details>

**Q4.** An n × n matrix with Aᵢᵢ = 1 (diagonal) and Aᵢⱼ = 0 for i ≠ j is called:

(a) null (b) singular (c) identity (d) none

<details class="beginner-answer" markdown="1"><summary>Answer: (c) identity matrix (I)</summary>

1s on the main diagonal, 0s everywhere else. AI = IA = A, just like × 1 for numbers.

- **Null (zero) matrix:** every entry is 0.
- **Singular matrix:** determinant = 0 (no inverse).
</details>

**Q5.** A symmetric matrix is one in which:

(a) all diagonal elements are 1 (b) all diagonal elements are 0 (c) A = Aᵀ (d) A = −Aᵀ

<details class="beginner-answer" markdown="1"><summary>Answer: (c) A = Aᵀ</summary>

Symmetric = equal to its own transpose (mirror image across the main diagonal: aᵢⱼ = aⱼᵢ).
A = −Aᵀ is **skew- (anti-) symmetric**.
</details>

**Q6.** A matrix with many rows and one column is a:

(a) column matrix (b) row matrix (c) diagonal matrix (d) none

<details class="beginner-answer" markdown="1"><summary>Answer: (a) column matrix</summary>

One **column** (n × 1) = column matrix. One **row** (1 × n) = row matrix.
</details>

**Q7.** Two matrices can be **added** if:

(a) rows of the first = columns of the second (b) both rows and columns are the same (c) rows same (d) columns same

<details class="beginner-answer" markdown="1"><summary>Answer: (b) both have the same number of rows and the same number of columns</summary>

**Addition:** same size (same order), add entry by entry.
**Multiplication A × B:** columns of A = rows of B — that is option (a), the trap.
</details>

## Matrix representation and coordinate conventions

A raster object consists of coloured pixels at positions in a 2D Cartesian coordinate system. Represent a point as a **column vector** P = [[m: x; y]]. Transform every defining point to transform the whole object. The PDF uses column vectors, so matrices multiply on the left: **P′ = MP**. Positive angles below turn counterclockwise in a Cartesian system with y upward. Screen coordinates often have y downward; do not silently switch conventions.

A transformation changes position, orientation or size. Translation moves an object. Rotation turns it around a pivot. Scaling changes its dimensions. Free Transform in a raster application combines operations such as moving, rotating, skewing and scaling; the options bar lets you inspect the parameters.

:::example The PDF's introductory shift
Add (2,2) to each vertex: (2,3) → (4,5), (4,5) → (6,7), (6,8) → (8,10). All vertices move the same distance and direction; shape and size stay the same.
:::

## Translation, rotation and scaling: formula and working

:::formula
Translation: x′ = x + tx; y′ = y + ty; P′ = P + T.
Rotation: x′ = x cos θ − y sin θ; y′ = x sin θ + y cos θ.
R = [[m: cosθ −sinθ; sinθ cosθ]].
Scaling: x′ = sx·x; y′ = sy·y; S = [[m: sx 0; 0 sy]].
:::

Rotation follows the angle-sum identities: if x = r cos α and y = r sin α, the new angle is α + θ while r stays unchanged. Expanding r cos(α + θ) and r sin(α + θ) gives the displayed equations. Equal scaling factors give uniform scaling; unequal factors distort proportions. A negative factor reflects along that coordinate direction. Unless stated otherwise, rotation and scaling here use the origin.

## Homogeneous coordinates and composite transformations

Ordinary translation uses addition, whereas ordinary rotation and scaling use multiplication. Homogeneous coordinates let all these operations use matrix multiplication. Add a final coordinate **h = 1** to represent a point: P = [[m: x; y; 1]].

:::warn Source correction
Page 6 prints xh = x/h and yh = y/h. For a homogeneous triple (xh,yh,h), the Cartesian coordinates are x = xh/h and y = yh/h; equivalently xh = h·x and yh = h·y. The lesson's choice h = 1 masks this reversal. Its displayed transformation matrices use the usual h = 1 convention.
:::

:::formula
T = [[m: 1 0 tx; 0 1 ty; 0 0 1]].
R = [[m: cosθ −sinθ 0; sinθ cosθ 0; 0 0 1]].
S = [[m: sx 0 0; 0 sy 0; 0 0 1]].
P′ = MP. The last row keeps the final coordinate equal to 1.
:::

For a sequence, the operation done first is nearest the point. “Translate, then scale” means P′ = STP. “Scale, then translate” means P′ = TSP. Matrix multiplication is generally not commutative. Write the order before multiplying; this prevents a correct matrix being applied in the wrong order.

:::example Homogeneous example 1
Formula: (x,y) = (xh/h,yh/h). Substitute (2/1,3/1). Working gives **(2,3) coordinate units**. Its h = 1 column is [[m: 2; 3; 1]].
:::

:::example Homogeneous example 2
Formula: (x,y) = (xh/h,yh/h). Substitute (4/2,6/2). Working gives **(2,3) coordinate units**. Its h = 1 column is [[m: 2; 3; 1]].
:::

:::example Homogeneous example 3
Formula: (x,y) = (xh/h,yh/h). Substitute (-6/3,9/3). Working gives **(-2,3) coordinate units**. Its h = 1 column is [[m: -2; 3; 1]].
:::

:::example Composite example 1: translate then scale
Formula: P′ = STP. Substitute P = (1,2), T = (3,1), S factors = (2,3). First obtain (1+(3), 2+(1)) = (4,3). Then multiply: (2×(4), 3×(3)). **Answer: (8,9) coordinate units**.
:::

:::example Composite example 2: translate then scale
Formula: P′ = STP. Substitute P = (2,1), T = (-1,2), S factors = (3,2). First obtain (2+(-1), 1+(2)) = (1,3). Then multiply: (3×(1), 2×(3)). **Answer: (3,6) coordinate units**.
:::

:::example Composite example 3: translate then scale
Formula: P′ = STP. Substitute P = (-1,3), T = (2,-1), S factors = (2,0.5). First obtain (-1+(2), 3+(-1)) = (1,2). Then multiply: (2×(1), 0.5×(2)). **Answer: (2,1) coordinate units**.

## Arbitrary pivot and Activity 6.1

To rotate about C = (xc,yc), translate C to the origin, rotate, and translate back. The pivot remains fixed. The same construction works for scaling.

:::formula
Rotation about C: M = T(xc,yc) R(θ) T(−xc,−yc).
x′ = xc + (x−xc)cosθ − (y−yc)sinθ.
y′ = yc + (x−xc)sinθ + (y−yc)cosθ.
Scaling about C: M = T(xc,yc) S T(−xc,−yc).
x′ = xc + sx(x−xc); y′ = yc + sy(y−yc).
:::

These equations redraw the meaning of Figures 6.4 and 6.5: the vector from C to P is rotated or stretched, then anchored back at C. For scaling, the homogeneous matrix has final-column entries xc(1−sx) and yc(1−sy). For rotation they are xc(1−cosθ)+yc sinθ and yc(1−cosθ)−xc sinθ.

:::

## Set up a digital image and understand the workspace

Set the physical width and height, pixel dimensions or resolution, colour depth and colour mode before drawing. At a fixed physical size, increasing pixels per inch increases pixel dimensions and memory. At fixed pixel dimensions, changing the print resolution changes the physical print size. The PDF calls resolution “pixels per square inch”; the usual linear unit is **pixels per inch**, measured separately along width and height. It also spells CMYK as CYMK in one place.

Choose **RGB** for light-emitting screens; it uses additive colour. Choose an appropriate **CMYK** workflow for printing with inks; it uses subtractive colour. Grayscale represents shades without independent colour channels. In Photoshop, File → New opens the setup dialog. The example in Figure 6.6 sets width, height, resolution, colour mode and background.

The workspace in Figure 6.7 contains a **menu bar** grouping commands by task, an **options bar** for the active tool, a **toolbox**, an **active image area**, a **palette well** that organises palettes, and **palettes/panels** for inspecting or modifying the image. The source shows an older Photoshop version; panel names and placement can differ in another version.

## Layers, blending, digital effects and Activities 6.2–6.3

Layers are like transparent sheets stacked above one another. Edit a foreground object without damaging the background. Layer order, opacity, masks, adjustment layers, fill layers and layer styles change the final composition. A blending mode determines how upper pixels combine with lower pixels. The source's **Pass Through** statement concerns a layer group, not the default mode of every ordinary layer. A non-Pass-Through group composites its members before blending the group with layers outside; internal adjustments can therefore be isolated.

## Saving, exam checks and answer-it-yourself practice

Keep an editable **PSD master** to retain layers, effects, masks and styles. Export a separate delivery copy. TIFF is a raster format with several storage options; GIF uses lossless compression with a limited palette; JPEG uses lossy compression. “Save for web” balances file size against visual quality and may reduce the colour lookup table. Inspect text, transparency and edges after export. Never assume a small delivery file preserves the editable master.

**Exam frame:** “Using column vectors, first state the pivot and operation order. Write P′ = MP, substitute the coordinates, multiply each row by the column, and report the transformed coordinates with units. For an arbitrary pivot, translate to the origin, transform, then translate back.”

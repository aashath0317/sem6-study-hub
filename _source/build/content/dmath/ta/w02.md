## கணச் சொற்களும் குறியீடும்

| வரையறை | பொருள் | எடுத்துக்காட்டு |
|---|---|---|
| **கணம்** (2.1.1) | **வரிசையற்ற பொருட்களின் தொகுப்பு** | எந்தப் பள்ளியிலும் தனித்த கணிதம் கற்கும் அனைத்து மாணவர்களும் |
| **மூலகம் / உறுப்பினர்** (2.1.2) | கணத்திலுள்ள பொருள். **a ∈ A**: a என்பது A-இன் மூலகம். **a ∉ A**: a மூலகமல்ல | 3 ∈ {1, 3, 5}; 4 ∉ {1, 3, 5} |
| **அனைத்துக் கணம் U** (2.1.3) | **கருதப்படும் அனைத்து மூலகங்களினதும்** கணம் | பூமியிலுள்ள அனைத்து உயிரினங்களும் |
| **வெற்றுக் கணம்** | **மூலகங்கள் இல்லாத** கணம்: **∅** அல்லது **{ }** | ஆறு கால்களுள்ள நாய்களின் கணம் |

### கணத்தைக் குறிப்பிடும் இரு வழிகள்

:::grid
**1. அட்டவணை (பட்டியல்) வடிவம்**

அனைத்து மூலகங்களையும் பட்டியலிடவும்.

O = {1, 3, 5, 7, 9}
+++
**2. கணம் அமைக்கும் குறியீடு**

உறுப்பினர்களுக்கு இருக்க வேண்டிய பண்பைக் கொடுக்கவும்.

O = {x | x என்பது 10-ஐவிடக் குறைந்த ஒற்றை நேர்மறை முழு எண்}
:::

### அறிந்திருக்க வேண்டிய எண் கணங்கள்

| குறியீடு | கணம் | வரையறை |
|---|---|---|
| **ℝ** | மெய்யெண்கள் | {x : −∞ < x < ∞} |
| **ℤ** | முழு எண்கள் | {…, −3, −2, −1, 0, 1, 2, 3, …} |
| **ℤ⁺** | நேர்மறை முழு எண்கள் | {1, 2, 3, …} |
| **ℤ⁻** | எதிர்மறை முழு எண்கள் | {−1, −2, −3, …} |
| **ℕ₀** | பூச்சியத்துடன் இயல் எண்கள் = முழுமை எண்கள் | {0, 1, 2, 3, …} |
| **ℕ** | இயல் எண்கள் | {1, 2, 3, …} |
| **ℚ** | விகிதமுறு எண்கள் | {x : x = p/q, p ∈ ℤ, q ∈ ℤ, q ≠ 0} |

:::key மெய்யெண் முறைமை (படம் 2.1), உள்ளிருந்து வெளியே
**இயல் எண்கள்** {1, 2, 3, …} ⊂ **முழுமை எண்கள்** (0 சேர்க்கிறது) ⊂ **முழு எண்கள்** (…, −2, −1 சேர்க்கிறது) ⊂ **விகிதமுறு எண்கள்** (1/2, −5/9, 3/8, … சேர்க்கிறது) ⊂ **மெய்யெண்கள்**
:::

## சமத்துவம், உட்கணங்கள், வெட்டாத கணங்கள்

### சம கணங்கள் (2.1.4)
**A, B ஒரே மூலகங்களைக் கொண்டிருந்தால் மட்டுமே A = B**: ∀x (x ∈ A ⇔ x ∈ B).

- {1, 3, 5} = {3, 5, 1}. **வரிசை முக்கியமல்ல.**
- {1, 3, 3, 3, 5, 5, 5, 5} = {1, 3, 5}. **மீளுரு முக்கியமல்ல.**

### உட்கணம் (2.1.5), முறையான உட்கணம் (2.1.6)

| கருத்து | குறியீடு | பொருள் |
|---|---|---|
| **உட்கணம்** | **A ⊆ B** | **A-இன் ஒவ்வொரு மூலகமும் B-இலும் உள்ளது** |
| உட்கணங்களால் சமத்துவம் | A = B ⇔ **A ⊆ B மற்றும் B ⊆ A** | இரு கணங்களும் சமம் என நிறுவும் வழக்கமான முறை |
| **முறையான உட்கணம்** | **A ⊂ B** | A ⊆ B **ஆனால் A ≠ B** (B-இல் குறைந்தது ஒரு கூடுதல் மூலகம் உள்ளது) |
| உட்கணமல்ல | **D ⊄ A** | D-இன் சில மூலகம் A-இல் இல்லை |

:::example எடுத்துக்காட்டு 2.1.6.1
A = {1, 3, 5}

- B = {1, 5} → **B ⊂ A** (முறையான உட்கணம்)
- C = {3, 1, 5} → **C ⊆ A**; ஆனால் C = A என்பதால் **முறையானதல்ல**
- D = {1, 4} → **D ⊄ A**; ஏனெனில் 4 ∉ A
:::

:::example எடுத்துக்காட்டு 2.1.6.2 — A = {a, b, c}-இன் அனைத்து உட்கணங்களும்
- **0 மூலகங்கள்:** ∅
- **1 மூலகம்:** {a}, {b}, {c}
- **2 மூலகங்கள்:** {a, b}, {a, c}, {b, c}
- **3 மூலகங்கள்:** {a, b, c}

அவை **8 = 2³ உட்கணங்கள்**. பொதுவாக n மூலகங்களுள்ள கணத்துக்கு **2ⁿ உட்கணங்கள்** உள்ளன (இந்தத் தொகுப்பே *அடுக்குக் கணம்*).
:::

:::warn வழக்கமான சிக்கல்கள்
- **ஒவ்வொரு** கணம் A-க்கும் **∅ ⊆ A**. ஆனால் ∅ ஒரு மூலகமாக நேரடியாகப் பட்டியலிடப்பட்டிருந்தால் மட்டுமே **∅ ∈ A**.
- **0 ≠ ∅.** 0 ஓர் எண்; ∅ ஒரு கணம்.
- **A ⊆ A** எப்போதும் உண்மை. **A ⊂ A** எப்போதும் பொய்.
- {a, b} ∈ {a, b, c} என்பது **பொய்**: {a, b} ஓர் *உட்கணம்*; *மூலகம்* அல்ல.
:::

### வெட்டாத கணங்கள் (2.1.7)
A, B-க்கு **பொதுவான மூலகங்கள் இல்லையெனில்** அவை **வெட்டாதவை**: A ∩ B = ∅.

*எடுத்துக்காட்டு 2.1.7.1:* A = {1, 2}, B = {4, 5, 6}, C = {5, 6, 7, 8}. **A, B** வெட்டாதவை; **A, C** வெட்டாதவை; ஆனால் **B, C வெட்டுகின்றன** (5, 6 பொதுவானவை).

## வென் வரைபடங்கள்

**வென் வரைபடங்கள்**, கணங்களைக் காட்சியாகக் காட்டுகின்றன:

- **அனைத்துக் கணம் U** ஒரு **செவ்வகம்**.
- U-இன் உட்கணங்கள் **அதற்குள் உள்ள பகுதிகள்** (பொதுவாக வட்டங்கள்).

| படம் | தொடர்பு |
|---|---|
| "A, B" என அடையாளமிட்ட ஒரு வட்டம் | **A = B** |
| தனித்தனியான இரு வட்டங்கள் | **A, B வெட்டாதவை** |
| B வட்டத்திற்குள் A வட்டம் | **A ⊂ B** |

## கணச் செயல்பாடுகள்

| செயல்பாடு | குறியீடு | கணம் அமைக்கும் வரையறை | வென் பகுதி |
|---|---|---|---|
| **சேர்ப்பு** | **A ∪ B** | {x \| x ∈ A **அல்லது** x ∈ B (அல்லது இரண்டிலும்)} | இரு வட்டங்களும் முழுவதும் |
| **வெட்டு** | **A ∩ B** | {x \| x ∈ A **மற்றும்** x ∈ B} | பொதுப் பகுதி மட்டும் |
| **நிரப்பு** | **Aᶜ** | {x \| x ∈ U மற்றும் x ∉ A} | A-க்கு **வெளியே** உள்ள அனைத்தும் |
| **வேறுபாடு** | **A \\ B** (அல்லது A − B) | {x \| x ∈ A, x ∉ B} | A-இலிருந்து பொதுப் பகுதியை **நீக்கியது** |

:::example எடுத்துக்காட்டு 2.3.1 — A = {a, b, c}, B = {a, c, d}, U = {a, b, c, d}
- A ∪ B = {a, b, c, d}
- A ∩ B = {a, c}
- Aᶜ = {d}
- A \\ B = {b}
:::

:::example எடுத்துக்காட்டு 2.3.2
A = {1, 3, 5, 7, 9}, B = {2, 4, 6, 8, 10}. அப்போது A ∩ B = ∅; எனவே **A, B வெட்டாதவை**.
:::

## கண விதிகள்

### நிரப்பு விதிகள்
**a.** Uᶜ = ∅  **b.** ∅ᶜ = U  **c.** (Aᶜ)ᶜ = A  **d.** A ∪ Aᶜ = U  **e.** A ∩ Aᶜ = ∅

### கணச் செயல்பாடுகளின் பண்புகள்

| விதி | சேர்ப்பு | வெட்டு |
|---|---|---|
| **பரிமாற்று** | A ∪ B = B ∪ A | A ∩ B = B ∩ A |
| **சேர்ப்பு** | A ∪ (B ∪ C) = (A ∪ B) ∪ C | A ∩ (B ∩ C) = (A ∩ B) ∩ C |
| **பங்கீட்டு** | A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) | A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) |

### டி மோர்கன் விதிகள்

:::formula
(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
:::

:::tip
சேர்ப்பு அல்லது வெட்டின் நிரப்பை எடுப்பது **∪ ↔ ∩-ஐ மாற்றி**, **ஒவ்வொரு கணத்தையும் நிரப்புகிறது**. தர்க்கத்தில் ¬(p ∨ q) ≡ ¬p ∧ ¬q என்பதன் அதே வடிவம். நிழலிடும் கருவியில் `(A ∪ B)'`, பின்னர் `A' ∩ B'` எனத் தட்டச்சிட்டு இருபக்கங்களையும் சரிபார்க்கவும்.
:::

:::example எடுத்துக்காட்டு 2.3.3 — (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ சரிபார்த்தல்
U = {1, …, 10}, A = {1, 2, 4, 8, 9}, B = {3, 4, 5, 6, 8}

**இடப்பக்கம்**
- A ∪ B = {1, 2, 3, 4, 5, 6, 8, 9}
- (A ∪ B)ᶜ = **{7, 10}**

**வலப்பக்கம்**
- Aᶜ = {3, 5, 6, 7, 10}
- Bᶜ = {1, 2, 7, 9, 10}
- Aᶜ ∩ Bᶜ = **{7, 10}**

இருபக்கங்களும் சமம். ✓
:::

:::example எடுத்துக்காட்டு 2.3.4 — விற்பனையாளர் வளாகத்திலுள்ள கார்கள்
A = தானியங்கிப் பற்சக்கர மாற்று, B = குளிரூட்டி, C = பக்கக் காற்றுப்பைகள்.

| விளக்கம் | கோவை |
|---|---|
| (a) குறைந்தது ஒரு விருப்பத் தெரிவு | **A ∪ B ∪ C** |
| (b) துல்லியமாக ஒரு விருப்பத் தெரிவு | **(A ∩ Bᶜ ∩ Cᶜ) ∪ (B ∩ Cᶜ ∩ Aᶜ) ∪ (C ∩ Aᶜ ∩ Bᶜ)** |
| (c) தானியங்கி மாற்றும் பக்கக் காற்றுப்பைகளும்; ஆனால் குளிரூட்டி **இல்லை** | **A ∩ C ∩ Bᶜ** |

நிழலிடும் கருவியில் (b), (c)-க்கான பொத்தான்கள் உள்ளன.
:::

## மூலக எண்ணிக்கை — உள்ளடக்கல்–விலக்கல்

- S கணத்தில் துல்லியமாக **n வேறுபட்ட மூலகங்கள்** இருந்தால் (n எதிர்மறையல்லாத முழு எண்), S **முடிவுள்ளது**; **n அதன் மூலக எண்ணிக்கை**; **|S|** அல்லது n(S) என எழுதப்படுகிறது.
- *எடுத்துக்காட்டு:* A = 10-ஐவிடக் குறைந்த ஒற்றை நேர்மறை முழு எண்கள்; எனவே |A| = 5. மேலும் **|∅| = 0**.

:::formula
**n(A ∪ B) = n(A) + n(B) − n(A ∩ B)**   (உள்ளடக்கல்–விலக்கல் கொள்கை)
A, B **வெட்டாதவை** எனில்: n(A ∪ B) = n(A) + n(B)
:::

**ஏன் கழிக்க வேண்டும்?** n(A) + n(B) கூட்டும்போது A, B இரண்டிலும் உள்ள மூலகங்கள் **இருமுறை எண்ணப்படுகின்றன**.

:::example எடுத்துக்காட்டு 2.4.1 — 100 கோப்பி அருந்துவோர்
70 பேர் சீனி (A), 60 பேர் கிரீம் (B), 50 பேர் இரண்டையும் சேர்க்கின்றனர்.

| கேள்வி | செய்முறை | விடை |
|---|---|---|
| (a) சீனி மட்டும் | n(A) − n(A ∩ B) = 70 − 50 | **20** |
| (b) கிரீம் மட்டும் | n(B) − n(A ∩ B) = 60 − 50 | **10** |
| (c) சீனி **அல்லது** கிரீம் | 70 + 60 − 50 | **80** |
| (d) துல்லியமாக ஒரு பொருள் | 20 + 10 | **30** |

(மேலும் 100 − 80 = **20** பேர் இரண்டையும் சேர்ப்பதில்லை.)
:::

:::formula
மூன்று கணங்கள்: **n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C)**
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- கணங்களை அமைக்கும்/அட்டவணை வடிவத்தில் எழுதுதல்
- ∈, ⊆, ∅ பற்றிய உண்மை/பொய்
- அனைத்து உட்கணங்களையும் பட்டியலிடுதல்
- ∪ ∩ ᶜ \\ கணக்கிடுதல்
- நேரடிக் கணக்கீட்டால் டி மோர்கனைச் சரிபார்த்தல்
- **சொற்கணக்குகளுக்குக் கணக் கோவைகளை எழுதுதல்** (கார்கள், மாணவர்கள், மருத்துவமனை ஊழியர்கள்)
- **உள்ளடக்கல்–விலக்கல்** கணக்கெடுப்புப் பிரச்சினைகள்: வென் வரைபடத்தை வரைந்து **முதலில் வெட்டுப் பகுதியை நிரப்பவும்**

**Q1.** Which set is { x : x < 6, x is a whole number }?

(a) {…, −2, −1, 0, 1, …, 5} (b) {1, 2, 3, 4, 5} (c) {0, 1, 2, 3, 4, 5}

**✅ Answer: (c) {0, 1, 2, 3, 4, 5}**

- **Whole numbers** start at **0**: 0, 1, 2, 3, … (no negatives).
- **Natural numbers** start at **1**: 1, 2, 3, …
- “x < 6” stops at 5, so the set is {0, 1, 2, 3, 4, 5}.


**Q2.** Which set equals {1, 4, 9, 16}?

(a) {square numbers} (b) { x² : x² < 20, x natural } … written as {x : x² < 20, x is a natural number} (c) {x : x² < 25, x is a whole number}

**✅ Answer: (b) the squares x² below 20 with x a natural number**

List them: 1² = 1, 2² = 4, 3² = 9, 4² = 16, 5² = 25 (too big, stop). That gives exactly {1, 4, 9, 16}.

- (a) “all square numbers” goes on forever (25, 36, …).
- (c) whole numbers include 0, so 0 would be in the set as well.


**Q3.** A = people in your class, B = people in your class who wear glasses. What is **A ∩ B**?

**✅ Answer: the people in your class who wear glasses**

**∩ (intersection) = in A AND in B** — the overlap. Everyone in B is already in A, so the overlap is just B.


**Q4.** Same A and B. What is **A ∪ B**?

**✅ Answer: all the people in your class**

**∪ (union) = in A OR in B (or both)** — put everyone together. B is inside A, so the union is just A.


**Q5.** Same A and B. What is **A \ B** (A minus B)?

**✅ Answer: the people in your class who do not wear glasses**

**A \ B (difference) = in A but NOT in B.** Take the class and remove everyone who wears glasses.


**Q6.** 80 students; 60 play rugby, 35 play tennis; everyone plays at least one. How many are in the **overlap** (both)?

(a) 80 (b) 95 (c) 15

**✅ Answer: (c) 15**

**Formula (memorise):** |R ∪ T| = |R| + |T| − |R ∩ T|
80 = 60 + 35 − both → both = 95 − 80 = **15**.
Why: adding 60 + 35 counts the “both” people twice, so the extra 15 is the overlap.


**Q7.** Same class. How many play **rugby only** (the left part of the rugby circle)?

(a) 80 (b) 45 (c) 60

**✅ Answer: (b) 45**

Rugby only = all rugby − both = 60 − 15 = **45**.
(Check: tennis only = 35 − 15 = 20, and 45 + 15 + 20 = 80 ✓.)


**Q8.** Which is true?

(a) {2, 4} ∈ {2, 4, 6} (b) ∅ ⊆ {2, 4, 6} (c) 4 ⊂ {2, 4, 6}

**✅ Answer: (b) ∅ ⊆ {2, 4, 6}**

- **∈ (“is an element of”)** is for a single member: 4 ∈ {2, 4, 6} ✓. {2, 4} is a set, not a member, so (a) is false (it should be ⊆).
- **⊆ / ⊂ (“is a subset of”)** is for a set inside a set. 4 is a number, not a set, so (c) is false.
- **The empty set ∅ is a subset of every set.** So (b) is true.


**Q9.** A = {1, 2, 3}. How many subsets have exactly **two** elements?

(a) 3 (b) 4 (c) 5

**✅ Answer: (a) 3**

List them: {1, 2}, {1, 3}, {2, 3} → **3**.
Formula: choose 2 from 3 = C(3, 2) = 3. (All subsets of a 3-element set: 2³ = 8.)


**Q10.** Two sets are **disjoint** if their ______ is the empty set.

**✅ Answer: intersection**

Disjoint = **no common elements** → A ∩ B = ∅. Example: {1, 2} and {3, 4}.

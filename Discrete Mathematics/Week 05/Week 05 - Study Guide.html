Matrix அளவு

வரிசைகளும் நிரல்களும் கொண்ட எண்ணட்டவணை Matrix. m×n என்றால் m rows, n columns. முதலில் size-ஐ எழுதினால் எந்த operation செய்யலாம் என்பதில் தவறு குறையும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

முழுப் படிகளுடன் புரிந்துகொள்ள

Matrix m×n என்றால்m rows,n columns. Entry aᵢⱼ rowi,columnj. ஒரு column m×1,row1×n. Equal matrices same dimensions+entrywise equality. Square m=n. Data table மட்டும் அல்ல;relations/graphs matrix representation-க்கும் பயன்படும்.

Matrices are used throughout discrete maths to express relationships between elements of sets. For example, they're used to model communication networks and transportation systems. Later they represent relations (Week 9) and graphs (Week 11).

Definition 1
  • A matrix is a rectangular array of numbers.
  • A matrix with m rows and n columns is an m × n matrix (rows first).
  • A matrix with the same number of rows and columns is a square matrix.
  • Two matrices are equal if they have the same size and equal entries in every position.
Example 5.1.1

101123 is a 2 × 3 matrix: 2 rows, 3 columns.

Rows, columns, entries (Definition 2)

  • A = [aᵢⱼ] is the general notation.
  • The i-th row is the 1 × n matrix [aᵢ₁ aᵢ₂ … aᵢₙ].
  • The j-th column is an m × 1 matrix (a₁ⱼ, a₂ⱼ, …, aₘⱼ written vertically).
  • The (i, j)-th entry is aᵢⱼ: row i, column j.

கண மூலகங்களுக்கிடையிலான தொடர்புகளை வெளிப்படுத்தத் தனித்த கணிதம் முழுவதும் அணிகள் பயன்படுகின்றன. எ.கா. தொடர்பாடல் வலையமைப்புகளையும் போக்குவரத்து முறைமைகளையும் மாதிரியாக்கப் பயன்படுகின்றன. பின்னர் தொடர்புகளையும் (வாரம் 9), வரைபுகளையும் (வாரம் 11) பிரதிநிதித்துவப்படுத்துகின்றன.

வரையறை 1
  • அணி என்பது செவ்வக வடிவிலான எண்களின் ஒழுங்கமைப்பு.
  • m நிரைகளும் n நிரல்களும் உள்ள அணி m × n அணி (நிரைகள் முதலில்).

  • ஒரே அளவும், ஒவ்வொரு இடத்திலும் சம உறுப்புகளும் உள்ள இரு அணிகள் சமம்.

2Matrix addition

அணிகளைக் கூட்டுதல்

ஒரே size உள்ள matrices-ஐ மட்டும் கூட்டலாம். பொருந்தும் இடங்களின் எண்களைச் சேருங்கள். Row 1 column 2-இன் எண்ணை அதே இடத்திலுள்ள எண்ணுடன் மட்டுமே கூட்ட வேண்டும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

முழுப் படிகளுடன் புரிந்துகொள்ள

Addition same dimensions மட்டும்;entrywise sum/subtract. Source3×3 example result rows (0,3,9),(1,0,−1),(2,−5,−3). Multiplication size rule-ஐ addition-க்கு பயன்படுத்தாதீர்கள்;2×3 மற்றும்3×2 add முடியாது.

If A = [aᵢⱼ] and B = [bᵢⱼ] are both m × n, then A + B = [aᵢⱼ + bᵢⱼ]. Add entries in the same position.

3Matrix multiplication

அணிகளைப் பெருக்குதல்

A m×n, B n×p என்றால் AB m×p. A-வின் row-ஐ B-யின் column-உடன் பெருக்கிச் சேர்ப்போம். ஒவ்வொரு இடத்திலுள்ள எண்களை நேரடியாகப் பெருக்குவது வழக்கமான matrix multiplication அல்ல.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

cᵢⱼ=Σₖ aᵢₖbₖⱼ. Row [1,2], column [3,4]ᵀ என்றால் entry 1×3+2×4=11. A 2×3, B 3×4 என்றால் AB 2×4; BA இங்கே defined அல்ல. AB=0 என்றதால் A=0 அல்லது B=0 என்று பொதுவாக முடிவு செய்ய முடியாது. எண்களின் எல்லா properties-யும் matrices-க்கு வராது.

முழுப் படிகளுடன் புரிந்துகொள்ள

(m×k)(k×n)→m×n;entry row·column sum. Example c11=3·1+1·4+4·2=15;fullAB rows (15,24,−3),(13,7,10). AB≠BA பொதுவாக;ஒரு product exist ஆனாலும் மற்றது இல்லாமல் இருக்கலாம். Standard square algorithm n³ multiplications,n²(n−1) mathematical additions;zero accumulator code-இல் extra additions இருக்கலாம்.

Let A be m × k and B be k × n. The product AB is m × n, and its (i, j) entry is the sum of products of row i of A with column j of B:

cij = ai1b1j + ai2b2j + … + aikbkj
Size rule

(m × k) · (k × n) = m × n. The inner sizes must match; the outer sizes give the result's size.

Example 5.2.2

A = 314−123 (2 × 3), B = 13−34−12241 (3 × 3), so AB is 2 × 3.

Matrix multiplication is NOT commutative (Example 5.2.3)

A = 1121, B = 2111

AB = 3253 but BA = 4332

So AB ≠ BA. Also, AB may exist while BA doesn't (when the sizes don't match).

Algorithm 1: matrix multiplication

procedure matrix multiplication (A: m×k, B: k×n)
for i := 1 to m
    for j := 1 to n
    begin
        c[i][j] := 0
        for q := 1 to k
            c[i][j] := c[i][j] + a[i][q] * b[q][j]
    end
{C = [c[i][j]] is the product of A and B}
Example 5.2.4 — cost of multiplying two n × n matrices
  • The product has n² entries.
  • Each entry needs n multiplications and n − 1 additions.

Total: n³ multiplications and n²(n − 1) additions. That's O(n³).

4Identity, powers, transpose & symmetric

அலகு அணியும் வரிசை மாற்றமும்

AI=IA=A; I-இன் diagonal-இல் 1. Transpose rows-ஐ columns-ஆக மாற்றும். Aᵀ=A என்றால் symmetric. AB மற்றும் BA பொதுவாகச் சமம் அல்ல.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

A⁰=I square matrix-க்கு; Aᵏ மீண்டும் மீண்டும் matrix multiplication. (AB)ᵀ=BᵀAᵀ — order திரும்பும். Symmetric matrix-க்கு aᵢⱼ=aⱼᵢ. Non-square matrix-க்கு same-size identity என்ற பெயரில் arbitrary array வைக்காதீர்கள்; left, right identity sizes multiplication-க்கு பொருந்த வேண்டும்.

முழுப் படிகளுடன் புரிந்துகொள்ள

I diagonal1 மற்றவை0;A square என்றால்A⁰=I,Aʳ repeated matrix products,entrywise power அல்ல. Transpose m×n→n×m;(AB)ᵀ=BᵀAᵀ order reverse. Symmetric A=Aᵀ square. RectangularA-க்கும்IₘA=AIₙ=A சரியான sizes-இல் பொருந்தும்.

Identity matrix (Definition 3)

Iₙ is the n × n matrix with 1s on the main diagonal and 0s everywhere else. E.g. I₃ = 100010001

If A is n × n: IₙA = AIₙ = A

Powers of matrices

For a square n × n matrix A:

A⁰ = Iₙ, Aʳ = A·A·…·A (r times)

Transpose (Definition 3)

The transpose Aᵗ of an m × n matrix is the n × m matrix you get by swapping rows and columns.

Example: A = 123456, so Aᵗ = 142536

Symmetric matrix (Definition 3)

A square matrix A is symmetric if A = Aᵗ. It is a mirror image across the main diagonal: aᵢⱼ = aⱼᵢ.

Example: 11−1120−105 is symmetric.

Useful transpose facts

(A + B)ᵗ = Aᵗ + Bᵗ · (AB)ᵗ = Bᵗ Aᵗ (the order reverses) · (Aᵗ)ᵗ = A

சமனி அணி (வரையறை 3)

Iₙ, முதன்மை மூலைவிட்டத்தில் 1-களும் மற்ற எல்லா இடங்களிலும் 0-களும் உள்ள n × n அணி. எ.கா. I₃ = 100010001

A என்பது n × n எனில்: IₙA = AIₙ = A

அணிகளின் அடுக்குகள்

சதுர n × n அணி A-க்கு:

A⁰ = Iₙ, Aʳ = A·A·…·A (r தடவைகள்)

இடமாற்று (வரையறை 3)

m × n அணியின் இடமாற்று Aᵗ, நிரைகளையும் நிரல்களையும் மாற்றுவதால் கிடைக்கும் n × m அணி.

எடுத்துக்காட்டு: A = 123456; எனவே Aᵗ = 142536

சமச்சீர் அணி (வரையறை 3)

சதுர அணி A-க்கு A = Aᵗ எனில் அது சமச்சீர். முதன்மை மூலைவிட்டத்தின் இருபக்கமும் கண்ணாடிப் படிமம்: aᵢⱼ = aⱼᵢ.

எடுத்துக்காட்டு: 11−1120−105 சமச்சீரானது.

பயனுள்ள இடமாற்று உண்மைகள்

(A + B)ᵗ = Aᵗ + Bᵗ · (AB)ᵗ = Bᵗ Aᵗ (வரிசை தலைகீழாகிறது) · (Aᵗ)ᵗ = A

5Zero–one matrices: join and meet

பூஜ்யம்–ஒன்று அணிகள்

ஒவ்வொரு இடமும் 0 அல்லது 1. Join என்பது OR; Meet என்பது AND. Join-இல் ஏதேனும் ஒன்று 1 என்றால் 1; Meet-இல் இரண்டும் 1 ஆக வேண்டும். இவை சாதாரண கூட்டல் விதிகள் அல்ல.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Join/Meet entry-wise: 1∨0=1; 1∧0=0; 1∨1=1; 1∧1=1. Join addition அல்ல: 1+1=2, ஆனால் 1∨1=1. Zero–one matrices relations-ஐக் குறிக்க உதவும். OR, AND எந்தப் பணியைச் செய்கிறது என்று truth table-உடன் இணைத்தால் நினைவில் நிற்கும்.

முழுப் படிகளுடன் புரிந்துகொள்ள

Zero–one entries0/1. Join OR ஒரே position-இல் குறைந்தது ஒன்று1;meet AND இரண்டும்1. Examplejoin rows(1,1,1),(1,1,0);meet(0,0,0),(0,1,0). Ordinary addition1+1=2;Boolean OR1∨1=1. Join/meet elementwise,ordinary row-column product அல்ல.

A zero–one matrix has entries that are only 0 or 1. Its arithmetic uses the Boolean operations ∧ and ∨:

b₁ ∧ b₂ = 1 if b₁ = b₂ = 1, otherwise 0
b₁ ∨ b₂ = 1 if b₁ = 1 or b₂ = 1, otherwise 0

For m × n zero–one matrices A = [aᵢⱼ] and B = [bᵢⱼ]:

Operation Notation (i, j) entry
Join A ∨ B aᵢⱼ ∨ bᵢⱼ (OR)
Meet A ∧ B aᵢⱼ ∧ bᵢⱼ (AND)

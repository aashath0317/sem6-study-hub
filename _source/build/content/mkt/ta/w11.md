- **செலுத்தும் விருப்பம்**: வாங்குபவர்களின் பண்புகளும் விருப்பங்களும்

## 6 படி விலையிடல் செயல்முறை

**புதிய தயாரிப்பை அறிமுகப்படுத்தும்போது**, **புதிய விநியோக வழியில்** நுழையும்போது அல்லது ஒப்பந்தப் பணிக்கு **விலைமனுக் கோரும்போது** நிறுவனம் விலை நிர்ணயிக்க வேண்டும்.

:::flow
1. விலையிடல் நோக்கத்தைத் தேர்ந்தெடுத்தல்
2. கேள்வியை நிர்ணயித்தல்
3. செலவுகளை மதிப்பிடுதல்
4. போட்டியாளர்களின் செலவுகள், விலைகள், வழங்கல்களைப் பகுப்பாய்வு செய்தல்
5. விலையிடல் முறையைத் தேர்ந்தெடுத்தல்
6. இறுதி விலையைத் தேர்ந்தெடுத்தல்
:::

### 1. விலையிடல் நோக்கத்தைத் தேர்ந்தெடுத்தல்
**நோக்கம் தெளிவாக இருக்குமளவு விலை நிர்ணயம் எளிதாகும்.**

| நோக்கம் | விலையிடல் விளைவு |
|---|---|
| **நிலைத்திருத்தல்** | கடுமையான போட்டியில் அளவை உயர்த்த **விலைகளைக் குறைத்தல்**. குறுகியகாலத்திற்கு மட்டும்: நீண்டகாலத்தில் செலவுகள் ஈடுசெய்யப்படுவதில்லை |
| **தற்போதைய இலாபத்தை அதிகபட்சமாக்குதல்** | **அதிகபட்ச தற்போதைய இலாபம்** தரும் விலை |
| **சந்தைப் பலனறுத்தல்** | சந்தையிலிருந்து பலனறுக்க **அதிக** விலைகள் |
| **சந்தைப் பங்கை அதிகபட்சமாக்குதல்** | கொள்ளளவு மற்றும் செலவுக் கட்டுப்பாடுகளுடன் பங்கை வளர்க்கும் நிலையான ஊடுருவல் விலை |
| **தயாரிப்புத் தரத் தலைமை** | தரம், **ஆராய்ச்சி மற்றும் அபிவிருத்தியை** ஈடுசெய்து சிறந்த தரத்தைக் காட்ட **அதிக** விலைகள் |

### 2. கேள்வியை நிர்ணயித்தல்
- **விலை உணர்திறன்:** அதிக விலை பொதுவாகக் கேள்வியைக் குறைத்து **மாற்றீடுகளுக்கு** நகர்த்துகிறது.
- **கேள்வி வளைகோடு:** விலைக்கும் கேட்கப்படும் அளவிற்கும் இடையிலான புள்ளியியல் உறவு. பொதுவாக **நேர்மாறானது**.
- **கேள்வியின் விலை நெகிழ்ச்சி:**

:::formula
**விலை நெகிழ்ச்சி = கேட்கப்படும் அளவின் % மாற்றம் ÷ விலையின் % மாற்றம்**
:::

- **நெகிழ்ச்சியுள்ள** (|E| > 1): விலையுடன் கேள்வி அதிகமாக மாறுகிறது.
- **நெகிழ்ச்சியற்ற** (|E| < 1): கேள்வி மிகக் குறைவாக மாறுகிறது.

**கருத்தாய்வுகள், விலைப் பரிசோதனைகள், புள்ளியியல் பகுப்பாய்வு** மூலம் கேள்வி வளைகோடுகள் அளவிடப்படுகின்றன.

### 3. செலவுகளை மதிப்பிடுதல்
- **நிலையான மற்றும் மாறும் செலவுகள்:** விலை இரண்டையும் ஈடுசெய்ய வேண்டும். சராசரி அலகுச் செலவுகள் **பொருத்தமான வெளியீட்டு வரம்பில் குறையலாம்** (அளவு/அனுபவம்); மொத்தச் செலவுகள் குறைய வேண்டியதில்லை; அளவுப் பாதகங்களும் ஏற்படலாம்; எனவே **வெவ்வேறு வெளியீட்டு நிலைகளில்** மதிப்பிடவும்.
- **செயற்பாட்டு அடிப்படையிலான செலவிடல் (ABC):** வெவ்வேறு சில்லறை விற்பனையாளர்களுக்குச் சேவை செய்ய வெவ்வேறு செலவுகள்.
- **இலக்குச் செலவிடல்:** **தயாரிப்பு விற்கக்கூடிய விலையிலிருந்து** தொடங்கி, **விரும்பிய இலாப வரம்பைக்** கழிக்கும்போது வடிவமைப்பு, பொறியியல், உற்பத்தி அடைய வேண்டிய **செலவு இலக்கு** கிடைக்கிறது.

### 4. போட்டியாளர்களைப் பகுப்பாய்வு செய்தல்
பொதுத் தரவு மற்றும் அறிக்கைகளால் உங்கள் விலை, தரம் மற்றும் போட்டியாளர் செலவுகளை **ஒப்பீட்டளவிடவும்**. போட்டியாளர் விலையை மாற்றும்போது **மூன்று பதில்கள்** உள்ளன:

1. **தற்போதைய நிலையைப் பேணுதல்** (பதிலளிக்காமை)
2. அவர்களின் விலைக்கு **இணையாக்குதல்**
3. அவர்களைவிட **குறைவாக விலையிடுதல்**

### 5. விலையிடல் முறையைத் தேர்ந்தெடுத்தல்

| அடிப்படை | முறை | எவ்வாறு |
|---|---|---|
| **செலவு அடிப்படை** | **செலவு-கூட்டல் (மேலதிக விகிதம்)** | விலை = சராசரிச் செலவு + மேலதிக விகிதம் %. முழுச் செலவு விலையிடலில் **P = அலகு மொத்தச் செலவு × (1 + மேலதிக விகிதம்)**; அலகு மொத்தச் செலவு = அலகு மாறும் செலவு + நிலையான செலவு / திட்டமிட்ட அலகுகள். மாறும் செலவு-கூட்டல் முறையில் அந்த வேறுபட்ட செலவு அடிப்படையை வெளிப்படையாகக் கூற வேண்டும். உற்பத்தியில் மிகப் பொதுவானது. **+** குறைந்த தகவல், எளிமை, செலவு மாற்றங்களிலிருந்து பாதுகாப்பு. **−** **போட்டியாளர்களையும் வாடிக்கையாளர்களையும் புறக்கணிக்கிறது** |
| | **இலக்கு ஈட்டம்** | **முதலீடு செய்யப்பட்ட மூலதனத்தில் விரும்பிய ஈட்டம்** தரும் விலை |
| **வாடிக்கையாளர் அடிப்படை** | **நல்ல மதிப்பு விலையிடல்** | **நியாயமான விலையில் தரமும் சேவையும் சரியாகக் கலந்தமை** |
| | **மதிப்புச் சேர்க்கப்பட்ட (உணரப்பட்ட மதிப்பு) விலையிடல்** | வேறுபடுத்த **அம்சங்களையும் சேவைகளையும் சேர்த்து**, பின்னர் **அதிகம் அறவிடுதல்** |
| **போட்டியாளர் அடிப்படை** | **நடப்பு வீத விலையிடல்** | போட்டியாளர் விலைகளை ஒப்பீட்டளவிடுதல் (ஒரே வழித்தட விமானங்கள்; பாடநூல் பதிப்பாளர்கள்) |
| | **மூடிய விலைமனு விலையிடல்** | போட்டியாளர்கள் எதிர்பார்க்கப்படும் விலைமனுக்களின் அடிப்படையில் விலைமனு வழங்குதல்; வழங்கல் கேள்விப்பத்திர விதிகள், தகுதி, விவரக்குறிப்புகளில் தங்கியுள்ளது; மிகக் குறைந்த விலை மட்டும் வெற்றிபெற வேண்டியதில்லை |

### 6. இறுதி விலையைத் தேர்ந்தெடுத்தல்
விலையிடல் முறைகள் வரம்பைக் குறுக்குகின்றன. இறுதித் தேர்வு மேலும் கருத்திற்கொள்பவை:

- **பிற சந்தைப்படுத்தல் செயற்பாடுகளின் தாக்கம்**
- **நிறுவன விலைக் கொள்கைகள்**
- **பலன்–ஆபத்துப் பகிர்வு விலையிடல்**
- **பிற தரப்புகளின் மீதான தாக்கம்** (விநியோகஸ்தர்கள், போட்டியாளர்கள், அரசு)

## விலை மாற்றங்களும் எதிர்வினைகளும்

### விலைக் குறைப்புகளைத் தொடங்குதல்
- **ஏன்:** **மிகை உற்பத்தித் திறன்**, வலுவான விலைப் போட்டியில் **குறைந்துவரும் கேள்வி**, **பலவீனமான பொருளாதாரம்**, அல்லது **குறைந்த செலவுகள் மூலம் ஆதிக்கம் செலுத்தி** பங்கையும் அளவையும் பெறுதல். *எடுத்துக்காட்டு:* வளரும் சந்தைகளில் **Lenovo** கைப்பேசிகளின் தீவிரக் குறைந்த விலைகள்.
- **ஆபத்து:** **விலைப் போர்கள்**, குறைந்த இலாப வரம்புகள்.

### விலை உயர்வுகளைத் தொடங்குதல்
- **ஏன்:** **செலவுப் பணவீக்கம்**, அல்லது **வழங்கலை மீறும் கேள்வி** (எ.கா. எண்ணெய் மற்றும் எரிவாயுத் துறை).

:::example 1% விலை உயர்வின் சக்தி
இலாப வரம்பு **விற்பனையின் 3%** எனில், அளவும் **மொத்தச் செலவுகளும் மாறாத நிலையில் 1% விலை உயர்வு**, இலாபத்தை **1/3 ≈ 33%** உயர்த்துகிறது.

*சரிபார்த்தல்:* விற்பனை Rs 100 → இலாபம் Rs 3. அதே செலவில் 1% உயர்வு விற்பனையை Rs 101 ஆக்குகிறது; எனவே இலாபம் Rs 4; இது +33%.
:::

**அநியாயமாக அதிக விலை அறவிடுபவராகத் தோன்றுவதைத் தவிர்க்கவும்.** நுகர்வோர் நீண்டகாலம் நினைவில் வைப்பர்; அநியாய விலை ஒழுங்குபடுத்தலைக் கொண்டுவரலாம்.

- உயர்விற்கான காரணங்களை **விளக்கவும்**.
- **மாற்றுவழிகளைக் கண்டறியவும்:** தயாரிப்பைச் சுருக்குதல் (சிறிய பொதி), மலிவான மூலப்பொருட்கள், அம்சங்கள் அல்லது சேவைகளை நீக்குதல், முன்பு சேர்த்திருந்த கூறுகளுக்குத் தனித்தனியாக விலையிடுதல்.

### வாங்குபவர் மற்றும் போட்டியாளர் எதிர்வினைகள்
**விலையும் பிம்பமும் நெருக்கமாக இணைந்தவை:**

- **Rolex விலை உயர்வு**, அதிக தனிச்சிறப்பு அல்லது சிறந்த தரத்தைக் குறிக்கலாம்.
- **Rolex விலைக் குறைப்பு**, **குறைந்த தரத்தையும்** மங்கிய ஆடம்பரப் பிம்பத்தையும் குறிக்கலாம்.

எனவே **விலைக் குறைப்புகள் வர்த்தகநாமத்தை வாடிக்கையாளர்கள் காணும் விதத்தைப் பாதிக்கலாம்**.

:::exam
எதிர்பார்க்கப்படுபவை:

- **அக மற்றும் புற விலையிடல் காரணிகள்**
- **விலையிடல் செயல்முறை** (உங்கள் தயாரிப்புடன் விளக்குக)
- **விலை நெகிழ்ச்சி**
- **செலவு-கூட்டல், இலக்கு ஈட்டம், மதிப்பு, நடப்பு வீத** விலையிடல்
- ஒவ்வொன்றின் நிபந்தனைகளுடன் **பலனறுத்தலும் ஊடுருவலும்**
- எடுத்துக்காட்டுகளுடன் **ஏழு சரிசெய்தல் உத்திகள்** (ஐந்து புவியியல் முறைகள்)
- **குறைப்புகளையும் உயர்வுகளையும் தொடங்குதல்** (3% → 33% எடுத்துக்காட்டு)
- FMCG விலை மாற்றங்கள்: பொதி அளவைக் குறைத்தல், மேம்படுத்தல்கள், உயர்வுகளை விளக்குதல்
:::

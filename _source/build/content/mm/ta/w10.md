## Selection, transforms, cloning, Activity 10.1

Click, region drag, name அல்லது colour/category போன்ற properties மூலம் select செய்யலாம். **Select and Move**, **Select and Rotate**, பொருத்தமான **Select and Scale** mode பயன்படுத்தவும். இவை object placement/dimensions மாற்றும். View navigation வேறு. Objects இடையில் துல்லியமான உறவு தேவைப்பட்டால் alignment tools பயன்படுத்தவும்.

**Cloning** என்பது objects அல்லது selection sets duplicate செய்வது. PDF கூறும் முறைகள்:

- **SHIFT+Clone:** காட்டப்பட்ட workflow-இல் selection-ஐ mouse மூலம் transform செய்யும்போது SHIFT பிடிக்கவும்.
- **Snapshot:** animated object-ஐத் தேர்ந்த times அல்லது movement spacing-இல் copies உருவாக்கவும்.
- **Array:** repeated copies-ஐ ஒழுங்காக அமைக்கவும்.
- **Mirror:** reflected arrangement உருவாக்கவும்.
- **Spacing Tool:** route-இல் objects பகிர்ந்து வைக்கவும்.
- **Clone and Align:** duplicate செய்து targets-க்கு align செய்யவும்.

Snapshot spacing uniform time intervals அல்லது uniform distance அடிப்படையில் இருக்கலாம். Speed மாறும்போது இவை வேறுபடும். ஒவ்வொரு copy-யையும் கையால் வைப்பதைவிட வேண்டிய regularity-ஐத் தெளிவாக்கும் method தேர்வு செய்யவும்.

**Activity 10.1 கேள்வி:** Array Copy மூலம் figure-இன் repeated arrangement உருவாக்கி Quick Render snapshot எடுக்கவும். **முழு model விடை:** முதலில் figure-இன் rounded stack போல ஒரு முழு repeated unit உருவாக்கவும். Pivot அமைத்து material, proportions சரிபார்க்கவும். Select செய்து Array-இல் horizontal axis displacement, ஒரு row-க்கு count கொடுக்கவும். மற்ற horizontal axis-இலும் array விரித்து parallel rows உருவாக்கவும். Spacing preview செய்து தவறான overlap தவிர்க்கவும். Repeated unit ஒரேபடி இருக்கட்டும். Scene lighting, background சேர்த்து rows தெரியும் perspective/camera view தேர்வு செய்து Quick Render செய்யவும். Rendered image export செய்வதற்கு முன் editable scene சேமிக்கவும். PDF visual arrangement தருகிறது; numeric count அல்லது dimensions தரவில்லை. எனவே இவை design choices; கொடுக்கப்பட்ட data போல invent செய்யவில்லை.

## Object conversion-உம் நான்கு modelling systems-உம்

தற்போதைய representation தேவையான editing controls தராவிட்டால் object convert செய்யவும். Source **primitive, extended primitive, compound, Editable Poly, Editable Mesh, Editable Patch, NURBS** object types கூறுகிறது. Editable form sub-object வேலை செய்ய உதவும். ஆனால் primitive-இன் original parameters இழக்கலாம். அவை தேவைப்பட்டால் copy வைத்திருக்கவும். Conversion மட்டும் smooth surface உறுதி தராது.

| System | Representation, பலம் | வரம்பு அல்லது முடிவு |
|---|---|---|
| Polygonal | Vertices, edges polygon faces உருவாக்கும்; நேரடியான local editing | Coarse silhouette faceted ஆகலாம்; close-up-க்கு கூடுதல் geometry தேவை |
| Spline | Control points curves அமைக்கும்; B-spline, Bézier, NURBS உதாரணங்கள் | Smooth description-க்கும் பொருத்தமான rendered approximation தேவை |
| Patch | Control vertices flexible patches-ஐப் பாதிக்கும்; subdivide, join செய்யலாம் | Joins இடையில் continuity கவனிக்க வேண்டும் |
| Parametric | Dimensions, segment counts, base construction settings காக்கும் | மீதமுள்ள parameters, history-க்கு ஏற்ப flexibility இருக்கும் |

Lesson Outline **Graphite modelling** என்கிறது. Body polygonal modelling விளக்குகிறது. Graphite 3ds Max modelling-tool context; இங்கே தனி mathematical surface representation அல்ல. Body-இன் polygon/vertex/edge/face operations கற்கவும். Source parametric modelling பொதுவாக spline-based என்கிறது. Parametric என்பது retained parameters கட்டுப்படுத்துவது; splines மட்டும் அல்ல. Box primitive ஓர் எதிர் உதாரணம்.

Polygon density viewing, deformation தேவைக்கு ஏற்றதாக இருக்க வேண்டும். Shading smooth போல இருந்தாலும் silhouette angular ஆகலாம். Spline resolution-independent description என்பதால் computer இலவசமாக infinite detail render செய்யும் என்று இல்லை. Selected control vertices பெரிய surface regions-ஐப் பாதிப்பதால் patches organic forms-க்கு உதவும். தேவையான shape, edits-க்கு ஏற்ப representation தேர்வு செய்யவும்.

## Lathe, extrusion, lofting, modelling activities

**Lathe** profile-ஐ axis சுற்றிச் சுழற்றி surface of revolution உருவாக்கும். Figure 10.5 chess pawn காட்டுகிறது. Week 10 PDF தவறாக **Activity 12.2** எனக் கூறும் கேள்வி demonstration-க்குப் பிறகு pawn உருவாக்கச் சொல்கிறது. **முழு model விடை:** பொருத்தமான orthographic viewport-இல் grid, 2D snapping அமைக்கவும். Base axis-இலிருந்து foot, stem, collar, head வழியாக pawn-இன் ஒரு பக்க outline வரையவும். Profile ஒழுங்காகவும் self-intersections இல்லாமலும் இருக்கட்டும். Vertical axis சுற்றி Lathe செய்து axis align செய்து முழுச் சுற்று கொடுக்கவும். Seam, cap, surface normals பார்க்கவும். Silhouette-க்கு போதுமான segments கூட்டி material கொடுத்து render செய்யவும். Profile/modifier editable ஆக வைத்திருக்கவும். Axis தவறானால் hole அல்லது தேவையற்ற offset வடிவம் வரலாம்.

**Extrude** 2D shape-க்கு depth சேர்க்கும். Figure 10.6 flat outline solid ஆவதைக் காட்டுகிறது. Closed solid வேண்டுமெனில் closed outline பயன்படுத்தவும். Caps, depth direction பார்க்கவும். **Face Extrude** selected faces-ஐ அவற்றின் normals வழியாக நகர்த்தி original object-உடன் இணைக்கும் side faces உருவாக்கும். Figure 10.7 ring-இன் selected faces வெளியே நீள்வதைக் காட்டுகிறது. Modifier animatable parameters தரும். எல்லா editable-mesh extrude commands-உம் இதே behaviour தராது.

**Loft** path, அதில் வைக்கப்பட்ட cross-sectional shapes மூலம் form உருவாக்கும். Figure 10.8 curved route-இல் circular section செல்லும் வடிவம் காட்டுகிறது. Cross-sections/path சேர்க்கலாம், மாற்றலாம். Path/shape parameters animate செய்யலாம்; surface parameters மாற்றலாம்.

**Page 10-இன் Activity 10.3 கேள்வி:** modelling operations மீண்டும் செய்து காட்டப்பட்ட varying tubular form உருவாக்கவும். **முழு model விடை:** model நீளத்தில் path வரையவும். Circular அல்லது பொருத்தமான cross-sections உருவாக்கவும். Path கொண்டு loft அமைத்து தேவையான இடங்களில் sections வைத்து, காட்டியபடி narrowing/widening வர size மாற்றவும். எல்லா viewports-இலும் twisting, continuity பார்த்து section orientation அல்லது surface subdivisions மாற்றவும். Material கொடுத்து render செய்யவும். மேம்படுத்த path, shapes editable ஆக வைத்திருக்கவும்.

## Animation, texture mapping, rendering, இறுதி Activity 10.3

Animation-இல் **keys** முக்கிய parameter values-ஐ keyframes-இல் store செய்யும். Software **tweens** interpolate செய்யும். PDF quick workflow: **Auto Key** enable செய்து வேறு frame-க்கு சென்று object transformation மாற்றவும். Starting key பார்க்கவும். Recording முடிந்ததும் Auto Key off செய்யவும். இல்லையெனில் பின்னர் edits தவறாக animation keys ஆகலாம்.

3ds Max position, rotation, scale மட்டும் animate செய்யாது. Source Bend/Taper modifier angles, material colour/transparency உதாரணங்கள் தருகிறது. Simple character-க்கு தொடர்புடைய parts சரியான hierarchy-இல் இருக்கட்டும். Parent நகர்ந்தால் children உடன் நகரும். Detailed motion சேர்க்குமுன் poses, pivots, timing திட்டமிடவும். முழு sequence preview செய்து contact, intersections, தேவையற்ற அசைவு பார்க்கவும். Outline character animation கேட்கிறது; PDF rigging tutorial தரவில்லை. இது அதன் parameter-keying model-இன் practical பயன்பாடு.

**Texture mapping** geometry-இல் surface detail கொடுக்கும். Wood grain, zebra stripes ஒவ்வொன்றையும் geometry-ஆக model செய்யாமல் image மூலம் தரலாம். Mapping coordinates image surface-இல் எப்படி படரும் என்பதை நிர்ணயிக்கும். Stretching, scale, seams, texture direction-form உறவு பார்க்கவும். Texture appearance மாற்றும்; object silhouette தானாக மாறாது.

**Rendering** scene, view, geometry, materials, lighting மூலம் output picture/frame sequence கணக்கிடும். Viewport preview வேகமாக வேலை செய்ய உதவும். Render intended output பார்க்க உதவும். Camera/view, output dimensions, frame range, destination அமைக்கவும். Animation முழுவதும் render செய்வதற்கு முன் representative frames preview செய்யவும். Textures சரியாகக் கிடைக்கிறதா, saved scene assets-உடன் மீண்டும் திறக்கிறதா பார்க்கவும்.

Starting pose, key அமைக்கவும். Later frame-க்கு சென்று Auto Key-உடன் transform அல்லது modifier parameter மாற்றவும். Play செய்து interpolation மேம்படுத்தி Auto Key off செய்யவும். Material உருவாக்கி/தேர்வு செய்து image map load செய்து object-க்கு assign செய்யவும். Stretch வராமல் mapping மாற்றவும். Light, பயனுள்ள camera view சேர்க்கவும். Material detail பார்க்க still render செய்து, பின்னர் தேவையான animation range-ஐ தனி output-க்கு render செய்யவும். Start, middle, end frames-இல் continuous motion, consistent texture பார்க்கவும். கிடைக்காத demonstrations-இன் exact settings invent செய்யப்படவில்லை.

“A parametric primitive is created with editable dimensions and segments. Modelling operations change or extend its geometry. Lathe revolves a profile, Extrude adds depth, and Loft combines a path with cross-sections. Keyframes store important parameter values for interpolation. Texture mapping adds surface detail, while rendering produces the final view from geometry, materials, lighting and camera settings.”

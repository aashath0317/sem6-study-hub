## முடிவெடுக்கும் மரங்கள்

:::key முடிவெடுக்கும் மரம் என்றால் என்ன?
**முடிவெடுக்கும் மரம்**, **தொடர்புடைய தேர்வுகளின் தொடரிலுள்ள சாத்தியமான விளைவுகளின் வரைபடம்**. அவற்றின் **செலவுகள், நிகழ்தகவுகள், நன்மைகள்** அடிப்படையில் நபரோ நிறுவனமோ **சாத்தியமான நடவடிக்கைகளை ஒன்றுடன் ஒன்று ஒப்பிட்டு மதிப்பிட** உதவுகிறது.
:::

- **மரம் போன்ற முடிவு மாதிரியைப்** பயன்படுத்துகிறது: சாத்தியமான விளைவுகளாகக் கிளைக்கும் **ஒற்றைக் கணுவில்** தொடங்குகிறது; ஒவ்வொரு விளைவும் மேலும் கணுக்களுக்கு இட்டுச் செல்கிறது.
- **முறைசாரா கலந்துரையாடலை** வழிநடத்தலாம் அல்லது சிறந்த தேர்வைக் கணித ரீதியாக முன்னறிவிக்கும் **படிமுறையை** வரைபடமாக்கலாம்.
- **வேருள்ள மரம்**, **வேர்** என்ற ஒரு சிறப்புக் கணு தனித்துக் குறிக்கப்பட்ட மரம்.

:::example நான் கார் வாங்க வேண்டுமா? [[01:44]]
- **நான் கார் வாங்க வேண்டுமா?** → எனக்கு நல்ல பொதுப் போக்குவரத்து உள்ளதா?
  - **ஆம்** → வாங்க வேண்டாம்
  - **இல்லை** → வாங்கவும்
- **வாங்குவதில்லை** என முடிவெடுத்தால் → நகரத்துக்கு வெளியே அடிக்கடி பயணிக்கிறேனா?
  - **ஆம்** → வாங்குவதைக் கருத்தில்கொள்க
  - **இல்லை** → வாங்க வேண்டாம்

மரம் **ஒரு கணுவில்** (கேள்வி) தொடங்கி, விளைவுகளாகக் (**ஆம் / இல்லை**) கிளைக்கிறது; ஒவ்வொரு விளைவும் மேலும் கணுக்களுக்கு இட்டுச் செல்கிறது.
:::

:::key வரையறை 1
**ஒவ்வொரு உள்முனையும் ஒரு முடிவுக்குப் பொருந்தி**, அந்த முடிவின் **ஒவ்வொரு சாத்தியமான விளைவுக்கும் அம்முனைகளில் உட்மரம்** இருக்கும் வேருள்ள மரம் **முடிவெடுக்கும் மரம்**.
:::

### உங்கள் சொந்த முடிவெடுக்கும் மரத்தை வரைதல்

| குறியீடு | குறிப்பது |
|---|---|
| **சதுரம்** ■ | எடுக்க வேண்டிய **முடிவு** |
| **வட்டம்** ● | **நிச்சயமற்ற** விளைவு (வாய்ப்பு) |
| எதுவுமில்லை / **முக்கோணம்** ▲ | இறுதி **முடிவு** |

:::flow
1. முடிவை இடப்புறத்தில் **சிறிய சதுரமாக** வரைக
2. வலப்புறத்தில் **விருப்பத்துக்கு ஒரு கோடு** வரைந்து அடையாளமிடுக
3. ஒவ்வொரு கோட்டின் முடிவிலும்: மற்றொரு முடிவு → **சதுரம்**; நிச்சயமற்றது → **வட்டம்**; விளைவு → எதுவுமில்லை
4. சதுரங்களிலிருந்து **தேர்வுகளையும்**, வட்டங்களிலிருந்து **சாத்தியமான விளைவுகளையும்** வரைக
5. ஒவ்வொரு பாதையும் முடிவில் நிறைவடையும்வரை தொடர்க
:::

### முடிவெடுக்கும் மரத்தை மதிப்பிடுதல்

1. ஒவ்வொரு இறுதி விளைவின் **மதிப்பை மதிப்பிடவும்**.
2. ஒவ்வொரு **வட்டத்திலும்**, ஒவ்வொரு விளைவுக்கும் **நிகழ்தகவை** ஒதுக்கவும். அவற்றின் கூட்டுத்தொகை **100%** (அல்லது **1**) ஆக வேண்டும்.
3. **கணக்கிடவும்**: ஒவ்வொரு இறுதி மதிப்பையும் அதன் நிகழ்தகவால் பெருக்கி, ஒவ்வொரு வட்டத்திலும் கூட்டவும். **நிகர மதிப்பைப்** பெறப் பாதையிலுள்ள **செலவுகளைக்** கழிக்கவும்.
4. **அதிக மதிப்புள்ள** விருப்பத்தைத் தேர்ந்தெடுக்கவும்.

:::example பாடத்திலிருந்து
பதவி உயர்வின் நிகழ்தகவு **0.7**, அதன் மதிப்பு **80,000**; எனவே அக்கிளையின் பங்களிப்பு 0.7 × 80,000 = **56,000**.
:::

:::formula
வாய்ப்புக் கணுவின் **எதிர்பார்க்கப்படும் மதிப்பு** = Σ (நிகழ்தகவு × மதிப்பு)
:::

:::example சுயமதிப்பீடு 2: புதிய தயாரிப்பை அறிமுகப்படுத்தலாமா? [[v2 00:08]]
மரத்தில் இரு தேர்வுகள்: **உருவாக்கு** அல்லது **உருவாக்க வேண்டாம்** (இலாபம் $0). "உருவாக்கு" என்பதற்குக் கீழ் **வெற்றி / தோல்வி** வாய்ப்புக் கணுவும், பின்னர் **அதிக / நடுத்தர / குறைந்த**, **விற்கலாம் / மதிப்பற்றது** வாய்ப்புக் கணுக்களும் உள்ளன [[v2 01:28]].

ஆய்வும் உருவாக்கமும் **$400,000** செலவாகிறது. வெற்றி **70%**, தோல்வி **30%**.

**வெற்றியடைந்தால்** (**இரு ஆண்டுகளுக்கான** இலாபங்கள்):

| பிரபலம் | நிகழ்தகவு | ஆண்டு இலாபம் | இரு ஆண்டு இலாபம் | நிகழ்தகவு × இலாபம் |
|---|---|---|---|---|
| அதிகம் | 0.2 | $500,000 | $1,000,000 | $200,000 |
| நடுத்தரம் | 0.5 | $400,000 | $800,000 | $400,000 |
| குறைவு | 0.3 | $300,000 | $600,000 | $180,000 |
| | | | **EV(வெற்றி)** | **$780,000** |

**தோல்வியடைந்தால்:** 0.6 × $50,000 + 0.4 × $0 = **$30,000**

**அறிமுகம்:** 0.7 × 780,000 + 0.3 × 30,000 = 546,000 + 9,000 = **$555,000**

**ஆய்வு–உருவாக்கச் செலவுக்குப் பின் நிகரம்:** 555,000 − 400,000 = **$155,000 > 0**

**பரிந்துரை:** உருவாக்கித் தயாரிப்பை அறிமுகப்படுத்தவும்; அறிமுகப்படுத்தாததன் **$0**-உடன் ஒப்பிடும்போது எதிர்பார்க்கப்படும் நிகர மதிப்பு நேர்மறையானது (**+$155,000**).
:::

### நன்மைகளும் தீமைகளும்

| நன்மைகள் | தீமைகள் |
|---|---|
| **அதிகக் கணக்கீடின்றி** வகைப்படுத்தலாம் | **பல வகுப்புகளும் சில பயிற்சி எடுத்துக்காட்டுகளும்** இருக்கும்போது **பிழைகள் ஏற்படக்கூடியது** |
| **தொடர்ச்சியான, வகைசார்** இருவகை மாறிகளையும் கையாளும் | **பயிற்றுவிக்க அதிகக் கணக்கீட்டுச் செலவு** (மரத்தை வளர்ப்பது செலவுடையது) |
| முன்னறிவிப்புக்கு **எந்தப் புலங்கள் முக்கியம்** எனத் தெளிவாகக் காட்டும் | |

விரிவுரை மேலும் சேர்ப்பவை [[05:23]]:

:::grid
**மேலும் நன்மைகள்**

1. பகுப்பாய்வுப் பின்னணி இல்லாதவர்களுக்கும் **புரிந்துகொள்ள எளிது**
2. **தரவு ஆராய்வில்** பயனுள்ளது: மிகவும் முக்கிய மாறிகளையும் அவற்றுக்கிடையிலான தொடர்புகளையும் கண்டறியும் விரைவான வழிகளில் ஒன்று
3. **தரவுத் தயாரிப்புக்குப்** பயனர்களிடமிருந்து **குறைந்த முயற்சி** தேவை
4. குறைந்த அளவுமாற்றம் தேவைப்படலாம்; ஆனால் **தரவுத் தரச் சரிபார்ப்புகளும் விடுபட்ட அல்லது முரண்பாடான பெறுமதிகளுக்குப் பொருத்தமான கையாளுதலும் இன்னும் தேவை**
5. எண்ணியல், வகைசார் அம்சங்களை மாதிரியாக்கலாம்; ஆனால் **செயலாக்கத்துக்கேற்ற குறியாக்கமும் உள்ளீட்டுக் கட்டுப்பாடுகளும் இன்னும் முக்கியம்**
6. **அளவுரு சாராதது**: வெளிப் பகிர்வு அல்லது வகைப்படுத்திக் கட்டமைப்பு பற்றிய அனுமானங்கள் இல்லை
7. **நேரியலற்ற உறவுகளை** மாதிரியாக்கலாம்; ஆனால் செயல்திறன் இன்னும் தரவு, மர அளவு, பிரதிநிதித்துவம், பயிற்சிச் செயல்முறை ஆகியவற்றைச் சார்ந்தது
+++
**மேலும் தீமைகள்** [[06:38]]

1. **மிகைப்பொருத்தம்**: நன்றாகப் **பொதுமைப்படுத்தாத** அதிகச் சிக்கலான மரங்கள்
2. **நிலையற்றது**: தரவின் சிறிய மாறுபாடுகள் **முற்றிலும் வேறுபட்ட மரத்தை** உருவாக்கலாம்
3. **பல வகுப்பு அடையாளங்களுடன்** கணக்கீடுகள் **சிக்கலாகின்றன**
:::

**முடிவெடுக்கும் மரத்தை எப்போது பயன்படுத்துவது** [[07:14]]:

1. முடிவெடுப்பவருக்கு **இலக்கு** உள்ளது (எ.கா. இலாபத்தை அதிகரி, செலவை உகப்பாக்கு)
2. **பல நடவடிக்கை வழிகள்** உள்ளன
3. மாற்றுகளுக்கு **கணக்கிடக்கூடிய நன்மை அளவை** உள்ளது
4. **முடிவெடுப்பவரின் கட்டுப்பாட்டுக்கு அப்பாலான நிகழ்வுகள்** உள்ளன (எ.கா. சுற்றுச்சூழல் காரணிகள்)
5. எந்த விளைவு உண்மையில் நிகழும் என்பதில் **நிச்சயமின்மை** உள்ளது

**பயன்பாட்டுத் துறைகள்:** மருத்துவம், திட்டமிடல், மருந்தியல், மூலக்கூற்று உயிரியல், வானியல், உயிர்மருத்துவப் பொறியியல், உற்பத்தி, தயாரித்தல்.

### எடுத்துக்காட்டு 13.1: பூப்பந்து விளையாடலாமா?

சனிக்கிழமை விளையாடுவதா என முடிவெடுக்க, கடந்த பத்து நாட்களின் **வெப்பநிலை, காற்று, ஈரப்பதம், வானிலை நிலை** (வெயில், மேகம், மழை) ஆகியவற்றை **தேடல் அட்டவணையில்** பதிவு செய்கிறீர்கள்.

- சிக்கல்: சனிக்கிழமை வானிலை அட்டவணையின் **எந்த நிரையுடனும் பொருந்தாமல்** இருக்கலாம்.
- **முடிவெடுக்கும் மரம்** இதைத் தீர்க்கிறது. இறுதி முடிவுக்கான **ஒவ்வொரு பாதையையும்** கருதுகிறது.
- ஒவ்வொரு **கணுவும் பண்புக்கூறு**, ஒவ்வொரு **கிளையும்** அப்பண்புக்கூறின் **விளைவு**, ஒவ்வொரு **இலையும் இறுதி முடிவு** (விளையாடு / விளையாட வேண்டாம்).

:::example பூப்பந்து மரம் [[08:49]]
- **வானிலை = வெயில்** → **ஈரப்பதத்தைச்** சார்ந்தது: அதிகம் → **விளையாட வேண்டாம்**; இயல்பு → **விளையாடு**
- **வானிலை = மேகம்** → **விளையாடு** (மற்ற மாறிகள் முக்கியமல்ல)
- **வானிலை = மழை** → **காற்றைச்** சார்ந்தது: வலிமை → **விளையாட வேண்டாம்**; பலவீனம் → **விளையாடு**

இந்த மரத்தில் வெப்பநிலை ஒருபோதும் முக்கியமல்ல.
:::

:::example சுயமதிப்பீடு 1: A, B தொடரிகள்
**அடுத்தடுத்த இரு A-கள் இல்லாமலும்**, **ஒருபோதும் அடுத்தடுத்த மூன்று B-கள் இல்லாமலும்**, அகரவரிசை இலைகளுடன் நீளம் ஆறுடைய அனைத்துத் தொடரிகளையும் பட்டியலிடவும்.

ஒவ்வொரு எழுத்தாக மரத்தை உருவாக்கி, **AA** அல்லது **BBB** உருவான உடனே கிளையை வெட்டவும். **9** இலைகள் உள்ளன:

ABABAB · ABABBA · ABBABA · ABBABB · BABABA · BABABB · BABBAB · BBABAB · BBABBA

## மரச் சுற்றல்

**மரச் சுற்றல்**, வரைபுச் சுற்றலின் ஒரு வடிவம்: **மரத்தின் ஒவ்வொரு கணுவையும் துல்லியமாக ஒருமுறை** அணுகுதல் [[v2 03:43]]. **வரிசைப்படுத்தப்பட்ட வேருள்ள மரங்கள்** தகவலைச் சேமிக்கின்றன; **கோவைகளைப்** (எண்கள், மாறிகள், செயல்பாடுகள்) பிரதிநிதித்துவப்படுத்தலாம். தரவைப் பயன்படுத்த **ஒவ்வொரு முனையையும் அணுகும்** செயல்முறைகள் தேவை: **சுற்றல் படிமுறைகள்**. இரண்டும் **மறுசுழற்சியாக** வரையறுக்கப்படுகின்றன.

:::grid
**முன்வரிசை: வேர் முதலில்**

**வேர் r-ஐ** அணுகி, T₁-ஐ முன்வரிசையில் சுற்றி, பின்னர் T₂, … பின்னர் Tₙ (**இடமிருந்து வலமாக** உட்மரங்கள்).
+++
**பின்வரிசை: வேர் இறுதியில்**

T₁-ஐ பின்வரிசையில் சுற்றி, பின்னர் T₂, … பின்னர் Tₙ; **இறுதியாக வேர் r-ஐ அணுகவும்**.
:::

:::key வரையறை 2 (பின்வரிசை)
T என்பது வேர் r உடைய வரிசைப்படுத்தப்பட்ட வேருள்ள மரமாக இருக்கட்டும். T-இல் r மட்டும் எனில் r-தான் பின்வரிசைச் சுற்றல். இல்லாவிட்டால் இடமிருந்து வலமாக T₁, …, Tₙ உட்மரங்களுடன் பின்வரிசைச் சுற்றல் **T₁ … Tₙ-ஐ பின்வரிசையில் சுற்றி, r-ஐ அணுகுவதுடன் முடிகிறது**.
:::

### எடுத்துக்காட்டு 13.2.1

பாடத்தின் T மரத்தில் வேர் **a**, அதன் பிள்ளைகள் **b, c, d**. பின்னர்:

- **b** → e, f
- **e** → j, k
- **k** → n, o, p
- **d** → g, h, i
- **g** → l, m

:::example T-இன் முன்வரிசை
a, **b**, e, j, k, n, o, p, **f**, **c**, **d**, g, l, m, h, i
:::

:::warn PDF திருத்தம்
PDF, முன்வரிசையை "a, b, e, j, k, n, o, p, **j**, c, …" எனப் பட்டியலிடுகிறது. இரண்டாவது **j**, **f** ஆக வேண்டும். e-இன் உட்மரத்தை முடித்தபின் b-இன் அடுத்த பிள்ளை f-ஐ அணுகுகிறீர்கள்.
:::

:::example அதே மரத்தின் பின்வரிசை
j, n, o, p, k, e, f, b, c, l, m, g, h, i, d, a
:::

- **முன்வரிசை:** வேரிலிருந்து மரத்தைச் சுற்றி இடஞ்சுழியாக நடந்து, ஒவ்வொரு முனையையும் கடக்கும் **முதல்** முறை பட்டியலிடவும்.
- **பின்வரிசை:** ஒவ்வொரு முனையையும் கடக்கும் **இறுதி** முறை பட்டியலிடவும்.
:::

## படரும் மரங்கள்

:::key வரையறை
G எளிய வரைபாக இருக்கட்டும். G-இன் **படரும் மரம்**, **G-இன் ஒவ்வொரு முனையையும் கொண்ட மரமாக இருக்கும் G-இன் உள்வரைபு**.
:::

### ஒன்றைக் கண்டறிதல்: சுற்றுகளிலிருந்து விளிம்புகளை நீக்குதல்

:::example எடுத்துக்காட்டு 13.3.1
G **இணைந்தது**; ஆனால் **எளிய சுற்றுகள்** இருப்பதால் மரமல்ல.

1. **{a, e}-ஐ** நீக்கவும்: ஒரு சுற்று அகல்கிறது; G ஒவ்வொரு முனையுடனும் இணைந்தே உள்ளது.
2. **{e, f}-ஐ** நீக்கவும்: இரண்டாவது சுற்று அகல்கிறது.
3. **{c, g}-ஐ** நீக்கவும்: எளிய சுற்றுகள் எதுவும் மீதமில்லை.

முடிவு G-இன் **படரும் மரம்**.
:::

:::key தேற்றம் 1
எளிய வரைபுக்குப் **படரும் மரம் இருந்தால் மட்டுமே அது இணைந்திருக்கும்**.
:::

:::formula
**n** முனைகளுள்ள மரத்துக்கு **n − 1** விளிம்புகள்; எனவே **n முனைகளும் m விளிம்புகளும்** உள்ள இணைந்த வரைபிலிருந்து படரும் மரத்தைப் பெற **m − (n − 1) = m − n + 1** விளிம்புகளை நீக்க வேண்டும்.
:::

### பயன்பாடு: IP பல்பரப்பு (எடுத்துக்காட்டு 13.3.2)

:::grid
**ஒற்றைப்பரப்பு**

ஒவ்வொரு பெறும் கணினிக்கும் **தனிப் பிரதியை** அனுப்புதல். திறனற்றது: ஒரே தரவின் பல பிரதிகள் வலையமைப்பைக் கடக்கின்றன.
+++
**IP பல்பரப்பு**

பங்கேற்கும் பெறுநர்களுக்கு **வளையமற்ற வழங்கல் மரத்தைப்** பயன்படுத்தி, தேவையான இடங்களில் பிரதிகளைக் கிளைக்கவும். முழு இயற்பியல் வலையமைப்பின் ஒவ்வொரு சாதனத்தையும் இது உள்ளடக்க வேண்டியதில்லை.
:::

- தரவு **ஒருபோதும் வளையக்கூடாது**: திசைவியை அடைந்ததும் மீண்டும் அங்கே திரும்பக்கூடாது. வளையங்கள் **சுற்றுகள்**; எனவே திசைவிகள் **படரும் மரத்தை** உருவாக்குகின்றன.
- **முனைகள்:** பல்பரப்பு மூலம், திசைவிகள், பெறும் கணினிகளுள்ள துணைவலையமைப்புகள்.
- **விளிம்புகள்:** கணினிகள் மற்றும்/அல்லது திசைவிகளுக்கிடையிலான இணைப்புகள்.
- **வேர்:** **பல்பரப்பு மூலம்**.
- **இலைகள்:** **பெறும் கணினிகளைக் கொண்ட துணைவலையமைப்புகள்**.

:::exam
- **முடிவெடுக்கும் மரம்:** சதுரங்கள், வட்டங்களுடன் வரைந்து, ஒவ்வொரு வாய்ப்புக் கணுவிலும் **நிகழ்தகவு × மதிப்பு** காட்டி, **செலவுகளைக்** கழித்து, தெளிவான **பரிந்துரையை** வழங்கவும்.
- **சுற்றல்:** முழு முனைப் பட்டியலையும் எழுதி, ஒவ்வொரு முனையும் **துல்லியமாக ஒருமுறை** வருகிறதா எனச் சரிபார்க்கவும்.
- **படரும் மரம்:** ஒவ்வொரு சுற்றிலிருந்தும் ஒரு விளிம்பை நீக்கவும்; n முனைகளுள்ள மரத்துக்கு **n − 1 விளிம்புகள்**.
:::

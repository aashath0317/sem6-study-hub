1Why graphs?

Graph ஏன்?

நகரங்களும் சாலைகளும், மனிதர்களும் தொடர்புகளும் போன்றவற்றை எளிமையாக மாதிரியாக்கலாம். பொருட்கள் Vertices, தொடர்புகள் Edges. எந்த விவரத்தை edge காட்டுகிறது என்பதைக் முதலில் தெளிவுபடுத்த வேண்டும்.

Graphs are discrete structures made of vertices and edges that connect them. They model a huge range of problems:

  • Competition between species in an ecological niche
  • Who influences whom in an organisation
  • Round-robin tournament outcomes
  • Acquaintanceships between people and links between websites
  • Roadmaps and assigning jobs to employees
  • Whether a circuit fits on a planar circuit board
  • Telling apart chemical compounds with the same formula but different structures
  • Whether two computers are connected in a network

2The birth of graph theory — Königsberg

Königsberg பிரச்சினை

ஒவ்வொரு பாலத்தையும் ஒரே முறை கடக்க முடியுமா என்ற கேள்வியில் நிலப்பகுதிகள் vertices; பாலங்கள் edges. Map-இன் துல்லியத் தூரத்தைவிட இணைப்பும் degree-யும் முக்கியம் என்பதே graph modelling-இன் பலம்.

The Königsberg bridge problem
  • Königsberg (Prussia) lay on the Pregel river, which split the city into four landmasses (including the island of Kneiphopf).
  • Seven bridges linked them.
  • Residents asked: can you leave home, cross each bridge exactly once, and return home?
  • Leonhard Euler (1707–1783) solved it. He turned each landmass into a vertex (A, B, C, D) and each bridge into an edge. His method is considered the birth of graph theory.
Euler's answer: no

For a finite undirected graph whose non-isolated vertices are connected, a closed walk using every edge exactly once exists iff every vertex has even degree (you leave a landmass as often as you enter it).

In Königsberg the degrees are A = 5, B = 3, C = 3, D = 3, all odd, so it's impossible. Load the Königsberg preset in the graph lab below to see it.

3What is a graph?

Graph அடிப்படை

Graph என்பது vertices மற்றும் edges சேர்ந்த அமைப்பு. Degree ஒரு vertex-க்கு சேர்ந்த edges எண்ணிக்கை; undirected loop இரண்டு முறை எண்ணப்படும். ஒரு படம் வேறுபட்டுப் பார்த்தாலும் இணைப்பு ஒரே மாதிரி இருக்கலாம்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Finite graph-க்கு vertices எண்ணிக்கை finite; loops ஒரு vertex-ஐ அதனுடனே இணைக்கும்; parallel edges அதே endpoint pair-ஐ மீண்டும் இணைக்கும். Undirected degree sum Σdeg(v)=2|E|. Directed graph-இல் indegree/outdegree தனியாக. Total indegree=total outdegree=|E|. ஒரு arrow-ஐ undirected edge போல degree கணக்கில் கலக்காதீர்கள்.

முழுப் படிகளுடன் புரிந்துகொள்ள

G=(V,E),edge endpoints;loop same endpoint;parallel edges same pair. Undirected loopdegree-க்கு2 contribution;Σdegree=2|E|;directed indegrees sum=outdegrees sum=|E|. Finite simple nvertices-க்கு maxdegree n−1. Loops/multiple allowed என்றால் அந்த bound பொதுவாக இல்லை.

Definition 1

A graph G = (V, E) consists of:

  • V: a non-empty set of vertices (nodes)
  • E: a set of edges

Each edge has one or two vertices associated with it, called its endpoints. An edge connects its endpoints.

Term Meaning
Infinite graph Infinite vertex set (or infinitely many edges)
Finite graph Finite vertex set and finite edge set. This course uses finite graphs only 01:24
Multiple edges Two or more edges joining the same pair of vertices
Multiplicity m When m different edges join the same unordered pair {u, v}, {u, v} is an edge of multiplicity m 06:43
Loop An edge that starts and ends at the same vertex 05:20

Directed graphs (digraphs)

Some links work in one direction only (simplex links), e.g. heavy traffic one way. So we use directed edges (arcs), drawn as arrows 01:42.

Definition 2 — directed graph

A directed graph (digraph) G = (V, E) has a non-empty vertex set V and a set E of directed edges. Each directed edge is associated with an ordered pair (u, v): it starts at u and ends at v.

Ordered vs unordered pairs 03:06
  • {u, v} (undirected): you can travel u → v or v → u.
  • (u, v) (directed): you must start at u and end at v. San Francisco → Denver does not allow Denver → San Francisco.
Type Definition
Simple directed graph Directed, no loops, no multiple directed edges. At most one edge per ordered pair, so (u, v) names the edge
Directed multigraph Directed, multiple directed edges (and loops) allowed. Formally G = (V, E, f), where f maps each edge to an ordered pair (Figure 7: e₁ v₁→v₂, e₂ v₂→v₃, e₄ v₁→v₃)
Mixed graph Has both directed and undirected edges, e.g. a network with two-way and one-way links

Cities: Boston, Newark, Miami, Detroit, Washington.

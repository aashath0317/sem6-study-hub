2Equality, subsets & disjoint sets

Subset மற்றும் Disjoint

A-வின் ஒவ்வொரு உறுப்பும் B-யில் இருந்தால் A⊆B. A=B-யும் subset ஆகும். உறுப்புகள் பொதுவாக ஒன்றுமே இல்லாவிட்டால் Disjoint. Proper subset-இல் A, B சமமாக இருக்கக்கூடாது.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

A=B iff A⊆B and B⊆A. A⊂B proper subset-இல் குறைந்தது ஒரு B member A-இல் இருக்காது. Empty set எல்லா set-க்கும் subset. x∈A என்பது ஒரு member பற்றியது; B⊆A ஒரு set-இன் அனைத்து members பற்றியது. A={1,2} என்றால் 1∈A; {1}⊆A; இவை ஒரே notation அல்ல.

முழுப் படிகளுடன் புரிந்துகொள்ள

A⊆B என்றால் A-வின் எல்லாம்B-இல்;proper subset என்றால் மேலும்A≠B. A=B நிரூபிக்க இரு inclusions. ∅ எல்லா set-க்கும் subset;ஒவ்வொரு set-உம் தனக்கே subset. n-element set-க்கு 2ⁿ subsets,nonempty2ⁿ−1;proper subsets2ⁿ−1. Disjoint A∩B=∅;equal என்றால் அதே elements,order/repetition முக்கியமில்லை.

Equal sets (2.1.4)

A = B if and only if they have the same elements: ∀x (x ∈ A ⇔ x ∈ B).

  • {1, 3, 5} = {3, 5, 1}. Order doesn't matter.
  • {1, 3, 3, 3, 5, 5, 5, 5} = {1, 3, 5}. Repeats don't matter.

Subset (2.1.5) and proper subset (2.1.6)

Concept Notation Meaning
Subset A ⊆ B Every element of A is also in B
Equality via subsets A = B ⇔ A ⊆ B and B ⊆ A The standard way to prove two sets are equal
Proper subset A ⊂ B A ⊆ B but A ≠ B (B has at least one extra element)
Not a subset D ⊄ A Some element of D isn't in A
Example 2.1.6.1

A = {1, 3, 5}

  • B = {1, 5} → B ⊂ A (a proper subset)
  • C = {3, 1, 5} → C ⊆ A, but not proper, since C = A
  • D = {1, 4} → D ⊄ A, since 4 ∉ A
Example 2.1.6.2 — all subsets of A = {a, b, c}
  • 0 elements: ∅
  • 1 element: {a}, {b}, {c}
  • 2 elements: {a, b}, {a, c}, {b, c}
  • 3 elements: {a, b, c}

That's 8 = 2³ subsets. In general, a set with n elements has 2ⁿ subsets (this collection is the power set).

Classic traps
  • ∅ ⊆ A for every set A. But ∅ ∈ A only if ∅ is literally listed as an element.
  • 0 ≠ ∅. 0 is a number; ∅ is a set.
  • A ⊆ A is always true. A ⊂ A is always false.
  • {a, b} ∈ {a, b, c} is false: {a, b} is a subset, not an element.

Disjoint sets (2.1.7)

A and B are disjoint if they have no elements in common: A ∩ B = ∅.

Example 2.1.7.1: A = {1, 2}, B = {4, 5, 6}, C = {5, 6, 7, 8}. A and B are disjoint and A and C are disjoint, but B and C are not (they share 5 and 6).

சம கணங்கள் (2.1.4)

A, B ஒரே மூலகங்களைக் கொண்டிருந்தால் மட்டுமே A = B: ∀x (x ∈ A ⇔ x ∈ B).

  • {1, 3, 5} = {3, 5, 1}. வரிசை முக்கியமல்ல.
  • {1, 3, 3, 3, 5, 5, 5, 5} = {1, 3, 5}. மீளுரு முக்கியமல்ல.

உட்கணம் (2.1.5), முறையான உட்கணம் (2.1.6)

கருத்து குறியீடு பொருள்
உட்கணம் A ⊆ B A-இன் ஒவ்வொரு மூலகமும் B-இலும் உள்ளது
உட்கணங்களால் சமத்துவம் A = B ⇔ A ⊆ B மற்றும் B ⊆ A இரு கணங்களும் சமம் என நிறுவும் வழக்கமான முறை
முறையான உட்கணம் A ⊂ B A ⊆ B ஆனால் A ≠ B (B-இல் குறைந்தது ஒரு கூடுதல் மூலகம் உள்ளது)
உட்கணமல்ல D ⊄ A D-இன் சில மூலகம் A-இல் இல்லை
எடுத்துக்காட்டு 2.1.6.1

A = {1, 3, 5}

  • B = {1, 5} → B ⊂ A (முறையான உட்கணம்)
  • C = {3, 1, 5} → C ⊆ A; ஆனால் C = A என்பதால் முறையானதல்ல
  • D = {1, 4} → D ⊄ A; ஏனெனில் 4 ∉ A
எடுத்துக்காட்டு 2.1.6.2 — A = {a, b, c}-இன் அனைத்து உட்கணங்களும்
  • 0 மூலகங்கள்: ∅
  • 1 மூலகம்: {a}, {b}, {c}
  • 2 மூலகங்கள்: {a, b}, {a, c}, {b, c}
  • 3 மூலகங்கள்: {a, b, c}

அவை 8 = 2³ உட்கணங்கள். பொதுவாக n மூலகங்களுள்ள கணத்துக்கு 2ⁿ உட்கணங்கள் உள்ளன (இந்தத் தொகுப்பே அடுக்குக் கணம்).

வழக்கமான சிக்கல்கள்
  • ஒவ்வொரு கணம் A-க்கும் ∅ ⊆ A. ஆனால் ∅ ஒரு மூலகமாக நேரடியாகப் பட்டியலிடப்பட்டிருந்தால் மட்டுமே ∅ ∈ A.
  • 0 ≠ ∅. 0 ஓர் எண்; ∅ ஒரு கணம்.
  • A ⊆ A எப்போதும் உண்மை. A ⊂ A எப்போதும் பொய்.
  • {a, b} ∈ {a, b, c} என்பது பொய்: {a, b} ஓர் உட்கணம்; மூலகம் அல்ல.

வெட்டாத கணங்கள் (2.1.7)

A, B-க்கு பொதுவான மூலகங்கள் இல்லையெனில் அவை வெட்டாதவை: A ∩ B = ∅.

எடுத்துக்காட்டு 2.1.7.1: A = {1, 2}, B = {4, 5, 6}, C = {5, 6, 7, 8}. A, B வெட்டாதவை; A, C வெட்டாதவை; ஆனால் B, C வெட்டுகின்றன (5, 6 பொதுவானவை).

4Set operations

Union மற்றும் Intersection

A∪B A அல்லது B-யில் உள்ளவர்கள்; A∩B இரண்டிலும் உள்ளவர்கள். A−B A-யில் இருந்து B உறுப்புகளை நீக்கியது. Complement universal set-ஐப் பொறுத்தது; அதை மறக்காதீர்கள்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

A={1,2,3}, B={3,4} என்றால் union {1,2,3,4}; intersection {3}; A−B={1,2}; B−A={4}. Difference commutative அல்ல. A−B=A∩Bᶜ. Complement-க்கு universal set சொல்லாமல் விடை முழுமையடையாது. A∪A=A; A∩A=A; repetitions set size-ஐ உயர்த்தாது.

Intersection A ∩ B {x | x ∈ A and x ∈ B} The overlap only
Complement Aᶜ {x | x ∈ U and x ∉ A} Everything outside A
Difference A \ B (or A − B) {x | x ∈ A, x ∉ B} A minus the overlap
Example 2.3.1 — A = {a, b, c}, B = {a, c, d}, U = {a, b, c, d}
  • A ∪ B = {a, b, c, d}
  • A ∩ B = {a, c}
  • Aᶜ = {d}
  • A \ B = {b}
Example 2.3.2

5Set laws

தொகுப்புகளின் விதிகள்

எண் algebra போல set operations-க்கும் விதிகள் உள்ளன. (A∪B)ᶜ = Aᶜ∩Bᶜ என்பது De Morgan. Union-ஐ மறுக்கும் போது intersection ஆகும்; இரு sets-க்கும் complement வர வேண்டும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

Commutative: A∪B=B∪A; A∩B=B∩A. Associative: grouping மாற்றலாம். Distributive: A∩(B∪C)=(A∩B)∪(A∩C); dual rule-உம் உண்டு. De Morgan: (A∪B)ᶜ=Aᶜ∩Bᶜ; (A∩B)ᶜ=Aᶜ∪Bᶜ. Complement of complement A. Formula-ஐ Venn shading அல்லது arbitrary member argument மூலம் சோதிக்கலாம்.

முழுப் படிகளுடன் புரிந்துகொள்ள

De Morgan:(A∪B)ᶜ=Aᶜ∩Bᶜ;(A∩B)ᶜ=Aᶜ∪Bᶜ. Complement செய்யும்போது union/intersection மாற்றி ஒவ்வொன்றையும் complement செய். Commutative order;associative grouping;distributive ஒரு operation-ஐ மற்ற grouping-க்குள் விரித்தல். U1…10,A1,2,4,8,9;B3,4,5,6,8→இருபக்கமும்{7,10}. ஒரே example law-க்கு general proof அல்ல;membership equivalence மூலம் general proof தரலாம்.

Complementation rules

a. Uᶜ = ∅ b. ∅ᶜ = U c. (Aᶜ)ᶜ = A d. A ∪ Aᶜ = U e. A ∩ Aᶜ = ∅

Properties of set operations

Law Union Intersection
Commutative A ∪ B = B ∪ A A ∩ B = B ∩ A
Associative A ∪ (B ∪ C) = (A ∪ B) ∪ C A ∩ (B ∩ C) = (A ∩ B) ∩ C
Distributive A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

De Morgan's laws

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
Tip

Complementing a union or intersection flips ∪ ↔ ∩ and complements each set. It's the same pattern as ¬(p ∨ q) ≡ ¬p ∧ ¬q in logic. Check both sides in the shader: type (A ∪ B)' and then A' ∩ B'.

6Number of elements — inclusion–exclusion

இருமுறை எண்ணுவதைத் தவிர்த்தல்

|A∪B| = |A| + |B| − |A∩B|. இரண்டு பாடங்களையும் படிப்பவர் இருமுறை எண்ணப்பட்டதால் intersection-ஐ ஒருமுறை கழிக்கிறோம். மூன்று sets-இல் pair overlaps கழித்து triple overlap மீண்டும் சேர்க்க வேண்டும்.

மேலும் புரிந்துகொள்ள · தேர்வுக் குறிப்புகள்

மூன்று Sets: |A∪B∪C|=|A|+|B|+|C|−|A∩B|−|A∩C|−|B∩C|+|A∩B∩C|. Only A=|A|−|A∩B| இரண்டு sets சூழலில். Neither=|U|−|A∪B|. “Exactly one”, “at least one”, “both” மூன்றும் வேறு பகுதிகள்; கேள்விச் சொல்லை வட்டமிடுங்கள்.

முழுப் படிகளுடன் புரிந்துகொள்ள

Inclusion–exclusion:|A∪B|=|A|+|B|−|A∩B|. Coffee100,sugar70,cream60,both50→only20/10,union80,exactly-one30,neither20. Three sets:singles−pair intersections+triple. Pair intersection counts-இல் triple பொதுவாக ஏற்கெனவே உள்ளது;“only pair” வேண்டுமெனில் triple கழிக்கவும். Venn fill order triple→pair-only→single-only→none;negative region வந்தால் data/interpretation பிழை.

  • If a set S has exactly n distinct elements (n a non-negative integer), S is finite and n is its cardinality, written |S| or n(S).
  • Example: A = odd positive integers less than 10, so |A| = 5. Also |∅| = 0.
n(A ∪ B) = n(A) + n(B) − n(A ∩ B) (principle of inclusion–exclusion)
If A and B are disjoint: n(A ∪ B) = n(A) + n(B)

Why subtract? Elements in both A and B are counted twice when you add n(A) + n(B).

Question Working Answer

(b) Only cream n(B) − n(A ∩ B) = 60 − 50 10
(c) Sugar or cream 70 + 60 − 50 80
(d) Exactly one item 20 + 10 30

(And 100 − 80 = 20 take neither.)

Three sets: n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C)

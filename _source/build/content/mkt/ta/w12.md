## மேம்படுத்தலுக்கு முன்

1. **உங்கள் தனித்துவ அம்சங்களையும் போட்டி அனுகூலத்தையும் அடையாளம் காணவும்**: உங்கள் **தனித்துவ மதிப்பு முன்மொழிவு**.
2. **இலக்குச் சந்தையை அணுகச் சிறந்த வழிகளைக் கண்டறியவும்**: அவர்களின் இணைய அறிவு, இணையத்தில் செலவிடும் நேரம், அச்சு, தொலைபேசி போன்றவற்றிற்கான விருப்பம்.
3. **பல கட்ட மேம்படுத்தல் உத்தியை வடிவமைக்கவும்.** ஒவ்வொரு கருவியும் வேறுபட்ட இலக்கிற்கு உதவுகிறது: **தனிப்பட்ட விற்பனை** நெருக்கமான உறவுகளை உருவாக்குகிறது; **விளம்பரம்** பெரிய பார்வையாளர் குழுக்களை அணுகுகிறது.

## விளம்பரம்

**அடையாளம் காணப்பட்ட அனுசரணையாளரின் கட்டண அறிவிப்புகள்** மூலம் தயாரிப்பிற்கு பொதுமக்களின் கவனத்தை ஈர்ப்பதே **விளம்பரம்**.

**நன்மைகள்:**

- பெரிய பார்வையாளர் குழுக்களில் நபரொன்றிற்கு **மிகக் குறைந்த செலவு**
- ஊடகங்கள் முழுவதும் **மீண்டும் வழங்கக்கூடியது**
- **மதிப்புச் சேர்த்து** நிறுவனப் பிம்பத்தை மேம்படுத்துகிறது

### விளம்பர உத்தி: நான்கு கொள்கைகள்
1. **தயாரிப்பின் குணங்கள்**: நோக்கம், அம்சங்கள், மாற்றுவழிகளைவிட அனுகூலங்கள். இவை செய்தியை வரையறுக்கின்றன.
2. **சந்தை நிலை**: வாங்கும் திறந்த மனப்பாங்கு, போட்டியாளர் பங்கு, பொருளாதாரம் (மந்தநிலையில் ஆடம்பரத்தை விற்பது கடினம்).
3. **விளம்பர இலக்குகள்**: பாதைவரைபடத்தையும் **விளைவுத்திறனை அளவிடும்** வழியையும் தரும் குறிப்பிட்ட இலக்குகள்.
4. **முறைமை**: தொனி, வலியுறுத்தப்படும் குணங்கள், **ஊடகம்** (தொலைக்காட்சி, சஞ்சிகைகள்), விளம்பர **இடம்**, **வரவுசெலவுத் திட்டம்**.

திட்டக் கூறுகள்: **தயாரிப்பும் அதன் அனுகூலங்களும்**, **வாடிக்கையாளரும் அவரது பண்புகளும்**, **வாங்குபவர்களுக்குத் தகவலளிக்கும் மாற்று வழிகள்**, **வரவுசெலவுத் திட்டத்திற்குள் தெரிவுகளை உகப்பாக்குதல்**. **எந்தத் திட்டமும் முழுமையானதல்ல**: வளங்கள் எப்போதும் வரையறுக்கப்பட்டவை.

இரண்டு முக்கியக் கூறுகள்:

1. **விளம்பரச் செய்தியை உருவாக்குதல்**: தயாரிப்பைப் பற்றிய சிறப்பான, தனித்துவமான ஒன்று.
2. **ஊடகங்களைத் தேர்ந்தெடுத்தல்**: செலவு–விளைவுத்திறன். **தவறான ஊடகத் தேர்வே பல விளம்பரத் தோல்விகளுக்குக் காரணம்.**

## செய்தி உத்தி

**கவனிக்க வேண்டிய காரணிகள்:**

- **இலக்குப் பார்வையாளரின் பண்புகள்** (வயது, இருப்பிடம், மனப்பாங்குகள்)
- **ஊடக வகை**
- **தயாரிப்புக் காரணிகள்** (புதியது அல்லது நிறுவப்பட்டது)
- **ஒட்டுமொத்த விளம்பர நோக்கம்** (உடனடி விற்பனை அல்லது ஆரம்ப விழிப்புணர்வு)

**படிகள்:** **நுகர்வோர் பயன்களை** அடையாளம் காணுதல் → **பொருளுள்ள, நம்பக்கூடிய, தனித்துவமான** ஈர்ப்புகளை உருவாக்குதல் → **படைப்பாக்கக் கருத்துருவை** உருவாக்குதல்.

### 1. செய்தியை வடிவமைத்தல்
**என்ன கூறுவது** (உள்ளடக்கம்), **எவ்வாறு கூறுவது** (கட்டமைப்பும் வடிவமும்) எனத் தீர்மானிக்கவும்.

### 2. ஈர்ப்பு

| ஈர்ப்பு | செயல்படும் விதம் | எடுத்துக்காட்டு |
|---|---|---|
| **பகுத்தறிவு** | **ஆதாரமும் காரணமும்**; **சுயநலனை** ஈர்க்கிறது | "30% எரிபொருளைச் சேமிக்கிறது" |
| **உணர்வுபூர்வம்** | வாங்கத் தூண்டும் **நேர்மறை அல்லது எதிர்மறை உணர்வுகளை** (அன்பு, பெருமை, மகிழ்ச்சி, நகைச்சுவை, அச்சம்) எழுப்புகிறது | பால்மா விளம்பரத்தில் குடும்பத் தருணங்கள் |
| **அறநெறி** | **சரியானதும் பொருத்தமானதும்** பற்றிய உணர்வை ஈர்க்கிறது | "மது அருந்திவிட்டு வாகனம் ஓட்டாதீர்", அறப்பணிப் பிரசாரங்கள் |

### 3. செய்திக் கட்டமைப்பு: மூன்று விடயங்கள்
1. பார்வையாளருக்கு **முடிவை வழங்குவதா**, அல்லது **அவர்களிடமே விடுவதா**?
2. **வலுவான வாதங்களை முதலில் அல்லது இறுதியில்** வைப்பதா?
3. **ஒருபக்கமானதா** (பலங்கள் மட்டும்), **இருபக்கமானதா** (பலங்களும் ஏற்றுக்கொள்ளப்பட்ட குறைபாடுகளும்)?

### 4. செய்தி வடிவம்
**புதுமையும் மாறுபாடும்** (கண்கவர் படங்கள், தலைப்புகள்), **தனித்துவ வடிவங்கள்** (அளவு, இடம்), **நிறம், வடிவம், அசைவு** பயன்படுத்தவும்.

**தெளிவான சந்தைப்படுத்தல் செய்திகள்:**

| பண்பு | எடுத்துக்காட்டு |
|---|---|
| **விடயத்தை நேரடியாகக் கூறுதல்** | "எங்கள் மென்பொருள் உங்கள் உற்பத்தி நேரத்தைக் குறைக்கிறது." |
| **வாடிக்கையாளரின் பார்வையை எடுத்தல்** | "எங்கள் தயாரிப்பைக் கற்க அதிகபட்சம் இரண்டு நிமிடங்களே தேவை." |
| **பழக்கமான மொழி** | "உங்கள் விற்பனைக் குழு பரிவர்த்தனைகளை விரைவாக முடிக்க உதவுகிறோம்." |
| **முறைசாராத உணர்வு** | "ஆச்சரியங்கள் இன்றி. எப்போதும்." |
| **புதுமையான ஒன்றைக் கூறுதல்** | "அதிர்ஷ்டலாபம் வென்றதாக எண்ணுமளவு சேமிப்பீர்கள்." |
| **விளக்கம் தேவையில்லை** | "உங்கள் விளம்பரங்களுக்கு அதிக பார்வைகளைப் பெறுகிறோம்." |
| **புன்னகைக்கச் செய்தல்** | "ஏவுகணை அறிவியலும் மூளை அறுவைச் சிகிச்சையும் இணைந்தது; ஆனால் பயன்படுத்த எளிது." |

## பொதுமக்கள் தொடர்பு

- **PR**, **புதிய வாடிக்கையாளர்களை ஈர்க்கவும் தற்போதைய விசுவாசத்தை வலுப்படுத்தவும்** வணிகம் பற்றிய **புலனுணர்வுகளை** முகாமைத்துவம் செய்கிறது.
- இடஒதுக்கீட்டுக் கட்டணமின்றி **ஈட்டிய ஊடகச் செய்தியை** PR நாடலாம்; ஆனால் பணியாளர்கள், நிகழ்வுகள், அனுசரணைகளுக்குச் செலவாகும்.
- சுயாதீனச் செய்தி நம்பகமாக **இருக்கலாம்**; நம்பகத்தன்மை மூலத்திலும் சூழலிலும் தங்கியுள்ளது; உலகளாவிய PR அனுகூலம் அல்ல.
- பரந்த சந்தைப்படுத்தல் தொடர்பாடலின் பகுதியாகவும் நிறுவன/பொது உறவுகளுக்குச் சேவை செய்வதாகவும் PR உள்ளது; சந்தைப்படுத்தலும் விழிப்புணர்வு மற்றும் நடத்தை மாற்றத்தை நாடலாம்.

| PR கருவி | அது என்ன |
|---|---|
| **ஊடக உறவுகள்** | ஆர்வமுள்ள கதைகளை (உண்மைகள், வாடிக்கையாளர் கதைகள், பேச்சாளர் செய்திகள்) செய்தித்தாள்கள், சஞ்சிகைகள், தொலைக்காட்சி, இணையத்திற்கு முன்வைத்தல். நல்ல தொடர்புப் பட்டியல்கள் **நெருக்கடிகளை முகாமைத்துவம் செய்யவும்** உதவுகின்றன |
| **விளம்பரக் கட்டுரைகள்** | **ஆசிரியர் உள்ளடக்கம்போல் வடிவமைக்கப்பட்ட கட்டண விளம்பரம்**; அனுசரணை உள்ளடக்கம் எனத் தெளிவாகக் காட்ட வேண்டும்; சுயாதீனமாக ஈட்டிய செய்தி அல்ல |
| **சமூக ஊடகம்** | **ஊடகத்தைத் தாண்டி** நேரடியாக வாடிக்கையாளர்களுடன் பேசுதல்; எதிர்மறைப் புலனுணர்வுகளுக்கு விரைவாகப் பதிலளித்தல் |
| **செய்திமடல்கள்** | அச்சு அல்லது மின்னஞ்சல்: வழக்கமான தொடர்பு, புதிய அறிமுகங்கள், வலுவான உறவுகள் |
| **சிற்றேடுகளும் பட்டியல்களும்** | வாடிக்கையாளர்கள் உங்களை நினைக்க வைத்தல்; தளம் அல்லது கடைக்கு வருகைகளை இயக்குதல் |
| **வணிக நிகழ்வுகள்** | வெளிப்பாடு, அறிமுகங்கள், சந்தேகங்களுக்குப் பதில், சந்தை ஆராய்ச்சி, அஞ்சல் பட்டியல் உருவாக்கம் |
| **பேச்சு நிகழ்வுகள்** | நிறுவனத்தைத் **தலைவராக** நிலைப்படுத்தும் உரைகள்; தொடர்புவலையமைத்தல் |

| **பணியாளர் உறவுகள்** | பணியாளர்களுக்குத் தகவலளித்தல் (மின்னஞ்சல், செய்திமடல்கள், அக இணையம்) |
| **ஊடகச் சுற்றுப்பயணம்** | பேச்சாளர், நிபுணர் அல்லது பிரபலம் இலக்கு நகரங்களில் சுற்றுப்பயணம் (எ.கா. வாசிப்புகளும் கையொப்பமிடல்களுமுள்ள நூல் அறிமுகங்கள்) |
| **நிதி உறவுகள்** | **முதலீட்டாளர்கள், பகுப்பாய்வாளர்கள், நிதிப் பத்திரிகையாளர்களுடன்** உறவுகள் (ஈட்டங்கள் பங்கு விலைகளைப் பாதிக்கின்றன) |

## விற்பனை மேம்படுத்தல்

:::key AMA வரைவிலக்கணம்
"**முயற்சித்துப் பார்த்தலைத் தூண்டவும், நுகர்வோர் கேள்வியை அதிகரிக்கவும், தயாரிப்பு கிடைக்கும்தன்மையை மேம்படுத்தவும்**, **முன்நிர்ணயிக்கப்பட்ட வரையறுக்கப்பட்ட காலத்திற்கு வழங்கப்படும் ஊடக மற்றும் ஊடகமல்லாத சந்தைப்படுத்தல் அழுத்தம்**."
:::

புதிய தயாரிப்புகளை அறிமுகப்படுத்தவும் **சரக்கை விற்றுமுடிக்கவும்**, வாடிக்கையாளர்களை ஈர்க்கவும் **தற்காலிகமாக விற்பனையை உயர்த்தவும்** பயன்படுகிறது.

**நோக்கங்கள்:**

- **புதிய தயாரிப்புகளுக்குச் சந்தை உருவாக்குதல்** (ஊடுருவல் விலை, சலுகைகள், தள்ளுபடிகள், அரிதாக்கம்)
- போட்டியாளர் குறுகியகாலத் தந்திரங்களுக்கு எதிராக **போட்டித்தன்மையைப் பேணுதல்**
- **விற்பனையாளர் நம்பிக்கை பெறுதல்** (அதிக விற்பனை அதிக விற்பனையாளர் வருமானம்)
- **புதிய சந்தைகளில் நுழைதல்**
- **வர்த்தகநாம விழிப்புணர்வை அதிகரித்தல்**
- போட்டியாளர்கள் கவர்வதற்கு எதிராக **தற்போதைய வாடிக்கையாளர்களை ஈர்த்தல்**

### மூன்று விற்பனை மேம்படுத்தல் உத்திகள்
- **இழுத்தல்**: தொடர்பாடல், பருவத் தள்ளுபடிகள், நிதித் திட்டங்களால் வாடிக்கையாளர்கள் நிறுவனத்திலிருந்து தயாரிப்பை **"இழுக்கின்றனர்"**.
- **தள்ளுதல்**: மறுவிற்பனையாளர்கள், விற்பனையாளர்கள், விநியோகஸ்தர்கள், முகவர்களை இலக்கிடும் வர்த்தக மேம்படுத்தல்களாலும் தனிப்பட்ட விற்பனையாலும் தயாரிப்பை வழியூடாக நுகர்வோரிடம் தள்ள **இடைத்தரகர்களை இணங்கவைத்தல்**.
- **கலப்பு**: **இரண்டும்**, எ.கா. நுகர்வோருக்குக் கூப்பன்களும் வணிகர்களுக்கு ஊக்குவிப்புகளும்.

### நுகர்வோர் மற்றும் வர்த்தக மேம்படுத்தல்கள்

:::grid
**நுகர்வோர் விற்பனை மேம்படுத்தல்** (இறுதிப் பயன்பாட்டாளர்களுக்கு)

- **இலவச மாதிரிகள்**: விழிப்புணர்வும் உடைமை உணர்வும்
- **இலவசப் பரிசுகள்**: குறைந்த தொகைக்கு அதிகம்
- **தள்ளுபடிகளும் கூப்பன்களும்**
- **மாற்றுத் திட்டங்கள்**: பழைய தயாரிப்புகளுக்கு மதிப்பு
- **நிதித் திட்டங்கள்**: விலையுயர்ந்த பொருட்களை வாங்கக்கூடியதாக்குதல்
- **அனுப்புகைத் திட்டங்கள்**: போக்குவரத்துத் தடையை நீக்குதல்
- **தொகுப்புத் தள்ளுபடிகள்**: விற்காத சரக்கை அகற்றுதல்
- **மொத்தக் கொள்வனவுச் சலுகைகள்**
+++
**வர்த்தக விற்பனை மேம்படுத்தல்** (விற்பனையாளர்கள், விநியோகஸ்தர்கள், முகவர்களுக்கு)

- **கொள்வனவுப் புள்ளி (POP) காட்சிகள்**: இலவசக் காட்சி அலகுகள்
- **வர்த்தகக் கண்காட்சிகள்**
- **தள்ளுதல் பணம் (spiffs)**: எ.கா. A அலகொன்றிற்கு Rs 50, B அலகொன்றிற்கு Rs 30 மேலதிகக் கொடுப்பனவு
- **கட்டளை ஊக்கப் பரிசுகள்**: குறிப்பிட்ட அளவைக் கட்டளையிடுவதற்குப் பரிசுகள்
- **வர்த்தகச் சலுகைகள்**: வரையறுக்கப்பட்ட காலத்திற்குத் தயாரிப்பை மேம்படுத்தச் சலுகைகள்
- **கொள்வனவுக் கொடுப்பனவுகள்**: குறிப்பிட்ட எண்ணிக்கையைக் கட்டளையிடத் தள்ளுபடிகள்

**நோக்கங்கள்:** அதிக அலமாரி இடம், ஊக்கமுள்ள விற்பனையாளர்கள், மறைமுக விற்பனை வளர்ச்சி.
:::

## தள்ளுதல் மற்றும் இழுத்தல் விநியோக வழிக் கொள்கைகள்

{{tool:pp}}

| | **தள்ளுதல்** | **இழுத்தல்** |
|---|---|---|
| **முக்கியக் கருவிகள்** | **விற்பனைப் படை, வர்த்தக மேம்படுத்தல்**, தனிப்பட்ட விற்பனை | **அதிக விளம்பரம், நுகர்வோர் மேம்படுத்தல்** |
| **திசை** | வழியூடாக நுகர்வோரிடம் தயாரிப்பு **தள்ளப்படுகிறது** | நுகர்வோர் கேள்வி தயாரிப்பை **இழுக்கிறது**: நுகர்வோர் → சில்லறை விற்பனையாளர் → மொத்த விற்பனையாளர் → உற்பத்தியாளர் |

:::

## சமூகப் பொறுப்புள்ள சந்தைப்படுத்தல் தொடர்பாடல்

- **சமூகப் பொறுப்பு:** வணிகங்கள் **நல்ல குடிமக்களாக** இருந்து, இலாபம் ஈட்டுவதை **சமூகத்தை ஆதரிக்கும்** செயல்களுடன் இணைக்க வேண்டும் (உள்ளூர், தேசிய, உலகளாவிய). தமது கொள்வனவுகள் **பொருளுள்ள தாக்கம்** ஏற்படுத்த வேண்டுமென விரும்பும் வாடிக்கையாளர்களை ஈர்க்கிறது.
- **எடுத்துக்காட்டுகள்:** **மீள்சுழற்சி பொதியிடல்**, **சமூகச் சிக்கல்கள்** பற்றிய விழிப்புணர்வு விளம்பரங்கள், **வருவாயின் ஒரு பகுதியை அறப்பணிக்கு** வழங்குதல்.

:::warn போலிப் பசுமை விளம்பரம் எதிர்விளைவளிக்கும்
சூழலுக்கேற்ற நடைமுறைகள் அல்லது தயாரிப்புகளை **ஏமாற்றும் விதத்தில் மேம்படுத்துவது**, நிறுவனத்திற்கு **உண்மையான அர்ப்பணிப்பில்லை** எனக் காட்டி, இறுதியில் **வர்த்தகநாமத்தையும் இலாபத்தன்மையையும் பாதிக்கிறது**. பொறுப்புள்ள நடத்தையை **உத்திசார்ந்து நேர்மையாகத்** தொடர்பாடவும்.
:::

:::exam
எதிர்பார்க்கப்படுபவை:

- **IMC இன் முக்கியத்துவம்**
- எடுத்துக்காட்டுகளுடன் **மேம்படுத்தல் நோக்கங்கள்**
- **மேம்படுத்தல் கலவைக் கூறுகள்**, எ.கா. **இலங்கைத் தொலைத்தொடர்பு நிறுவனம்** பயன்படுத்துபவை: தொலைக்காட்சி, எண்ணிம விளம்பரங்கள் (Dialog, Mobitel), மீள்நிரப்பல் மற்றும் தரவு **விற்பனை மேம்படுத்தல்கள்**, சில்லறை **தனிப்பட்ட விற்பனை**, **அனுசரணைகள்** (கிரிக்கெட், நிகழ்வுகள்), **SMS நேரடிச் சந்தைப்படுத்தல்**
- **விளம்பர வகைகள்**
- **செய்தி உத்தி** (ஈர்ப்புகள், கட்டமைப்பு, வடிவம்)
- **PR கருவிகள்**
- **நுகர்வோர் மற்றும் வர்த்தக மேம்படுத்தல்கள்**
- **தள்ளுதலும் இழுத்தலும்**
- **சமூகப் பொறுப்பு**
- செயற்பாடு: அண்மைய விளம்பரத்தின் **செய்தி உத்தியைத்** திறனாய்வு செய்க: ஈர்ப்பு, கட்டமைப்பு (முடிவா? ஒரு அல்லது இருபக்கமா?), வடிவம்
:::

## வினாடிவினா 12: மாதிரி விடை

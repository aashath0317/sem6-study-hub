## What is a function?

Many questions ask **how one quantity depends on another**: a company's profit vs production level, bacteria population vs time, vocabulary learned vs learning time. **Functions** describe these relationships.

:::key Definition
A **function** f from A to B is a rule that assigns to **each** element of A **one and only one** element of B. We write **f : A → B**. Functions are also called **mappings** or **transformations**.
:::

| Term | Meaning |
|---|---|
| **Domain** | The set A: the inputs |
| **Codomain** | The set B: where the outputs are allowed to land |
| **Image** | If f(a) = b, then b is the **image** of a (and a is a **preimage** of b) |
| **Range** | The set of **all images**, f(A) ⊆ B. The range can be **smaller** than the codomain |
| "f maps A to B" | Another way of saying f : A → B |

:::warn Two conditions for a function
1. **Every** element of A has an image (nothing in A is left out).
2. Each element of A has **exactly one** image (no element goes to two places).

Many elements of A **may** share the same image, and some elements of B **may** have no preimage. That's still a function.
:::

:::example Example 3.1 — f : ℤ → ℤ, f(x) = x²
- **Domain:** all integers
- **Codomain:** all integers
- **Range:** the perfect squares {0, 1, 4, 9, …}

The range is **not** the whole codomain.
:::

### Finding the domain of a real function

Exclude anything that makes the formula undefined:

- **Square root of a negative number** is not allowed: need inside ≥ 0.
- **Division by zero** is not allowed: need denominator ≠ 0.

:::example Find the domain
**(a) f(x) = √(x − 1)**

Need x − 1 ≥ 0, so x ≥ 1. Domain = **[1, ∞)**.

**(b) f(x) = 1 / (x² − 4)**

Need x² − 4 ≠ 0, so x ≠ ±2. Domain = **(−∞, −2) ∪ (−2, 2) ∪ (2, ∞)**.
:::

## One-to-one (injective)

:::key Definition
f is **one-to-one (injective)** if and only if **f(a) = f(b) implies a = b** for all a, b in the domain.

- **Lemma 3.2.1:** equivalently, **a ≠ b ⇒ f(a) ≠ f(b)**. Different inputs always give different outputs.
- **With quantifiers:** ∀a ∀b (f(a) = f(b) → a = b)
:::

:::example Proving / disproving one-to-one
**f(x) = 3x − 5 is one-to-one.**

Let f(x₁) = f(x₂). Then 3x₁ − 5 = 3x₂ − 5, so 3x₁ = 3x₂, so x₁ = x₂. ∎

**f(x) = x² is not one-to-one.**

f(1) = f(−1) = 1, but 1 ≠ −1. **One counterexample is enough.**
:::

## Onto (surjective) & bijection

:::key Onto
f : A → B is **onto (surjective)** if for **every b ∈ B** there is an **a ∈ A with f(a) = b**. In other words, **range = codomain**: nothing in B is missed.
:::

:::example Example 3.2
**f : ℝ → ℝ, f(x) = 3x − 5 is onto.**

Given any y, solve 3x − 5 = y to get x = (y + 5)/3, which is a real number. So every y is hit. ✓

**f : ℝ → ℝ, f(x) = x² is not onto.**

ℝ contains negative numbers, and no real x has x² = −1. ✗
:::

:::key Bijection (one-to-one correspondence)
f is a **bijection** if it is **both one-to-one and onto**.

*Example:* the **identity function** ι_A : A → A, ι_A(x) = x, sends each element to itself. It is one-to-one and onto, so it's a bijection.
:::

| Type (Figure 3.3) | One-to-one? | Onto? |
|---|---|---|
| (a) | ✓ | ✗ |
| (b) | ✗ | ✓ |
| (c) | ✓ | ✓ (**bijection**) |
| (d) | ✗ | ✗ |
| (e) one element sent to **two** elements | **Not a function** | — |

## Inverse functions

:::key Definition
Let f be a **bijection** from A to B. The **inverse function** f⁻¹ assigns to each b ∈ B the **unique** a ∈ A with f(a) = b:

**f⁻¹(b) = a ⇔ f(a) = b**
:::

- **Only bijections have inverses.** If f isn't one-to-one, some b would need two outputs. If f isn't onto, some b would have none.
- ⚠️ **Don't confuse f⁻¹ with 1/f.** f⁻¹ "undoes" f; 1/f is the reciprocal.

:::example Example — f : ℝ → ℝ, f(x) = 3x − 5
f is a bijection (shown above), so it is invertible.

Let y = 3x − 5 and solve for x: x = (y + 5)/3.

So **f⁻¹(y) = (y + 5)/3**.

*Check:* f(f⁻¹(y)) = 3·(y + 5)/3 − 5 = y ✓
:::

:::warn Note on the PDF
The lesson PDF works this example as "y = x + 1, so f⁻¹ = y − 1". That's the textbook example for **f(x) = x + 1**, pasted under the wrong function. For f(x) = x + 1 the inverse is indeed f⁻¹(y) = y − 1. For f(x) = 3x − 5 it is **(y + 5)/3**.
:::

**Recipe for an inverse:**
1. Write y = f(x).
2. Solve for x in terms of y.
3. Swap the names if needed: f⁻¹(y) = …

## Composition of functions

:::key Definition
Let g : A → B and f : B → C. The **composition f ∘ g** is defined by **(f ∘ g)(a) = f(g(a))**.

**Apply g first, then f.** f ∘ g is only defined when the **range of g is a subset of the domain of f**.
:::

```
   A ──g──▶ B ──f──▶ C
   a  ↦  g(a)  ↦  f(g(a))      (f∘g)(a) = f(g(a))
```

:::example Example — f(x) = x² − 1, g(x) = √x + 1
**(a) g ∘ f.** Put f(x) into g:

(g ∘ f)(x) = g(f(x)) = √(f(x)) + 1 = **√(x² − 1) + 1**

Over the reals, **g ∘ f** has domain **(−∞, −1] ∪ [1, ∞)** because x² − 1 ≥ 0.

**(b) f ∘ g.** Put g(x) into f:

(f ∘ g)(x) = f(g(x)) = (g(x))² − 1 = (√x + 1)² − 1 = x + 2√x + 1 − 1 = **x + 2√x**
:::

**f ∘ g** has domain **[0, ∞)** inherited from g(x) = √x + 1. Simplifying the formula does not remove its original domain restrictions.

:::warn Order matters
In general **f ∘ g ≠ g ∘ f**, as the example shows.
:::

:::formula
For a bijection f : A → B:
(f⁻¹ ∘ f)(a) = f⁻¹(f(a)) = f⁻¹(b) = **a**   and   (f ∘ f⁻¹)(b) = f(f⁻¹(b)) = f(a) = **b**
:::

So composing a function with its inverse gives the **identity**.

## Quick revision sheet

| Concept | Remember it as |
|---|---|
| Function | Each element of A → exactly one element of B; f : A → B |
| Domain / codomain / range | Inputs / allowed outputs / actual outputs |
| x² on ℤ | Range = {0, 1, 4, 9, …} |
| Domain rules | √(…) ≥ 0; denominator ≠ 0 |
| One-to-one | f(a) = f(b) ⇒ a = b; x² fails (1, −1) |
| Onto | Every b has a preimage; range = codomain |
| Bijection | One-to-one + onto; identity ι_A |
| Inverse | Only for bijections; f(x) = 3x − 5 ⇒ f⁻¹(y) = (y + 5)/3 |
| f⁻¹ ≠ 1/f | Undo vs reciprocal |
| Composition | (f∘g)(a) = f(g(a)): g first; f∘g ≠ g∘f |
| f⁻¹∘f | Identity |

## Official quiz 3 — every question explained

These are all **10 questions from the official CODL Quiz 3 — Functions**. Cover the answer, try the question yourself, then click **Answer** to check. Each answer gives the quick method in a few short steps — the same steps you can write in the written exam.

**Q1.** A function is ______ if and only if f(a) = f(b) implies a = b for all a, b in the domain.

(a) many-to-many (b) one-to-one (c) many-to-one (d) one-to-many

<details class="beginner-answer" markdown="1"><summary>Answer: (b) one-to-one (injective)</summary>

“If the outputs are equal, the inputs must be equal” = **no two different inputs share an output** = **one-to-one**.

- **One-to-one (injective):** different inputs → different outputs.
- **Onto (surjective):** every value in the codomain is hit by some input.
- **Bijection:** both one-to-one and onto.
</details>

**Q2.** Which f : Z × Z → Z is **not onto**?

(a) a + b (b) a (c) |b| (d) a − b

<details class="beginner-answer" markdown="1"><summary>Answer: (c) f(a, b) = |b|</summary>

Onto means **every integer** (…, −2, −1, 0, 1, 2, …) can come out.

- |b| (absolute value) is **never negative**, so −1 can never be an output → **not onto**.
- a + b, a, a − b can each give any integer (e.g. a + b = n with a = n, b = 0).
</details>

**Q3.** f(x) = 2x + 1, g(x) = 3x + 4. The composition of f and g (f ∘ g) is:

(a) 6x + 9 (b) 6x + 7 (c) 6x + 6 (d) 6x + 8

<details class="beginner-answer" markdown="1"><summary>Answer: (a) 6x + 9</summary>

**(f ∘ g)(x) = f(g(x))**: do g first, then put the result into f.

1. g(x) = 3x + 4
2. f(3x + 4) = 2(3x + 4) + 1 = 6x + 8 + 1 = **6x + 9**

Careful: g ∘ f = g(f(x)) = 3(2x + 1) + 4 = 6x + 7 — that is option (b), the trap.
</details>

**Q4.** The inverse of f(x) = x³ + 2 is:

(a) (y − 2)^(1/2) (b) (y − 2)^(1/3) (c) y^(1/3) (d) y − 2

<details class="beginner-answer" markdown="1"><summary>Answer: (b) f⁻¹(y) = (y − 2)^(1/3) = ∛(y − 2)</summary>

**Method for an inverse (3 steps):**

1. Write y = x³ + 2.
2. Solve for x: subtract 2 → y − 2 = x³; take the cube root → x = ∛(y − 2).
3. So f⁻¹(y) = (y − 2)^(1/3).

Check: f(2) = 8 + 2 = 10, and ∛(10 − 2) = ∛8 = 2 ✓.
</details>

**Q5.** From the graph (closed dot at x = −4, open circle at x = 3), find the **domain**.

(a) [−4, 3] (b) (−4, 3) (c) (−4, 3] (d) [−4, 3)

<details class="beginner-answer" markdown="1"><summary>Answer: (d) [−4, 3)</summary>

- **Domain = all x-values the graph covers** (read left → right).
- **Closed dot ● = included → square bracket [ ]. Open circle ○ = not included → round bracket ( ).**
- Starts at −4 with ● → “[−4”. Ends at 3 with ○ → “3)”. So [−4, 3).
</details>

**Q6.** From the graph (starts with a closed dot at height y = 2, then goes down forever with an arrow), find the **range**.

(a) [−4, ∞) (b) (−∞, 2] (c) [2, ∞) (d) (−∞, ∞)

<details class="beginner-answer" markdown="1"><summary>Answer: (b) (−∞, 2]</summary>

- **Range = all y-values the graph covers** (read bottom → top).
- Highest point: y = 2 with a closed dot → included → “2]”.
- The arrow keeps going down forever → “(−∞”. Infinity always takes a round bracket.
</details>

**Q7.** 180 g of candies, 6 g each. As each candy is eaten, the mass left is plotted against the **number of candies left**. Range of this relation (as given in the quiz)?

(a) all real numbers (b) {0, 1, 2, …, 30} (c) {0, 6, 12, …, 180} (d) {0, 1, …, 6}

<details class="beginner-answer" markdown="1"><summary>Answer given by the quiz: (b) {0, 1, 2, …, 30}</summary>

Number of candies at the start: 180 ÷ 6 = **30**. As they are eaten the count goes 30, 29, …, 0, so the possible candy counts are {0, 1, …, 30}.
Note: the masses would be {0, 6, 12, …, 180}. The quiz treats the candy count as the range, so remember **(b)** for this question.
</details>

**Q8.** Which arrow diagram is **not a function**?

<details class="beginner-answer" markdown="1"><summary>Answer: (a) — the input 7 has two arrows (to 2 and to 9)</summary>

**Function rule: every input has exactly ONE output.**

- In (a), 7 → 2 and 7 → 9: one input, two outputs → **not a function**.
- Many inputs going to the same output (like all → 5 in (b) and (c)) is **allowed**.
</details>

**Q9.** Domain of f(x) = x⁻¹ (that is, 1/x) so it is defined everywhere?

(a) (2, ∞) (b) [0, ∞) (c) (−∞, ∞) − {0}

<details class="beginner-answer" markdown="1"><summary>Answer: (c) all real numbers except 0</summary>

x⁻¹ = 1/x, and **you cannot divide by 0**. Every other real number is fine, so remove only 0.
</details>

**Q10.** Range of f(x) = 2x?

(a) (0, ∞) (b) (−∞, ∞) − {0} (c) (−∞, ∞)

<details class="beginner-answer" markdown="1"><summary>Answer: (c) (−∞, ∞) — all real numbers</summary>

To get any output y, use x = y/2: f(y/2) = y. So every real number (including 0, from x = 0) is an output.
</details>

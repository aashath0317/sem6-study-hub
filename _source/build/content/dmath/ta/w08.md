## எண்ணல் ஏன்?

*6–8 எழுத்துக்குறிகளுள்ள (இலக்கங்கள் அல்லது எழுத்துகள்) எத்தனை கடவுச்சொற்களில் குறைந்தது ஓர் இலக்கம் உள்ளது?* இத்தகைய கேள்விகளுக்கு **எண்ணல் நுட்பங்கள்** தேவை. கணிதத்திலும் கணினி அறிவியலிலும் எண்ணல் எங்கும் வருகிறது:

- **நிகழ்தகவு:** வெற்றிகரமான விளைவுகளையும் சாத்தியமான அனைத்து விளைவுகளையும் எண்ணுதல்.
- **படிமுறைச் சிக்கல்தன்மை:** படிமுறை மேற்கொள்ளும் செயல்பாடுகளை எண்ணுதல்.

இரு அடிப்படைக் கொள்கைகள்: **பெருக்கல் விதி**, **கூட்டல் விதி**.

## பெருக்கல் விதி ("மற்றும்", பின்னர் பெருக்கு)

:::key பெருக்கல் விதி
செயல்முறை **இரு பணிகளின் தொடராகப்** பிரிந்து, முதலாவதைச் செய்ய **n₁** வழிகளும், இரண்டாவதைச் செய்ய **n₂** வழிகளும் (முதலாவதைச் செய்யும் ஒவ்வொரு வழிக்கும்) இருந்தால், செயல்முறையைச் செய்ய **n₁ × n₂** வழிகள் உள்ளன.
:::

:::example எடுத்துக்காட்டு 8.1.1 — லில்லியின் உடைகள்
சட்டைகள்: சிவப்பு, ஊதா, நீலம் (3). காற்சட்டைகள்: கறுப்பு, வெள்ளை (2). உடைகள் = **3 × 2 = 6**.

| சட்டை | சிவப்பு | நீலம் | ஊதா | சிவப்பு | நீலம் | ஊதா |
|---|---|---|---|---|---|---|
| காற்சட்டை | கறுப்பு | கறுப்பு | கறுப்பு | வெள்ளை | வெள்ளை | வெள்ளை |
:::

:::example எடுத்துக்காட்டு 8.1.2 — m-கணத்திலிருந்து n-கணத்துக்கான சார்புகள்
ஆட்களத்தின் ஒவ்வொரு m மூலகமும், துணை ஆட்களத்தின் n மூலகங்களில் ஒன்றைச் சுயாதீனமாகத் தேர்ந்தெடுக்கிறது: n · n · … · n = **nᵐ**.

*எ.கா.* 3-மூலகக் கணத்திலிருந்து 5-மூலகக் கணத்துக்கு **5³ = 125** சார்புகள் உள்ளன.
:::

:::example எடுத்துக்காட்டு 8.1.3 — துறைகள்
32 நுண்கணினிகள் × ஒவ்வொன்றுக்கும் 24 துறைகள் = **768** துறைகள்.
:::

:::example எடுத்துக்காட்டு 8.1.4 — m-கணத்திலிருந்து n-கணத்துக்கான ஒன்றுக்கொன்றான சார்புகள்
- **m > n எனில் எதுவுமில்லை** (இரு மூலகங்கள் படிமத்தைப் பகிர வேண்டியிருக்கும்).
- m ≤ n எனில்:
  - a₁-க்கு n தெரிவுகள்.
  - a₂-க்கு n − 1 (a₁-இன் பெறுமதியை மீண்டும் பயன்படுத்த முடியாது).
  - …
  - aₘ-க்கு n − m + 1.

மொத்தம் = **n(n − 1)⋯(n − m + 1)**. *எ.கா.* 3-கணத்திலிருந்து 5-கணத்துக்கு: 5 × 4 × 3 = **60**.
:::

## கூட்டல் விதி ("அல்லது", பின்னர் கூட்டு)

:::key கூட்டல் விதி
ஒரு பணியை **n₁ வழிகளில் ஒன்றிலோ அல்லது n₂ வழிகளில் ஒன்றிலோ** செய்ய முடிந்து, **இரு கணங்களுக்கும் பொதுவான வழி இல்லாவிட்டால்**, **n₁ + n₂** வழிகள் உள்ளன.
:::

:::example எடுத்துக்காட்டு 8.1.5 — பிரதிநிதியைத் தேர்ந்தெடுத்தல்
பிரதிநிதி கணிதப் பீட உறுப்பினர் (37) அல்லது கணித முதன்மைப்பாட மாணவர் (83). யாரும் இரண்டுமல்ல; எனவே 37 + 83 = **120** தெரிவுகள்.
:::

### உள்ளடக்கல்–விலக்கல் (கழித்தல் கொள்கை)
சில வழிகள் **இரு** கணங்களுக்கும் **பொதுவானவை** எனில் கூட்டுவது அவற்றை **இருமுறை எண்ணும்**; எனவே பொதுப் பகுதியைக் கழிக்கவும்:

:::formula
|A₁ ∪ A₂| = |A₁| + |A₂| − |A₁ ∩ A₂|
:::

வாரம் 2-இல் கணங்களுடன் பார்த்த அதே கொள்கை.

:::tip பெருக்கலா கூட்டலா?
- இதைச் செய்; **அதன்பின்** அதைச் செய் (படிகளின் தொடர்) → **பெருக்கு**.
- இதைச் செய் **அல்லது** அதைச் செய் (தனித்த, வெட்டாத நிகழ்வுகள்) → **கூட்டு**.
- நிகழ்வுகள் வெட்டினால் → **கூட்டிப் பின்னர் பொதுப் பகுதியைக் கழி**.
:::

## மர வரைபடங்கள்

**மரத்துக்கு வேர்**, சாத்தியமான ஒவ்வொரு தெரிவுக்கும் **கிளைகள்**, **சாத்தியமான விளைவுகளாக** இருக்கும் **இலைகள்** (மேலும் கிளைகளற்ற முடிவுப் புள்ளிகள்) உள்ளன. இலைகளை எண்ணவும்.

:::example எடுத்துக்காட்டு 8.1.5 — அடுத்தடுத்த இரு 1-கள் இல்லாத நீளம் 4 உடைய பிட் சரங்கள்
- முதல் பிட்: 1 அல்லது 0.
- பிட் **1** எனில் அடுத்தது **0** ஆக வேண்டும்.
- அது **0** எனில் அடுத்தது 0 அல்லது 1 ஆகலாம்.

மரத்தைப் பின்பற்றினால் **8** சரங்கள் கிடைக்கின்றன: 1010, 1001, 1000, 0101, 0100, 0010, 0001, 0000.

**மரத்தைப் பயன்படுத்தும்போது ஒவ்வொரு இலையையும் நோக்கிச் செல்லும் பாதையின் தெரிவு எண்ணிக்கைகள் மாறலாம்.** எனவே சாதாரண பெருக்கல் விதி உதவாத இடங்களில் மரங்கள் உதவுகின்றன.
:::

## சேர்வுகள் — வரிசை முக்கியமல்ல

இரு வகைக் கேள்விகள்:

- புகைப்படத்துக்காக 5 மாணவர்களில் 3 பேரை **வரிசையில்** அமைத்தல் → **வரிசை முக்கியம்** → **ஒழுங்கமைப்பு**.
- 4 மாணவர்களில் 3 பேர் கொண்ட **குழுவைத்** தேர்ந்தெடுத்தல் → **வரிசை முக்கியமல்ல** → **சேர்வு**.

:::key சேர்வு
**வரிசை முக்கியமில்லாத**, **மீளுரு அனுமதிக்கப்படாத** பொருட்களின் **தேர்வு**:

**ⁿCᵣ = C(n, r) = n! / ( r! (n − r)! )**

இங்கு n! = 1 × 2 × 3 × ⋯ × (n − 1) × n (மேலும் 0! = 1). **0 ≤ r ≤ n**-க்கு செல்லுபடியாகும்.
:::

:::example எடுத்துக்காட்டு 8.2.1 — மந்திரவாதி
10 பார்வையாளர்களில் 2 பேரைத் தேர்ந்தெடுக்கவும். John, Alice-ஐத் தேர்ந்தெடுப்பதும் Alice, John-ஐத் தேர்ந்தெடுப்பதும் அதே சோடி.

¹⁰C₂ = 10! / (2! · 8!) = (10 × 9) / (2 × 1) = **45**
:::

:::tip பெருக்குமுன் வெட்டிச்சுருக்கவும்
10!/(2!·8!): 8!-ஐ வெட்டினால் மேலே 10 × 9 மட்டுமே மீதமாகும்; பின்னர் 2!-ஆல் வகுக்கவும். முழு 10!-ஐக் கணக்கிடத் தேவையில்லை.
:::

## ஒழுங்கமைப்புகள் — வரிசை முக்கியம்

**ஒழுங்கமைப்பு** என்பது வேறுபட்ட பொருட்களின் **வரிசைப்படுத்தப்பட்ட அமைப்பு**. "top", "pot" என்பவை ஒரே மூன்று எழுத்துகளின் வெவ்வேறு ஒழுங்கமைப்புகள்.

### நிகழ்வு 1: மீளுரு அனுமதிக்கப்படுகிறது
r இடங்களில் ஒவ்வொன்றுக்கும் சுயாதீனமாக n தெரிவுகள்; எனவே பெருக்கல் விதியால்:

:::formula
**P(n, r) = nʳ**   (மீளுருவுடன்)
:::

*எ.கா.* 4-இலக்க PIN-கள்: 10⁴ = 10,000.

### நிகழ்வு 2: மீளுரு அனுமதிக்கப்படவில்லை
ஒவ்வொருமுறையும் தெரிவுகள் ஒன்று குறைகின்றன: n, பின்னர் n − 1, பின்னர் n − 2, …

:::formula
**ⁿPᵣ = P(n, r) = n × (n − 1) × ⋯ × (n − r + 1) = n! / (n − r)!**
:::

:::example எடுத்துக்காட்டு 8.2.1 — பத்திலிருந்து சிறந்த மூன்று கோல்கள்
¹⁰P₃ = 10!/(10 − 3)! = 10 × 9 × 8 = **720**
:::

:::example எடுத்துக்காட்டு 8.2.2 — 100 பேரிலிருந்து 1-ஆவது, 2-ஆவது, 3-ஆவது பரிசு
எந்த நபர் எந்தப் பரிசைப் பெறுகிறார் என்பது முக்கியம்; எனவே இது ஒழுங்கமைப்பு:

¹⁰⁰P₃ = 100 × 99 × 98 = **970,200**
:::

:::key P, C இடையிலான தொடர்பு
**ⁿPᵣ = ⁿCᵣ × r!**. குழுவைத் தேர்ந்தெடுத்து (C), பின்னர் r! வரிசைகளில் அமைக்கவும். *எ.கா.* ¹⁰P₂ = 45 × 2 = 90.
:::

{{tool:pc}}

:::exam
**முதலில் தீர்மானிக்கவும்:**

- வரிசை முக்கியமா? → **P** அல்லது **C**.
- மீளுரு அனுமதிக்கப்படுகிறதா? → nʳ.
- படிகளின் தொடரா அல்லது தனித்த நிகழ்வுகளா? → **பெருக்கல்** அல்லது **கூட்டல்** விதி.

பின்னர் சூத்திரம், பிரதியீடு, வெட்டிச்சுருக்கல் காட்டவும். வழக்கமான கேள்விகள்: உடைகள், எண் தகடுகள் (பெருக்கல் விதி); வெட்டாத குழுக்களிலிருந்து பிரதிநிதி (கூட்டல் விதி); பிட் சரங்கள் (மர வரைபடம்); பரிசு வெற்றியாளர்கள் (P); குழுக்கள் (C).
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|
| பெருக்கல் விதி | பணிகளின் தொடர் → n₁ × n₂ (சட்டைகள் × காற்சட்டைகள் = 6) |
| சார்புகள் m → n | nᵐ (5³ = 125) |
| ஒன்றுக்கொன்று m → n | n(n−1)⋯(n−m+1); m > n எனில் 0 (5·4·3 = 60) |
| கூட்டல் விதி | வெட்டாத மாற்றுகள் → n₁ + n₂ (37 + 83 = 120) |
| உள்ளடக்கல்–விலக்கல் | \|A∪B\| = \|A\| + \|B\| − \|A∩B\| |
| மர வரைபடம் | இலைகள் = விளைவுகள்; "11" இல்லாத நீளம்-4 பிட் சரங்கள் = 8 |
| சேர்வு | ⁿCᵣ = n!/(r!(n−r)!); வரிசை முக்கியமல்ல (¹⁰C₂ = 45) |
| ஒழுங்கமைப்பு | ⁿPᵣ = n!/(n−r)!; வரிசை முக்கியம் (¹⁰P₃ = 720, ¹⁰⁰P₃ = 970,200) |
| மீளுருவுடன் | nʳ |
| தொடர்பு | ⁿPᵣ = ⁿCᵣ · r! |

## சார்பு என்றால் என்ன?

**ஒரு அளவு மற்றொன்றை எவ்வாறு சார்ந்துள்ளது** எனப் பல கேள்விகள் கேட்கின்றன: நிறுவன இலாபமும் உற்பத்தி நிலையும், பக்டீரியாத் தொகையும் காலமும், கற்ற சொற்களும் கற்றல் நேரமும். **சார்புகள்** இத்தொடர்புகளை விவரிக்கின்றன.

:::key வரையறை
A-இலிருந்து B-க்கான **சார்பு** f என்பது A-இன் **ஒவ்வொரு** மூலகத்துக்கும் B-இன் **ஒரேயொரு** மூலகத்தை ஒதுக்கும் விதி. **f : A → B** என எழுதுகிறோம். சார்புகள் **பொருத்துதல்கள்** அல்லது **உருமாற்றங்கள்** என்றும் அழைக்கப்படுகின்றன.
:::

| சொல் | பொருள் |
|---|---|
| **ஆட்களம்** | A கணம்: உள்ளீடுகள் |
| **துணை ஆட்களம்** | B கணம்: வெளியீடுகள் செல்ல அனுமதிக்கப்பட்ட இடம் |
| **படிமம்** | f(a) = b எனில் b என்பது a-இன் **படிமம்** (a என்பது b-இன் **முன்படிமம்**) |
| **வீச்சு** | **அனைத்துப் படிமங்களினதும்** கணம், f(A) ⊆ B. துணை ஆட்களத்தைவிட வீச்சு **சிறியதாக** இருக்கலாம் |
| "f, A-ஐ B-க்குப் பொருத்துகிறது" | f : A → B என்பதைக் கூறும் மற்றொரு வழி |

:::warn சார்புக்கான இரு நிபந்தனைகள்
1. A-இன் **ஒவ்வொரு** மூலகத்துக்கும் படிமம் உள்ளது (A-இல் எதுவும் விடப்படுவதில்லை).
2. A-இன் ஒவ்வொரு மூலகத்துக்கும் **துல்லியமாக ஒரு** படிமம் (ஒரு மூலகம் இரு இடங்களுக்குச் செல்லாது).

A-இன் பல மூலகங்கள் ஒரே படிமத்தைப் பகிர **முடியும்**; B-இன் சில மூலகங்களுக்கு முன்படிமம் இல்லாமலும் **இருக்கலாம்**. இருந்தாலும் அது சார்பே.
:::

:::example எடுத்துக்காட்டு 3.1 — f : ℤ → ℤ, f(x) = x²
- **ஆட்களம்:** அனைத்து முழு எண்களும்
- **துணை ஆட்களம்:** அனைத்து முழு எண்களும்
- **வீச்சு:** முழுவர்க்கங்கள் {0, 1, 4, 9, …}

வீச்சு முழுத் துணை ஆட்களமும் **அல்ல**.
:::

### மெய்ச் சார்பின் ஆட்களத்தைக் கண்டறிதல்

சூத்திரத்தை வரையறுக்கப்படாததாக்கும் அனைத்தையும் விலக்கவும்:

- **எதிர்மறை எண்ணின் வர்க்கமூலம்** அனுமதிக்கப்படுவதில்லை: உள்ளே உள்ள பெறுமதி ≥ 0 தேவை.
- **பூச்சியத்தால் வகுத்தல்** அனுமதிக்கப்படுவதில்லை: பகுதி ≠ 0 தேவை.

:::example ஆட்களத்தைக் கண்டறியவும்
**(a) f(x) = √(x − 1)**

x − 1 ≥ 0 தேவை; எனவே x ≥ 1. ஆட்களம் = **[1, ∞)**.

**(b) f(x) = 1 / (x² − 4)**

x² − 4 ≠ 0 தேவை; எனவே x ≠ ±2. ஆட்களம் = **(−∞, −2) ∪ (−2, 2) ∪ (2, ∞)**.
:::

## ஒன்றுக்கொன்று (உட்சார்பு)

:::key வரையறை
ஆட்களத்திலுள்ள அனைத்து a, b-க்கும் **f(a) = f(b) எனில் a = b** என்றால் மட்டுமே f **ஒன்றுக்கொன்றானது (உட்சார்பு)**.

- **துணைத்தேற்றம் 3.2.1:** அதற்குச் சமமாக **a ≠ b ⇒ f(a) ≠ f(b)**. வெவ்வேறு உள்ளீடுகள் எப்போதும் வெவ்வேறு வெளியீடுகளை வழங்குகின்றன.
- **அளவைக்குறிகளுடன்:** ∀a ∀b (f(a) = f(b) → a = b)
:::

:::example ஒன்றுக்கொன்றானதா என நிறுவுதல் / மறுத்தல்
**f(x) = 3x − 5 ஒன்றுக்கொன்றானது.**

f(x₁) = f(x₂) என்க. அப்போது 3x₁ − 5 = 3x₂ − 5; எனவே 3x₁ = 3x₂; எனவே x₁ = x₂. ∎

**f(x) = x² ஒன்றுக்கொன்றானதல்ல.**

f(1) = f(−1) = 1; ஆனால் 1 ≠ −1. **ஓர் எதிர் எடுத்துக்காட்டு போதும்.**
:::

## மேல் சார்பும் இருவழிச் சார்பும்

:::key மேல் சார்பு
**ஒவ்வொரு b ∈ B-க்கும்**, **f(a) = b ஆகும் a ∈ A** இருந்தால் f : A → B **மேல் சார்பு**. அதாவது **வீச்சு = துணை ஆட்களம்**: B-இல் எதுவும் விடப்படுவதில்லை.
:::

:::example எடுத்துக்காட்டு 3.2
**f : ℝ → ℝ, f(x) = 3x − 5 மேல் சார்பு.**

எந்த y கொடுக்கப்பட்டாலும் 3x − 5 = y தீர்த்தால் x = (y + 5)/3 என்ற மெய்யெண் கிடைக்கும். எனவே ஒவ்வொரு y-உம் அடையப்படுகிறது. ✓

**f : ℝ → ℝ, f(x) = x² மேல் சார்பல்ல.**

ℝ-இல் எதிர்மறை எண்கள் உள்ளன; எந்த மெய்யெண் x-க்கும் x² = −1 இல்லை. ✗
:::

:::key இருவழிச் சார்பு (ஒன்றுக்கொன்று ஒத்திசைவு)
f **ஒன்றுக்கொன்றானதாகவும் மேல் சார்பாகவும்** இருந்தால் அது **இருவழிச் சார்பு**.

*எடுத்துக்காட்டு:* **சமனிச் சார்பு** ι_A : A → A, ι_A(x) = x, ஒவ்வொரு மூலகத்தையும் அதற்கே அனுப்புகிறது. ஒன்றுக்கொன்றானதும் மேல் சார்பும் என்பதால் இருவழிச் சார்பு.
:::

| வகை (படம் 3.3) | ஒன்றுக்கொன்றா? | மேல் சார்பா? |
|---|---|---|
| (a) | ✓ | ✗ |
| (b) | ✗ | ✓ |
| (c) | ✓ | ✓ (**இருவழிச் சார்பு**) |
| (d) | ✗ | ✗ |
| (e) ஒரு மூலகம் **இரு** மூலகங்களுக்கு அனுப்பப்படுகிறது | **சார்பு அல்ல** | — |

## நேர்மாறுச் சார்புகள்

:::key வரையறை
f என்பது A-இலிருந்து B-க்கான **இருவழிச் சார்பாக** இருக்கட்டும். **நேர்மாறுச் சார்பு** f⁻¹, ஒவ்வொரு b ∈ B-க்கும் f(a) = b ஆகும் **தனித்துவமான** a ∈ A-ஐ ஒதுக்குகிறது:

**f⁻¹(b) = a ⇔ f(a) = b**
:::

- **இருவழிச் சார்புகளுக்கு மட்டுமே நேர்மாறுகள் உள்ளன.** f ஒன்றுக்கொன்றானதல்ல எனில் சில b-க்கு இரு வெளியீடுகள் தேவைப்படும். f மேல் சார்பல்ல எனில் சில b-க்கு எதுவும் இருக்காது.
- ⚠️ **f⁻¹-ஐ 1/f-உடன் குழப்ப வேண்டாம்.** f⁻¹, f-ஐ "செயல்தவிர்க்கிறது"; 1/f தலைகீழ்.

:::example எடுத்துக்காட்டு — f : ℝ → ℝ, f(x) = 3x − 5
f இருவழிச் சார்பு (மேலே காட்டப்பட்டது); எனவே நேர்மாறுடையது.

y = 3x − 5 என்க; x-க்குத் தீர்க்கவும்: x = (y + 5)/3.

எனவே **f⁻¹(y) = (y + 5)/3**.

*சரிபார்ப்பு:* f(f⁻¹(y)) = 3·(y + 5)/3 − 5 = y ✓
:::

:::warn PDF பற்றிய குறிப்பு
பாட PDF, எடுத்துக்காட்டை "y = x + 1; எனவே f⁻¹ = y − 1" எனச் செய்கிறது. அது **f(x) = x + 1**-க்கான பாடநூல் எடுத்துக்காட்டு; தவறான சார்பின்கீழ் ஒட்டப்பட்டுள்ளது. f(x) = x + 1-க்கு நேர்மாறு உண்மையில் f⁻¹(y) = y − 1. f(x) = 3x − 5-க்கு அது **(y + 5)/3**.
:::

**நேர்மாறுக்கான செய்முறை:**
1. y = f(x) எழுதவும்.
2. y-இன்படி x-க்குத் தீர்க்கவும்.
3. தேவைப்பட்டால் பெயர்களை மாற்றவும்: f⁻¹(y) = …

## சார்புகளின் தொகுப்பு

:::key வரையறை
g : A → B, f : B → C என்க. **f ∘ g தொகுப்பு**, **(f ∘ g)(a) = f(g(a))** என வரையறுக்கப்படுகிறது.

**முதலில் g, பின்னர் f-ஐப் பயன்படுத்தவும்.** **g-இன் வீச்சு, f-இன் ஆட்களத்தின் உட்கணமாக** இருந்தால் மட்டுமே f ∘ g வரையறுக்கப்படுகிறது.
:::

```
   A ──g──▶ B ──f──▶ C
   a  ↦  g(a)  ↦  f(g(a))      (f∘g)(a) = f(g(a))
```

:::example எடுத்துக்காட்டு — f(x) = x² − 1, g(x) = √x + 1
**(a) g ∘ f.** f(x)-ஐ g-க்குள் இடவும்:

(g ∘ f)(x) = g(f(x)) = √(f(x)) + 1 = **√(x² − 1) + 1**

மெய்யெண்களில் **g ∘ f**-இன் ஆட்களம் **(−∞, −1] ∪ [1, ∞)**; ஏனெனில் x² − 1 ≥ 0.

**(b) f ∘ g.** g(x)-ஐ f-க்குள் இடவும்:

(f ∘ g)(x) = f(g(x)) = (g(x))² − 1 = (√x + 1)² − 1 = x + 2√x + 1 − 1 = **x + 2√x**
:::

**f ∘ g**-இன் ஆட்களம் **[0, ∞)**; g(x) = √x + 1-இலிருந்து பெறப்பட்டது. சூத்திரத்தைச் சுருக்குவது மூல ஆட்களக் கட்டுப்பாடுகளை அகற்றுவதில்லை.

:::warn வரிசை முக்கியம்
எடுத்துக்காட்டு காட்டுவதுபோல் பொதுவாக **f ∘ g ≠ g ∘ f**.
:::

:::formula
இருவழிச் சார்பு f : A → B-க்கு:
(f⁻¹ ∘ f)(a) = f⁻¹(f(a)) = f⁻¹(b) = **a**   மற்றும்   (f ∘ f⁻¹)(b) = f(f⁻¹(b)) = f(a) = **b**
:::

எனவே சார்பை அதன் நேர்மாறுடன் தொகுப்பது **சமனியை** வழங்குகிறது.

{{tool:cp}}

:::exam
எதிர்பார்க்க வேண்டியவை:

- கொடுக்கப்பட்ட சார்புகளுக்கு **ஆட்களம் / துணை ஆட்களம் / வீச்சு**
- ஆட்களங்களைக் கண்டறிதல் (√, வகுத்தல்)
- **ஒன்றுக்கொன்றானதை நிறுவுதல்** (f(x₁) = f(x₂) என அனுமானித்து x₁ = x₂ காட்டுதல்) அல்லது எதிர் எடுத்துக்காட்டால் **மறுத்தல்**
- **மேல் சார்பு என நிறுவுதல்** (y = f(x)-ஐ x-க்குத் தீர்த்து, x ஆட்களத்தில் உள்ளதா எனச் சரிபார்த்தல்)
- **நேர்மாறுகளைக்** கண்டறிதல்
- **f ∘ g, g ∘ f** கணக்கிடுதல்
:::

| ஆட்களம் / துணை ஆட்களம் / வீச்சு | உள்ளீடுகள் / அனுமதிக்கப்பட்ட வெளியீடுகள் / உண்மையான வெளியீடுகள் |
| ℤ-இல் x² | வீச்சு = {0, 1, 4, 9, …} |
| ஆட்கள விதிகள் | √(…) ≥ 0; பகுதி ≠ 0 |

| மேல் சார்பு | ஒவ்வொரு b-க்கும் முன்படிமம் உள்ளது; வீச்சு = துணை ஆட்களம் |

| நேர்மாறு | இருவழிச் சார்புகளுக்கு மட்டும்; f(x) = 3x − 5 ⇒ f⁻¹(y) = (y + 5)/3 |

| தொகுப்பு | (f∘g)(a) = f(g(a)): முதலில் g; f∘g ≠ g∘f |
| f⁻¹∘f | சமனி |

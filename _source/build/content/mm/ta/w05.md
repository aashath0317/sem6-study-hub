## Pixel planes, points மற்றும் line equations

Vector shape mathematical-ஆகச் சேமிக்கப்படும். Pixel display அதைக் காட்ட discrete pixel locations தேர்ந்தெடுக்க வேண்டும். **Rasterization** continuous geometry-ஐ pixel grid-க்கு மாற்றுகிறது. Figure 5.1 house-ஐ lines/shapes மூலம் காட்டுகிறது; பெரிதாக்கினால் pixels தெரியும். Raster drawing tools-க்கும் ஆரம்ப shape pixels தேர்ந்தெடுக்கும் முறை தேவை.

**Point** அடிப்படை building block. Application coordinate தருகிறது; output device அந்த இடத்தை activate செய்கிறது. பழைய CRT-இல் electron beam phosphor-ஐ ஒளிரச் செய்வதை lesson உதாரணமாகச் சொல்கிறது. Thick point பல pixels-ஐப் பிடிக்கலாம். **Line algorithm** endpoints இடையிலான positions கணக்கிட்டு அருகிலுள்ள pixels தேர்ந்தெடுக்கிறது.

Real position (11.38, 21.59)-ஐ round செய்தால் pixel (11,22). Diagonal line படிக்கட்டு போலத் தெரியலாம்; இதுவே **jaggies**. அதிக display resolution உதவலாம். Anti-aliasing grid continuous என்று கருதாமல் edge intensities-ஐச் சரிசெய்கிறது.

நல்ல line நேராகத் தெரிய வேண்டும்; endpoints சரியாக இருந்து connected segments இடையே gap இருக்கக்கூடாது; length/slope மாறினாலும் thickness சீராக இருக்க வேண்டும்; வேகமாக generate ஆக வேண்டும்.

:::formula
Line: y = mx + c
Slope: m = (y₂ − y₁)/(x₂ − x₁) = Δy/Δx
Intercept: c = y₁ − mx₁
Increment relation: Δy = mΔx
:::

Vertical line-இல் Δx zero; slope division முடியாது. Fixed x வைத்து y-ஐ step செய்யுங்கள். Zero-length line-க்கு ஒரே point. Negative coordinates/slopes மற்றும் reverse endpoints-ஐயும் algorithm கையாள வேண்டும்.

## DDA: முறையும் முழு iteration tables-உம்

**DDA** incremental scan-conversion முறை. ஒவ்வொரு point-க்கும் y = mx + c multiplication செய்யாமல் increments சேர்க்கிறது. PDF dominant coordinate-இல் unit step; மற்ற coordinate-இல் fractional increment பயன்படுத்துகிறது.

Positive shallow slope: Δx = 1; y next = y + m. Positive steep slope: Δy = 1; x next = x + 1/m. General method: **steps = max(|Δx|, |Δy|)**; x increment = Δx/steps; y increment = Δy/steps. Signed increments endpoint direction-ஐக் காக்கின்றன. Real accumulated values-ஐ வைத்துக்கொண்டு plot செய்யும் coordinates மட்டும் round செய்யுங்கள்.

:::warn Source ambiguity மற்றும் rounding
PDF negative-slope summary direction signs கொடுக்கவில்லை; signed increments பயன்படுத்துங்கள். “first 3 points” example starting point-உடன் மூன்று updates காட்டுகிறது. இங்கே **first N points-இல் starting point-உம் சேரும்**; full table மீதியையும் காட்டுகிறது. Ties zero-விலிருந்து வெளியே round ஆகும். Exam tie rule தராவிட்டால் நீங்கள் பயன்படுத்துவதைச் சொல்லுங்கள்; சம தூர pixels-இல் வேறு tie rules வேறு தேர்வு தரலாம்.
:::

## Bresenham: integer decision உருவாக்குதல்

வலப்பக்கம் செல்லும் shallow line-க்கு E = (x+1,y) அல்லது NE = (x+1,y+1) தேர்ந்தெடுக்கிறோம். Mathematical line அவற்றுக்கு இடையே செல்கிறது. கீழ் pixel-இலிருந்து line-க்கு distance d₁; line-இலிருந்து மேல் pixel-க்கு distance d₂.

y = m(x+1)+c மூலம் d₁ − d₂ = 2m(x+1)+2c−2y−1. Positive Δx-ஆல் பெருக்கி m = Δy/Δx substitute செய்தால் sign மாறாது; fraction division போகும். pᵢ = 2Δy xᵢ − 2Δx yᵢ + A; A = 2Δy + Δx(2c−1). Consecutive decisions கழித்தால் p next = p + 2Δy − 2Δx(y next−y). Initial point substitute செய்தால் **p₁ = 2Δy−Δx**.

:::formula
p < 0 என்றால் E; p next = p + 2Δy
இல்லாவிட்டால் NE; p next = p + 2Δy − 2Δx
:::

Start plot செய்து இரண்டு increments-ஐ ஒருமுறை கணக்கிடுங்கள். Endpoint அடையும் வரை Δx transitions. Steep slope-க்கு major/minor axes மாற்றி output-இல் மீண்டும் மாற்றுங்கள். Negative slope-க்கு minor movement sign பயன்படுத்துங்கள். Tables decision-க்கு positive distances, coordinate movement-க்கு signs பயன்படுத்துகின்றன.

:::warn Source arithmetic wording
Page 11 prose ஒருமுறை 2Δy−Δx-ஐ increment என்கிறது; அது **initial decision**. Diagonal update 2Δy−2Δx; numbered algorithm சரியாகத் தருகிறது. p = 0-இல் PDF “otherwise” branch. “First 5 points” example starting point உட்பட ஆறு points காட்டுகிறது.
:::

## PDF equations மூலம் circle drawing

Circle-இன் எல்லா points-உம் centre (x꜀,y꜀)-இலிருந்து radius r தூரத்தில் உள்ளன. Figure 5.5 centre/radius/angle காட்டுகிறது.

:::formula
(x−x꜀)² + (y−y꜀)² = r²
x = x꜀ + r cos θ
y = y꜀ + r sin θ
:::

Circle-க்கு **eight-way symmetry**. Centre-relative (a,b)-இலிருந்து (±a,±b), (±b,±a) உருவாக்கி centre சேருங்கள். ஒரு 45° octant மட்டும் generate செய்தால் போதும். PDF 90°-இலிருந்து 45° நோக்கி வரச் சொல்கிறது; x அதிகரித்து y குறையும். True circle-க்கு அருகிலுள்ள pixels தேர்ந்தெடுக்க வேண்டும்.

PDF **midpoint/Bresenham circle recurrence தரவில்லை**. இங்கே அதன் Cartesian equation-ஐப் பயன்படுத்துகிறோம்: integer a ≥ 0-க்கு b = √(r²−a²), b-ஐ round செய்து plot; a > rounded b என்றால் plot செய்யாமல் நிறுத்தவும். பின்னர் reflections. இது equation-based sampling; midpoint algorithm என்று கூறவில்லை.

**Bézier curve** mathematical path. Nodes முக்கிய points; control handles node அருகே direction/shape நிர்ணயிக்கும். Figure 5.7-இல் மூன்று nodes; selected middle node-இன் handles தெரிகின்றன. Pen/curve/shape tools இவற்றை create/edit செய்யும். Text/basic shape-ஐ curves-ஆக மாற்றினால் node-level editing கிடைக்கும்; ஆனால் converted text சாதாரண editable characters ஆக இருக்காது.

**Rasterization** vector/text-ஐ தேர்ந்த resolution bitmap-ஆக மாற்றும். **Vectorization/tracing** pixels-இலிருந்து paths ஊகிக்கும். Bitmap-இல் “இது circle” என்ற object label இல்லை. Boundaries, unnecessary nodes, holes, colour regions சரிபார்க்கவும். Original geometry அப்படியே திரும்பும் என்று guarantee இல்லை.

**Filled areas** boundary/fill parameters பயன்படுத்தும். Region-க்குள் colour/pattern போட software தீர்மானிக்கும். Closed shape interior-ஐத் தெளிவாக்கும். Vector effects simple pixel fill-ஐவிட அதிக processing கேட்கலாம். PDF பொதுவாக cost அதிகம் என்கிறது; actual effort geometry/effects/implementation-ஐப் பொறுத்தது.

## Calculation practice மற்றும் answer-it-yourself

### DDA: ஐந்து practice questions

<details markdown="1"><summary>1. (0,0)→(4,2)-க்கு start உட்பட முதல் மூன்று DDA pixels காண்க.</summary>

Increments = (1,0.5). Real points (0,0), (1,0.5), (2,1). Half ties-ஐ zero-இலிருந்து விலக்கி round செய்தால்: **(0,0), (1,1), (2,1)**.

</details>

<details markdown="1"><summary>2. (1,1)→(1,4)-க்கு எல்லா DDA pixels காண்க.</summary>

Δx = 0, Δy = 3, steps = 3. Increments (0,1). **(1,1), (1,2), (1,3), (1,4)**. Slope காண zero-ஆல் வகுக்க வேண்டாம்.

</details>

<details markdown="1"><summary>3. (0,3)→(4,1)-க்கு முதல் மூன்று pixels காண்க.</summary>

Steps = 4; increments (1,−0.5). Real values (0,3), (1,2.5), (2,2). குறிப்பிட்ட tie rule-படி **(0,3), (1,3), (2,2)**.

</details>

<details markdown="1"><summary>4. (2,2)→(6,7)-க்கு இரு endpoints உட்பட எத்தனை plotted pixels?</summary>

Steps = max(4,5) = 5 transitions. ஆரம்ப point உட்பட **6 plotted positions**.

</details>

<details markdown="1"><summary>5. Endpoints இரண்டும் (−2,1), (−2,1) என்றால் DDA என்ன செய்யும்?</summary>

Steps = 0. **(−2,1)-ஐ ஒருமுறை plot செய்யவும்**; increments காண zero-ஆல் வகுக்க வேண்டாம்.

</details>

### Bresenham: ஐந்து practice questions

<details markdown="1"><summary>1. (0,0)→(5,2)-க்கு p₁ காண்க.</summary>

p₁ = 2Δy−Δx = 2×2−5 = **−1**. முதல் move E; point (1,0).

</details>

<details markdown="1"><summary>2. p = −1, Δy = 2, Δx = 5 என்றால் E-க்குப் பின் next decision காண்க.</summary>

p next = p+2Δy = −1+4 = **3**.

</details>

<details markdown="1"><summary>3. p = 3, Δy = 2, Δx = 5 என்றால் NE-க்குப் பின் next decision காண்க.</summary>

p next = p+2Δy−2Δx = 3+4−10 = **−3**.

</details>

<details markdown="1"><summary>4. Positive shallow line-இல் p = 0 என்றால் என்ன செய்வது?</summary>

PDF-இன் “otherwise” branch பயன்படுத்தி **(x+1,y+1)** தேர்ந்தெடுத்து 2Δy−2Δx சேர்க்கவும். இதுவே பயன்படுத்தும் tie convention.

</details>

<details markdown="1"><summary>5. (0,0)→(2,5)-க்கு shallow algorithm-ஐ எப்படி மாற்றுவது?</summary>

Major/minor axes மாற்றவும். Major = 5, minor = 2; p₁ = 4−5 = **−1**. ஒவ்வொரு step-லும் y நகரும்; அடுத்த முதல் pixel **(0,1)**.

</details>

### Circle drawing: ஐந்து practice questions

<details markdown="1"><summary>1. r = 5, relative x = 3 என்றால் upper circle-இன் relative y காண்க.</summary>

y = √(r²−x²) = √(25−9) = √16 = **4 pixel units**.

</details>

<details markdown="1"><summary>2. Centre (2,−1), radius 5 என்றால் rightmost point காண்க.</summary>

x = x꜀+r = 2+5 = 7; y = y꜀ = −1. **(7,−1)**.

</details>

<details markdown="1"><summary>3. Centre (1,2), radius 3-க்கு θ = 90° பயன்படுத்தவும்.</summary>

x = 1+3 cos 90° = 1; y = 2+3 sin 90° = 5. **(1,5)**.

</details>

<details markdown="1"><summary>4. Relative (0,5)-இலிருந்து எத்தனை தனித்தனி symmetry points கிடைக்கும்?</summary>

Signs மாற்றியும் coordinates மாற்றியும் **4** தனித்தனி cardinal points கிடைக்கும். எட்டு formal reflections-இல் சில ஒன்றாக அமையும்.

</details>

<details markdown="1"><summary>5. Rasterized circle-ஐ trace செய்தால் original circle object மீண்டும் கிடைக்கும் என்று ஏன் உறுதி செய்ய முடியாது?</summary>

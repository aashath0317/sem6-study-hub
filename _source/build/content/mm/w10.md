## The 3D environment and viewing tools

3D graphics packages may provide programming utilities, a graphical interface or both. The lesson uses **3ds Max** to apply the previous week's spatial concepts. A scene is built from geometry, viewing arrangements, lighting and other organised objects; the interface is a way to manipulate that structure.

The PDF's default workspace has **Top, Front, Left and Perspective** viewports. Each is a view of the same scene, not a different copy of the model. Orthographic views help align dimensions; Perspective helps judge spatial appearance. The exact layout depends on the installed version and custom settings. Figure 10.1 labels the workspace; Figure 10.2 highlights the **Create panel**, **Modify panel** and object categories.

| View tool | What it changes | Keep separate from |
|---|---|---|
| Pan | Moves the viewed region horizontally or vertically | Moving the object itself |
| Zoom | Changes viewing magnification | Scaling the model geometry |
| Arc Rotate | Orbits the view around the model | Rotating the object itself |

In the source interface, Pan uses a hand icon, Zoom uses a magnifying glass and Arc Rotate uses a circular axis icon. Inspect an object from several views before changing its geometry. A shape that looks aligned in one view can be displaced in depth in another. Give objects meaningful names so selection remains manageable as the scene grows.

## Creating primitives and editing parameters

Use the **Create panel**, select a category and object type, then click or drag in a viewport to define its initial parameters. The panel categories in the source are **Geometry, Shapes, Lights, Cameras, Helpers, Space Warps and Systems**. The Create menu also lists **Standard Primitives, Extended Primitives, AEC Objects, Compound, Particles, Patch Grids, NURBS, Dynamics**, followed by the other scene categories.

A **parameter** is a changeable setting. A **parametric object** updates its geometry when such a setting changes. A box may expose width, length, height and segments. A sphere exposes a radius. The illustrated tube can change inner and outer radii, height and segment settings. Parameter editing is more precise and repeatable than guessing dimensions through repeated dragging.

A primitive is a useful starting structure, not necessarily the final model. Increase segments when the intended deformation or silhouette needs them. More segments mean more geometry to process; a distant background object may need less detail than a close-up object. Preserve the editable primitive or a copy before a conversion that removes its convenient original parameters. The source mentions an inner radius of a cylinder; the hollow **tube** shown is the clearer example of inner/outer-radius parameters.

## Selection, transforms, cloning and Activity 10.1

Select by clicking, dragging a region, name or properties such as colour and category. Use **Select and Move**, **Select and Rotate**, or the appropriate **Select and Scale** mode. These change the object's placement or dimensions; they are different from view navigation. Use alignment tools when a precise relationship between objects is needed.

**Cloning** means duplicating objects or selection sets. The PDF lists these techniques:

- **SHIFT+Clone:** hold SHIFT while transforming a selection with the mouse in the demonstrated workflow.
- **Snapshot:** create copies of an animated object at selected times or spacing along its movement.
- **Array:** arrange repeated copies systematically.
- **Mirror:** create a reflected arrangement.
- **Spacing Tool:** distribute objects along a route.
- **Clone and Align:** duplicate and align to targets.

Snapshot spacing can be based on uniform time intervals or uniform distance. These differ when speed changes. For a repeated design, choose a method that makes the intended regularity explicit rather than manually placing every copy.

**Activity 10.1 question:** create the figure's repeated graphical arrangement using Array Copy and obtain a Quick Render snapshot. **Full model answer:** first construct one complete repeated unit resembling the rounded stack in the figure. Set its pivot and verify its material and proportions. Select it and use Array with displacement along one horizontal axis, choosing a count that fills a row. Extend the array along the other horizontal axis to form parallel rows. Preview spacing to prevent accidental overlap. Keep the repeated unit consistent, add suitable scene lighting and a background, select a perspective or camera view showing the rows, and use Quick Render. Save the editable scene before exporting the rendered image. The PDF provides the visual arrangement but no numeric array count or dimensions, so these are design choices rather than invented given data.

## Object conversion and the four modelling systems

Convert an object when its current representation does not expose the editing controls you need. The source names **primitive, extended primitive, compound, Editable Poly, Editable Mesh, Editable Patch and NURBS** objects. Converting to an editable form enables sub-object work, but may remove access to the original primitive's parameters. Keep a copy when that loss matters. Conversion alone does not guarantee a smooth surface.

| System | Representation and strength | Limitation or decision |
|---|---|---|
| Polygonal | Vertices and edges form polygon faces; direct local editing | Coarse silhouettes can look faceted; more geometry may be needed close up |
| Spline | Curves defined by control points; B-spline, Bézier and NURBS are examples | Smooth mathematical descriptions still need an appropriate rendered approximation |
| Patch | Control vertices influence flexible surface patches; patches can be subdivided and joined | Continuity across joins needs care |
| Parametric | Retains dimensions, segment counts and base construction settings | Flexibility depends on which parameters and history remain available |

The Lesson Outline says **Graphite modelling**, while the body explains polygonal modelling. Graphite is a modelling-tool context in 3ds Max, not a separate mathematical surface representation here. Learn the polygon/vertex/edge/face operations described in the body. The source also says parametric modelling is usually spline-based; parametric means controlled by retained parameters and is not restricted to splines. A box primitive is already a counterexample.

Polygon density should match viewing and deformation needs. A smooth-looking shaded surface can still have a visibly angular silhouette. A spline's resolution-independent description does not mean a computer renders infinite detail for free. Patches are useful for organic forms because selected control vertices can influence broader surface regions. Choose the representation for the shape and edits required.

## Lathe, extrusion, lofting and the modelling activities

**Lathe** revolves a profile around an axis to create a surface of revolution. Figure 10.5 shows a chess pawn. **Activity 12.2**, as misnumbered in this Week 10 PDF, asks you to create it after the demonstration. **Full model answer:** in a suitable orthographic viewport, set the grid and 2D snapping. Draw one side of the pawn's outline from its axis at the base through its foot, stem, collar and head. Keep the profile coherent and avoid self-intersections. Apply Lathe around the vertical axis, align the axis correctly, and use a full revolution. Inspect the seam, cap and surface normals. Increase segments enough for the intended silhouette, then assign a material and render. Keep the profile/modifier editable. A badly positioned axis can create a hole or an unwanted offset form.

**Extrude** adds depth to a 2D shape. Figure 10.6 shows a flat outline becoming a solid. Use a closed outline when a closed solid is required; inspect caps and depth direction. **Face Extrude** pushes selected faces along their normals and creates side faces connecting them to the original object. Figure 10.7 shows selected faces of a ring extending outward. The modifier exposes animatable parameters; its behaviour is not identical to every editable-mesh extrude command.

**Loft** builds a form from a path and cross-sectional shapes placed along it. Figure 10.8 shows a circular section swept along a curved route. You can add or replace cross-sections or the path, animate path/shape parameters, and change surface parameters.

**Activity 10.3 on page 10 question:** repeat the modelling operations and create the illustrated varying tubular form. **Full model answer:** draw a path along the model's length. Create circular or otherwise suitable cross-sections. Build a loft using the path, place sections at the required positions, and vary their size to match the illustrated narrowing and widening. Inspect every viewport, check twisting and continuity, and adjust section orientation or surface subdivisions as needed. Apply a material and render. Keep path and shapes editable so the model can be refined.

:::flow Redrawing the modelling operations
Lathe: profile → revolve around axis → rotational form
Extrude: flat outline → add depth → prism-like form
Face Extrude: selected face → move along normal → new side faces
Loft: path + cross-sections → continuous swept form
:::

## Animation, texture mapping, rendering and the final Activity 10.3

In animation, **keys** store important parameter values at keyframes. The software interpolates **tweens**. The PDF's quick workflow is to enable **Auto Key**, move to another frame and change an object's transformation. Check the starting key and turn Auto Key off after recording, or later edits may accidentally become animation keys.

3ds Max can animate more than position, rotation and scale. The source gives Bend or Taper modifier angles and material colour or transparency as examples. For a simple character, organise related parts into a sensible hierarchy so moving the parent carries its children. Plan clear poses, pivots and timing before adding detailed motion. Preview the full sequence and inspect contact, intersections and unintended motion. The outline asks for character animation but supplies no rigging tutorial in the PDF; this is a practical application of its parameter-keying model.

**Texture mapping** places surface detail on geometry. Wood grain or zebra stripes can be supplied by an image rather than modelling every stripe as separate geometry. Mapping coordinates control how the image covers the surface. Inspect stretching, scale, seams and the relationship between texture direction and form. A texture changes appearance; it does not automatically change the object's silhouette.

**Rendering** calculates the output picture or frame sequence from the scene, view, geometry, materials and lighting. A viewport preview helps work quickly; a render checks the intended output. Set the camera/view, output dimensions, frame range and destination. For an animation, preview representative frames before committing to the whole range. Check that required textures resolve correctly and that the saved scene can reopen with its assets.

**Final Activity 10.3 on page 12 question:** repeat the animation and texture demonstrations. This number duplicates the page 10 activity; keep both tasks. **Full model answer:** save an editable scene, select a model, establish a starting pose and key, move to a later frame and change a transform or modifier parameter with Auto Key. Play and refine the interpolation, then turn Auto Key off. Create or choose a material, load a suitable image map, assign it to the object and adjust mapping to avoid obvious stretch. Add light and a useful camera view. Render a still to inspect material detail, then render the required animation range to a separate output. Compare start, middle and end frames for continuous motion and consistent texture. The unavailable demonstrations' exact settings are not invented.

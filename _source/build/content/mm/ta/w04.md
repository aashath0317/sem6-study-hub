## Pictures, images, raster மற்றும் vector graphics

Lesson visual scene-ஐ **picture**, அதன் digitised copy-ஐ **image**, photos/drawings/line art உள்ளிட்ட பெரிய வகையை **graphic** என்கிறது. **Computer graphics** visual models உருவாக்கி சேமித்து மாற்றுகிறது; real/synthetic world-இன் image உருவாக்குகிறது. Camera/scanner scene capture செய்யும்; drawing program shapes மூலம் உருவாக்கலாம்.

**Raster/bitmap** pixels grid சேமிக்கிறது. ஒவ்வொரு pixel-க்கும் position/colour உண்டு. Raster edit செய்தால் pixels மாறும். Photos/painting-இல் நுணுக்கமான colour மாற்றங்களை இது காட்டும். Pixel dimensions fixed என்பதால் resolution-dependent. பெரிதாக்கும்போது blocks/jagged edges தெரியலாம். பொதுவாக அதிக pixels-க்கு அதிக raw storage வேண்டும்.

**Vector** mathematical commands-ஆக objects சேமிக்கிறது: positions, lines, curves, circles, fills, strokes. ஒவ்வொரு pixel-ஐயும் தனியாக மாற்றாமல் object-ஐ மாற்றுகிறோம். Tyre-ஐ centre/radius/stroke/fill கொண்ட circle-ஆகச் சொல்லலாம். அதன் geometric definition-ஐ scale செய்யலாம்.

| Property | Raster | Vector |
|---|---|---|
| Stored description | Pixel colours | Geometry objects/parameters |
| Edit unit | Pixels/selected regions | Objects/paths தனித்தனியாக |
| Scaling | Fixed detail; enlargement pixelate ஆகலாம் | Geometry scale ஆகும்; display resolution இன்னும் finite |
| Use | Photo/texture/painting | Logo/symbol/diagram/lettering |
| Formats | BMP, GIF, JPEG, PNG, TIFF, TGA | SVG, AI, CDR, EPS; PDF-இலும் vectors இருக்கலாம் |
| PDF tools | Photoshop, GIMP, PhotoPaint | Illustrator, CorelDRAW; InDesign முக்கியமாக page layout |

:::warn Source-இன் பொதுவான கூற்றுகள்
Vectors-க்கு texture இருக்க முடியாது, எப்போதும் memory குறைவு என்று PDF சொல்கிறது. Complex vector art பெரியதாகவும் patterns/effects/embedded rasters கொண்டதாகவும் இருக்கலாம். Simple geometry பல நேரங்களில் compact; photos-க்கு raster பொருந்தும். PDF/EPS mixed content வைத்திருக்கலாம்; extension மட்டும் பார்த்து எல்லாமே vector என்று சொல்ல முடியாது.
:::

## Resolution, aspect ratio மற்றும் Activity 4.1

**Image resolution** image detail; வழக்கமாக width × height pixels. **Display resolution** display-இன் pixel capability. **Colour resolution/depth** ஒரு pixel colour-க்காக ஒதுக்கும் bits. இவை வேறு அளவுகள். Pixel count அதிகமானால் colour depth தானாக அதிகரிக்காது.

Pixel dimensions, physical print size, pixel density தொடர்புடையவை. Fixed pixels-ஐப் பெரிய paper area-வில் வைத்தால் அவை பரவுகின்றன. Pixels/inches, bits/bytes வேறுபாடு கவனியுங்கள். PDF KB convention தரவில்லை. இங்கே **1 KiB = 1024 bytes**; decimal units கேட்டால் **1 kB = 1000 bytes** என்று தெளிவாகச் சொல்கிறோம்.

:::formula
Pixels = width × height
Aspect ratio = width : height; common factor-ஆல் குறைக்கவும்
Pixel density (ppi) = edge pixels ÷ printed inches
Printed inches = edge pixels ÷ ppi
:::

**Activity 4.1 கேள்வி:** Raster/vector graphic devices survey செய்து features ஒப்பிடுங்கள்; LCD/LED display-இல் தொடங்கலாம்.

**மாதிரி விடை:** LCD/LED-backlit screen fixed pixel grid காட்டும். Scanner/camera pixel dimensions/depth கொண்ட raster capture செய்யும். Raster printer page-ஐ dots-ஆக மாற்றும். Pen plotter vector paths-ஐ physical pen மூலம் பின்பற்றலாம்; technical drawing-க்கு உதவும். Addressable resolution, size, colour, intended use ஒப்பிடுங்கள். Modern screen vector-ஐ rasterize செய்தே காட்டும்; vector file வைத்தால் LCD vector-display ஆகாது. உண்மையான survey-இல் actual specifications பதிவு செய்ய வேண்டும்; இங்கே device classes மட்டுமே, கற்பனை measurements இல்லை.

## RGB, CMYK, HSB மற்றும் grey colour

PDF spectrum-இல் visible light சுமார் **400–700 nm**. Colour visual-system perception. **Colour model** ஒரு task-க்கு உதவும் parameters மூலம் colour-ஐக் குறிக்கிறது.

**RGB** red/green/blue light-ஐ add செய்கிறது. மூன்றும் maximum சமமாக இருந்தால் white; அனைத்தும் zero என்றால் black. Channel ஒன்றுக்கு 8 bits என்றால் 0 முதல் 255 வரை. மூன்று channels-க்கு 24 bits/pixel; 16,777,216 combinations. சம components RGB cube-இன் grey diagonal-இல் இருக்கும். Display additive light பயன்படுத்துகிறது.

**CMYK** cyan/magenta/yellow/black inks. இது subtractive: white light-இன் சில பகுதிகளை ink உறிஞ்சி மீதியை reflect செய்கிறது. Ideal CMY black தரலாம்; actual inks முழுமையான black தராது. K black component உதவுகிறது. Four-colour printing print-க்கு ஏற்றது. RGB/CMY primaries complementary; screen/print colour வேறுபடலாம்.

**HSB** hue/saturation/brightness. Hue colour wheel இடம்; saturation grey-க்கு ஒப்பான colour strength; brightness light/dark value. Source wheel: red 0°, yellow 60°, green 120°, cyan 180°, blue 240°, magenta 300°, மீண்டும் red 360°. Saturation 0% grey முதல் 100% fully saturated வரை.

:::warn PDF-இன் HSB wording
HSB-ஐ HSV என்றும் கூறுவார்கள். ஆனால் HSL/HSI definitions வேறு; அதே coordinates-க்கு வேறு பெயர் மட்டும் அல்ல. HSV-இல் 100% value என்றால் கட்டாயம் white இல்லை; fully saturated red-க்கும் maximum value இருக்கலாம். Source-இன் “100% white” மிக எளிமைப்படுத்தப்பட்ட கூற்று.
:::

இந்த lesson **grey mode**-இல் 8 bits/pixel; 256 brightness levels: 0 black, 255 white. Ink coverage-இல் 0% black ink white paper; 100% black. Grayscale-இல் tones உண்டு; தனித்தனி hue channels இல்லை.

**Activity 4.2: RGB/grey வேறுபாடு.** RGB தனித்தனி red/green/blue channels மூலம் colour காட்டும். Lesson RGB 24 bits/pixel; grey ஒரே brightness channel, 8 bits/pixel. அதே dimensions, overhead இல்லை என்றால் RGB pixel data grey-ஐவிட மூன்று மடங்கு. Grey monochrome documents/tonal work-க்கு; RGB screen colour images-க்கு.

## Image data, colour depth மற்றும் படிப்படியான கணக்குகள்

Figure 4.7 direct raster pixel information-ஐ vector mathematical model-உடன் ஒப்பிடுகிறது. இரண்டுக்கும் கடைசியில் colour model/output resolution தேவை. Raster storage width/height/bits-per-pixel-ஐப் பொறுத்தது.

:::formula
b bits/pixel-இல் maximum codes/colours = 2^b
N colours-க்கான minimum index depth = ceil(log₂ N)
Uncompressed pixel-data bits = W × H × b
Uncompressed pixel-data bytes = W × H × b ÷ 8
:::

குறிப்பிடாவிட்டால் headers, palettes, metadata, row padding, compression, extra channels இந்த formulas-இல் இல்லை. Actual disk size வேறுபடலாம். Packed result whole byte இல்லை என்றால் round up செய்ய வேண்டும்; format alignment கூடுதல் இடம் கேட்கலாம்.

### Image size: மூன்று solved examples

**Example 1, PDF:** 30 × 40 pixels, 8 bits/pixel. Formula: bytes = W × H × b ÷ 8. Substitute: 30 × 40 × 8 ÷ 8. Working: 1200 × 1. **விடை: 1200 bytes** raw pixel data.

**Example 2, Activity 4.3:** 240 × 320 pixels, 8-bit. Formula: bytes = W × H × b ÷ 8. Substitute: 240 × 320 × 8 ÷ 8 = 76,800. Conversion: 76,800 ÷ 1024 = 75. **விடை: 76,800 bytes = 75 KiB**, overhead இல்லாமல்.

**Example 3:** 640 × 480 RGB, 24 bits/pixel. Formula: bytes = W × H × b ÷ 8. Substitute: 640 × 480 × 24 ÷ 8 = 307,200 × 3. **விடை: 921,600 bytes = 900 KiB**, overhead இல்லாமல்.

### Colour depth: மூன்று solved examples

**Example 1:** 1 bit-இல் codes? Formula N = 2^b. Substitute 2^1. **விடை: 2 colour codes**. Black/white அல்லது வேறு இரண்டு colours குறிக்கலாம்; Figure 4.8 இதைக் காட்டுகிறது.

**Example 2:** 8 bits-இல் codes? Formula N = 2^b. Substitute 2^8. **விடை: 256 codes**; 8 colours அல்ல.

**Example 3:** 100 palette colours-க்கு minimum index depth? Formula b = ceil(log₂ N). 2^6 = 64 < 100; 2^7 = 128 ≥ 100. **விடை: 7 bits/index** ideal packing-இல். Palette-க்கும் storage வேண்டும்.

### Resolution: மூன்று solved examples

**Example 1:** 800 × 600 pixel count. Formula pixels = W × H. Substitute 800 × 600. **விடை: 480,000 pixels**.

**Example 2:** 1200 pixels width, 4 inches print width. Formula ppi = pixels ÷ inches. Substitute 1200 ÷ 4. **விடை: 300 ppi** அந்த edge-இல்.

**Example 3:** 1800 × 1200 image, 300 ppi. Formula inches = pixels ÷ ppi. Substitute 1800 ÷ 300 = 6; 1200 ÷ 300 = 4. **விடை: 6 × 4 inches**. Size கணக்கிடுவதால் புதிய pixels உருவாகாது.

### Aspect ratio: மூன்று solved examples

**Example 1:** 800 × 600 ratio 800:600. இரண்டையும் 200-ஆல் வகுக்கவும். **விடை: 4:3**, width/height = 4/3.

**Example 2:** 1920 × 1080 ratio 1920:1080. இரண்டையும் 120-ஆல் வகுக்கவும். **விடை: 16:9**.

**Example 3:** 1280 pixels width-இல் 16:9 காக்கவும். Formula H = W × 9/16. Substitute 1280 × 9/16 = 80 × 9. **விடை: 720 pixels height**. வேறு ratio-க்கு stretch செய்தால் படம் distort ஆகும்.

## Palettes, codecs, compression மற்றும் dithering

**CLUT** palette entries சேமிக்கிறது; pixel indices அவற்றைக் குறிக்கின்றன. சில colours மட்டும் உள்ள image-க்கு storage குறையலாம். தேவைப்படும் எல்லா colours-உம் பாதுகாக்கப்பட்டால் lossless; palette-ஐக் குறைத்தால் colour information போகலாம். Palette கட்டாயம் external file இல்லை; transition description-உம் இல்லை; index எப்போதும் ஒரு byte-க்குக் குறைவாக இருக்காது. Page 13 கூற்றுகள் குறிப்பிட்ட representation-க்கு மட்டும் பொருந்தலாம்.

**Codec** data encode/decode செய்கிறது. Figure 4.9: original bitmap → encoder → coded file → decoder → reconstructed bitmap. Compatible decoder தேவை; அதே physical software instance வேண்டும் என்று அர்த்தமில்லை.

**Lossless compression** represented data-ஐ அப்படியே மீட்டுத் தரும். RLE runs-ஐ encode செய்யும்; LZW patterns reuse செய்யும்; GIF/PNG lossless compression தரும். **Lossy compression** தகவலை நிரந்தரமாக விடுகிறது. பொதுவான JPEG photographic compression file size/visible quality இடையே trade-off. அதிக compression artefacts தரலாம். Photo-வை limited GIF palette-க்கு மாற்றும்போதே colours போகலாம்; அதற்குப் பின் GIF compression lossless என்றாலும் அவை திரும்பாது.

**Activity 4.4: Lossless/lossy வேறுபாடு.** Lossless reversible; exact diagrams/text-like graphics/editing masters-க்கு உதவும். Lossy irreversible; சிறிய distortion ஏற்கும் photos/video/audio-வில் சிறிய files தரலாம். மீண்டும் மீண்டும் lossy encode செய்தால் degradation கூடலாம். Acceptable error/delivery needs பார்த்து தேர்வு செய்யுங்கள்; file size மட்டும் பார்க்க வேண்டாம்.

**Dithering** கிடைக்காத colours/tones-ஐ available colours patterns மூலம் உணர்த்தும். Low-colour display/printing-இல் richer image போலத் தெரிய உதவும். ஒவ்வொரு colour-க்கும் nearest colour மட்டும் தேர்வது quantisation; dithering spatial patterns-உம் பயன்படுத்தும். Dots/lines/shapes இருக்கலாம். Palette/algorithm-ஐப் பொறுத்து result மாறும். Black/white dots புதிய ink இல்லாமலே grey போலத் தெரியலாம்.

## PDF-இன் நான்கு review விடைகள்

**1. Vector/raster formats ஒப்பீடு.** Raster pixel data சேமித்து photos/tonal painting-க்கு உதவும்; stored detail scaling-ஐக் கட்டுப்படுத்தும். Vector objects/mathematical paths சேமிப்பதால் logos/diagrams edit/resize செய்ய வசதி. சில containers இரண்டையும் கொண்டிருக்கலாம்; extension மட்டும் பார்த்துத் தீர்மானிக்க வேண்டாம்.

**2. CLUT/JPEG ஒப்பீடு.** CLUT palette entries/pixel indices சேமிக்கிறது. எல்லா colours-உம் பொருந்தினால் exact; palette குறைத்தால் colour detail போகலாம். பொதுவான JPEG photo தகவலில் சிலவற்றை விடுத்து size குறைக்கிறது; quality ஒரு trade-off. Indexed line art-க்கும் richly shaded photo-க்கும் தேவைகள் வேறு.

**3. RGB-ஐவிட HSV-இன் வசதி.** Colour family, strength, brightness-ஐத் தனித்தனியாக மாற்றலாம்; சாதாரணமாக நாம் colour-ஐ விவரிக்கும் முறைக்கு நெருக்கம். RGB display primaries intensities-ஐ நேரடியாக மாற்றுகிறது. HSV தானாக அதிக colours/accuracy தராது; வேறு பயனுள்ள coordinate system தருகிறது.

**4. JPEG compression/decompression.** PDF அளவில்: encoder original bitmap-ஐ சிறிய coded representation-ஆக மாற்றும்; compatible decoder display pixels மீண்டும் உருவாக்கும். பொதுவான lossy JPEG colour representation மாற்றி blocks-க்கு frequency transform, quantisation, encoding செய்கிறது. Decode coding/transform-ஐ reverse செய்யும்; quantisation-இல் போன தகவல் திரும்பாது. இந்த விரிவான sequence PDF-இன் general codec diagram-க்கு மேலான விளக்கம்; lecture-இல் இந்த detailed diagram இல்லை.

:::exam English answer frame
“Uncompressed pixel data equals width × height × bits per pixel. Divide by 8 for bytes and state any unit conversion. This excludes format overhead and compression. Raster stores pixel colours; vector stores mathematical objects. RGB is additive display light, CMYK is subtractive ink, and indexed colour uses a palette. Lossless compression restores represented data exactly; lossy compression trades information for reduced size.”
:::

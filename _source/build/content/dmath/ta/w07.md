## தொகுத்தறிதல் ஏன்?

**அனைத்து நேர்மறை முழு எண்கள் n-க்கும்** ஒரு பண்பு பொருந்துகிறது எனப் பல வாக்கியங்கள் கூறுகின்றன. எடுத்துக்காட்டாக:

- 1 + 2 + … + n = n(n + 1)/2
- n³ − n, 3-ஆல் வகுபடும்
- 4ⁿ⁺¹ > (n + 2)²

முடிவற்ற நிகழ்வுகளை ஒவ்வொன்றாகச் சரிபார்க்க முடியாது. **கணிதத் தொகுத்தறிதல்** அனைத்தையும் ஒரே நேரத்தில் நிறுவுகிறது.

:::key கணிதத் தொகுத்தறிதல் கொள்கை
அனைத்து நேர்மறை முழு எண்கள் n-க்கும் **P(n)** நிறுவ:

1. **அடிப்படைப் படி:** **P(1)** உண்மை எனச் சரிபார்க்கவும்.
2. **தொகுத்தறிதல் படி:** **அனைத்து** நேர்மறை முழு எண்கள் k-க்கும் **P(k) → P(k + 1)** உண்மை எனக் காட்டவும்.
:::

:::key குறிப்பு 1 — தொகுத்தறிதல் கருதுகோள்
தொகுத்தறிதல் படியில் ஏதாவது k-க்கு **P(k) உண்மை என அனுமானிக்கிறீர்கள்**. இந்த அனுமானமே **தொகுத்தறிதல் கருதுகோள்**. பின்னர் **P(k + 1)-உம் பொருந்துகிறது எனக் காட்டுகிறீர்கள்**.
:::

**இது செயல்படுவது ஏன்:**

- P(1) உண்மை (அடிப்படைப் படி).
- P(1) ⇒ P(2); எனவே P(2) உண்மை.
- P(2) ⇒ P(3); எனவே P(3) உண்மை.
- … இவ்வாறு ஒவ்வொரு n-க்கும் P(n) உண்மை.

### டொமினோ காட்சி

1, 2, 3, … என எண்ணிடப்பட்ட முடிவற்ற டொமினோக் கட்டைகளை வரிசைப்படுத்தவும். P(n) = "டொமினோ n விழுகிறது" என்க.

- **அடிப்படை:** டொமினோ 1-ஐத் தள்ளுகிறீர்கள்; எனவே P(1) உண்மை.
- **தொகுத்தறிதல் படி:** டொமினோ k விழும்போதெல்லாம் k + 1-ஐ விழுத்துகிறது; எனவே P(k) → P(k + 1).

ஆகவே **ஒவ்வொரு டொமினோவும் விழுகிறது**.

## செய்முறைத் தொகுத்தறிதல் நிறுவல்கள்

:::example எடுத்துக்காட்டு 7.1.1 — 1 + 2 + ⋯ + n = n(n + 1)/2
P(n): "முதல் n நேர்மறை முழு எண்களின் கூட்டுத்தொகை n(n + 1)/2" என்க.

**அடிப்படைப் படி:** 1 = 1·(1 + 1)/2; எனவே P(1) உண்மை.

**தொகுத்தறிதல் படி:**
- **P(k)-ஐ அனுமானிக்கவும்:** 1 + 2 + ⋯ + k = k(k + 1)/2. (இதுவே தொகுத்தறிதல் கருதுகோள்.)
- **காட்ட வேண்டியது P(k + 1):** 1 + 2 + ⋯ + k + (k + 1) = (k + 1)(k + 2)/2.
- P(k)-இன் இருபக்கங்களிலும் (k + 1) சேர்க்கவும்:

1 + 2 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = [k(k + 1) + 2(k + 1)]/2 = **(k + 1)(k + 2)/2** ✓

எனவே P(k + 1) பொருந்துகிறது. தொகுத்தறிதலால் அனைத்து நேர்மறை முழு எண்கள் n-க்கும் P(n) உண்மை. ∎
:::

:::example எடுத்துக்காட்டு 7.1.2 — 1 + 3 + 5 + ⋯ + (2n − 1) = n²
P(n): "முதல் n ஒற்றை முழு எண்களின் கூட்டுத்தொகை n²" என்க.

**அடிப்படைப் படி:** 1 = 1²; எனவே P(1) உண்மை.

**தொகுத்தறிதல் படி:**
- 1 + 3 + ⋯ + (2k − 1) = k² என **அனுமானிக்கவும்**.
- (2k + 1) வரையான கூட்டுத்தொகை (k + 1)²-க்குச் சமம் எனக் **காட்டவும்**.
- அடுத்த ஒற்றை எண்ணான (2k + 1)-ஐ இருபக்கங்களிலும் சேர்க்கவும்:

1 + 3 + ⋯ + (2k − 1) + (2k + 1) = k² + 2k + 1 = **(k + 1)²** ✓ ∎
:::

:::example எடுத்துக்காட்டு 7.1.3 — n < 2ⁿ (ஓர் அசமத்துவம்)
**அடிப்படைப் படி:** 1 < 2¹ = 2; எனவே P(1) உண்மை.

**தொகுத்தறிதல் படி:**
- k < 2ᵏ என **அனுமானிக்கவும்**.
- k + 1 < 2ᵏ⁺¹ எனக் **காட்டவும்**.
- கருதுகோளின் இருபக்கங்களிலும் 1 சேர்த்து, 1 ≤ 2ᵏ பயன்படுத்தவும்:

k + 1 < 2ᵏ + 1 ≤ 2ᵏ + 2ᵏ = 2·2ᵏ = **2ᵏ⁺¹** ✓ ∎
:::

:::example எடுத்துக்காட்டு 7.1.4 — n³ − n, 3-ஆல் வகுபடும் (வகுபடுதன்மை நிறுவல்)
**அடிப்படைப் படி:** 1³ − 1 = 0; 3 | 0; எனவே P(1) உண்மை.

**தொகுத்தறிதல் படி:**
- 3 | (k³ − k) என **அனுமானிக்கவும்**.
- 3 | ((k + 1)³ − (k + 1)) எனக் **காட்டவும்**.
- விரித்துப் புதிதாகத் தொகுக்கவும்:

(k + 1)³ − (k + 1) = (k³ + 3k² + 3k + 1) − (k + 1) = **(k³ − k) + 3(k² + k)**

முதல் அடைப்புக்குறிப் பகுதி 3-ஆல் வகுபடும் (கருதுகோளால்). இரண்டாவது முழு எண்ணின் 3 மடங்கு. எனவே அவற்றின் **கூட்டுத்தொகை 3-ஆல் வகுபடும்** ✓ ∎
:::

:::tip பொதுச் செய்முறை
1. **P(n)-ஐத்** தெளிவாக **வரையறுக்கவும்**.
2. **அடிப்படை:** n = 1 (அல்லது கொடுக்கப்பட்ட ஆரம்பப் பெறுமதி) பிரதியிட்டு இருபக்கங்களையும் சரிபார்க்கவும்.
3. **கருதுகோள் P(k)**, **இலக்கு P(k + 1)** ஆகியவற்றை வெளிப்படையாக **எழுதவும்**.
4. **P(k + 1)-இலிருந்து தொடங்கி**, அதற்குள் P(k)-ஐக் கண்டறிந்து **கருதுகோளைப் பயன்படுத்தவும்**. கூட்டுத்தொகைகளுக்கு இறுதி உறுப்பைப் பிரிக்கவும். வகுபடுதன்மைக்கு "கருதுகோள் பகுதி + m-இன் மடங்கு" என மீள்தொகுக்கவும்.
5. **முடிக்கவும்:** "கணிதத் தொகுத்தறிதல் கொள்கையால் அனைத்து n-க்கும் P(n) பொருந்துகிறது."
:::

## நன்கு வரிசைப்படுத்தல் பண்பு

:::key நன்கு வரிசைப்படுத்தல் பண்பு
**எதிர்மறையல்லாத முழு எண்களின் ஒவ்வொரு வெற்றல்லாத கணத்துக்கும் மிகச்சிறிய மூலகம் உள்ளது.** ஒவ்வொரு அத்தகைய கணம் A-க்கும் அனைத்து x ∈ A-க்கும் a ≤ x ஆகும் a ∈ A உள்ளது.

நன்கு வரிசைப்படுத்தல் கொள்கை, கணிதத் தொகுத்தறிதல் கொள்கைக்குச் **சமமானது**.
:::

:::example எடுத்துக்காட்டுகள் 7.1.5, 7.1.6
- A = {3, 11, 5, 9, 2, 8, 16, 21}-இன் மிகச்சிறிய மூலகம் **2**.
- A = {n ∈ ℕ : n > 7} முடிவற்றது; இருந்தாலும் மிகச்சிறிய மூலகம் **8** உள்ளது.
:::

## மறுசுழற்சி

சிலசமயம் பொருளை **வெளிப்படையாக** வரையறுப்பது கடினம்; ஆனால் **அதனையே அடிப்படையாகக் கொண்டு** வரையறுப்பது எளிது. இதுவே **மறுசுழற்சி**. இது **தொடரிகள், சார்புகள், கணங்களை** வரையறுக்கலாம்.

:::grid
**மறுசுழற்சியாக வரையறுக்கப்பட்ட தொடரி**

- **அடிப்படைப் படி:** ஆரம்ப உறுப்பு a₀ கொடுக்கவும்.
- **மறுசுழற்சிப் படி:** முந்தைய உறுப்பு(கள்) அடிப்படையில் ஒவ்வொரு உறுப்புக்கும் விதி கொடுக்கவும்.
+++
**மறுசுழற்சியாக வரையறுக்கப்பட்ட சார்பு** (ஆட்களம் = எதிர்மறையல்லாத முழு எண்கள்)

- **அடிப்படைப் படி:** **பூச்சியத்தில்** பெறுமதி கொடுக்கவும்.
- **மறுசுழற்சிப் படி:** **சிறிய முழு எண்களிலுள்ள** பெறுமதிகளிலிருந்து ஒரு முழு எண்ணின் பெறுமதிக்கான விதி கொடுக்கவும்.
:::

:::example எடுத்துக்காட்டு 7.2.1 — 3-இன் அடுக்குகள்
வெளிப்படைச் சூத்திரம் aₙ = 3ⁿ. மறுசுழற்சியாக: n = 0, 1, 2, …-க்கு **a₀ = 1, aₙ₊₁ = 3aₙ**.
:::

:::example எடுத்துக்காட்டு 7.2.2 — f(0) = 3, f(n + 1) = 2f(n) + 3
- f(1) = 2·3 + 3 = **9**
- f(2) = 2·9 + 3 = **21**
- f(3) = 2·21 + 3 = **45**
- f(4) = 2·45 + 3 = **93**
:::

:::example எடுத்துக்காட்டு 7.2.3 — காரணியல் F(n) = n!
(n + 1)! = (n + 1)·n! என்பதால்:

- **F(0) = 1**
- **F(n + 1) = (n + 1)·F(n)**
:::

:::example எடுத்துக்காட்டு 7.2.4 — aⁿ அடுக்குகள் (a ≠ 0, n ≥ 0)
- **a⁰ = 1**
- **aⁿ⁺¹ = a·aⁿ**
:::

:::example எடுத்துக்காட்டு 7.2.5 — முதல் n உறுப்புகளின் கூட்டுத்தொகை
- **அடிப்படை:** Σ<sub>k=0</sub><sup>0</sup> aₖ = a₀
- **மறுசுழற்சி:** Σ<sub>k=0</sub><sup>n+1</sup> aₖ = (Σ<sub>k=0</sub><sup>n</sup> aₖ) + aₙ₊₁
:::

:::example ஃபிபொனாச்சி எண்கள்
- **f₀ = 0, f₁ = 1**
- n = 2, 3, 4, …-க்கு **fₙ = fₙ₋₁ + fₙ₋₂**

முன்னோக்கிக் கணக்கிடுதல்:
- f₂ = 1 + 0 = 1
- f₃ = 1 + 1 = 2
- f₄ = 2 + 1 = 3
- f₅ = 3 + 2 = 5
- f₆ = 5 + 3 = **8**

ஒவ்வொரு உறுப்பும் அதற்கு முந்தைய இரண்டைப் பயன்படுத்துவதால் **இரு** ஆரம்பப் பெறுமதிகள் தேவை.
:::

:::key குறிப்பு 2
மறுசுழற்சியாக வரையறுக்கப்பட்ட சார்புகள் **நன்கு வரையறுக்கப்பட்டவை**: ஒவ்வொரு நேர்மறை முழு எண்ணிலும் பெறுமதி **ஐயமின்றி** தீர்மானிக்கப்படுகிறது. இது கணிதத் தொகுத்தறிதல் கொள்கையிலிருந்து பெறப்படுகிறது.
:::

{{tool:rc}}

:::exam
எதிர்பார்க்க வேண்டியவை:

- **முழுத் தொகுத்தறிதல் நிறுவல்** (கூட்டுத்தொகைச் சூத்திரம், அசமத்துவம் அல்லது வகுபடுதன்மை). மதிப்பெண்கள்: P(n)-ஐத் தெளிவாக வரையறுத்தல், அடிப்படைப் படி, **தொகுத்தறிதல் கருதுகோளைக் குறிப்பிடுதல்**, தொகுத்தறிதல் படி, முடிவு.
- "நன்கு வரிசைப்படுத்தல் பண்பைக் கூறி, கணத்தின் மிகச்சிறிய மூலகத்தைக் கண்டறியவும்."
- "தொடரொன்றுக்கு மறுசுழற்சி வரையறை கொடுக்கவும்". a₁-இல் தொடங்கி, ஒவ்வொரு உறுப்பும் முந்தையதிலிருந்து எப்படி வருகிறது எனக் கூறவும்:
    - aₙ = 6n: a₁ = 6, aₙ₊₁ = aₙ + 6
    - aₙ = 2n + 1: a₁ = 3, aₙ₊₁ = aₙ + 2
    - aₙ = 5: a₁ = 5, aₙ₊₁ = aₙ
    - aₙ = 4n − 2: a₁ = 2, aₙ₊₁ = aₙ + 4
- "மறுசுழற்சி விதி கொடுக்கப்பட்டால் f(1)…f(5) கண்டறியவும்."
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|
| தொகுத்தறிதல் | அடிப்படை P(1) + தொகுத்தறிதல் படி P(k) → P(k + 1) |

**Q1.** True or false: mathematical induction can prove that a property is true for **all positive integers**.

**✅ Answer: True**

That is exactly what induction is for: statements of the form “P(n) is true for every n ≥ 1” (or every n ≥ some starting number).


**Q2.** Which statement is **incorrect**?

(a) The inductive hypothesis is not used in the basis step. (b) An induction proof has three parts: basis step, inductive step and **conclusive step**. (c) Induction can prove n³ − n is divisible by 3 for every positive n. (d) In the basis step we show the statement is true for the smallest integer in the statement.

**✅ Answer: (b) — there is no “conclusive step”**

An induction proof has **two** steps:

1. **Basis step:** show P(1) is true (or P(smallest n)).
2. **Inductive step:** assume P(k) is true (the **inductive hypothesis**) and show P(k + 1) is true.

Then you conclude P(n) is true for all n — that is the conclusion, not a separate step.


**Q3.** P(n): 1² + 2² + … + n² = n(n + 1)(2n + 1)/6 for n > 0. What is **P(1)**?

(a) 0² = 0(0+1)(0+1)/6 (b) n = 1 (c) the general formula (d) 1² = 1(1+1)(2+1)/6

**✅ Answer: (d) 1² = 1(1 + 1)(2 + 1)/6**

Replace **every n with 1**. The left side stops at the 1st term (1²); the right side becomes 1 × 2 × 3 / 6 = 1. Both sides equal 1 ✓ — that is the basis step.


**Q4.** In the inductive step, assuming P(k) is true, what must be shown?

(a) P(1) (b) P(k − 1) (c) the general formula (d) P(k + 1)

**✅ Answer: (d) P(k + 1) holds**

**Assume P(k), prove P(k + 1).** Like dominoes: if any one falls (k), the next one falls too (k + 1).


**Q5.** For this proof, what do you need in order to prove the inductive step?

(a) both the inductive hypothesis and the basis-step result (b) only the basis-step result (c) only the inductive hypothesis (d) none

**✅ Answer given by the quiz: (a) both**

The inductive step itself uses the **inductive hypothesis** P(k). The basis step is what lets the chain start at n = 1, so the quiz treats both as needed to complete the proof. Remember **(a)** for this question.


**Q6.** How many times do we need to use the inductive hypothesis in the inductive step?

(a) not needed (b) twice (c) only once (d) none

**✅ Answer: (c) only once**

You use it once: replace the part that equals P(k) (for example 1² + … + k²) with its formula, then simplify to get the P(k + 1) formula.


**Q7.** True or false: the **well-ordering property** says every non-empty set of non-negative integers has a least element.

**✅ Answer: True**

Any non-empty set of numbers from {0, 1, 2, …} has a smallest member. (This is why induction works.)


**Q8.** aₙ = 4ⁿ for n = 0, 1, 2, … can be defined recursively by:

(a) a₀ = 1; aₙ₊₁ = 4n·aₙ (b) a₀ = 1; aₙ₊₁ = 4aₙ for n = 1, 2, … (c) a₀ = 1; aₙ₊₁ = 4aₙ for n = 0, 1, 2, … (d) none

**✅ Answer: (c) a₀ = 1; aₙ₊₁ = 4aₙ for n = 0, 1, 2, …**

A recursive definition needs two parts:

1. **Starting value:** a₀ = 4⁰ = 1.
2. **Rule to get the next term from the previous one:** each power of 4 is the previous × 4 → aₙ₊₁ = 4aₙ.

(b) starts the rule at n = 1, so a₁ would never be defined. (a) multiplies by 4n, which is wrong.


**Q9.** f(0) = 1 and f(n + 1) = 2f(n) + 7. Find f(1).

(a) 6 (b) 9 (c) 7 (d) 10

**✅ Answer: (b) 9**

Put n = 0 into the rule: f(1) = 2f(0) + 7 = 2(1) + 7 = **9**.
Next would be f(2) = 2(9) + 7 = 25 — always use the value you just found.

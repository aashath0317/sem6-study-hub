## Multimedia என்பதன் பொருள்

:::key வரையறை
**Multimedia** என்பது digital வடிவில் உள்ள text, images, graphics, sound, animation, video ஆகியவற்றைச் சேர்த்து computer அல்லது வேறு electronic device மூலம் தகவல் தருவது. “Multi” என்றால் பல. “Media” என்றால் தகவலைப் பகிரும் வழிகள்.
:::

ஒரு **multimedia asset** என்பது தனியான உள்ளடக்கப் பொருள்: photograph, sound recording, text பகுதி அல்லது animation. ஒரு நோக்கத்துக்காக இவற்றை இணைப்பது **multimedia project**. அந்த project-ஐப் பயனாளர் பயன்படுத்தும் வகையில் தொகுத்த software அல்லது presentation தான் **multimedia title**. இதை download, website அல்லது DVD போன்ற storage வழியாக வழங்கலாம்.

இந்தப் பாடம் desktop computers, phones, ubiquitous computing சூழல்கள் பற்றிப் பேசுகிறது. Graphic design, web design, animation, audio production, video production, project management ஆகியவை இதனுடன் தொடர்புள்ள வேலைகள். Developer-க்கு technical திறனுடன் செய்தியும் audience-உம் பற்றிய புரிதல் வேண்டும்.

| Element | என்ன உதவி செய்கிறது | இலங்கை எடுத்துக்காட்டு |
|---|---|---|
| Text | பெயர்கள், வழிமுறைகள், தகவல்கள், கண்ணால் காட்ட முடியாத கருத்துகள் | Railway ticket kiosk-இல் தமிழ் வழிமுறைகள் |
| Still image | நிஜ உலகின் ஒரு காட்சியைப் பதிவு செய்கிறது | Sigiriya photograph |
| Graphics | திட்டமிட்டு உருவாக்கிய visual தகவல் | Bus-route diagram |
| Sound | பேச்சு, இசை, effects | சிங்களத்தில் சொல்லப்படும் வழிகாட்டல் |
| Animation | காலத்துடன் திட்டமிட்டு மாறும் காட்சி | Water pump இயங்கும் விதத்தைக் காட்டும் diagram |
| Video | நகரும் காட்சிப் பதிவு; பெரும்பாலும் audio-வும் இருக்கும் | தேநீர் தயாரிக்கும் demonstration |

**Virtual reality** ஒருவரை simulated சூழலில் மூழ்கியிருப்பது போல உணரச் செய்கிறது. **Augmented reality** நிஜ உலகக் காட்சிக்கு மேலாக digital தகவலைச் சேர்க்கிறது. Multimedia பார்வை, கேட்டல் ஆகிய உணர்வுகளையும், பொருத்தமான hardware இருந்தால் touch அல்லது haptic feedback-ஐயும் பயன்படுத்தலாம். எல்லா multimedia-விலும் இந்த மூன்றும் இருக்க வேண்டியதில்லை.

:::example பயனுள்ள சேர்க்கை
ஒரு திண்மத்தின் அமைப்பைப் பற்றிய lesson-இல் definition, labels உள்ள diagram, சுழலும் 3D model, voice explanation இருக்கலாம். ஒவ்வொரு element-உம் அதே கருத்தைப் புரிய உதவ வேண்டும். தொடர்பில்லாத இசை அல்லது animation கவனத்தைச் சிதறடிக்கலாம்.
:::

## Interactive media, hypertext, hypermedia

**Interactive multimedia**-வில் எந்த உள்ளடக்கம் வர வேண்டும், எப்போது தொடங்க வேண்டும், நிற்க வேண்டும், மாற வேண்டும் என்பதை user கட்டுப்படுத்தலாம். User செய்யும் செயல் அனுபவத்தை மாற்றுகிறது. **Non-interactive multimedia**-வில் உள்ளடக்கத்தின் ஓட்டத்தைக் கட்டுப்படுத்தாமல் ஏற்கெனவே முடிவுசெய்த வரிசையை audience பின்பற்றுகிறது.

| வகை | முக்கிய அம்சம் | எடுத்துக்காட்டு |
|---|---|---|
| Non-interactive | முடிவுசெய்த presentation வரிசை | Cinema screening |
| Interactive | User input அனுபவத்தை மாற்றும் | Lesson-ஐத் தேர்ந்தெடுக்கக்கூடிய learning application |
| Hypertext | Text-இல் மற்ற தகவலுக்கான links | ஒரு term-ஐ click செய்தால் அதன் definition வருவது |
| Hypermedia | வெவ்வேறு media வகைகள் links மூலம் இணையும் | Photographs, audio, video-வுடன் இணைந்த museum map |

Hypertext-ஐ ஒரே நேர்கோட்டு வரிசையில் மட்டும் படிக்க வேண்டியதில்லை. Text-க்கு அப்பாலும் linked structure-ஐ விரிவாக்குவது hypermedia. Interactivity இருக்கிறதா என்பதும் media வகைகள் எத்தனை என்பதும் வெவ்வேறு கேள்விகள். Recorded video-வில் பல media elements இருக்கலாம்; அதன் presentation non-interactive ஆகவும் இருக்கலாம்.

:::warn Source-இன் சொற்கள்
Section 1.2-இல் multimedia என்பது “at least one” information type-ஐ interactive-ஆகப் பயன்படுத்துவது என உள்ளது. இதை section 1.1-இன் combination definition, section 1.3-இன் interactive/non-interactive வேறுபாடு ஆகியவற்றுடன் சேர்த்துப் படிக்கவும். Interactivity ஒரு application-இன் பண்பு; எல்லா multimedia presentation-க்கும் அது கட்டாயமில்லை.
:::

## Devices மற்றும் multimedia system

பாடத்தின் “multimedia elements” பகுதி system இயங்கத் தேவையான equipment பற்றியும் கூறுகிறது. Exam answer-இல் **content elements** மற்றும் **hardware/software components** ஆகியவற்றைத் தனித்தனியாகத் தெளிவுபடுத்தவும்.

| Component | வேலை | எடுத்துக்காட்டு |
|---|---|---|
| Processing device | Digital data-ஐ encode, decode, transform செய்கிறது | Computer அல்லது server |
| Input device | User-இன் தெரிவுகளைப் பெறுகிறது | Keyboard, mouse, joystick, touchscreen |
| Output device | உணர்வுகளுக்குத் தகவலை வழங்குகிறது | Screen, speaker, haptic device |
| Capturing device | நிஜ உலகிலிருந்து assets பெறுகிறது | Camera அல்லது microphone |
| Storage device | Digital assets-ஐ வைத்திருக்கும் அல்லது வழங்கும் | Hard disk அல்லது DVD |
| Software and utilities | Assets-ஐ உருவாக்கும், இணைக்கும் அல்லது இயக்கும் | Image editor, authoring program, media player |

Touchscreen input device-ஆகவும் output device-ஆகவும் இருக்கலாம். Camera என்பது capture செய்வதற்கான input source. ஒரே physical device ஒன்றுக்கு மேற்பட்ட வேலைகளைச் செய்யலாம்.

:::flow Capture-இலிருந்து audience வரை
Camera அல்லது microphone asset-ஐப் பதிவு செய்கிறது
Computer அதை process மற்றும் encode செய்கிறது
Storage asset-ஐ வைத்திருக்கிறது
Network அல்லது storage medium அதை வழங்குகிறது
Application decode செய்து காட்டுகிறது
User input device மூலம் தொடர்புகொள்கிறார்
:::

**Connecting devices** equipment அல்லது interfaces-ஐ இணைக்கின்றன. உதாரணமாக microphone-ஐ computer-உடன் இணைக்கும் USB connection. **Communication devices** systems இடையே data அனுப்புகின்றன. உதாரணமாக network adapter, router, modem. உள்ளூர் device-ஐ இணைப்பதும் network வழியாகத் தொடர்புகொள்வதும் தொடர்புள்ள ஆனால் வேறுபட்ட வேலைகள்.

## Assets வகைப்படுத்தல்: உருவான விதமும் காலமும்

PDF இரண்டு தனித்தனி classification dimensions பயன்படுத்துகிறது. முதலில் **தகவல் எங்கிருந்து வந்தது** என்று கேளுங்கள். அடுத்து **அதன் பொருள் காலத்துடன் தொடர்புடையதா** என்று கேளுங்கள்.

- **Captured media:** நிஜ உலகிலிருந்து பெறப்பட்டது. Photographs, recorded video, recorded sound எடுத்துக்காட்டுகள்.
- **Synthesized media:** Computer உருவாக்கியது. Text, designed graphics, computer animation எடுத்துக்காட்டுகள்.
- **Discrete media:** கட்டாயமான time dimension இல்லாமல் இடத்தில் அமைந்தது. Static, non-time-based, non-temporal, space-based என்றும் சொல்வார்கள்.
- **Continuous media:** காலத்துடன் மாறும் அல்லது விரியும். Dynamic, time-based, temporal என்றும் சொல்வார்கள்.

## Multimedia ஏன் பயனுள்ளது?

PDF ஆறு system properties அல்லது நன்மைகளைக் கொடுக்கிறது. ஒவ்வொன்றும் user-இன் வேலைக்கு எப்படி உதவுகிறது என்று விளக்கவும்.

1. **Ease of use:** தெளிவான application முயற்சியைக் குறைத்து செயல்திறனை உயர்த்தும்; training நேரத்தையும் குறைக்கும்.
2. **Intuitive interface:** Control-இன் தோற்றமே அதன் வேலையை உணர்த்தும். House icon home-க்குத் திரும்புவதைக் குறிக்கும். தெரியாத user-க்கு தெளிவான label-உம் தேவை.
3. **Immersive experience:** மற்ற கவனச்சிதறல்கள் குறைந்து user application-இல் கவனம் செலுத்துவார். இது கவனத்தையும் பயனுள்ள செயலையும் ஆதரிக்கலாம்.
4. **Self-paced interaction and retention:** Learner தனக்கேற்ற வேகத்தில் pause, repeat, next செய்யலாம். மீண்டும் பார்ப்பது நினைவில் வைத்திருக்க உதவும்.
5. **Better understanding:** ஒன்றுக்கொன்று உதவும் words, pictures, animation, narration மூலம் text மட்டும் விளக்கக் கடினமான தொடர்புகளைப் புரியவைக்கலாம்.
6. **Cost effectiveness:** தெளிவான digital செய்தி பலரைச் சென்றடையலாம்; அடுத்த version-க்கு மாற்றுவது எளிதாகலாம். ஆரம்ப production செலவு அதிகமாக இருந்தாலும் இது ஒரு சாத்தியமான நன்மை.

:::example கல்வி, பொழுதுபோக்கு, பொதுச் சேவைகள்
O/L science lesson-இல் animation-ஐ மீண்டும் பார்த்துக் கேள்விகளுக்குப் பதில் சொல்லலாம். Game graphics, sound, user control-ஐ இணைக்கிறது. Tourism kiosk language choices, maps, narrated information தருகிறது. Business training, sales-க்கு product demonstrations பயன்படுத்துகிறது. Government service ஒரு form-ஐத் தெளிவான படிகளிலும் voice guidance-உடனும் விளக்கலாம்.

## தகவலை ஒழுங்குபடுத்துதல்

Screens அல்லது information units எப்படித் தொடர்புபடுகின்றன என்பதை content structure காட்டுகிறது. நோக்கத்துக்கும் audience-க்கும் ஏற்ற material-ஐச் சேகரித்து, பொருளுள்ள பகுதிகளாகப் பிரித்து, அவற்றை எளிதாகக் கண்டுபிடிக்க உதவும் structure-ஐத் தேர்ந்தெடுக்கவும்.

| Structure | Navigation விதி | எடுத்துக்காட்டும் காரணமும் |
|---|---|---|
| Linear | ஒரு item-க்கு அடுத்து மற்றது என்ற வரிசை | படிகளின் வரிசை முக்கியமான safety demonstration |
| Hierarchical | Tree-இன் branches வழியாகச் செல்லுதல் | Website: home → subjects → lessons |
| Nonlinear | முன்கூட்டியே முடிவுசெய்த ஒரே வழியின்றி links வழியாகச் செல்லுதல் | Cross-references உள்ள encyclopedia |
| Composite | Free navigation-உம் கட்டாய வரிசையும் இணைதல் | Lesson-ஐத் தேர்ந்து, அதன் demonstration வரிசையைப் பின்பற்றுதல் |

## Multimedia system-இன் மூன்று layers

Figure 1.4-ஐ physical support-இலிருந்து user application வரை மேல்நோக்கிப் படிக்கலாம். தொடர்புள்ள elements சரியான நேரத்தில் நடக்க synchronisation முழு structure-ஐயும் இணைக்கிறது.

:::grid
**Application layer**

Tools, applications, documents, user interfaces, programming abstractions, development methods. இந்த layer project-ஐ உருவாக்கவும் வழங்கவும் உதவுகிறது.
+++
**System layer**

Operating systems, database systems, communication systems. பொதுவான computing, networking services-ஐ வழங்குகிறது.
+++
**Device layer**

Storage, networking, compression, sound, images, graphics, video, animation processing. அடிப்படை செயல்முறைகளையும் physical-device support-ஐயும் தருகிறது.
:::

## Development tools மற்றும் new media

Multimedia system தகவலை உருவாக்கும், represent செய்யும், store செய்யும், transmit செய்யும், search, retrieve, deliver செய்யும். செய்ய வேண்டிய operation-க்கும் asset-க்கும் ஏற்ற tool-ஐத் தேர்ந்தெடுக்கவும்.

| Tool category | முக்கிய வேலை |
|---|---|
| Music sequencing and notation | Musical events, scores ஒழுங்குபடுத்துதல் |
| Digital audio editing and synthesis | Sound record, trim, mix அல்லது generate செய்தல் |
| Graphics and image editing | Graphics வரைதல், photographs process செய்தல் |
| Video editing | Moving-picture clips, audio தேர்ந்து ஒழுங்குபடுத்துதல் |
| Animation | Object properties காலத்துடன் மாறுமாறு உருவாக்குதல் |
| Multimedia authoring | Assets, navigation, timing, user interaction இணைத்தல் |

**New media** என்பது computer அடிப்படையிலான digital வடிவங்கள். Computation, interaction ஆகியவற்றுக்கான வாய்ப்புகள் இருக்கும். PDF blogs, social networks, digital games, virtual reality, online newspapers ஆகியவற்றை எடுத்துக்காட்டுகிறது.

| Traditional mass media model | New-media model |
|---|---|
| பெரும்பாலும் ஒரே producer-இலிருந்து பல receivers | பலர் உருவாக்கவும் பெறவும் முடியும் |
| பெரும்பாலும் ஒருவழி distribution | Feedback, interaction content-ஐ மாற்றலாம் |
| எடுத்துக்காட்டுகள்: broadcast radio, television, printed newspaper | எடுத்துக்காட்டுகள்: blogs, social networks, interactive digital experiences |

Figure 1.5 முதல் model-இல் ஒரு மைய source-இலிருந்து வெளியே distribution-ஐயும், இரண்டாவதில் இணைந்த participants network-ஐயும் காட்டுகிறது. Passive Web 1.0 பயன்பாட்டிலிருந்து Web 2.0 participation-க்கு ஏற்பட்ட மாற்றத்தைப் பாடம் குறிப்பிடுகிறது. இது communication models ஒப்பீடு. ஒவ்வொரு online page-உம் interactive என்றோ broadcasting மறைந்துவிட்டது என்றோ பொருளில்லை.

## சவால்களும் மதிப்பீடும்

Multimedia development-க்கு அதிக செலவு, சிரமம், நேரம் தேவைப்படலாம். Continuous assets-க்கு அதிக storage, transmission bandwidth தேவை. Timing constraints முக்கியம்: தாமதமான frames, playback தடைகள், speech synchronisation இல்லாமை quality-ஐக் குறைக்கும். Audio, images, video-ஐத் தானாக analyse, index, organise செய்வது text search-ஐவிடக் கடினம். பொருத்தமான algorithms, hardware, பல துறைகளின் அறிவு தேவை.

PDF **இரண்டு evaluation perspectives** தருகிறது. Title இயங்குகிறது என்பதால் மட்டும் அது பயனுள்ளது என்று முடிவுசெய்ய முடியாது.

| User perspective | பார்க்க வேண்டியது |
|---|---|
| Subject and content | எனது தேவைக்குப் பொருத்தமா? |
| Platform | எனது hardware, software-இல் இயங்குமா? |
| Usability | புரிந்துகொண்டு பயன்படுத்த முடியுமா? |
| Cost | செலவு ஏற்றதா? |

| Developer perspective | பார்க்க வேண்டியது |
|---|---|
| Content | Subject, materials பொருத்தமாகவும் சரியாகவும் உள்ளனவா? |
| Performance | Application திறமையாக இயங்கி content flow நன்றாக உள்ளதா? |
| Delivery | Distribution medium பொருத்தமா? |
| Interface | User, purpose-க்கு interface பொருந்துகிறதா? |

:::exam Ready-to-write answer
“Multimedia combines digital text, graphics, images, sound, animation and video. An interactive title lets the user control what is presented and when. Its advantages include self-paced learning and clearer explanation, while its challenges include storage, bandwidth, synchronisation and production cost. For example, a science lesson can combine a labelled diagram, narration and a replayable animation.”

## PDF-இன் ஆறு review questions: முழுப் பதில்கள்

### 1. Multimedia என்றால் என்ன? Mass media-விலிருந்து எப்படி வேறுபடுகிறது? New media-வின் முக்கிய அம்சங்கள் என்ன?

Multimedia பல digital media elements-ஐ electronic presentation-இல் இணைக்கிறது. Mass media அதிக audience-க்கான communication-ஐக் குறிக்கிறது; பொதுவாக one-to-many model. இவை வெவ்வேறு dimensions: television programme multimedia-வாகவும் mass media-வாகவும் இருக்கலாம். New media computer-based; computation, interaction, feedback, many-to-many participation தருகின்றன. Social learning forum-இல் students material-ஐப் பயன்படுத்தவும் explanations சேர்க்கவும் முடியும்.

### 2. மேம்பட்ட multimedia platform-இன் சவால்கள் என்ன?

பெரிய assets-ஐ store செய்து, போதிய வேகத்தில் transmit செய்து, playback timing-ஐப் பின்பற்றி, media-ஐ synchronise செய்து, வெவ்வேறு formats-ஐ process செய்ய வேண்டும். Image, audio, video content-ஐ search, index செய்வது கடினம். திறமையான algorithms, hardware, specialist skills, நேரம், பணம் தேவை. High-resolution lesson video குறைந்த connection-இல் சரியாக இயங்க compression, பொருத்தமான delivery strategy தேவைப்படலாம்.

### 3. கல்வியிலும் பொழுதுபோக்கிலும் உள்ள பயன்பாடுகளை விளக்கவும்.

கல்வியில் narration உள்ள demonstrations, animations செயல்முறைகளை விளக்கும். Interactive exercises feedback தரும். Replay self-paced learning-க்கு உதவும். பொழுதுபோக்கில் films video, sound-ஐ இணைக்கும்; games player input-க்கு பதிலளிக்கும்; virtual experiences audience-ஐ மூழ்கடிக்கும். இலங்கை history lesson site map-ஐ photographs, voice explanations-உடன் இணைக்கலாம். Game animated characters, sound effects, choices-ஐ இணைக்கலாம்.

### 4. Multimedia-வின் வெவ்வேறு categories என்ன?

Application interactive அல்லது non-interactive ஆகலாம். Assets captured அல்லது synthesized; discrete அல்லது continuous ஆகலாம். Information linear, hierarchical, nonlinear அல்லது composite structure-இல் அமையலாம். எந்த classification dimension பற்றி எழுதுகிறீர்கள் என்று கூறி examples தரவும். இவை ஒன்றைத் தேர்ந்தால் மற்றது இருக்க முடியாத ஒரே பட்டியல் அல்ல.

### 5. Connecting, storage, input/output, communication devices விளக்கவும்.

Connecting devices/interfaces equipment-ஐ இணைக்கும்; microphone-க்கான USB connection எடுத்துக்காட்டு. Storage devices assets-ஐ வைத்திருக்கும்; hard disk, DVD எடுத்துக்காட்டுகள். Input devices user actions-ஐப் பெறும்; keyboard, touchscreen எடுத்துக்காட்டுகள். Output devices content-ஐ வழங்கும்; screen, speaker, haptic unit எடுத்துக்காட்டுகள். Network adapter, router போன்ற communication devices systems இடையே data பகிரும். ஒரே device பல வேலைகளைச் செய்யலாம்.

### 6. Multimedia contents classification விளக்கவும்.

Origin-by-time table பயன்படுத்தவும். Photograph captured discrete. Recorded speech, recorded video captured continuous. Typed text, designed graphic synthesized discrete. Computer animation synthesized continuous. “Static” என்பது இயல்பாக time-based இல்லை என்பதே; file-ஐ edit செய்யவே முடியாது என்பதல்ல. “Dynamic” என்பது asset காலத்துடன் விரிகிறது என்பதே.

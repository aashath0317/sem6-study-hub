## Sound மற்றும் digital representation

Audio **symbolic sounds**, **speech**, **music** மூலம் தகவல் தருகிறது. விளக்கத்தைச் சொல்லலாம், warning தரலாம், கவனத்தை ஈர்க்கலாம், mood அமைக்கலாம். Message-க்கு உதவும் sound தேருங்கள். Tamil spoken instruction demonstration புரிய உதவும்; பொருத்தமில்லாத loud music instruction-ஐ மறைக்கலாம்.

அதிரும் பொருளிலிருந்து sound தொடங்குகிறது. **Source** vibration தரும்; **medium** அதை எடுத்துச் செல்லும்; **detector** பெறும். Loudspeaker காற்றை நகர்த்துகிறது; pressure changes காதை அடைகின்றன. Microphone variation-ஐ electrical signal-ஆக மாற்றுகிறது. Continuous waveform analogue ஆகும். Computer-க்கு discrete numerical data தேவை.

:::key Sampling மற்றும் quantization
**Sampling** waveform-ஐ discrete time intervals-இல் அளக்கும். **Sampling rate** second-க்கு எத்தனை samples என்பதாகும். **Quantization** அளந்த amplitude-ஐக் கிடைக்கும் discrete level-க்கு மாற்றும். **Bit depth** எத்தனை levels கிடைக்கும் என நிர்ணயிக்கும்.
:::

:::flow Figure 13.1-இன் மறுவரைவு
Microphone → analogue signal
ADC → sampling மற்றும் quantization
DSP → processing, filtering அல்லது compression
Storage அல்லது transmission → encoded data
DSP → decoding மற்றும் playback processing
DAC → analogue signal → speaker
:::

**ADC** analogue input-ஐ digital samples-ஆக மாற்றும். **DAC** samples-ஐ analogue output-ஆக மாற்றும். **DSP** filtering, effects, compression/decompression போன்ற digital signal processing செய்யும். Capturing incoming audio-ஐப் பெறுகிறது; recording அதைக் கூடுதலாக save செய்கிறது. Live processing நிரந்தரமாக record செய்யாமலும் capture செய்யலாம்.

## Attributes: physical மற்றும் digital அளவுகளைப் பிரித்துப் புரியுங்கள்

| Attribute | பொருள் |
|---|---|
| Waveform frequency | Physical oscillation cycles/second; Hz |
| Sampling rate | Numerical measurements/second; samples/s அல்லது Hz |
| Period | Periodic cycle-க்கு நேரம்; P = 1/f |
| Bit depth அல்லது sound resolution | Bits/sample; அதிக bits finer amplitude steps தரும் |
| Channels | தனித்த streams; mono ஒன்று, stereo இரண்டு |
| Amplitude | Signal variation-இன் அளவு; digital-இல் sample values |
| Pitch | கேட்பவருக்கு high/low எனத் தோன்றுவது; முக்கியமாக frequency தொடர்புடையது |
| Loudness | உணரப்படும் sound strength; intensity மற்றும் perception தொடர்புடையது |
| Bandwidth | எடுத்துச் செல்லப்படும் அல்லது தக்கவைக்கப்படும் frequency range |
| Dynamic range | உயர்ந்த மற்றும் தாழ்ந்த levels இடையிலான வேறுபாடு |

PDF infrasonic **0–20 Hz**, பொதுவான human hearing **20 Hz–20 kHz**, ultrasound **20 kHz–1 GHz**, hypersound **1 GHz–10 THz** என்கிறது. Hearing limits மாறும். இது பாடத்தின் classification ranges; எல்லாரும் முழு range கேட்பார்கள் என்ற உறுதி அல்ல.

**Intensity** power/area; unit **W/m²**. பாடம் **10^-12 W/m²**-ஐ hearing reference என்றும் **1 W/m²**-ஐ threshold-of-feeling example என்றும் பயன்படுத்துகிறது. Relative intensity formula **dB = 10 log10(I₂/I₁)**. Orchestra **30 dB**-இலிருந்து **130 dB** வரை சென்றால் dynamic range **130 − 30 = 100 dB**.

:::warn Source corrections மற்றும் limits
“Frequency” கீழுள்ள முதல் வரையறை உண்மையில் **sampling rate**-ஐக் கூறுகிறது; waveform frequency அல்ல. Sampling rate அதிகமென்றால் மட்டும் தெளிவான audio உறுதி இல்லை. Capture quality, source bandwidth, noise, processing-உம் முக்கியம். Stereo இரண்டு channels மற்றும் spatial cues தரலாம்; ஒரே clear voice-க்கு mono பொருத்தமாகலாம். Source normalisation suggestion **80%–90%** ஒரு teaching example; எல்லா delivery-க்கும் universal loudness standard அல்ல.
:::

## Sampling rate மற்றும் Nyquist: solved examples

:::formula
பாடத்தின் reconstruction condition: sampling rate fₛ > 2 × highest retained frequency fₘₐₓ
Nyquist frequency = fₛ ÷ 2
ஒரு channel-இன் sample count = fₛ × time
Sampling interval = 1 ÷ fₛ seconds
:::

Source highest frequency-இன் இருமடங்கை **விட அதிகம்** என்கிறது. Ideal theoretical boundary-இல் மற்ற assumptions முக்கியம். நடைமுறையில் anti-alias filter-க்கு transition band விடுங்கள். Sampling rate குறைக்கும்முன் புதிய limit-ஐ மீறும் frequency content அகற்றுங்கள்; இல்லையெனில் aliasing தவறான low frequencies-ஆகத் தோன்றலாம்.

:::example மூன்று Nyquist examples
**A:** **8 kHz** வரை retain செய்ய வேண்டும். Formula → fₛ > 2fₘₐₓ. Substitution → **fₛ > 2 × 8 = 16 kHz**. தேர்ந்த **22.05 kHz** rate இந்த condition-ஐப் பூர்த்தி செய்கிறது.

**B:** **44.1 kHz**-இல் Nyquist frequency = **44.1 ÷ 2 = 22.05 kHz**. பாடத்தின் strict wording-இன்படி boundary-க்கு கீழே retain செய்யுங்கள்.

**C:** **20 kHz** வரை retain செய்ய வேண்டும். Requirement → **fₛ > 2 × 20 = 40 kHz**. தேர்ந்த **48 kHz** பொருந்தும்; **32 kHz** பொருந்தாது.
:::

:::example மூன்று sample-count examples
**A:** **8,000 samples/s**, **3 s**. N = fₛt = **8,000 × 3 = 24,000 samples/channel**.

**B:** **44,100 samples/s**, **60 s**. N = **44,100 × 60 = 2,646,000 samples/channel**.

**C:** **48,000 samples/s**, **2 s**. N = **48,000 × 2 = 96,000 samples/channel**. Interval = **1/48,000 s ≈ 20.833 microseconds**.
:::

Source sampling-rate table பழைய பயன்பாடுகளைக் காட்டுகிறது: **8,000 Hz** telephony/UNIX, **11,000 Hz** quarter-CD-era Macintosh, **16,000 Hz** G.722, **18,900 Hz** CD-ROM XA, **22,000 Hz** half-CD-era Macintosh, **32,000 Hz** HDTV/long-play DAT, **37,800 Hz** CD XA, **44,056 Hz** professional audio, **44,100 Hz** CD, **48,000 Hz** DAT. Quarter/half CD labels rounded source values; exact CD fractions அல்ல. Calculation-இல் தெளிவாகக் கொடுத்த rate பயன்படுத்துங்கள்.

## Bit depth, channels மற்றும் raw capacity

:::formula
Quantization levels = 2^b; b = bits/sample
Audio bytes = C × S × T × B
C = channels; S = sampling rate in Hz; T = seconds; B = bits/sample ÷ 8
PCM bit rate = C × S × bits/sample
Decimal MB = bytes ÷ 1,000,000
:::

இது **uncompressed PCM payload** estimate. Headers, metadata சேரவில்லை. Compressed format-க்கு அதன் encoded bit rate பயன்படுத்தலாம். Bits/bytes-ஐ வேறுபடுத்துங்கள். மற்றவை மாறாமல் duration, channels, bit depth அல்லது sampling rate இருமடங்கானால் raw capacity-உம் இருமடங்காகும்.

:::example மூன்று bit-depth examples
**A:** **8-bit** audio-க்கு **2^8 = 256 levels**, **8/8 = 1 byte/sample**.

**B:** **16-bit** audio-க்கு **2^16 = 65,536 levels**, **16/8 = 2 bytes/sample**.

**C:** **24-bit** audio-க்கு **2^24 = 16,777,216 levels**, **24/8 = 3 bytes/sample**. இந்த worked depth கூடுதல் example. PDF **8-bit, 16-bit, 32-bit** குறிப்பிடுகிறது.
:::

:::example Activity 13.1 உட்பட மூன்று size examples
**A, PDF example:** **1 minute**, **44.1 kHz**, **16-bit**, stereo.
Formula → C × S × T × B. Substitution → **2 × 44,100 × 60 × 2**.
Working → **10,584,000 bytes**. Answer → **10.584 MB ≈ 10.6 MB**. PDF போல decimal MB.

**B, Activity 13.1:** CD-rate, **2-minute**, **16-bit mono** capacity கணக்கிடவும்.
**S = 44,100 Hz**, **T = 2×60 = 120 s**, **C = 1**, **B = 16/8 = 2**.
Working → **1 × 44,100 × 120 × 2 = 10,584,000 bytes = 10.584 MB**. “CD quality” sampling rate தருகிறது; கேள்வி mono எனக் கூறுகிறது.

**C:** **10 s**, **48,000 Hz**, **24-bit**, stereo.
Working → **2 × 48,000 × 10 × 3 = 2,880,000 bytes = 2.88 MB**.
:::

:::example மூன்று channel மற்றும் bit-rate examples
**A:** **8,000 Hz**, **8-bit mono**. Rate = **1 × 8,000 × 8 = 64,000 bit/s = 64 kb/s**.

**B:** **44,100 Hz**, **16-bit stereo**. Rate = **2 × 44,100 × 16 = 1,411,200 bit/s = 1.4112 Mb/s**.

**C:** **48,000 Hz**, **16-bit**, **5 s**. Mono size = **1 × 48,000 × 5 × 2 = 480,000 bytes**. Stereo size = **2 × 48,000 × 5 × 2 = 960,000 bytes**. Channel ratio = **960,000/480,000 = 2**.
:::

## Filtering, encoding மற்றும் Activity 13.3

**High-pass filter** உயர்ந்த frequencies-ஐ வைத்து rumble போன்ற low-frequency material-ஐக் குறைக்கும். **Low-pass filter** தாழ்ந்த frequencies-ஐ வைத்து உயர்ந்தவற்றைக் குறைக்கும். **Amplitude response** ஒவ்வொரு frequency-இன் gain-ஐக் காட்டும். Time-domain அல்லது frequency-domain processing மூலம் filters செய்யலாம்.

:::warn Source limit
Filters attenuation மட்டும் செய்யும், boost செய்யாது என PDF கூறுகிறது. அது இங்குள்ள simple cleanup examples-க்கு மட்டும் பொருந்தும். எல்லா filters/EQ-க்கும் அல்ல. Equalization சில ranges cut அல்லது boost செய்யலாம். “Higher sampling rate → higher quality” என்பதும் simplification; fixed settings-இல் raw capacity அதிகரிக்கும் என்பது சரி.
:::

**Encoding** audio-ஐ storage/transmission-க்கு represent செய்கிறது. Compression data குறைக்கும். **Lossless** original digital data மீண்டும் தரும். **Lossy** சில information-ஐ இழக்கும். Fidelity, storage, bandwidth, platform, editing தேவைகளுக்கேற்ப தேருங்கள்.

**Activity 13.3 கேள்வி:** lossy மற்றும் lossless audio formats பட்டியலிடவும்.

| Category | Model answer | முக்கிய வேறுபாடு |
|---|---|---|
| Lossy | MP3, AAC, Vorbis, Opus | சிறிய delivery copies சில தகவலை இழக்கும் |
| Lossless compression | FLAC, ALAC | Original numerical samples மீண்டும் கிடைக்கும் |
| பொதுவான uncompressed audio | PCM in WAV அல்லது AIFF | Uncompressed என்பதும் lossless compression என்பதும் ஒன்றல்ல |

ஒரு container பல encodings ஏற்கலாம். Extension மட்டும் பார்க்காமல் actual codec பாருங்கள்.

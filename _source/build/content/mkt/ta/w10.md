## தயாரிப்பு உத்தி

**தயாரிப்பு உத்தி**, தயாரிப்பின் மூலம் வணிகம் எதை அடைய விரும்புகிறது, எவ்வாறு அடையும் என்பதை விவரிக்கும் **உயர்மட்டத் திட்டமாகும்**. இது பதிலளிப்பவை:

- **யாருக்குச்** சேவை செய்யும் (இலக்குச் சந்தை)?
- **எவ்வாறு** அவர்களுக்குப் பயனளிக்கும்?
- தயாரிப்பின் **வாழ்க்கைச் சுழற்சி முழுவதற்குமான இலக்குகள்** என்ன?

இது தயாரிப்பை உருவாக்குவதற்கான **பாதைவரைபடம்**. தரம், NPD, பொதியிடல், வர்த்தகநாமமிடல், ஆராய்ச்சி மற்றும் அபிவிருத்தியை உள்ளடக்கி, உற்பத்திக்கு முன், உற்பத்தியின்போது, பின்னர் **வெற்றியை அளவிடுவதற்கான அடிப்படையாக** அமைகிறது.

:::key தயாரிப்பு என்றால் என்ன? (Kotler)
"**விருப்பம் அல்லது தேவையை நிறைவேற்றக்கூடிய, கவனம், பெறுதல், பயன்பாடு அல்லது நுகர்விற்காகச் சந்தைக்கு வழங்கக்கூடிய எதுவும்.**" பௌதிகப் பொருட்கள், **சேவைகள்** (காப்புறுதி, வங்கி, திரைப்படங்கள்), அனுபவங்கள், நிகழ்வுகள், நபர்கள், இடங்கள், சொத்துக்கள், அமைப்புகள், தகவல், கருத்துக்கள் இதில் அடங்கும்.
:::

## தயாரிப்பின் மூன்று நிலைகள்

| நிலை | பொருள் |

| **மையத் தயாரிப்பு** | வாடிக்கையாளர் உண்மையில் வாங்கும் **அடிப்படைப் பயன்** |
| **உண்மையான தயாரிப்பு** | குறிப்பிட்ட வழங்கலும் பண்புகளும் (சேவைகளில் பௌதிகப் பொருளாக இருக்க வேண்டியதில்லை): **வடிவமைப்பு, தரநிலை, வர்த்தகநாமப் பெயர், அம்சங்கள்**, பொதியிடல் |

3. **போட்டியாளர்கள் குறைந்த செலவில் அடிப்படைப் பயன்களை வழங்கலாம்** (கூடுதல் அம்சங்கள் நீக்கப்பட்ட தயாரிப்பு).

## தயாரிப்பு வகைப்பாடுகள்

### நீடித்தன்மை மற்றும் தொட்டுணரும்தன்மையின்படி

| வகை | பொருள் | சந்தைப்படுத்தல் விளைவு |
|---|---|---|
| **நீடிக்காத பொருட்கள்** | தொட்டுணரக்கூடியவை; **ஒன்று அல்லது சில பயன்பாடுகளில்** தீர்ந்துவிடும்; **அடிக்கடி** வாங்கப்படும் (ஷாம்பு) | **பல இடங்களில்** கிடைக்கச்செய்தல்; முயற்சியைத் தூண்டி விருப்பத்தை உருவாக்க **விளம்பரப்படுத்துதல்** |
| **நீடித்த பொருட்கள்** | தொட்டுணரக்கூடியவை; **நீண்டகாலம் நீடிக்கும்**; அரிதாக மாற்றீடு செய்யப்படும் (குளிர்சாதனப் பெட்டி) | அதிக **தனிப்பட்ட விற்பனையும் சேவையும்**, **விற்பனையாளர் உத்தரவாதங்கள்**, **அதிக இலாப வரம்புகள்** |
| **சேவைகள்** | விற்பனைக்கு வழங்கப்படும் செயற்பாடுகள், பயன்கள் அல்லது திருப்திகள் | கீழுள்ள **4 பண்புகளையும்** முகாமைத்துவம் செய்தல் |

**சேவைகளின் நான்கு பண்புகள்:**

- **தொட்டுணர முடியாதவை:** வாங்கும்முன் காணவோ சுவைக்கவோ உணரவோ கேட்கவோ நுகரவோ முடியாது
- **பிரிக்க முடியாதவை:** **ஒரே நேரத்தில் உற்பத்தி செய்யப்பட்டு நுகரப்படுகின்றன**
- **மாறுபடுபவை:** தரம் **யார், எப்போது, எங்கே** என்பதில் தங்கியுள்ளது
- **அழியக்கூடியவை:** **சேமிக்க முடியாது**

### வாங்கும் பழக்கங்களின்படி நுகர்வோர் பொருட்கள்

| வகை | பொருள் | எடுத்துக்காட்டுகள் |
|---|---|---|
| **வசதிப் பொருட்கள்** | **அடிக்கடி, உடனடியாக, குறைந்த முயற்சியுடன்** வாங்கப்படும் | சவர்க்காரம், பற்பசை, செய்தித்தாள்கள் |
| ↳ **அத்தியாவசிய** | **வழக்கமாக** வாங்கப்படும் | சவர்க்காரம் |
| ↳ **உந்துதல்** | **திட்டமிடாமல்** வாங்கப்படும்; பரவலாகக் காட்சிப்படுத்தப்படும் | **பணம் செலுத்துமிடத்தில் இனிப்புப் பட்டைகள்** |
| ↳ **அவசரம்** | **அவசரத் தேவையால்** வாங்கப்படும் | **புயல்மழையில் குடை** |
| **ஒப்பீட்டுக் கொள்வனவுப் பொருட்கள்** | பொருத்தம், தரம், விலை, பாணியை வாடிக்கையாளர்கள் **ஒப்பிடுகின்றனர்** | உடைகள், தளபாடங்கள் |
| **சிறப்புப் பொருட்கள்** | **தனித்துவப் பண்புகள் அல்லது வர்த்தகநாம அடையாளம்**: வாங்குபவர்கள் **சிறப்புக் கொள்வனவு முயற்சி** செய்கின்றனர் | குறிப்பாக நாடப்படும் கணினி வர்த்தகநாமம்/மாதிரி (எல்லாக் கணினிகளும் அல்ல), ஆடம்பர வர்த்தகநாமங்கள் |
| **தேடப்படாத பொருட்கள்** | நுகர்வோருக்கு **தெரியாதவை**, அல்லது தெரிந்தும் **பொதுவாக நினைக்கப்படாதவை** | அறிமுகமில்லாத சில புதிய தயாரிப்புகள்; செயலில் நாடப்படாத ஆயுள் காப்புறுதி |

## தயாரிப்புக் கலவையும் தயாரிப்பு வரிசை முடிவுகளும்

**தயாரிப்புக் கலவை** (தொகுப்பு): விற்பனையாளர் வழங்கும் **அனைத்துத் தயாரிப்பு வரிசைகளும் பொருட்களும்**.

| பரிமாணம் | பொருள் |
|---|---|
| **அகலம்** | **வெவ்வேறு தயாரிப்பு வரிசைகளின் எண்ணிக்கை** |
| **நீளம்** | அனைத்து வரிசைகளிலுமுள்ள **மொத்தப் பொருட்களின் எண்ணிக்கை** |
| **ஆழம்** | ஒவ்வொரு தயாரிப்பின் **மாறுவகைகளின் எண்ணிக்கை** |
| **ஒத்திசைவு** | இறுதிப் பயன்பாடு, உற்பத்தி, விநியோக வழிகளில் வரிசைகள் **எவ்வளவு நெருக்கமாகத் தொடர்புடையவை** |

{{tool:pmx}}

இந்தப் பரிமாணங்களைப் பயன்படுத்தி **வளரும் நான்கு வழிகள்**:

1. **அகலப்படுத்துதல்**: அதிக வாடிக்கையாளர்களுக்குச் சேவை செய்யப் புதிய வரிசைகளைச் சேர்த்தல்.
2. **நீளப்படுத்துதல்**: ஒவ்வொரு வரிசையிலும் அதிக பொருட்களைச் சேர்த்தல்.
3. **ஆழப்படுத்துதல்**: அதிக மாறுவகைகளைச் சேர்த்தல்.
4. **அதிக அல்லது குறைந்த ஒத்திசைவை** நாடுதல்: ஒரு துறையில் வலுவான நற்பெயர் அல்லது பல துறைகளில் இருப்பு.

### தயாரிப்பு வரிசை முடிவுகள்
**Kotler:** **ஒத்த செயல்பாட்டைச் செய்வதால்**, **ஒரே வாடிக்கையாளர் குழுக்களுக்கு விற்கப்படுவதால்**, **ஒரே விநியோக வழிகளில் செல்வதால்**, அல்லது **குறிப்பிட்ட விலை வரம்பிற்குள் இருப்பதால்** **நெருக்கமாகத் தொடர்புடைய** தயாரிப்புக் குழுவே **தயாரிப்பு வரிசையாகும்**.

| முடிவு | பொருள் |
|---|---|
| **தயாரிப்பு வரிசைப் பகுப்பாய்வு** | எதை **வளர்க்க, பேண, பலனறுக்க அல்லது விலக்க** வேண்டும் எனத் தீர்மானிக்க ஒவ்வொரு பொருளின் **விற்பனையையும் இலாபத்தையும் போட்டியாளர்களுக்கு எதிரான நிலைப்பாட்டையும்** அறிதல் |
| **வரிசை நீளம்** | உற்பத்தி மற்றும் சந்தைப்படுத்தல் திறன்கள், நிதி, நோக்கங்களில் தங்கியுள்ளது. **குறுகிய** வரிசைகளுள்ள நிறுவனங்கள் பொருட்களைச் **சேர்ப்பதன்** மூலம் இலாபமடையலாம்; நீண்ட வரிசைகளுள்ள முதிர்ந்த நிறுவனங்கள் **மெதுவாக விற்பனையாகுபவற்றை நீக்கி** இலாபமடையலாம் |
| **வரிசை நீட்டித்தல்** | **தற்போதைய வரம்பைத் தாண்டி** வரிசையை நீளப்படுத்துதல்: **கீழ்நோக்கி, மேல்நோக்கி அல்லது இருவழியாக** |
| **வரிசை நிரப்புதல்** | **தற்போதைய வரம்பிற்குள்** பொருட்களைச் சேர்த்தல். ஒவ்வொன்றும் **கவனிக்கத்தக்க வேறுபாட்டுடன்** ஒரு தேவையை நிறைவேற்ற வேண்டும் |
| **வரிசை நவீனமயமாக்கல்** | பாணிகள், அளவுகள், வடிவங்களை **காலமுறையில் புதுப்பித்தல்** (விரைவாக மாறும் சந்தைகளில் தொடர்ச்சியாக) |
| **வரிசை வெட்டுதல்** | **மோசமாகச் செயல்படும் பொருட்களை நீக்குதல்** |

## வர்த்தகநாமங்கள், அவற்றின் பொருள் மற்றும் வர்த்தகநாமப் பெறுமதி

:::key வரைவிலக்கணம் (AMA)
ஒரு விற்பனையாளரின் பொருட்கள் அல்லது சேவைகளை **அடையாளப்படுத்தி**, போட்டியாளர்களிடமிருந்து **வேறுபடுத்துவதற்கான பெயர், சொல், குறி, சின்னம் அல்லது வடிவமைப்பு, அல்லது அவற்றின் கலவையே வர்த்தகநாமமாகும்**.
:::

- **வர்த்தகநாமப் பெயர்**, **சொல் அல்லது எழுத்துப்** பகுதியாகும்.
- **வர்த்தக முத்திரை**, **சட்டச்** சொல்: சட்டம் பாதுகாக்கும் குறிகள்.
- வர்த்தகநாமம் நீடிக்கலாம்; ஆனால் **வர்த்தக முத்திரைப் பாதுகாப்பு தானாகவே என்றென்றும் நீடிப்பதில்லை**: பொருந்தும் பயன்பாடு, பராமரிப்பு, புதுப்பித்தல் தேவைகள் முக்கியம். எடுத்துக்காட்டாக, தேவையான ஆவணங்களுடன் அமெரிக்கப் பதிவுகளைப் புதுப்பிக்கலாம் ([USPTO](https://www.uspto.gov/trademarks/maintain/post-registration-faqs)).
- நோக்கம், செயலாற்றல், தரம், விலை பற்றிய **எதிர்பார்ப்புகளை** வர்த்தகநாமங்கள் உருவாக்குகின்றன; இதனால் **மதிப்புச் சேர்க்கவும் வேறுபடுத்தவும்** முடிகிறது.
- நிலையான அம்சங்கள், பயன்கள், சேவைகளை வழங்கும் விற்பனையாளரின் **உறுதிப்பாடே** வர்த்தகநாமமாகும். வலுவான வர்த்தகநாமம் எதிர்பார்க்கப்படும் தரத்தைக் குறிக்கலாம்; ஆனால் அந்த வாக்குறுதி தானாகவே சட்ட உத்தரவாதமல்ல.

:::

### வர்த்தகநாமப் பெறுமதி
வர்த்தகநாமங்கள் **சக்தியிலும் மதிப்பிலும்** வேறுபடுகின்றன. அவை **விழிப்புணர்வு → ஏற்றுக்கொள்ளும்தன்மை → விருப்பம் → விசுவாசம்** என நகர்கின்றன.

**Aaker இன் ஐந்து வாடிக்கையாளர் மனப்பாங்கு நிலைகள்** (கீழிருந்து மேலாக):

1. குறிப்பாக **விலைக்காக** வர்த்தகநாமங்களை மாற்றுகிறார்: **விசுவாசமில்லை**
2. **திருப்தியடைந்தவர்**: மாறக் காரணமில்லை
3. திருப்தியடைந்தவர்; **மாறினால் செலவுகள் ஏற்படும்**
4. **வர்த்தகநாமத்தை மதித்து** நண்பராகக் காண்கிறார்
5. வர்த்தகநாமத்திற்கு **முழு அர்ப்பணிப்புள்ளவர்**

**பல வாடிக்கையாளர்கள் 3, 4, 5 நிலைகளில் இருக்கும்போது வர்த்தகநாமப் பெறுமதி அதிகம்.** அது **பெயரறிதல், உணரப்படும் தரம், வலுவான மன மற்றும் உணர்வுத் தொடர்புகளிலும்**, **காப்புரிமைகள், வர்த்தக முத்திரைகள், விநியோக வழி உறவுகள்** போன்ற சொத்துக்களிலும் தங்கியுள்ளது.

### 1. வர்த்தகநாமமிடுவதா இல்லையா?
வர்த்தகநாமமிடலுக்குச் செலவாகும்; ஆனால் தருபவை:

- **சட்டப் பாதுகாப்பு** (வர்த்தக முத்திரை)
- போட்டியை எதிர்கொள்ள **விசுவாசமான, இலாபகரமான** வாடிக்கையாளர் தளம்
- சந்தையைப் **பிரிவாக்கும்** ஆற்றல்
- புதிய அறிமுகங்களை எளிதாக்கும் **நிறுவனப் பிம்பம்**

கையாள எளிதாகவும் தரத்தைக் குறிக்கவும் இருப்பதால் **விநியோகஸ்தர்கள்** வர்த்தகநாமங்களை விரும்புகின்றனர். **தரத்தை அடையாளம் காணவும் திறம்பட வாங்கவும் வாடிக்கையாளர்கள்** பயன்படுத்துகின்றனர்.

புதிய போட்டி அல்லது மாறும் விருப்பங்கள் வர்த்தகநாமத்தை **மறுநிலைப்படுத்தக்** கட்டாயப்படுத்தலாம்.

*எடுத்துக்காட்டு:* **7 Up**, **முதியோருக்கான** மென்மையான எலுமிச்சைப் பானமாகத் தொடங்கியது. பல மென்பானப் பயன்பாட்டாளர்கள் எப்போதும் கோலாவை விரும்பவில்லை என ஆராய்ச்சி காட்டியதால், 7 Up **"கோலா அல்லாதது"** என மறுநிலைப்படுத்தப்பட்டது: இளமையான, புத்துணர்ச்சியான, **கோலாக்களுக்கு மாற்றானது**.

## பொதியிடலும் அடையாளச்சீட்டிடலும்

சில சந்தைப்படுத்துநர்கள் பொதியிடலை **"ஐந்தாவது P"** என அழைக்கின்றனர்; பிறர் தயாரிப்பு உத்தியின் பகுதியாகக் கருதுகின்றனர்.

- **பொதியிடல்**, **கொள்கலனை** வடிவமைத்து உருவாக்குதல்; **மூன்று நிலைகள்** வரை இருக்கலாம்: **முதன்மை** (உடனடிக் கொள்கலன்), **இரண்டாம் நிலை** (வெளிப்பெட்டி), **அனுப்புகைப்** பொதியிடல்.
- **சுயசேவை, நுகர்வோர் செல்வநிலை, நிறுவனம் மற்றும் வர்த்தகநாமப் பிம்பம், புதுமை வாய்ப்புகள்** காரணமாகப் பொதியிடலின் முக்கியத்துவம் வளர்ந்தது. **வசதியையும் மேம்படுத்தல் மதிப்பையும்** தருகிறது.

**பொதியிடல் முடிவுகள்:**

1. **பொதியிடல் கருத்துருவை** வரையறுத்தல் (பொதி என்னவாக இருக்க வேண்டும்; என்ன செய்ய வேண்டும்).
2. விலை மற்றும் விளம்பரத்துடன் ஒத்திசையும் **அளவு, வடிவம், பொருட்கள், நிறம், உரை, வர்த்தகநாமத்தைத்** தீர்மானித்தல்.
3. **சோதித்தல்**:
   - **பொறியியல்**: வழக்கமான நிலைமைகளைத் தாங்குகிறதா?
   - **காட்சி**: வாசிக்கக்கூடியதா, ஒத்திசையும் நிறங்களா?
   - **விற்பனையாளர்**: கவர்ச்சியானதா, கையாள எளிதா?
   - **நுகர்வோர்**: சாதகமான பதிலா?
4. **சூழல் மற்றும் பாதுகாப்புக்** கவலைகளைக் கருத்திற்கொள்ளுதல்.

எளிய **சீட்டுகளிலிருந்து** பொதியின் பகுதியாக இருக்கும் விரிவான வரைகலை வரை **அடையாளச்சீட்டுகள்** அமைகின்றன. சிலவற்றில் வர்த்தகநாமம் மட்டும்; பிறவற்றில் அதிக தகவல்கள்; அவற்றில் சில **சட்டத்தால் தேவைப்படுபவை**.

:::exam
எதிர்பார்க்கப்படுபவை:

- **எடுத்துக்காட்டுடன் 3 தயாரிப்பு நிலைகள்**
- **நுகர்வோர் தயாரிப்புகளை வகைப்படுத்துதலும்** அவற்றின் சந்தைப்படுத்தல் விளைவுகளும்
- எடுத்துக்காட்டுடன் **தயாரிப்புக் கலவை** (அகலம், நீளம், ஆழம், ஒத்திசைவு)
- **வரிசை நீட்டித்தலும் வரிசை நிரப்புதலும்**
- **வர்த்தகநாமப் பெறுமதி** (Aaker இன் 5 நிலைகள்)
- **வர்த்தகநாமமிடல் முடிவுகள்**
- **வரிசை விரிவாக்கமும் வர்த்தகநாம விரிவாக்கமும்**
- **பொதியிடலும் அடையாளச்சீட்டிடலும்**
- செயற்பாடு: **இலங்கைக்கான நுண்ணறித் தொலைபேசி வர்த்தகநாமப் பெயரை முன்மொழிந்து**, நல்ல பெயரின் 5 பண்புகளின் அடிப்படையில் நியாயப்படுத்துதல்
:::

## வினாடிவினா 10: மாதிரி விடை

சந்தைப்படுத்தல் கோப்புறையில் உள்ள `Week 11/Quiz 10.docx` இலிருந்து.

:::exam வினாடிவினா 10
**வினா:** இலங்கையில் அறிமுகமாகும் புதிய நுண்ணறித் தொலைபேசிக்கு பயனுள்ள வர்த்தகநாமப் பெயரை முன்மொழிந்து, நல்ல பெயரின் பண்புகளை எந்தளவிற்கு பிரதிபலிக்கிறது என விவாதிக்கவும்.

**மாதிரி விடை உள்ளடக்குபவை:**

1. **தயாரிப்பின் பயன்களைக் குறிக்க வேண்டும்**
2. செயல் அல்லது நிறம் போன்ற **குணங்களைக் குறிக்க வேண்டும்**
3. **உச்சரிக்க, அறிய, நினைவில் கொள்ள எளிதாக இருக்க வேண்டும்**
4. **தனித்துவமாக இருக்க வேண்டும்**
5. பிற நாடுகளிலும் மொழிகளிலும் **மோசமான பொருளைக் கொண்டிருக்கக் கூடாது**
:::

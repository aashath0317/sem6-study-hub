## மரங்கள்

:::key வரையறை 1
- **சுற்று** என்பது **ஒரே முனையில் தொடங்கி முடியும் பாதை**.
- **மரம்** என்பது **எளிய சுற்றுகள் இல்லாத இணைந்த வரைபு**.
:::

**வரலாறும் பயன்பாடுகளும்:**

- **Arthur Cayley (1857)**, **வேதிச் சேர்மங்களை எண்ண** மரங்களைப் பயன்படுத்தினார்.
- **கணினி அறிவியல்:** **பட்டியலில் பொருட்களைக் கண்டறியும்** திறமையான படிமுறைகள்.
- செக்கர்ஸ், சதுரங்கம் போன்ற **விளையாட்டுகள்**: **வெற்றி உத்திகளைக்** கண்டறிதல்.
- **முடிவுகளின் தொடர்களை** மாதிரியாக்குதல்; எ.கா. வரிசைப்படுத்தல் படிமுறைகளின் சிக்கல்தன்மை.
- **குடும்ப மரங்கள்** (வம்சாவளி விளக்கப்படங்கள்): முனைகள் மக்கள்; விளிம்புகள் பெற்றோர்–பிள்ளை இணைப்புகள்.

:::key மரங்கள் எளிய வரைபுகள்
மரத்தில் **எளிய சுற்று இருக்க முடியாது**; எனவே **பல்விளிம்புகளோ வளையங்களோ இருக்க முடியாது**. **ஒவ்வொரு மரமும் எளிய வரைபு.**
:::

:::example எடுத்துக்காட்டு 12.1.1 — எவை மரங்கள்?
| வரைபு | மரமா? | காரணம் |
|---|---|---|
| G₁ | ✓ | இணைந்தது, எளிய சுற்றுகள் இல்லை |
| G₂ | ✓ | இணைந்தது, எளிய சுற்றுகள் இல்லை |
| G₃ | ✗ | e, b, a, d, e ஓர் **எளிய சுற்று** |
| G₄ | ✗ | **இணையவில்லை** |
:::

### காடுகள்
**எளிய சுற்றுகள் இல்லாத**, **இணைந்திருக்க வேண்டிய அவசியமில்லாத** வரைபு **காடு**. **ஒவ்வொரு இணைந்த கூறும் ஒரு மரம்.** (படம் 3: ஒரு வரைபு, மூன்று கூறுகள், மூன்று மரங்கள்.)

:::key தேற்றம் 1
**எந்த இரு முனைகளுக்கிடையிலும் தனித்துவமான எளிய பாதை இருந்தால் மட்டுமே**, திசையற்ற வரைபு மரமாகும்.
:::

:::tip விரைவான மரச் சோதனைகள்
n முனைகளுள்ள வரைபுக்கு இவற்றில் **ஏதாவது இரண்டு** பொருந்தினால் அது மரம்:

1. அது **இணைந்துள்ளது**.
2. அதில் **எளிய சுற்றுகள் இல்லை**.
3. துல்லியமாக **n − 1 விளிம்புகள்** உள்ளன.
:::

## வேருள்ள மரங்களும் சொற்களும்

:::key வரையறை 2
**ஒரு முனை வேராகக் குறிக்கப்பட்டு**, **ஒவ்வொரு விளிம்பும் வேரிலிருந்து வெளியே திசைப்படுத்தப்பட்டுள்ள** மரம் **வேருள்ள மரம்**.
:::

- **எந்த** முனையையும் வேராகத் தேர்ந்தெடுக்கலாம்; **வெவ்வேறு வேர்கள் வெவ்வேறு வேருள்ள மரங்களைத் தருகின்றன** (படம் 4: அதே T மரம் a-இலும் c-இலும் வேரூன்றியது).
- **வேரை மேலே** வரைந்து **அம்புகளைத் தவிர்க்கிறோம்**: வேரின் தேர்வு அவற்றின் திசைகளைத் தீர்மானிக்கிறது.

| சொல் | வரையறை |
|---|---|
| v-இன் **பெற்றோர்** | **u → v** திசை விளிம்புள்ள தனித்துவமான முனை u |
| u-இன் **பிள்ளை** | u என்பது v-இன் பெற்றோர் எனில் v, u-இன் பிள்ளை |
| **சகோதர முனைகள்** | **ஒரே பெற்றோருள்ள** முனைகள் |
| v-இன் **மூதாதைகள்** | **வேரிலிருந்து v வரையான** பாதையின் முனைகள்; **v-ஐ விலக்கி**, **வேரை உள்ளடக்கி** |
| v-இன் **வழித்தோன்றல்கள்** | **v-ஐ மூதாதையாகக்** கொண்ட முனைகள் |
| **இலை** | **பிள்ளைகள் இல்லாத** முனை |
| **உள்முனை** | **பிள்ளைகள் உள்ள** முனை. வேர் ஒரே முனையாக இருந்தாலன்றி உள்முனை (ஒரே முனை எனில் இலை) |
| a-இல் வேரூன்றிய **உட்மரம்** | a, அதன் அனைத்து வழித்தோன்றல்களும், **அம்முனைகளுக்கிடையிலான** விளிம்புகளும்; a-இலிருந்து அதன் பெற்றோருக்கான விளிம்பை விலக்கவும் |

{{tool:rt}}

:::example எடுத்துக்காட்டு 12.1.2 (படம் 5, வேர் a)
| கேள்வி | விடை |
|---|---|
| c-இன் பெற்றோர் | **b** |
| g-இன் பிள்ளைகள் | **h, i, j** |
| h-இன் சகோதர முனைகள் | **i, j** |
| e-இன் மூதாதைகள் | **c, b, a** |
| b-இன் வழித்தோன்றல்கள் | **c, d, e** |
| உள்முனைகள் | **a, b, c, g, h, j** |
| இலைகள் | **d, e, f, i, k, l, m** |
| g-இல் வேரூன்றிய உட்மரம் | g-க்கு h, i, j பிள்ளைகள்; h → k; j → l, m (படம் 6) |
:::

## வரிசைப்படுத்தப்பட்ட வேருள்ள மரங்களும் இரும மரங்களும்

| கருத்து | வரையறை |
|---|---|
| **வரிசைப்படுத்தப்பட்ட வேருள்ள மரம்** | **ஒவ்வொரு உள்முனையின் பிள்ளைகளும் வரிசைப்படுத்தப்பட்டு**, **இடமிருந்து வலமாக** வரையப்பட்ட வேருள்ள மரம் |
| **இரும மரம்** (வரிசைப்படுத்தப்பட்ட இரும மரம்) | ஒவ்வொரு முனைக்கும் **அதிகபட்சம் இரு பிள்ளைகள்**, இடது, வலது எனக் குறிக்கப்பட்டவை. இரண்டு இருந்தால் முதலாவது இடது பிள்ளை; இரண்டாவது வலது பிள்ளை |
| **இடது / வலது உட்மரம்** | ஒரு முனையின் **இடது / வலது பிள்ளையில்** வேரூன்றிய மரம் |

சில பயன்பாடுகளில் வேர் அல்லாத ஒவ்வொரு முனையும் **ஒரே பிள்ளையாக இருந்தாலும்**, இடது அல்லது வலது என அடையாளமிடப்படுகிறது.

:::example எடுத்துக்காட்டு 12.1.3 — படம் 7(a)
- **d-இன் இடது பிள்ளை f**, **வலது பிள்ளை g**.
- **c-இன் இடது உட்மரம்**, h-இல் வேரூன்றியது (h → j).
- **c-இன் வலது உட்மரம்**, i-இல் வேரூன்றியது (i → k, l; l → m).
:::

## இருமத் தேடல் மரங்கள் (BST)

**இலக்கு:** பொருட்கள் **முழுமையாக வரிசைப்படுத்தப்பட்டிருந்தால்**, பட்டியலில் திறம்படத் தேடுதல்.

:::key இருமத் தேடல் மரம்
பின்வரும் பண்புள்ள **இரும மரம்**:

- ஒவ்வொரு பிள்ளையும் **இடது அல்லது வலது** எனக் குறிக்கப்பட்டது
- **எந்த முனைக்கும் ஒன்றுக்கு மேற்பட்ட இடது அல்லது வலது பிள்ளை இல்லை**
- ஒவ்வொரு முனையும் **சாவியால்** (பொருட்களில் ஒன்று) அடையாளமிடப்பட்டது

**ஒவ்வொரு முனையின் சாவியும் அதன் இடது உட்மரத்தின் ஒவ்வொரு சாவியைவிடப் பெரியதும், வலது உட்மரத்தின் ஒவ்வொரு சாவியைவிடச் சிறியதும் ஆகும்.**
:::

### ஒன்றை உருவாக்குதல் (செருகல்)
1. **முதல் பொருள் வேராகிறது**.
2. ஒவ்வொரு புதிய பொருளுக்கும் வேரில் தொடங்கவும்:
    - **சிறியது → இடது செல்லவும்**; **பெரியது → வலது செல்லவும்**.
    - தேவையான பிள்ளை **இல்லாதவரை** மீண்டும் செய்யவும்.
3. புதிய இடது அல்லது வலது பிள்ளையாக **அங்கே பொருளைச் செருகவும்**.

:::example எடுத்துக்காட்டு 12.2.1 — mathematics, physics, geography, zoology, meteorology, geology, psychology, chemistry
1. **mathematics** → வேர்
2. **physics** > mathematics → mathematics-இன் வலது பிள்ளை
3. **geography** < mathematics → mathematics-இன் இடது பிள்ளை
4. **zoology** > mathematics, > physics → physics-இன் வலது பிள்ளை
5. **meteorology** > mathematics, < physics → physics-இன் இடது பிள்ளை
6. **geology** < mathematics, > geography → geography-இன் வலது பிள்ளை
7. **psychology** > mathematics, > physics, < zoology → zoology-இன் இடது பிள்ளை
8. **chemistry** < mathematics, < geography → geography-இன் இடது பிள்ளை

```
                 mathematics
               /             \
        geography            physics
        /       \           /       \
  chemistry   geology  meteorology  zoology
                                    /
                              psychology
```
:::

### படிமுறை 1 — பொருளைக் கண்டறிந்து சேர்த்தல்

```
procedure insertion(T: binary search tree, x: item)
v := root of T              {a vertex not present in T has the value null}
while v ≠ null and label(v) ≠ x
begin
    if x < label(v) then
        if left child of v ≠ null then v := left child of v
        else add new vertex as a left child of v and set v := null
    else
        if right child of v ≠ null then v := right child of v
        else add new vertex as a right child of v and set v := null
end
if root of T = null then add a vertex v to the tree and label it with x
else if v is null or label(v) ≠ x then label new vertex with x and let v be this new vertex
{v = location of x}
```

:::example எடுத்துக்காட்டு 12.2.2 — "oceanography" செருகுதல்
- **mathematics**-இல்: oceanography > mathematics → physics-க்கு **வலது** செல்லவும்.
- **physics**-இல்: oceanography < physics → meteorology-க்கு **இடது** செல்லவும்.
- **meteorology**-இல்: oceanography > meteorology. **வலது பிள்ளை இல்லை**; எனவே meteorology-இன் **புதிய வலது பிள்ளையைச்** சேர்க்கவும். v := null அமைத்துச் சுழலிலிருந்து வெளியேறவும்.
- புதிய முனைக்கு **oceanography** என அடையாளமிடவும்.
:::

:::tip மரங்களின் பிற பயன்பாடுகள் [[v2 12:59]]
- **முடிவெடுக்கும் மரங்கள்:** ஒவ்வொரு உள்முனையும் **முடிவு**; ஒவ்வொரு **சாத்தியமான விளைவுக்கும்** உட்மரம்.
- **விளையாட்டு மரங்கள்:** முனைகள் விளையாட்டின் **நிலைகள்**; விளிம்புகள் **செல்லுபடியான நகர்வுகள்**.
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- "இந்த வரைபுகளில் எவை மரங்கள்?" **இணைப்பு + எளிய சுற்றின்மை** சரிபார்த்து **n − 1 விளிம்புகள்** பயன்படுத்தவும்.
- கொடுக்கப்பட்ட வேருள்ள மரத்தின் **சொற்கள்**: வேர், உள்முனைகள், இலைகள், பிள்ளைகள், பெற்றோர், சகோதர முனைகள், மூதாதைகள், வழித்தோன்றல்கள், உட்மரம்.
- இரும மரத்தில் **இடது, வலது பிள்ளைகளும் உட்மரங்களும்**.
- ஒவ்வொரு ஒப்பீட்டையும் காட்டி (அகரவரிசை அல்லது எண்) பட்டியலிலிருந்து **BST உருவாக்குதல்**.
- படிமுறை 1-ஆல் **புதிய பொருளைச் செருகுதல்**.
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|

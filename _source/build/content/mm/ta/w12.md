## Editing மூலம் திட்டமிட்ட கதையைச் சொல்லுதல்

:::key Video editing
Video editing என்பது shots, sound மற்றும் பிற elements-ஐத் தேர்ந்து, வரிசைப்படுத்தி, இணைத்து, திட்டமிட்ட message-ஐ audience-க்கு எடுத்துச் சொல்வது. Shaky shot-ஐ அகற்றுவது அதன் ஒரு சிறிய பகுதிதான். பொருள், continuity, முக்கியத்துவம், வேகம் மற்றும் முழுக் கதையின் presentation-ஐ editor கட்டுப்படுத்துகிறார்.
:::

Purpose மற்றும் storyboard-இலிருந்து தொடங்குங்கள். ஒவ்வொரு shot என்ன சேர்க்கிறது, ஏன் அந்த இடத்தில் வருகிறது, பார்ப்பவரால் தொடர முடியுமா என்று கேளுங்கள். அழகான clip கூட தவறான கருத்தைத் தருமானால் பொருத்தமில்லை. Effects கதைக்கு உதவ வேண்டும்; கவனத்தைப் பறிக்கக்கூடாது.

:::example உள்ளூர் கதை
காலியில் உள்ள craft workshop பற்றிய video முதலில் இடத்தைக் காட்டலாம். பிறகு craftsperson வேலை செய்வதை, அருகிலிருந்து விவரங்களை, இறுதியில் முடித்த பொருளைக் காட்டலாம். அழகான shots-ஐ மட்டும் எதார்த்தமின்றி இணைத்தால் யார் செய்தார், எப்படிச் செய்தார் என்பது புரியாமல் போகலாம். தனித்த recordings-ஐ புரியும் sequence-ஆக editing மாற்றுகிறது.
:::

இந்தப் பாடத்தின் outcomes: non-linear editing-ஐ விளக்குதல், editing software மூலம் video உருவாக்குதல், பொருத்தமான effects சேர்த்தல், distribution-க்கு compress செய்தல். கீழே உள்ள workflow lesson outline-ஐ முழுமையான பயிற்சியாக விளக்குகிறது. இந்த வாரத்துக்கு கூடுதல் official quiz அல்லது past paper வழங்கப்படவில்லை.

## Linear மற்றும் non-linear editing

Film-ஐ முன்பு வெட்டி ஒட்டலாம். Tape-based linear video editing-இல் தேர்ந்த shots இறுதி வரிசையில் master tape-க்கு copy செய்யப்பட்டன. இது பொதுவாக real time எடுத்தது. நடுவில் scene சேர்த்தாலும் நீக்கினாலும் பின்னர் வரும் material-ஐ மீண்டும் record செய்ய வேண்டியிருக்கலாம். பெரிய மாற்றங்கள் மெதுவாக நடந்தன.

**Non-linear editing**, அல்லது **NLE**, digital media-க்கு random access பயன்படுத்துகிறது. Clips-ஐ எந்த வரிசையிலும் பார்க்கவும் மாற்றவும் முடியும். Project source references, in/out points, positions, effects மற்றும் track levels போன்ற முடிவுகளைச் சேமிக்கிறது. Original source files பொதுவாக பாதுகாக்கப்படுகின்றன. அந்த முடிவுகளிலிருந்து final production render அல்லது export செய்யப்படுகிறது.

| அம்சம் | Linear tape editing | Non-linear digital editing |
|---|---|---|
| Access | Sequential | Random access |
| Assembly | Clips-ஐ வரிசையில் master-க்கு copy செய்தல் | Timeline-இல் source references அமைத்தல் |
| பெரிய insertion | பின்னர் வரும் scenes-ஐ மீண்டும் copy செய்யலாம் | Clips-ஐச் சேர்த்து அல்லது நகர்த்தி edit மாற்றலாம் |
| Original footage | தனி source tapes | Source files தொடர்ந்து கிடைக்கும் |
| மாற்றங்கள் | மெதுவானதும் கட்டுப்பாடுள்ளதும் | Undo மற்றும் alternate versions மூலம் எளிது |
| Output | Recorded master | Export செய்த delivery file |

“Non-destructive” என்றால் original media-ஐ நிரந்தரமாக மாற்றாமல் edit முடிவை மாற்றலாம். Source file-ஐ delete செய்தால் அது பாதுகாப்பளிக்காது. Project மற்றும் linked assets-ஐ ஒன்றாக வைத்துப் backup எடுங்கள். சிறிய project file மட்டும் முடிந்த movie அல்ல.

PDF-இல் Premiere, Final Cut, Media Composer ஆகியவை professional NLE examples. Windows Live Movie Maker, iMovie ஆகியவை எளிய alternatives. இவை பழைய course examples. Free அல்லது bundled என்ற source கூற்றை தற்போதைய வாங்கும் வழிகாட்டியாகக் கருதாதீர்கள். Software மாறினாலும் editing concepts பயன்படும்.

## Post-production workflow மற்றும் workspace

:::flow நோக்கமுள்ள edit
Source media import செய்து ஒழுங்குபடுத்துதல்
தேவையான output-க்கு sequence அமைத்தல்
Takes பார்த்து in/out points குறித்தல்
Storyboard அடிப்படையில் rough assembly செய்தல்
Timing, continuity, sound சரிசெய்தல்
தேவையான effects, titles, transitions சேர்த்தல்
Delivery copy export செய்தல்
Exported file-ஐப் பார்த்துச் சரிபார்த்தல்
:::

பொதுவாக workspace-இல் assets-க்கு **project/media panel**, clip பார்க்க **source monitor**, sequence மற்றும் tracks-க்கு **timeline**, current edit பார்க்க **programme monitor**, **effects panel**, **audio meters** இருக்கும். ஒவ்வொரு software-இலும் இடமமைப்பு மாறலாம்.

Cut செய்யும்முன் dimensions, frame rate, aspect ratio, audio settings ஆகிய sequence settings-ஐத் தேருங்கள். Footage settings வேறுபட்டால் scale அல்லது interpret செய்வதை முடிவு செய்யுங்கள். Picture தவறாக stretch ஆகக்கூடாது. Original recordings வைத்துக்கொண்டு interviews, supporting pictures, music, graphics, exports ஆகியவற்றை folders அல்லது bins-இல் ஒழுங்குபடுத்துங்கள்.

**In point** தேர்ந்த பகுதியின் தொடக்கம். **Out point** அதன் முடிவு. Trimming இந்த எல்லைகளை மாற்றும். Splitting timeline-இல் தனித்த பகுதிகளை உருவாக்கும். Moving வரிசையை அல்லது இடத்தை மாற்றும். Gap இருந்தால் black video அல்லது silence வரலாம். Overlap transition-க்கு உதவலாம்; அது மட்டும் கதையைத் தெளிவாக்காது.

Ripple edit-இல் clip duration மாறும்போது பின்னர் வரும் material-உம் நகரும். ஒரு track மட்டும் நகர்ந்தால் speech/music sync கெடலாம். பெரிய edit-க்குப் பின் linked picture/sound, track locks, பின்னர் வந்த மாற்றங்கள் ஆகியவற்றைப் பாருங்கள்.

## Shots, A-Roll மற்றும் B-Roll

**Wide shot** location மற்றும் இடங்களின் தொடர்பை அறிமுகப்படுத்தும். **Medium shot** ஒருவரையும் அவரைச் சுற்றிய செயலையும் காட்டும். **Close-up** முகம், கை அல்லது சிறிய பொருள் விவரத்தில் கவனத்தை வைக்கும். **Insert** முக்கியமான சிறிய செயலைத் தெளிவாக்கும். Scene-ஐ விளக்க editor-க்கு பொருத்தமான பல views கிடைக்கும்படி capture செய்யுங்கள்.

இணைக்கப்பட்ட [Pond5 விளக்கம்](https://blog.pond5.com/8324-a-roll-and-b-roll-the-two-types-of-footage-you-need-to-tell-a-great-story/) **A-Roll**-ஐ முக்கிய narrative footage என்றும் **B-Roll**-ஐ supporting views என்றும் வேறுபடுத்துகிறது. Interview-led video-இல் பேசுபவர் விளக்கத்தை நடத்தும்போது detail shots அதைக் காட்டலாம். Main narration தொடரும்போது cutaway தேவையான edit-ஐ மறைக்கவும் உதவும்.

Workshop example-இல் craftsperson-இன் explanation narrative ஆக இருக்கட்டும். Tool பற்றிப் பேசும்போது அதை கைகள் பயன்படுத்துவதைக் காட்டுங்கள். முகபாவம் முக்கியமெனில் மீண்டும் அவரைக் காட்டுங்கள். Supporting footage claim மற்றும் context-க்கு பொருந்த வேண்டும். தொடர்பில்லாத அழகான picture தவறான பொருள் தரலாம்.

Continuity என்றால் edits-க்கு இடையிலும் action மற்றும் அதன் தொடர்புகள் புரிய வேண்டும். Movement direction, object position, eyeline, light/sound மாற்றங்கள் ஆகியவற்றைப் பாருங்கள். தனியாக நல்ல shot அடுத்த shot-உடன் பொருந்தாமல் இருக்கலாம். Sound உடன் முழு sequence பாருங்கள்; mute செய்தாலும் visual story புரிகிறதா பாருங்கள்.

## Cuts மற்றும் transitions

இணைக்கப்பட்ட [PremiumBeat cuts guide](https://www.premiumbeat.com/blog/8-essential-cuts-every-editor-should-know/) கீழுள்ள எட்டு groups-ஐ விளக்குகிறது. சுருக்கங்கள் நம்முடைய சொற்களில் எழுதப்பட்டவை.

| Cut | நடப்பது |
|---|---|
| Standard/hard cut | ஒரு shot உடனே மற்றொன்றால் மாறும் |
| Jump cut | தொடர்புள்ள material-இல் தெரியும் time jump வரும் |
| L cut | முந்தைய audio அடுத்த picture-இன் கீழ் தொடரும் |
| J cut | அடுத்த audio அதன் picture-க்கு முன் தொடங்கும் |
| Cutting on action | ஒரு action edit-க்கு அப்பாலும் தொடரும் |
| Cutaway | தொடர்புள்ள detail main view-ஐ இடையில் மாற்றும் |
| Cross-cut | தனித்த actions மாறிமாறிக் காட்டப்படும் |
| Montage | குறுகிய views ஒரு process அல்லது காலத்தைச் சுருக்கும் |
| Match cut | ஒத்த movement அல்லது form shots-ஐ இணைக்கும் |

Article L மற்றும் J cuts-ஐ ஒரே group-இல் வைக்கிறது. Table புரிதலுக்காக அவற்றைத் தனி rows-இல் காட்டுகிறது; source வேறு எண்ணிக்கை கொடுத்ததாகக் கருத வேண்டாம்.

**Transition** clips-இன் boundary எப்படி தோன்றும் என்பதைக் கட்டுப்படுத்தும். Straight cut பல இடங்களில் போதும். Dissolve pictures-ஐச் சிறிது நேரம் கலந்து time/place மாற்றத்தை உணர்த்தலாம். Fade picture-க்கும் plain field-க்கும் இடையில் மாறும். Wipe ஒரு region-ஐ மற்றொன்றால் மாற்றும். Effects library-இல் இருப்பதால் மட்டும் பயன்படுத்தாமல் அதன் பொருளுக்காகப் பயன்படுத்துங்கள்.

## Effects, titles மற்றும் audio finishing

Effects library reusable operations/presets தருகிறது. Colour correction அடுத்தடுத்த shots-ஐ ஒத்ததாக மாற்றலாம். Cropping/reframing கவனத்தைச் செலுத்தலாம். Stabilisation சில camera movement-ஐக் குறைக்கலாம்; ஆனால் frame crop ஆகலாம். Keyframed properties காலத்துடன் மாறும். தேவையான size-இல் preview செய்துவிட்டு exported result-ஐயும் பாருங்கள்; preview reduced quality-இல் இருக்கலாம்.

Titles பெயர், speaker role, location, section அல்லது closing instruction தரும். குறுகிய wording, போதிய contrast, வாசிக்க நேரம் ஆகியவை தேவை. Phone-இல் சிறிய decorative font படிக்க முடியாமல் போகலாம். முக்கிய text-ஐ edges-இலிருந்து விலக்கி light/dark backgrounds-இல் பாருங்கள். Captions speech மற்றும் பயனுள்ள sound information தரும்; decorative title captions-க்கு மாற்றாகாது.

Speech, music, effects levels-ஐ திட்டமிட்டு balance செய்யுங்கள். Music explanation-ஐ மறைக்கக்கூடாது. Abrupt cuts, room-tone changes, clipping, noise ஆகியவற்றைப் பாருங்கள். Click தவிர்க்கவும் entry smooth ஆகவும் சிறிய fades உதவலாம். பொருளுள்ள pauses-ஐ வைத்திருங்கள். Headphones மற்றும் speakers வெவ்வேறு பிரச்சினைகளை வெளிப்படுத்தலாம்; கிடைத்தால் இரண்டிலும் பாருங்கள்.

{{tool:mm12-duration}}

Duration tool opening மற்றும் main clip இடையே ஒரு overlap இருப்பதாகக் கருதுகிறது. இருமுறை எண்ணப்பட்ட நேரத்தை கழிக்கிறது. ஏற்கெனவே உள்ள shot-க்கு மேலே title வைத்தால் sequence duration கட்டாயமாக அதிகரிக்காது. எது sequential, எது simultaneous என்று தெளிவுபடுத்துங்கள்.

## Compression மற்றும் delivery checks

Export playable file உருவாக்கும்; project save editable முடிவுகளைப் பாதுகாக்கும். Receiving system-க்கு பொருத்தமான container, codecs, dimensions, frame rate, bit rate, audio settings தேருங்கள். Higher bit rate detail-ஐப் பாதுகாக்கலாம்; file size-ஐயும் கூட்டும். சிறிய display-க்கு lower dimensions பயன்படலாம்; spatial detail குறையும்.

நல்ல-quality master வைத்துக்கொண்டு தனி delivery copy உருவாக்குங்கள். Lossy copy-ஐ export செய்து அதையே திரும்பத் திரும்ப edit/export செய்வதைத் தவிருங்கள்; quality loss கூடலாம். Delivery file முழுவதையும் பார்த்து missing media, தவறான aspect ratio, black gaps, unreadable titles, sync errors, clipping, abrupt ending ஆகியவற்றைச் சரிபாருங்கள்.

Local file, intranet player, public web service ஆகியவை வேறு settings ஏற்கலாம். Network capacity, formats, file-size limits, audience device, duration ஆகியவை distribution constraints. Timeline preview சரியாக இருப்பதை மட்டும் நம்பாமல் actual exported file-ஐ உண்மையான route மூலம் test செய்யுங்கள்.

## Activity 12.1: முழுமையான model production

**கேள்வி:** பல sources-இலிருந்து பெற்ற video clips மற்றும் existing music பயன்படுத்தி music video தயாரிக்கவும்.

**Model answer:** மாணவர் ஒருவர் community arts event-க்கு செல்லும் பயணம் போன்ற தெளிவான theme தேருங்கள். Reuse permission உள்ள music/pictures பயன்படுத்தி credits எழுதுங்கள். Materials தயாரித்தல், பயணம், வருகை, setup, முடிந்த event ஆகியவற்றைப் பதிவு செய்யுங்கள். Source, technical settings, allowed uses ஆகியவற்றுடன் bins-இல் ஒழுங்குபடுத்துங்கள்.

Track-ஐக் கேட்டு opening, main phrases, ending குறியுங்கள். Theme-க்கு storyboard அமைத்து consistent dimensions/frame rate-இல் sequence உருவாக்குங்கள். Music structure edit-ஐ நடத்தினால் அதை முதலில் import செய்யுங்கள். Rough picture sequence அமைத்து accidental starts/stops-ஐ trim செய்யுங்கள். Wide views இடத்தை அறிமுகப்படுத்தட்டும்; close-ups முக்கிய விவரங்களைக் காட்டட்டும். Music-இன் பொருத்தமான நேரங்களில் actions/scene changes அமைக்கலாம். மிக வேகமான cuts கதையை மறைக்கக்கூடாது.

Continuity மற்றும் timing சரிசெய்யுங்கள். ஒவ்வொரு edit-க்கும் வேறு effect போடாமல் பொருளுள்ள மாற்றத்தில் restrained transition பயன்படுத்துங்கள். Opening title, closing credit சேருங்கள். Exposure/colour வேறுபாடுகளைச் சரிசெய்யுங்கள். Live sound இருந்தால் music-உடன் clarity கெடாமல் balance செய்யுங்கள். புதிய viewer-க்கு theme புரிகிறதா முழு timeline பார்த்துச் சோதியுங்கள்.

High-quality master மற்றும் compatible compressed copy export செய்யுங்கள். Phone மற்றும் பெரிய screen-இல் shape, titles/captions, sync, ending பாருங்கள். Project, media inventory, permissions வைத்திருங்கள். இது practical activity-க்கான முழு model workflow. தனி music-video file எடுத்து submit செய்ததாகக் கூறவில்லை.

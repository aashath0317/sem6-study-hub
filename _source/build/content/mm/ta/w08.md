
## Interactive multimedia சேர்க்கும் அம்சம்

:::key வரையறை
Interactive multimedia user input-க்கு ஏற்ப behaviour மாற்றும். Fixed presentation-ஐப் பார்ப்பதற்கு பதிலாக user text, graphics, animation, sound, video ஆகியவற்றைக் கட்டுப்படுத்தவோ இணைக்கவோ மாற்றவோ செய்கிறார்.
:::

சாதாரண animation தன் timeline-ஐப் பின்பற்றும். Interactive animation click-க்காகக் காத்திருக்கலாம்; தேர்ந்த இடத்துக்கு நகரலாம்; ஒரு பகுதியை repeat செய்யலாம்; வேறு scene-க்கு branch ஆகலாம். User-க்கும் system-க்கும் active role உள்ளது. User action செய்கிறார்; system அதை விளக்கிக் கொண்டு செயல்படுகிறது; தெரியும் அல்லது கேட்கும் response நடந்ததை user-க்கு விளக்குகிறது.

Learning title-இல் மாணவர் topic தேர்வு செய்து, demonstration pause செய்து, parameter மாற்றி மீண்டும் முயலலாம். இலங்கை railway kiosk-இல் traveller language, destination தேர்வு செய்தபின் பொருத்தமான தகவல் வரும். Game-இல் keyboard அல்லது pointer input character-ஐ நகர்த்தலாம். ஒவ்வொன்றிலும் input, rule, output கூறவும். Stage-இல் அலங்கார button வைத்தால் மட்டும் interaction செயல்படாது.

Script எழுதுவதற்கு முன் interaction modes திட்டமிடவும். Learner எதைக் கட்டுப்படுத்த வேண்டும், எந்த control அதைத் தெளிவாக்கும், success/failure எப்படி தெரியும், தவறான தேர்விலிருந்து எப்படி திரும்பலாம் என்று கேட்கவும். தொடர்புடைய controls அருகில், நோக்கத்தின் அடிப்படையில் group செய்யப்பட்டிருக்கட்டும். PDF steering, aircraft controls போன்ற physical systems-உடன் ஒப்பிடுகிறது. Arrangement task-ஐ ஆதரிக்க வேண்டும்.

## Flow control, frame control, time control

| Control | எடுக்கப்படும் முடிவு | உதாரணம் |
|---|---|---|
| Flow control | அடுத்து எந்த sequence அல்லது branch? | சரியான விடை அடுத்த scene திறக்கும் |
| Frame control | எந்த frame காட்ட அல்லது play செய்ய வேண்டும்? | Label கொடுத்த demonstration frame-க்கு jump செய்யும் |
| Time control | எப்போது நடக்கும் அல்லது எவ்வளவு நேரம் இருக்கும்? | Timer காத்திருத்தல், input வரை hold, delay-க்குப் பிறகு repeat |

PDF flow control-இல் events அடுத்த frame sequence-ஐ நிர்ணயிக்கின்றன. Time-control விளக்கத்தில் repeat, hold, முன்கூட்டிய triggers உள்ளன. இவை சேர்ந்து செயல்படலாம். Timer event ஏற்படுத்தலாம்; handler அடுத்த frame தேர்வு செய்யலாம். Frame number-ஐ elapsed seconds-உடன் குழப்ப வேண்டாம். Frame-இன் time movie frame rate-ஐச் சாரும்.

Interactive lesson-இல் decision screen-இல் stop செய்து input காத்திருக்கவும். Valid selection-க்குப் பிறகே branch செய்யவும். Demonstration-இல் assets duplicate செய்யாமல் replay கொடுக்கவும். Package அனுமதித்தால் முக்கிய destinations-க்கு frame labels கொடுக்கவும். பொருளுள்ள label பராமரிக்க எளிது. Playhead மீண்டும் frame-க்குள் நுழையும் ஒவ்வொரு முறையும் அதே listener மீண்டும் register ஆகாமல் கவனிக்கவும்.

Bus-safety lesson introduction-இல் தொடங்குகிறது. Learner Start அழுத்தி, வரிசையான crossing demonstration பார்த்து question-க்கு வருகிறார். ## Actions, events, listeners, trigger functions, handlers

**User action** என்பது click, pointer நகர்த்தல், touch, key அழுத்தல் போன்ற செயல். **Event** என்பது நடந்த ஒன்றை program குறிக்கும் விதம். **Event listener** குறிப்பிட்ட object-இல் குறிப்பிட்ட event-ஐக் கவனிக்க register செய்யும். **Callback அல்லது event handler** என்பது அந்த event வந்தபோது ஓடும் function.

பொருத்தமான code தேர்வு செய்யும் முறையை PDF **trigger function** என்கிறது. Environment-க்கு ஏற்ப சொற்கள் மாறலாம். ஆனால் காரணத் தொடர் மாறாது: action → event → listener/dispatch → handler → state change → output. Timer அல்லது வேறு program event-உம் handler-ஐ இயக்கலாம். Events mouse actions மட்டும் அல்ல. Main event loop அல்லது runtime dispatch-ஐ நிர்வகிப்பதால் blocking loop-இல் தொடர்ந்து user choice கேட்காமல் program பதிலளிக்கும்.

:::flow Event-driven தொடர்
User button activate செய்கிறார்
Click event உருவாகிறது
Registered listener event-ஐ அறிகிறது
Handler தற்போதைய state பார்க்கிறது
Handler movie அல்லது data update செய்கிறது
Interface feedback காட்டுகிறது
:::

பாடம் Flash/Animate tutorials-இல் ActionScript 3 குறிப்பிடுகிறது. துல்லியமான API document type, scripting environment சார்ந்தது. இதே event-driven கருத்து browser JavaScript-க்கும் பொருந்தும். Code கொடுக்கும்போது environment கூறவும். ActionScript, JavaScript snippets-ஐ ஒன்றின் project-இல் மற்றொன்றாக நேரடியாக paste செய்ய முடியாது.

```javascript
startButton.addEventListener('click', startLesson);
function startLesson(event) {
  currentScene = 'demonstration';
  showScene(currentScene);
}
```

இந்த browser-style உதாரணம் function-ஐ register செய்கிறது; உடனே call செய்யவில்லை. Event-க்குப் பிறகு handler ஓடும். Function-ஐத் தராமல் அதன் call result-ஐத் தருவது ஒரு பொதுவான தவறு. Display மாற்றி, பின்னர் decisions பயன்படுத்தும் state-ஐ update செய்ய மறப்பதும் தவறு. Replay/reset-க்குப் பிறகும் interaction-ஐப் பலமுறை சோதிக்கவும்.

## மீண்டும் பயன்படுத்தும் components, libraries, widgets

**Component** என்பது button, graphic, movie clip, animation போன்ற reusable element. **Library** reuse செய்வதற்கான definitions வைத்திருக்கும். **Instance** என்பது definition-ஐ stage-இல் பயன்படுத்திய ஒன்று. Shared library definition edit செய்தால் அதன் instances update ஆகலாம் என்று PDF வலியுறுத்துகிறது. Position, state போன்ற instance-specific values வேறுபடலாம். எல்லா instances-உம் எப்போதும் ஒரே appearance, behaviour கொண்டிருக்க வேண்டும் என்று நினைக்க வேண்டாம்.

Stage-இல் உள்ள button click, mouse-up, keyboard activation போன்ற events தரலாம். Environment ஆதரிக்கும் script event-ஐ behaviour-உடன் இணைக்கும். Reusable butterfly symbol-க்குள் wing animation இருக்கலாம்; அதன் instance main stage-இல் position மாற்றலாம். Component-based development மீண்டும் drawing செய்வதைக் குறைக்கும்; பொருளுள்ள visual objects-உடன் program செய்ய உதவும்.

நோக்கத்திற்கேற்ற widget தேர்வு செய்யவும். Button action தொடங்கும். Slider range value மாற்றும். Checkbox தனி option-ஐ on/off செய்யும். List alternatives-இல் தேர்வு செய்யும். Visible label, தெளிவான state கொடுக்கவும். Focus அதனை அடையவும் keyboard-இல் activate செய்யவும் முடிய வேண்டும். Control-க்கு அருகே feedback காட்டவும். Action கிடைக்கவில்லை என்றால் காரணம் புரிய வேண்டும்; அமைதியாக ஒன்றும் செய்யாமல் இருக்கக்கூடாது.

Library names, instance names வேறுபடும். Library symbol-ஐ வரையறுக்கும்; code பொதுவாக stage-இல் உள்ள குறிப்பிட்ட instance-ஐத் தேடும். Script target கிடைக்காவிட்டால் instance name, timeline scope, frame-இல் object இருப்பது, script ஓடுமுன் object உருவானதா ஆகியவற்றைப் பார்க்கவும். Visual symbol reuse செய்தாலும் event behaviour திட்டமிட வேண்டும்.

## Activity 8.1(i): click செய்த இடத்துக்கு butterfly நகர்தல்

**கேள்வி:** User stage-இல் click செய்த இடத்துக்கு butterfly நகரும் animation உருவாக்கவும்.

**முழு model விடை:** Butterfly symbol உருவாக்கி background layer-க்கு மேல் பெயரிட்ட instance வைக்கவும். அதன் centre அருகே registration point அமைக்கவும். Stage-இல் click listener register செய்யவும். Click coordinates-ஐ stage-இன் local coordinate system-இல் வாசித்து butterfly-க்கு target position கொடுக்கவும். எளிய response-க்கு உடனே நகர்த்தலாம்; flight தெரிய வேண்டுமெனில் தற்போதைய இடத்திலிருந்து interpolate செய்யலாம். Wing-flapping தனி internal animation ஆக இருக்கட்டும். Travel, flapping தனித்தனியாகக் கட்டுப்படுத்தலாம். Stage edge-இல் butterfly முழுவதும் தெரிய வேண்டுமெனில் target-ஐ வரம்புக்குள் வைக்கவும்.

```text
on stageClick(event):
    target = convertPointerToStage(event)
    target = keepInsideStage(target, butterflyBounds)
    moveButterflyFromCurrentPositionTo(target)
```

ஒவ்வொரு corner அருகிலும், travel நடக்கும்போதும், butterfly மேலேயும் click செய்து சோதிக்கவும். புதிய click பழைய destination-ஐ மாற்றுமா என்று முடிவு செய்யவும். வரம்பில்லாத movement loops தொடங்க வேண்டாம். Web page-இல் displayed stage rectangle-இலிருந்து internal drawing coordinates-க்கு pointer coordinates scale செய்யவும். இல்லையெனில் responsive resize-க்குப் பிறகு destination தவறும். Keyboard மூலம் move செய்ய அல்லது destination தேர்வு செய்ய வழி கொடுக்கவும். கீழுள்ள model pointer, arrow-key control கொடுத்து object-ஐ stage-க்குள் வைத்திருக்கும்.

## Activity 8.1(ii): வரிசையாக random paths

**கேள்வி:** Ball stage-இல் வெவ்வேறு paths-இல் ஒன்றன்பின் ஒன்றாக நகரட்டும்; ஒவ்வொரு movement-க்கும் path random-ஆகத் தேர்வு செய்யப்படட்டும்.

**முழு model விடை:** Point lists அல்லது labelled timeline segments ஆக பல valid routes தயார் செய்யவும். ஒவ்வொரு route-க்கும் start state, end state, duration கொடுக்கவும். Ball-இன் current route, progress, playing/paused state store செய்யவும். Movement முடிந்ததும் random route index தேர்வு செய்து அதை initialise செய்து தொடரவும். ஒரே update mechanism பயன்படுத்தவும். அடுத்தடுத்த routes கண்டிப்பாக வேறாக வேண்டுமெனில் முந்தைய index-ஐ நிராகரித்து தேர்வு செய்யவும். Random selection மட்டும் செய்தால் அதே path மீண்டும் வரலாம். இந்த வேறுபாட்டைக் கூறவும்; repeat இல்லை என்று தவறாக உறுதி கூற வேண்டாம்.

```text
on movementComplete:
    next = chooseRandomRouteExcluding(previousRoute)
    initialise(next)
    play(next)
on pause:
    preserve current route and progress
on resume:
    continue from preserved progress
```

Route வேறு இடத்தில் தொடங்கினால் ball திரும்பிச் செல்வதைக் காட்டுவீர்களா அல்லது routes ஒரே endpoints கொண்டிருக்குமா என்று முடிவு செய்யவும். காரணமில்லாத திடீர் teleport பொதுவாக design defect. Start, Pause, Resume, Reset controls தெளிவான states-உடன் கொடுக்கவும். Reset original ball, route state மீட்க வேண்டும். Random selection சோதிக்கும் முன் ஒவ்வொரு route-ஐயும் தனியாகச் சோதிக்கவும். இல்லையெனில் randomness சோதிக்காத branch-ஐ மறைக்கலாம். புதிய mouse click இல்லாவிட்டாலும் completion அடுத்த choice-ஐத் தூண்டுவதால் இது event-driven sequence.

### Model தரச் சரிபார்ப்பு

Logical control grouping, சரியான event target, தேவையான action-க்கு ஒரே listener, தெரியும் response, சரியான coordinate conversion, stage boundaries, மீண்டும் செய்யக்கூடிய reset ஆகியவற்றைப் பார்க்கவும். Keyboard operation, mobile interaction சோதிக்கவும். Folder-இல் ஐந்து-page lesson மட்டுமே உள்ளது; தனி ActionScript tutorials அல்லது recordings இல்லை. மேலுள்ள procedures கிடைக்காத file-ஐ மீண்டும் செய்ததாகக் கூறாமல் stated tasks-ஐ முழுமைப்படுத்துகின்றன.

:::exam English answer frame
“Interactive multimedia responds to user input. A user action generates an event. A registered listener invokes a handler, which checks state and changes the movie. For example, a stage-click handler reads the pointer coordinates and moves a butterfly instance to that location. A reusable library symbol supplies the visual component, while timeline and time controls govern its playback.”
:::

## சரக்கும் LKAS 2உம்

:::key வரையறை
**சரக்கு** என்பது வியாபாரத்தின் சொத்துகளில் **விற்பனைக்குத் தயாராக உள்ள அல்லது தயாராகவுள்ள மூலப்பொருட்கள், நடைபெறும் வேலை, முடிவுப் பொருட்கள்** ஆகும்.
:::

:::flow
மூலப்பொருட்கள்
நடைபெறும் வேலை (WIP)
முடிவுப் பொருட்கள்
:::

**LKAS 2 நோக்கம்:** சரக்குகளுக்கான கணக்கீட்டை நிர்ணயித்தல்:

- **கிரயத்தைத் தீர்மானித்தல்**
- **NRVக்கான பெறுமதிக் குறைப்பு** உட்பட **செலவை இனங்காணல்**
- பயன்படுத்தப்படும் **கிரயச் சூத்திரங்கள்**

:::key LKAS 2இன் அடிப்படைக் கொள்கை
**சரக்குகள் கிரயம் மற்றும் தேறிய தேறற்பெறுமதியில் (NRV) குறைந்த பெறுமதியில் காட்டப்படுகின்றன.**
:::

### சரக்குக் கிரயத்தில் அடங்குபவை

| **சேர்ப்பவை** | **விலக்குபவை** |
|---|---|
| **கொள்வனவுக் கிரயங்கள்:** விலை + **மீளப்பெற முடியாத வரிகள்**, போக்குவரத்தும் கையாளுதலும், **வியாபாரக் கழிவுகளையும் மானியங்களையும் கழித்து** | **அசாதாரண விரயம்** |
| **மாற்றக் கிரயங்கள்:** நேரடி உழைப்பு + **நிலையான மற்றும் மாறும் உற்பத்திப் பொதுச் செலவுகள்** | **களஞ்சியப்படுத்தல் செலவுகள்** |
| சரக்கை **தற்போதைய இடத்துக்கும் நிலைக்கும்** கொண்டுவரும் **ஏனைய கிரயங்கள்** | உற்பத்தியுடன் தொடர்பற்ற **நிர்வாகப் பொதுச் செலவுகள்** |
| | **விற்பனைச் செலவுகள்** |
| | அண்மைய வெளிநாட்டு நாணயக் கொள்வனவுகளின் **வெளிநாட்டுச் செலாவணி வேறுபாடுகள்** |
| | ஒத்திவைத்துத் தீர்க்கப்படும் கொள்வனவுகளின் **வட்டி** |

| கழி: மானியங்கள் | (xxx) |

| **மொத்தக் கொள்வனவுக் கிரயம்** | **xxxx** |

### தேறிய தேறற்பெறுமதி

:::formula
**NRV = மதிப்பிடப்பட்ட விற்பனை விலை − மதிப்பிடப்பட்ட பூர்த்திசெய்யும் கிரயங்கள் − மதிப்பிடப்பட்ட விற்பனைக் கிரயங்கள்**
:::

- **NRVக்கான பெறுமதிக் குறைப்புகள்**, அவை ஏற்படும் காலத்தின் **செலவு**. **மீள்திருப்பல்கள்** ஏற்படும் காலத்தின் வருமானக் கூற்றில் இனங்காணப்படும்.
- NRVஐ **உருப்படி வாரியாக** (உருப்படி முறை) அல்லது **ஒத்த உருப்படிக் குழுக்களாக** (தொகுதி முறை) ஒப்பிடலாம்.
- பரிமாற்றக்கூடிய உருப்படிகளின் **கிரயச் சூத்திரங்கள்:** **FIFO** அல்லது **நிறையிட்ட சராசரி** (**LIFO அனுமதிக்கப்படுவதில்லை**).
- **செலவு இனங்காணல்:** சரக்கு விற்கப்படும்போது, அதன் கொண்டுசெல்லும் பெறுமதி **விற்ற பொருட்களின் கிரயமாகிறது**. பெறுமதிக் குறைப்புகளும் நட்டங்களும் ஏற்படும்போதே செலவாக்கப்படுகின்றன.

:::example கிரயம், NRVஇல் குறைந்தது
| உருப்படி | கிரயம் | NRV | பயன்படுத்தும் பெறுமதி |
|---|---:|---:|---:|
| A | 1,000 | 1,300 | **1,000** |
| B | 800 | 650 | **650** |
| C | 500 | 500 | **500** |
| **உருப்படி வாரியான மொத்தம்** | | | **2,150** |

அதற்குப் பதிலாக **மொத்தங்களை** ஒப்பிட்டால் (கிரயம் 2,300, NRV 2,450), 2,300 கிடைக்கும். அது **Bஇன் நட்டத்தை மறைப்பதால்**, உருப்படி முறை விரும்பப்படுகிறது.
:::

## செயற்பாடு 1: கொள்வனவுகளை முகாமை செய்தல்

### மையப்படுத்திய மற்றும் பரவலாக்கிய கொள்வனவு

| | **மையப்படுத்திய கொள்வனவு** | **பரவலாக்கிய கொள்வனவு** |
|---|---|---|
| **நன்மைகள்** | ஒரேமாதிரியான **கொள்வனவுக் கொள்கை** · **சிறந்த கட்டுப்பாடு** · **நிபுணத்துவக் கொள்வனவு ஊழியர்கள்** · **மிகைச் சரக்கைத்** தவிர்த்தல் | **குறைந்த போக்குவரத்துச் செலவு** · நிராகரிப்புகள், பற்றாக்குறைகள், மிகைப் பெறுதல்கள் **விரைவாகத் தீர்க்கப்படுதல்** · **உள்ளூர்க் கொள்வனவு நன்மைகள்** (குறைந்த அல்லது பருவகால விலைகள்) |
| **தீமைகள்** | **குறைந்த நெகிழ்வுத்தன்மை** · **அதிக ஆரம்பச் செலவு** · **அதிக போக்குவரத்துச் செலவு** | **அதிக சரக்கு வைத்திருக்கும் செலவு** |

### கொள்வனவு நடைமுறை

:::flow
1. கொள்வனவு வேண்டுகோள் (எப்போது?)
2. அளவைத் தீர்மானித்தல் (எவ்வளவு?)
3. வழங்குநரைத் தேர்ந்தெடுத்தல் (எங்கே?)
4. கொள்வனவுக் கட்டளையும் பின்தொடர்தலும்
5. பெறுதலும் பரிசோதித்தலும் (GRN)
6. விலைப்பட்டியலைச் சரிபார்த்துச் செலுத்த அனுப்புதல்
:::

| படி | விவரங்கள் |
|---|---|
| **1. கொள்வனவு வேண்டுகோள் (PR)** | வாங்குவதற்கான கோரிக்கை; பொதுவாக **மூன்று பிரதிகளில்**: கொள்வனவுப் பிரிவுக்கு, உற்பத்திக் கட்டுப்பாட்டுக்கு, தொடங்கிய திணைக்களம் வைத்திருக்க |
| **2. அளவு** | **உற்பத்தி மற்றும் விற்பனைத்** திட்டங்களுக்கு ஏற்ப. **உகந்த அளவு**, மிகைச் சரக்கின்றி (EOQ) |
| **3. வழங்குநர்** | **விசாரணைகளும் கேள்விப்பத்திரங்கள் அல்லது விலைமனுக்களும்** → கேள்விப்பத்திரங்களை ஆராய்தல் → சிறந்த மூலத்தைத் தேர்ந்தெடுத்தல் |
| **4. கொள்வனவுக் கட்டளை** | பெரிய நிறுவனம் **5 பிரதிகள்** தயாரிக்கலாம்: வழங்குநர், பெறும் திணைக்களம், கணக்குகள், வேண்டுகோள் திணைக்களம், கொள்வனவுப் பிரிவு வைத்திருக்கும் பிரதி |
| **5. பெறுதலும் பரிசோதித்தலும்** | இறக்குதல், பொதியகற்றல், குறியிடுதல்; **தரத்தையும் அளவையும்** சரிபார்த்தல்; தொழிற்சாலைக்குள் நகர்த்தல். **களஞ்சியப் பேரேட்டுப் பதிவுகளின் அடிப்படையான பொருட்கள் பெற்ற குறிப்பை (GRN)** தயாரித்தல் |
| **6. விலைப்பட்டியல்** | PO, GRN உடன் ஒப்பிட்டுச் சரிபார்த்து, செலுத்துவதற்கு அனுப்புக |

### மூலப்பொருள் கிரயம்
**விலைப்பட்டியல் விலை + சரக்குக் கட்டணம் + உற்பத்தித் தீர்வை + திருப்பித்தர முடியாத கொள்கலன்கள்** (LKAS 2இன் கொள்வனவுக் கிரயமாக).

- **காசுக் கழிவு** ஒரு **நிதிசார்** உருப்படி; மூலப்பொருள் கிரயத்திலிருந்து **கழிக்கப்படுவதில்லை**.
- **திருப்பித்தரக்கூடிய கொள்கலன்கள்:** **தேறிய** கிரயம் (கட்டணம் − திருப்பியபோது வரவு) மட்டும் சேர்க்கப்படுகிறது.

:::example விரிவுரை எடுத்துக்காட்டு: திரு. நலீனிடமிருந்து 6,000 அலகுகளின் மூலப்பொருள் கிரயம்
- விலைமனு: 2,000 அலகுகள் @ ரூ 5.00; 4,000 @ ரூ 4.75; **6,000 @ ரூ 4.00**
- **வியாபாரக் கழிவு 25%**; 10 நாட்களுக்குள் 5% காசுக் கழிவு
- சரக்குக் கட்டணம் **ஒவ்வொரு கட்டளைக்கும் ரூ 200**
- கொள்கலன்கள் **ஒன்றுக்கு ரூ 0.50**, ஒவ்வொரு 100 அலகுகளுக்கும் ஒன்று; இரண்டு மாதங்களுக்குள் திருப்பினால் **ஒன்றுக்கு ரூ 0.30 வரவு**

| | ரூ |
|---|---:|
| 6,000 × ரூ 4.00 | 24,000 |
| கழி: வியாபாரக் கழிவு 25% | (6,000) |
| | 18,000 |
| சரக்குக் கட்டணம் | 200 |
| கொள்கலன்கள்: 60 × 0.50 = 30; வரவு 60 × 0.30 = 18 கழித்து → தேறிய தொகை | 12 |
| **மொத்த மூலப்பொருள் கிரயம்** | **18,212** |
| **அலகுக் கிரயம்** = 18,212 ÷ 6,000 | **≈ ரூ 3.035** |

**காசுக் கழிவு புறக்கணிக்கப்படுகிறது:** அது நிதியளிப்பு முடிவு; மூலப்பொருளின் கிரயம் அல்ல.
:::

## செயற்பாடு 2: மூலப்பொருள் களஞ்சியப்படுத்தலும் சரக்கு மட்டங்களும்

**திறனான களஞ்சியப்படுத்தல் ஏன்?**

- களஞ்சியப் பொருட்களை **முறையான பொறுப்பில்** வைத்திருத்தல்
- **திருட்டு, பழுதடைதல், ஆவியாதல், சிறுதிருட்டு** ஆகியவற்றிலிருந்து பாதுகாத்தல்
- உற்பத்திக்கு **சீரான, ஒழுங்கான பாய்வைப்** பேணுதல்

**களஞ்சிய இடங்கள்:** மையப்படுத்தியவை, பரவலாக்கியவை அல்லது இரண்டும் இணைந்தவை.

| **மையப்படுத்திய களஞ்சியங்கள்: நன்மைகள்** | **தீமைகள்** |
|---|---|
| சிறந்த அமைப்பு, குறைந்த உபகரணங்கள், **சிறந்த மேற்பார்வை**, **செலவுச் சிக்கனம்**, சிறந்த சரக்கு முன்கணிப்பு | **அதிக போக்குவரத்துச் செலவு**, **அதிக தீ ஆபத்து**, உற்பத்தியில் **தாமதங்கள்** |

### சரக்குக் கட்டுப்பாட்டு மட்டங்கள்

| மட்டம் | சூத்திரம் | பொருள் |
|---|---|---|
| **மீள்கட்டளை மட்டம் (ROL)** | **அதிகபட்ச நுகர்வு × அதிகபட்ச முன்னோடிக் காலம்** (அல்லது குறைந்தபட்சச் சரக்கு + சராசரி நுகர்வு × சராசரி முன்னோடிக் காலம்) | களஞ்சியக் காப்பாளர் **கொள்வனவு வேண்டுகோளை** எழுப்பும் நேரம் |
| **அதிகபட்சச் சரக்கு மட்டம்** | **ROL + ROQ − (குறைந்தபட்ச நுகர்வு × குறைந்தபட்ச முன்னோடிக் காலம்)** | இதற்கு மேல் சரக்கு உயரக்கூடாது (**மூலதனம் முடங்குவதைத்** தவிர்க்கிறது) |
| **குறைந்தபட்சச் சரக்கு மட்டம்** (பாதுகாப்பு அல்லது இடையகச் சரக்கு) | **ROL − (சராசரி நுகர்வு × சராசரி முன்னோடிக் காலம்)** | இதற்குக் கீழ் சரக்கு குறையக்கூடாது |
| **சராசரிச் சரக்கு மட்டம்** | **(அதிகபட்சம் + குறைந்தபட்சம்) ÷ 2**, அல்லது **குறைந்தபட்சம் + ½ ROQ** | |

:::example விரிவுரை எடுத்துக்காட்டு: சரக்கு மட்டங்கள்
- ROQ = 36,000 அலகுகள்
- முன்னோடிக் காலம் 2–4 மாதங்கள் (சராசரி 3)
- அதிகபட்ச நுகர்வு மாதத்துக்கு 9,000; வழமையான நுகர்வு மாதத்துக்கு 6,000
- வழமையானது அதிகபட்சம், குறைந்தபட்சத்தின் சராசரி என்பதால், குறைந்தபட்ச நுகர்வு = 2 × 6,000 − 9,000 = **3,000** என **கருதுக**

| மட்டம் | கணக்கீடு | அலகுகள் |
|---|---|---:|
| **மீள்கட்டளை மட்டம்** | 9,000 × 4 | **36,000** |
| **குறைந்தபட்ச மட்டம்** | 36,000 − (6,000 × 3) | **18,000** |
| **அதிகபட்ச மட்டம்** | 36,000 + 36,000 − (3,000 × 2) | **66,000** |
| **சராசரி மட்டம்** | (66,000 + 18,000) ÷ 2 | **42,000** (அல்லது 18,000 + ½ × 36,000 = 36,000) |
:::

### பொருளாதாரக் கட்டளை அளவு (EOQ)

:::formula
**EOQ = √( 2 × D × Co ÷ Ch )**
D = வருடாந்தத் தேவை · Co = ஒரு கட்டளையை இடும் செலவு · Ch = வருடத்துக்கு ஓர் அலகை வைத்திருக்கும் செலவு
:::

**EOQ ஊகங்கள்:**

- துல்லியமாக **முன்கணிக்கக்கூடிய**, **சீரான** தேவை
- **நிலையான முன்னோடிக் காலம்**
- **நிலையான மூலப்பொருள் விலை**
- அலகுக்கு **நிலையான வைத்திருக்கும் செலவு**

:::example விரிவுரை எடுத்துக்காட்டு: EOQ
- மாதாந்தப் பயன்பாடு 250; எனவே வருடத்துக்கு **D = 3,000**
- **Co = ரூ 30**
- அலகுக் கிரயம் ரூ 5, வைத்திருக்கும் செலவு 10%; எனவே **Ch = ரூ 0.50**

EOQ = √(2 × 3,000 × 30 ÷ 0.5) = √360,000 = **600 அலகுகள்**
:::

## செயற்பாடு 3: மூலப்பொருள் வழங்கல்களை விலையிடுதல் — FIFO மற்றும் நிறையிட்ட சராசரி

| முறை | கருத்து | விலைகள் உயரும்போது விளைவு |
|---|---|---|
| **FIFO** (முதலில் வந்தவை முதலில் செல்லும்) | வழங்கல்கள் முதலில் **பழைய** தொகுதிகளின் விலையில் மதிப்பிடப்படுகின்றன | வழங்கல்கள் பழைய (குறைந்த) விலைகளில்; எனவே **இறுதிச் சரக்கு அண்மைய (அதிக) விலைகளில்** உள்ளது; இலாபமும் அதிகம் |
| **நிறையிட்ட சராசரிக் கிரயம் (WAC)** | ஒவ்வொரு பெறுதலுக்குப் பின்னும் **சராசரி = மொத்தப் பெறுமதி ÷ மொத்த அலகுகள்**; அந்தச் சராசரியில் வழங்குக | விலை மாற்றங்களைச் சீராக்குகிறது |

## தொடக்கநிலைப் பயிற்சி — கேள்விகளும் படிப்படியான விடைகளும்

**இந்தப் பகுதி இன்னும் தமிழில் மொழிபெயர்க்கப்படவில்லை; தற்போது ஆங்கிலத்தில் மட்டும் உள்ளது.**

**Week 08 learning path:** Week 08: Pricing material issues → Net realisable value.

**Start from zero:** Inventory is stock held for sale or production. FIFO means first in, first out. A moving weighted average recalculates unit cost after each receipt. NRV means estimated selling price less completion and selling costs.

These are **new beginner learning questions**, not official past-paper questions or a replacement for the course-paper practice above. All amounts are in Sri Lankan rupees (Rs) unless stated otherwise.

### Practice 08.1 — Compare FIFO and moving weighted average

**Question:** Start with 10 units at Rs 100 each. Buy 10 units at Rs 120 each, then issue 12 units. There are no other movements. Find issue cost and closing inventory using FIFO and moving weighted average.

<details class="beginner-answer" markdown="1">
<summary>Show step-by-step answer — Practice 08.1</summary>

1. Total available quantity = 10 + 10 = **20 units**. Total cost = 10 × 100 + 10 × 120 = **Rs 2,200**.
2. **FIFO issue:** use the oldest layer first: 10 × 100 + 2 × 120 = **Rs 1,240**.
3. **FIFO closing stock:** 8 units remain in the newer layer: 8 × 120 = **Rs 960**.
4. **Weighted-average rate after receipt:** 2,200 ÷ 20 = **Rs 110 per unit**.
5. **Average issue cost:** 12 × 110 = **Rs 1,320**. Closing stock = 8 × 110 = **Rs 880**.

**Check:** FIFO 1,240 + 960 = 2,200; average 1,320 + 880 = 2,200. Both leave 8 physical units. The cost assigned differs.

</details>

### Practice 08.2 — Value inventory at lower of cost and NRV

**Question:** There are 20 identical items, cost Rs 80 each. Each can sell for Rs 90 but needs Rs 5 completion work and Rs 10 selling costs. Find the inventory value and write-down.

<details class="beginner-answer" markdown="1">
<summary>Show step-by-step answer — Practice 08.2</summary>

1. NRV per unit = selling price 90 − completion 5 − selling costs 10 = **Rs 75**.
2. Compare cost 80 with NRV 75. Use the **lower**, Rs 75.
3. Inventory value = 20 × 75 = **Rs 1,500**.
4. Original cost = 20 × 80 = 1,600. Write-down = 1,600 − 1,500 = **Rs 100**. Record an expense and reduce inventory by 100.

**Check:** do not use the Rs 90 selling price as NRV. Costs still necessary to sell must be deducted.

</details>

## மதிப்பீடு எங்கு அமைகிறது?

:::flow
1. தேவைகளைக் கண்டறிதல் (தேவைகளை நிறுவுதல்)
2. மாற்று வடிவமைப்புகள்
3. முன்மாதிரி உருவாக்குதல்
4. **மதிப்பீடு**
:::

:::key மதிப்பீடு
நாம் வடிவமைத்த **இடைமுகம் எவ்வளவு பயன்படுத்தக்கூடியது** என்பதை **மதிப்பீடு** கண்டறிகிறது. இது **பயன்பாட்டுத் திறனின் அளவீடு** [[00:03]].
:::

- மதிப்பீடு **பயனர்மைய வடிவமைப்பின் மையம்** [[00:26]]. பயனர் திருப்தியடைந்தாரா என்று தெரியாவிட்டால், பயனர்மைய வடிவமைப்பைச் செய்வதில் பயனில்லை.
- பயனர் பின்னூட்டம் அவரது **திருப்தி நிலை**, **மேம்படுத்த வேண்டிய பகுதிகள்**, **மிகவும் பிடித்த அம்சங்கள்** ஆகியவற்றைத் தெரிவிக்கிறது. மீதமுள்ள உருவாக்கத்துக்கான **நல்ல நடைமுறைகளுக்கும்** வழிகாட்டுகிறது.
- இது **நாம் திட்டமிட்டதைப் பற்றியதல்ல; வடிவமைத்ததைப் பற்றிய பின்னூட்டம்** [[01:23]].

## மதிப்பீட்டை முன்மாதிரியுடன் பொருத்துதல்

வடிவமைப்பு பொதுவாகப் பயனர்களுக்கு ஒரு **முன்மாதிரியாகக்** காட்டப்படுகிறது. முன்மாதிரி **வெவ்வேறு நிலைகளில் வெவ்வேறு செயல்பாடுகளைச்** செய்கிறது [[01:38]]:

- வடிவமைப்பின் **தொடக்கத்தில்**, உண்மையில் என்ன தேவை என்பதைக் கண்டறிய அதன் செயல்பாடுகள் **அடிப்படையானவை**.
- **பின்னர்**, அது வழங்கும் **செயல்பாடுகளுக்காக** மதிப்பிடப்படுகிறது.

:::key விதி
முன்மாதிரியின் **செயல்பாடுகள் மற்றும் நிலைக்கு** ஏற்ப **மதிப்பீட்டு முறை அதனுடன் பொருந்த வேண்டும்** [[02:28]]. செயல்பாடுகள், நிலை, முன்மாதிரியின் வகை ஆகியவை **அனைத்தும் ஒன்றுடன் ஒன்று இணைந்தவை**.
:::

## வடிவமைப்பு வாழ்க்கைச் சுழற்சி முழுவதும் மதிப்பீடு

| நிலை | பின்னூட்டத்தின் வகை | எடுத்துக்காட்டுக் கேள்விகளும் அளவீடுகளும் |
|---|---|---|
| **தொடக்கம்** [[03:18]] | **தரம்சார்**, கருத்தளவிலானது; பயனர் **விருப்பங்கள்** | பயனர்களுக்கு இந்த **நிறத் தோற்றம்** அல்லது கருத்து பிடிக்கிறதா? முனைப்பாக இருக்க வேண்டுமா, பின்னணியில் இருக்க வேண்டுமா? **வாசிக்கவும் புரிந்துகொள்ளவும் முடியுமா?** |
| **இடைநிலை** [[04:32]] | **பயன்பாட்டுத் திறன்** | உங்கள் **பணிச்சுமையைக் குறைக்கிறதா?** **இயல்பாகப் புரிகிறதா?** **கற்க எளிதா?** (கற்க எளிதாக இல்லாவிட்டால் மக்கள் பயன்படுத்த மாட்டார்கள்.) |
| **இறுதிநிலை** [[05:37]] | **அளவுசார்:** எண்கள், நிகழ்வெண்கள், செயல்திறன் குறியீடுகள் | இந்தப் படிவத்தை நிரப்பிச் சமர்ப்பிக்க **எவ்வளவு நேரம்** ஆகிறது? ஒரு பணியாளர் நாளொன்றில் முடிக்கும் **வேலைகளின் எண்ணிக்கை** உயர்ந்துள்ளதா? **விற்பனை அளவு** அதிகரித்துள்ளதா? |

:::tip மதிப்பீடு ஒரு பயணம் [[08:13]]
**தொடக்கத்திலும் இடையிலும் இறுதியிலும்** மதிப்பிடலாம். பயனர்கள் **உண்மையில் விரும்புவதை** இடைமுகம் தருகிறது என்பதை உறுதிசெய்யும் வரை **மீண்டும் மீண்டும் மேம்படுத்துகிறீர்கள்**. வடிவமைப்புச் செயல்முறையின் எந்த நிலையில் உள்ளீர்கள் என்பதுடன் மதிப்பீட்டு வகை **நெருக்கமாக இணைந்துள்ளது**.
:::

## மூன்று மதிப்பீட்டு வகைகள்

| வகை | பயனர்களுடன்? | செய்வது என்ன? | எடுத்துக்காட்டு |
|---|---|---|---|
| **தரம்சார்** | ஆம் | **தரம்சார் பின்னூட்டத்தைச்** சேகரித்தல்; விருப்பங்களுக்குப் பின்னுள்ள **தர அம்சங்களைக்** கண்டறிதல். **எண்ணியல் அளவீடுகள் இல்லை** | “இந்த வடிவங்களில் உங்களுக்கு மிகவும் பிடித்தது எது?” |
| **அனுபவச் சான்றுசார்** [[10:36]] | ஆம் | **கட்டுப்படுத்தப்பட்ட சோதனைகளால் அளவுசாராக** மதிப்பிட்டு, முடிவுகளை ஒப்பிடுதல் | பழைய மற்றும் புதிய இடைமுகங்களின் பணி நேரத்தை அளவிடுதல் |
| **முன்கணிப்பு** [[11:21]] | **இல்லை** | ஒரு நபரை மெய்நிகராகக் குறிக்கும் மனித உள்ளீட்டு/வெளியீட்டு **மாதிரியைப்** பயன்படுத்துதல்; மதிப்பீட்டாளர் **பயனரைப் போல் செயல்படுகிறார்** | மாதிரி அடிப்படையிலான பணி ஆய்வு |

:::warn முதலில் தரம்சார் மதிப்பீடு
**அனுபவச் சான்றுசார்** மதிப்பீட்டுக்கு முன், **தரம்சார்** மதிப்பீட்டைச் செய்து தரம்சார் பின்னூட்டத்தைச் சேகரிக்கவும் [[11:04]].
:::

:::grid
**முன்கணிப்பு மதிப்பீடு: விரிவுரையின் எச்சரிக்கை**

விரிவான மாதிரியாக்கம் நேரமெடுக்கலாம்; உண்மையான பயனர் பின்னூட்டத்தைத் தவறவிடலாம் என்று விரிவுரை எச்சரிக்கிறது. அதன் செலவும் பயனும் பணியையும் இருக்கும் மாதிரிகளையும் சார்ந்தவை; செயல்படுத்துவதற்கு முன்பே வடிவமைப்புகளை ஒப்பிடவும் முன்கணிப்பு உதவும்.
+++
**UCD-க்குத் தேவையானது**

பயனர்மைய வடிவமைப்புக்கு **உண்மையான பயனர் சான்றுகள்** தேவை. முன்கணிப்பு மாதிரிகள் அவற்றுக்குத் துணையாகலாம்; முன்கணிப்பு மட்டும் உண்மையான பயன்பாட்டுத் திறனையோ திருப்தியையோ நிறுவாது.
:::

## நான்கு முக்கியச் சொற்கள்

| சொல் | பொருள் | விரிவுரை எடுத்துக்காட்டு |
|---|---|---|
| **நம்பகத்தன்மை** [[13:50]] | மதிப்பீடு **காலப்போக்கில் ஒரேமாதிரியாக** உள்ளதா: மீண்டும் செய்தால் அதே முடிவு கிடைத்தல் | தெற்கு அதிவேக நெடுஞ்சாலை வழியாக இரு நகரங்களுக்கு இடையிலான தொலைவு: பாதை மாறாவிட்டால் எப்போதும் ஒரே பதில் |
| **செல்லுபடித்தன்மை** [[15:07]] | மதிப்பீடு **நிஜத்தை எவ்வளவு சரியாக அளக்கிறது** | **அச்சுப் பிழையுள்ள** தொலைவு அட்டவணை (சுமார் 100 கி.மீ. என்பதற்குப் பதில் 150 கி.மீ.) ஒவ்வொரு முறையும் அதே தவறான பதிலைத் தருகிறது: **நம்பகமானது, ஆனால் செல்லுபடியாகாதது** |
| **பொதுமைப்படுத்தக்கூடிய தன்மை** [[19:14]] | மதிப்பீட்டில் கற்றது **பரந்த பயனர் தொகுதிக்கு எவ்வளவு பொருந்துகிறது** | சில சோதனைப் பயனர்களிடமிருந்து கற்றவை இன்னும் பலருக்கும் பொருந்துதல் |
| **நுண்துல்லியம்** [[19:50]] | மதிப்பீடு **எவ்வளவு நுணுக்கமானது** | 106 கி.மீ. (கி.மீ. அளவு) · 106.4 கி.மீ. (100 மீ.) · 106.43 கி.மீ. (10 மீ.) · 106.434 கி.மீ. (1 மீ.) |

:::example நம்பகமானது, ஆனால் செல்லுபடியாகாதது: அலுவலக எழுத்தர்
**தலைமை நிர்வாக அதிகாரியை** எப்போது சந்திக்கலாம் என்று வருகையாளர்கள் கேட்கும்போது, எழுத்தர் **நேர அட்டவணையைப்** படித்துப் பதிலளிக்கிறார். ஒரே கேள்வியை இருமுறை கேட்டால் ஒரே பதில் கிடைக்கிறது; எனவே எழுத்தர் **நம்பகமானவர்**. ஆனால் அட்டவணை காலாவதியானதாக இருந்தால் ஒவ்வொரு பதிலும் தவறு; எனவே பதில்கள் **செல்லுபடியாகாதவை** [[15:36]].
:::

:::key நம்பகத்தன்மை ≠ செல்லுபடித்தன்மை
ஒரு மதிப்பீடு **100% நம்பகமாக இருந்தும் முற்றிலும் தவறாக இருக்கலாம்**. எப்போதும் **இரண்டையும்** சரிபாருங்கள்.

:::exam தேர்வில் கவனம் செலுத்த வேண்டியவை
- **மதிப்பீடு ஏன் UCD-இன் மையம்** என்று விளக்குக.
- ஒவ்வொரு நிலைக்கும் எடுத்துக்காட்டுடன், பின்னூட்டம் **தரம்சார் → பயன்பாட்டுத் திறன் → அளவுசார்** என மாறுவதை விவரிக்கவும்.
- **தரம்சார், அனுபவச் சான்றுசார், முன்கணிப்பு** மதிப்பீடுகளை ஒப்பிடுக: யார் ஈடுபடுகிறார்கள், எது அளக்கப்படுகிறது, நன்மை குறைகள்.
- **நம்பகத்தன்மை, செல்லுபடித்தன்மை, பொதுமைப்படுத்தக்கூடிய தன்மை, நுண்துல்லியம்** ஆகியவற்றை வரையறுத்து, **நம்பகமான ஆனால் செல்லுபடியாகாத** எடுத்துக்காட்டைக் கொடுக்கவும்.
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்க |
|---|---|
| மதிப்பீடு | **பயன்பாட்டுத் திறனின்** அளவீடு; **UCD-இன் மையம்** |
| பின்னூட்டம் | நாம் திட்டமிட்டது அல்ல; **வடிவமைத்தது** பற்றியது |
| பொருத்தம் | மதிப்பீட்டு முறை ↔ முன்மாதிரியின் **செயல்பாடுகளும் நிலையும்** |
| தொடக்கம் | **தரம்சார்:** விருப்பங்கள், நிறம், வாசிப்புத்தன்மை |
| இடைநிலை | **பயன்பாட்டுத் திறன்:** பணிச்சுமை, இயல்பாகப் புரிதல், கற்றல் எளிமை |
| இறுதிநிலை | **அளவுசார்:** பணி நேரம், நாளாந்த வேலைகள், விற்பனை |
| பயணம் | தொடக்கம், இடைநிலை, இறுதியில் மதிப்பிடுங்கள்; **மீளச்செய்யுங்கள்** |
| தரம்சார் | பயனர்கள்; விருப்பங்கள்; அளவீடுகள் இல்லை |
| அனுபவச் சான்றுசார் | பயனர்கள்; அளவுசார்; **கட்டுப்படுத்தப்பட்ட சோதனைகள்**; முதலில் தரம்சார் ஆய்வு |
| முன்கணிப்பு | பயனர் அமர்வின்றி மாதிரி அடிப்படையிலான மதிப்பீடுகள்; முயற்சியும் பயனும் பணியைச் சார்ந்தவை; பயனர் சான்றுக்குத் துணை |
| நம்பகத்தன்மை | காலப்போக்கில் **ஒரேமாதிரியாக** இருத்தல் |
| செல்லுபடித்தன்மை | நிஜத்துக்கு **சரியாக** இருத்தல் (நம்பகமானது ≠ செல்லுபடியானது) |
| பொதுமைப்படுத்தக்கூடிய தன்மை | **பரந்த பயனர் தொகுதிக்குப்** பொருந்துதல் |
| நுண்துல்லியம் | எவ்வளவு **நுணுக்கம்:** 106, 106.4, 106.43 கி.மீ. |

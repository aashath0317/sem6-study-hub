## பேய்சியன் வகைப்படுத்திகள் — கண்ணோட்டம்

- **பேய்சியன் வகைப்படுத்திகள் புள்ளிவிவர வகைப்படுத்திகள்.** அவை **வகுப்பு உறுப்புரிமை நிகழ்தகவுகளை**, அதாவது ஒரு வரிசை ஒரு வகுப்பைச் சாரும் நிகழ்தகவை முன்னறிவிக்கின்றன.
- **பேய்சின் தேற்றத்தை** அடிப்படையாகக் கொண்டவை.
- எளிய **எளிமைப் பேய்சியன் வகைப்படுத்தி**, **முடிவெடுக்கும் மரங்கள் மற்றும் சில நரம்பியல் வலையமைப்புகளுக்கு ஒப்பாகச்** செயல்படுகிறது; **பெரிய தரவுத்தளங்களில் அதிகத் துல்லியமும் வேகமும்** கொண்டது.

:::key ஏன் "எளிமை"?
**வகுப்பின் மீது ஒரு பண்புக்கூறுப் பெறுமதியின் விளைவு, பிற பண்புக்கூறுகளின் பெறுமதிகளிலிருந்து சுயாதீனமானது** என அனுமானிக்கிறது. இது **வகுப்பு-நிபந்தனைச் சுயாதீனம்** எனப்படுகிறது. இந்த அனுமானம் கணக்கீட்டை எளிதாக்குவதால் "எளிமை" எனப்படுகிறது.
:::

**பேய்சியன் நம்பிக்கை வலையமைப்புகள்**, எளிமைப் பேய்சைப் போலல்லாமல் பண்புக்கூறு உட்கணங்களுக்கிடையே **சார்புகளைப் பிரதிநிதித்துவப்படுத்தக்கூடிய வரைகலை மாதிரிகள்**. வகைப்படுத்தலுக்கும் பயன்படுத்தலாம்.

## பேய்சின் தேற்றம்

நிகழ்தகவு மற்றும் முடிவுக் கோட்பாட்டில் பணியாற்றிய 18-ஆம் நூற்றாண்டு ஆங்கில மரபுசாரா மதகுரு **Thomas Bayes**-இன் பெயரால் அழைக்கப்படுகிறது.

| குறியீடு | பெயர் | எடுத்துக்காட்டுப் பொருள் (வயது 35, வருமானம் $40,000 உள்ள வாடிக்கையாளர்) |
|---|---|---|
| **X** | **சான்று**: தரவு வரிசை | வாடிக்கையாளரின் வயதும் வருமானமும் |
| **H** | **கருதுகோள்**: X என்பது C வகுப்பைச் சார்ந்தது | "கணினி வாங்குவார்" |
| **P(H\|X)** | X கொடுக்கப்பட்டபோது H-இன் **பின்னர்** நிகழ்தகவு | **இந்த** வாடிக்கையாளர் கணினி வாங்கும் நிகழ்தகவு |
| **P(H)** | H-இன் **முன்** நிகழ்தகவு | **எந்தவொரு** வாடிக்கையாளரும் கணினி வாங்கும் நிகழ்தகவு |
| **P(X\|H)** | H-இன்கீழ் சான்றின் **வாய்ப்புத்தன்மை** | வாங்குபவரின் வயது 35, வருமானம் $40,000 ஆக இருக்கும் நிகழ்தகவு |
| **P(X)** | X-இன் **முன்** நிகழ்தகவு | வாடிக்கையாளரின் வயது 35, வருமானம் $40,000 ஆக இருக்கும் நிகழ்தகவு |

:::formula
**P(H | X) = P(X | H) · P(H) / P(X)**
:::

:::example மூளையுறை அழற்சி
- மூளையுறை அழற்சி (M), 50% சந்தர்ப்பங்களில் கழுத்து விறைப்பை (S) ஏற்படுத்துகிறது: P(S|M) = 0.5
- P(M) = 1/50,000
- P(S) = 1/20

நோயாளிக்குக் கழுத்து விறைப்பு இருந்தால், மூளையுறை அழற்சிக்கான நிகழ்தகவு என்ன?

P(M|S) = P(S|M)·P(M) / P(S) = 0.5 × (1/50,000) / (1/20) = **0.0002**

இந்த **பயிற்சிக்காக உருவாக்கப்பட்ட நிகழ்தகவுகளின்கீழ்**, பின்னர் நிகழ்தகவு 0.02%. இது நிகழ்தகவு விளக்கம்; மருத்துவ நோயறிதல் விதி அல்ல.
:::

## எளிமைப் பேய்சியன் வகைப்படுத்தி

**அமைப்பு:**

- பயிற்சித் தொகுப்பு D. ஒவ்வொரு வரிசையும் A₁ … Aₙ பண்புக்கூறுகளின் X = (x₁, …, xₙ).
- C₁ … Cₘ என m வகுப்புகள் உள்ளன.

:::key முடிவு விதி
**அதிகப் பின்னர் நிகழ்தகவுள்ள** Cᵢ வகுப்பை, அதாவது **அதிகபட்சப் பின்னர் கருதுகோளை**, முன்னறிவிக்கவும்:

அனைத்து j ≠ i-க்கும் P(Cᵢ|X) > P(Cⱼ|X)
:::

பேய்சின்படி: P(Cᵢ|X) = P(X|Cᵢ)P(Cᵢ) / P(X).

1. **ஒவ்வொரு வகுப்புக்கும் P(X) ஒன்றே**; எனவே **P(X|Cᵢ)·P(Cᵢ)** மட்டும் அதிகரிக்கவும்.
2. வகுப்பு முன் நிகழ்தகவுகள் **தெரியாவிட்டால்**, அனைத்தும் **சம சாத்தியமுள்ளவை** என அனுமானித்து **P(X|Cᵢ)**-ஐ அதிகரிக்கவும். இல்லாவிட்டால் **P(Cᵢ) = |Cᵢ,D| / |D|** என மதிப்பிடவும்.
3. பல பண்புக்கூறுகளுடன் P(X|Cᵢ)-ஐ நேரடியாகக் கணக்கிடுவது மிகச் செலவானது. **வகுப்பு-நிபந்தனைச் சுயாதீனம்** தருவது:

:::formula
P(X | Cᵢ) = Π<sub>k=1..n</sub> P(x<sub>k</sub> | Cᵢ) = P(x₁|Cᵢ) × P(x₂|Cᵢ) × … × P(xₙ|Cᵢ)
:::

### P(xₖ|Cᵢ)-ஐ மதிப்பிடுதல்

:::grid
**வகைசார் பண்புக்கூறு**

P(xₖ|Cᵢ) = (xₖ பெறுமதியுள்ள Cᵢ-வகுப்பு வரிசைகளின் எண்ணிக்கை) / |Cᵢ,D|
+++
**தொடர்ச்சியான பண்புக்கூறு**

அந்த வகுப்புக்கான சராசரி μ, நியம விலகல் σ உடன் **கௌசியன் (இயல்நிலை)** பகிர்வை அனுமானிக்கவும்:

g(x, μ, σ) = 1/(√(2π)·σ) · e<sup>−(x−μ)² / (2σ²)</sup>

தொடர்ச்சியான x-க்கு, துல்லியமான ஒரு புள்ளியின் நிகழ்தகவுக்குப் பதிலாக **அடர்த்தி** g(xₖ, μ<sub>Cᵢ</sub>, σ<sub>Cᵢ</sub>)-ஐப் பயன்படுத்தவும். வகுப்பு மதிப்பெண்ணில் அடர்த்திகள் பயன்படுத்தப்படுகின்றன.
:::

:::example கௌசியன் எடுத்துக்காட்டு
வாங்குபவர்களின் வயது 38 ± 12 (μ = 38, σ = 12). வயது = 35 உள்ள X-க்கு:

g(age = 35 | yes) = 1/(√(2π)·12) · e<sup>−(35−38)²/(2·12²)</sup> = 0.0332 × e<sup>−0.03125</sup> ≈ **0.0322**
:::

## செய்முறை எடுத்துக்காட்டு — X கணினி வாங்குவாரா?

வாரம் 11-இன் அதே 14-வரிசைப் பயிற்சித் தொகுப்பு (9 ஆம், 5 இல்லை). வகைப்படுத்தவும்:

:::formula
X = (வயது = இளைஞர், வருமானம் = நடுத்தரம், மாணவர் = ஆம், கடன்_மதிப்பீடு = நியாயம்)
:::

**முன் நிகழ்தகவுகள்**

- P(yes) = 9/14 = **0.643**
- P(no) = 5/14 = **0.357**

**நிபந்தனை நிகழ்தகவுகள்**

| | P(·\|yes) | P(·\|no) |
|---|---|---|
| வயது = இளைஞர் | 2/9 = 0.222 | 3/5 = 0.600 |
| வருமானம் = நடுத்தரம் | 4/9 = 0.444 | 2/5 = 0.400 |
| மாணவர் = ஆம் | 6/9 = 0.667 | 1/5 = 0.200 |
| கடன்_மதிப்பீடு = நியாயம் | 6/9 = 0.667 | 2/5 = 0.400 |

**பெருக்கவும்**

- P(X|yes) = 0.222 × 0.444 × 0.667 × 0.667 = **0.044**
- P(X|no) = 0.600 × 0.400 × 0.200 × 0.400 = **0.019**

**முன் நிகழ்தகவுகளால் பெருக்கவும்**

- P(X|yes)·P(yes) = 0.044 × 0.643 = **0.028**
- P(X|no)·P(no) = 0.019 × 0.357 = **0.007**

0.028 > 0.007; எனவே முன்னறிவிப்பு **கணினி_வாங்குவார் = ஆம்**.

துல்லியப் பின்னங்களால் இயல்பாக்கப்படாத மதிப்பெண்கள் 0.0282187, 0.00685714. இயல்பாக்கினால் இந்த மாதிரியின்கீழ் P(yes|X) ≈ **0.8045**. 0.028 என்ற மூல மதிப்பெண்ணைப் பின்னர் நிகழ்தகவாகக் கருத வேண்டாம்.

வகைசார் **லப்ளாஸ் சீராக்கலுக்கு**, **(count + 1)/(class_count + v)** பயன்படுத்தவும்; v என்பது அந்தப் பண்புக்கூறின் வகைகளின் எண்ணிக்கை. தொகுதியும் பகுதியும் மாறுகின்றன. [எளிமைப் பேய்ச் ஆவணத்தைப்](https://scikit-learn.org/stable/modules/naive_bayes.html) பார்க்கவும்.

{{tool:nb}}

எளிமைப் பேய்ச் கணக்கீடுகள் மிகவும் பொதுவானவை. அட்டவணையைப் போலவே அமைக்கவும்:

1. **முன் நிகழ்தகவுகள்**
2. **ஒவ்வொரு நிபந்தனை நிகழ்தகவையும் பின்னமாக**
3. **P(X|C) பெருக்கல்கள்**
4. **முன் நிகழ்தகவுகளால் பெருக்குதல்**
5. **ஒப்பிட்டு** வகுப்பைக் கூறுதல்

## விதி சார்ந்த வகைப்படுத்தல்

**விதி சார்ந்த வகைப்படுத்தி**, **IF-THEN விதிகளின்** தொகுப்பைப் பயன்படுத்துகிறது:

:::formula
**R1: எனில்** வயது = இளைஞர் **மற்றும்** மாணவர் = ஆம் **அப்போது** கணினி_வாங்குவார் = ஆம்
(வயது = இளைஞர்) ∧ (மாணவர் = ஆம்) ⇒ (கணினி_வாங்குவார் = ஆம்)
:::

| பகுதி | பெயர் |
|---|---|
| IF பகுதி (இடப்பக்கம்) | **விதி முன்னுறுப்பு** அல்லது **முன்நிபந்தனை**: **AND-ஆல்** இணைந்த ஒன்று அல்லது பல பண்புக்கூறுச் சோதனைகள் |
| THEN பகுதி (வலப்பக்கம்) | **விதி பின்னுறுப்பு**: **வகுப்பு முன்னறிவிப்பு** |

ஒரு வரிசைக்கு முன்னுறுப்பின் அனைத்துச் சோதனைகளும் உண்மையானால், விதி **நிறைவேறுகிறது**; அந்த வரிசையை **உள்ளடக்குகிறது**.

### உள்ளடக்கமும் துல்லியமும்

:::formula
**coverage(R)** = n<sub>covers</sub> / |D|      **accuracy(R)** = n<sub>correct</sub> / n<sub>covers</sub>
:::

- **n<sub>covers</sub>** = விதி உள்ளடக்கும் வரிசைகளின் எண்ணிக்கை
- **n<sub>correct</sub>** = அவற்றில் சரியாக வகைப்படுத்திய எண்ணிக்கை
- **|D|** = மொத்த வரிசை எண்ணிக்கை

:::example 14-வரிசைத் தரவில் R1
R1 **2** வரிசைகளை உள்ளடக்குகிறது (RID 9, 11; இருவரும் இளம் மாணவர்கள்); **இரண்டையும்** சரியாக வகைப்படுத்துகிறது.

- உள்ளடக்கம் = 2/14 ≈ **14.29%**
- துல்லியம் = 2/2 = **100%**
:::

## முடிவெடுக்கும் மரத்திலிருந்து விதிகளைப் பிரித்தெடுத்தல்

முடிவெடுக்கும் மரங்கள் துல்லியமானவையும் புரிந்துகொள்ள எளியவையும்; ஆனால் **பெரிய மரங்களை விளக்குவது கடினமாகிறது**. குறிப்பாக மரம் மிகப்பெரியதாக இருக்கும்போது IF-THEN விதிகள் **மனிதர்களுக்கு எளிதாக** இருக்கலாம்.

:::key பிரித்தெடுப்பது எப்படி
- **வேரிலிருந்து இலைவரையான ஒவ்வொரு பாதைக்கும் ஒரு விதியை** உருவாக்கவும்.
- முன்னுறுப்பை உருவாக்க **பாதையின் பிரிப்பளவுகோல்கள் AND-ஆல் இணைக்கப்படுகின்றன**.
- **இலையின் வகுப்பு** பின்னுறுப்பு.
:::

buys_computer மரத்திலிருந்து (வயது → மாணவர் / ஆம் / கடன் மதிப்பீடு):

| விதி | எனில் | அப்போது |
|---|---|---|
| R1 | வயது = இளைஞர் மற்றும் மாணவர் = இல்லை | கணினி_வாங்குவார் = **இல்லை** |
| R2 | வயது = இளைஞர் மற்றும் மாணவர் = ஆம் | கணினி_வாங்குவார் = **ஆம்** |
| R3 | வயது = நடுத்தர_வயது | கணினி_வாங்குவார் = **ஆம்** |
| R4 | வயது = முதியவர் மற்றும் கடன்_மதிப்பீடு = மிகச்சிறப்பு | கணினி_வாங்குவார் = **இல்லை** |
| R5 | வயது = முதியவர் மற்றும் கடன்_மதிப்பீடு = நியாயம் | கணினி_வாங்குவார் = **ஆம்** |

:::warn கவனம்: PDF, R4, R5-ஐ மாற்றியுள்ளது
பாட PDF, முதியவர் + மிகச்சிறப்பு → ஆம், முதியவர் + நியாயம் → இல்லை என்கிறது. தரவு வேறுவிதமாகக் கூறுகிறது. முதியவர் + மிகச்சிறப்பு வரிசைகள் (RID 6, 14) இரண்டும் **இல்லை**; முதியவர் + நியாயம் வரிசைகள் (4, 5, 10) அனைத்தும் **ஆம்**. மேலுள்ள அட்டவணையைப் பயன்படுத்தவும். விதி மதிப்பீட்டியில் சரிபார்க்கலாம்.
:::

மரத்திலிருந்து பிரித்தெடுத்த விதிகளின் பண்புகள்:

- **பரஸ்பரம் விலக்குபவை**: இரு விதிகள் ஒரே வரிசையை உள்ளடக்குவதில்லை.
- **முழுமையாக உள்ளடக்குபவை**: பண்புக்கூறுப் பெறுமதிகளின் ஒவ்வொரு சேர்க்கைக்கும் விதி உள்ளது.

## Weka: பயிற்சியும் சோதனையும்

| காணொளி | முக்கிய கற்றல்கள் |
|---|---|
| **2.1 வகைப்படுத்தியாகுங்கள்!** | Weka-வின் **UserClassifier**-ஆல் 2-D வரைபில் பகுதிகளை வரைந்து, **கைமுறையில்** மரத்தை உருவாக்கவும். உங்கள் துல்லியத்தை J48-உடன் ஒப்பிடவும் |
| **2.2 பயிற்சியும் சோதனையும்** | **காணப்படாத தரவின் செயல்திறனுக்குச் சார்பற்ற மதிப்பீடாகப் பயிற்சித் துல்லியத்தைப் பயன்படுத்த வேண்டாம்.** பயிற்சி மதிப்பெண்களைப் பிழையறிதலுக்கு ஆராயலாம். தனி **சோதனைத் தொகுப்பு** அல்லது **சதவீதப் பிரிப்பைப்** பயன்படுத்தவும் (ஒதுக்கீடு; எ.கா. 66% பயிற்சி / 34% சோதனை). பயிற்சித் துல்லியம் மிகையான நம்பிக்கையுடையது |
| **2.3 மீண்டும் பயிற்சியும் சோதனையும்** | வெவ்வேறு சீரற்ற பிரிப்புகள் வெவ்வேறு துல்லியங்களை வழங்குகின்றன. வெவ்வேறு **சீரற்ற விதைகளுடன் மீண்டும் செய்து**, **சராசரியெடுத்து**, **சராசரியையும் நியம விலகலையும்** தெரிவிக்கவும். இது **குறுக்கு உறுதிப்படுத்தலுக்கு** இட்டுச் செல்கிறது |

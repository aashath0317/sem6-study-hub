## அணிகள் தரவைப் பிரதிநிதித்துவப்படுத்துகின்றன

கண மூலகங்களுக்கிடையிலான **தொடர்புகளை** வெளிப்படுத்தத் தனித்த கணிதம் முழுவதும் அணிகள் பயன்படுகின்றன. எ.கா. **தொடர்பாடல் வலையமைப்புகளையும் போக்குவரத்து முறைமைகளையும்** மாதிரியாக்கப் பயன்படுகின்றன. பின்னர் **தொடர்புகளையும்** (வாரம் 9), **வரைபுகளையும்** (வாரம் 11) பிரதிநிதித்துவப்படுத்துகின்றன.

:::key வரையறை 1
- **அணி** என்பது **செவ்வக வடிவிலான எண்களின் ஒழுங்கமைப்பு**.
- **m நிரைகளும் n நிரல்களும்** உள்ள அணி **m × n அணி** (நிரைகள் முதலில்).
- ஒரே எண்ணிக்கையான நிரைகளும் நிரல்களும் உள்ள அணி **சதுர அணி**.
- **ஒரே அளவும்**, **ஒவ்வொரு இடத்திலும் சம உறுப்புகளும்** உள்ள இரு அணிகள் **சமம்**.
:::

:::example எடுத்துக்காட்டு 5.1.1
[[m: 1 0 1; 1 2 3]] ஒரு **2 × 3** அணி: 2 நிரைகள், 3 நிரல்கள்.
:::

### நிரைகள், நிரல்கள், உறுப்புகள் (வரையறை 2)

- A = [aᵢⱼ] பொதுக் குறியீடு.
- **i-ஆவது நிரை**, 1 × n அணி [aᵢ₁ aᵢ₂ … aᵢₙ].
- **j-ஆவது நிரல்**, **m × 1** அணி (a₁ⱼ, a₂ⱼ, …, aₘⱼ செங்குத்தாக எழுதப்பட்டவை).
- **(i, j)-ஆவது உறுப்பு**, **aᵢⱼ**: நிரை i, நிரல் j.

## அணிக் கூட்டல்

A = [aᵢⱼ], B = [bᵢⱼ] **இரண்டும் m × n** எனில் **A + B = [aᵢⱼ + bᵢⱼ]**. ஒரே இடத்திலுள்ள உறுப்புகளைக் கூட்டவும்.

:::example எடுத்துக்காட்டு 5.2.1
A = [[m: 1 0 4; −1 2 2; 0 −2 −3]] B = [[m: −1 3 5; 2 −2 −3; 2 −3 0]]

A + B = [[m: 0 3 9; 1 0 −1; 2 −5 −3]]
:::

:::warn
**ஒரே அளவுள்ள** அணிகளை மட்டுமே கூட்டலாம்.
:::

## அணிப் பெருக்கல்

**A என்பது m × k**, **B என்பது k × n** என்க. **AB பெருக்கல் m × n**; அதன் (i, j) உறுப்பு, **A-இன் நிரை i-யையும் B-இன் நிரல் j-யையும் பெருக்கியவற்றின் கூட்டுத்தொகை**:

:::formula
c<sub>ij</sub> = a<sub>i1</sub>b<sub>1j</sub> + a<sub>i2</sub>b<sub>2j</sub> + … + a<sub>ik</sub>b<sub>kj</sub>
:::

:::key அளவு விதி
(m × **k**) · (**k** × n) = **m × n**. **உள் அளவுகள் பொருந்த வேண்டும்**; **வெளி அளவுகள் முடிவின் அளவை வழங்குகின்றன**.
:::

:::example எடுத்துக்காட்டு 5.2.2
A = [[m: 3 1 4; −1 2 3]] (2 × 3), B = [[m: 1 3 −3; 4 −1 2; 2 4 1]] (3 × 3); எனவே AB **2 × 3**.

| உறுப்பு | A-இன் நிரை · B-இன் நிரல் | பெறுமதி |
|---|---|---|
| c₁₁ | (3)(1) + (1)(4) + (4)(2) | **15** |
| c₁₂ | (3)(3) + (1)(−1) + (4)(4) | **24** |
| c₁₃ | (3)(−3) + (1)(2) + (4)(1) | **−3** |
| c₂₁ | (−1)(1) + (2)(4) + (3)(2) | **13** |
| c₂₂ | (−1)(3) + (2)(−1) + (3)(4) | **7** |
| c₂₃ | (−1)(−3) + (2)(2) + (3)(1) | **10** |

AB = [[m: 15 24 −3; 13 7 10]]
:::

:::warn அணிப் பெருக்கல் பரிமாற்றுப் பண்புடையதல்ல (எடுத்துக்காட்டு 5.2.3)
A = [[m: 1 1; 2 1]], B = [[m: 2 1; 1 1]]

AB = [[m: 3 2; 5 3]] ஆனால் BA = [[m: 4 3; 3 2]]

எனவே **AB ≠ BA**. மேலும் AB இருக்கும்போது BA இல்லாமலும் இருக்கலாம் (அளவுகள் பொருந்தாதபோது).
:::

### படிமுறை 1: அணிப் பெருக்கல்

```
procedure matrix multiplication (A: m×k, B: k×n)
for i := 1 to m
    for j := 1 to n
    begin
        c[i][j] := 0
        for q := 1 to k
            c[i][j] := c[i][j] + a[i][q] * b[q][j]
    end
{C = [c[i][j]] is the product of A and B}
```

:::example எடுத்துக்காட்டு 5.2.4 — இரு n × n அணிகளைப் பெருக்கும் செலவு
- பெருக்கலில் **n²** உறுப்புகள் உள்ளன.
- ஒவ்வொரு உறுப்புக்கும் **n பெருக்கல்களும் n − 1 கூட்டல்களும்** தேவை.

மொத்தம்: **n³ பெருக்கல்கள்**, **n²(n − 1) கூட்டல்கள்**. அது O(n³).
:::

## சமனி, அடுக்குகள், இடமாற்று, சமச்சீர்

### சமனி அணி (வரையறை 3)

**Iₙ**, **முதன்மை மூலைவிட்டத்தில் 1-களும் மற்ற எல்லா இடங்களிலும் 0-களும் உள்ள n × n அணி**. எ.கா. I₃ = [[m: 1 0 0; 0 1 0; 0 0 1]]

:::formula
A என்பது n × n எனில்: **IₙA = AIₙ = A**
:::

### அணிகளின் அடுக்குகள்
**சதுர** n × n அணி A-க்கு:

:::formula
**A⁰ = Iₙ**,   **Aʳ = A·A·…·A**  (r தடவைகள்)
:::

### இடமாற்று (வரையறை 3)
m × n அணியின் **இடமாற்று Aᵗ**, **நிரைகளையும் நிரல்களையும் மாற்றுவதால்** கிடைக்கும் **n × m** அணி.

*எடுத்துக்காட்டு:* A = [[m: 1 2 3; 4 5 6]]; எனவே Aᵗ = [[m: 1 4; 2 5; 3 6]]

### சமச்சீர் அணி (வரையறை 3)
**சதுர** அணி A-க்கு **A = Aᵗ** எனில் அது **சமச்சீர்**. முதன்மை மூலைவிட்டத்தின் இருபக்கமும் கண்ணாடிப் படிமம்: aᵢⱼ = aⱼᵢ.

*எடுத்துக்காட்டு:* [[m: 1 1 −1; 1 2 0; −1 0 5]] சமச்சீரானது.

:::tip பயனுள்ள இடமாற்று உண்மைகள்
(A + B)ᵗ = Aᵗ + Bᵗ  ·  **(AB)ᵗ = Bᵗ Aᵗ** (வரிசை தலைகீழாகிறது)  ·  (Aᵗ)ᵗ = A
:::

**கீழுள்ள பகுதி இன்னும் தமிழில் மொழிபெயர்க்கப்படவில்லை; தற்போது ஆங்கிலத்தில் மட்டும் உள்ளது.**

### Determinant and inverse of a matrix (examined: January 2023)

The lesson PDF stops at transposes, but the **January 2023 paper asked for a 3 × 3 inverse**. Learn this method.

:::key 2 × 2 matrices
For A = [[m: a b; c d]]:

- **det A = ad − bc**
- If det A ≠ 0, **A⁻¹ = (1/det A) · [[m: d −b; −c a]]**: swap the diagonal, change the signs of the other two, divide by the determinant.
- If det A = 0 the matrix has **no inverse** (it is *singular*).
:::

*Example:* A = [[m: 4 7; 2 6]]. det A = 4·6 − 7·2 = **10**, so A⁻¹ = (1/10)·[[m: 6 −7; −2 4]].

:::key 3 × 3 matrices: the four-step method
1. **Determinant:** expand along row 1 with the signs **+ − +**: det A = a₁₁·M₁₁ − a₁₂·M₁₂ + a₁₃·M₁₃, where M is the 2 × 2 determinant left after deleting that entry's row and column.
2. **Cofactors:** for every entry, Cᵢⱼ = (sign) × (its 2 × 2 minor), using the chessboard of signs [[m: + − +; − + −; + − +]].
3. **Adjugate:** adj A = the **transpose** of the cofactor matrix (rows become columns).
4. **Inverse:** **A⁻¹ = (1/det A) · adj A**. Check by multiplying: A·A⁻¹ must give I₃.
:::

:::example January 2023 Q3(c): A = [[m: 1 2 3; 2 1 3; 3 2 1]]
**Step 1, determinant (row 1, signs + − +):**

det A = 1·(1·1 − 3·2) − 2·(2·1 − 3·3) + 3·(2·2 − 1·3) = 1·(−5) − 2·(−7) + 3·(1) = −5 + 14 + 3 = **12**

**Step 2, cofactors:**

| Entry | Minor (delete its row and column) | Sign | Cofactor |
|---|---|---|---|
| a₁₁ | 1·1 − 3·2 = −5 | + | **−5** |
| a₁₂ | 2·1 − 3·3 = −7 | − | **7** |
| a₁₃ | 2·2 − 1·3 = 1 | + | **1** |
| a₂₁ | 2·1 − 3·2 = −4 | − | **4** |
| a₂₂ | 1·1 − 3·3 = −8 | + | **−8** |
| a₂₃ | 1·2 − 2·3 = −4 | − | **4** |
| a₃₁ | 2·3 − 3·1 = 3 | + | **3** |
| a₃₂ | 1·3 − 3·2 = −3 | − | **3** |
| a₃₃ | 1·1 − 2·2 = −3 | + | **−3** |

Cofactor matrix C = [[m: −5 7 1; 4 −8 4; 3 3 −3]]

**Step 3, adjugate (transpose of C):** adj A = [[m: −5 4 3; 7 −8 3; 1 4 −3]]

**Step 4, inverse:** A⁻¹ = (1/12)·[[m: −5 4 3; 7 −8 3; 1 4 −3]]

*Check one entry of A·A⁻¹:* row 1 of A · column 1 of adj A = 1(−5) + 2(7) + 3(1) = 12, and 12/12 = **1** ✓
:::

:::warn Solving matrix equations: keep X on the right
To solve **BX = 2X + C**, move the X terms together: BX − 2X = C. Factor X out **on the right**: **(B − 2I)X = C**. Write 2I, not 2, because you can't subtract a number from a matrix. Then multiply by the inverse **on the left**: **X = (B − 2I)⁻¹C**. Since matrix multiplication isn't commutative, CA⁻¹ is wrong here.
:::

## பூச்சியம்–ஒன்று அணிகள்: சேர்வும் சந்திப்பும்

**பூச்சியம்–ஒன்று அணியில் 0 அல்லது 1 மட்டுமே** உறுப்புகளாக உள்ளன. அதன் எண்கணிதம் **பூலியன் செயல்பாடுகள் ∧, ∨**-ஐப் பயன்படுத்துகிறது:

| b₁ ∧ b₂ | b₁ = b₂ = 1 எனில் = 1; இல்லாவிட்டால் 0 |
|---|---|
| **b₁ ∨ b₂** | **b₁ = 1 அல்லது b₂ = 1 எனில் = 1; இல்லாவிட்டால் 0** |

m × n பூச்சியம்–ஒன்று அணிகள் A = [aᵢⱼ], B = [bᵢⱼ]-க்கு:

| செயல்பாடு | குறியீடு | (i, j) உறுப்பு |
|---|---|---|
| **சேர்வு** | **A ∨ B** | aᵢⱼ ∨ bᵢⱼ (OR) |
| **சந்திப்பு** | **A ∧ B** | aᵢⱼ ∧ bᵢⱼ (AND) |

:::example எடுத்துக்காட்டு 5.2.4 (சேர்வும் சந்திப்பும்)
A = [[m: 1 0 1; 0 1 0]], B = [[m: 0 1 0; 1 1 0]]

A ∨ B = [[m: 1∨0 0∨1 1∨0; 0∨1 1∨1 0∨0]] = [[m: 1 1 1; 1 1 0]]

A ∧ B = [[m: 1∧0 0∧1 1∧0; 0∧1 1∧1 0∧0]] = [[m: 0 0 0; 0 1 0]]
:::

:::exam
எதிர்பார்க்க வேண்டியவை:

- அணி அளவுகள்
- கூட்டல்
- **அனைத்துச் செய்முறையுடனும் பெருக்கல்** (c<sub>ij</sub> கூட்டுத்தொகைகள்)
- எந்தப் பெருக்கல்கள் வரையறுக்கப்படுகின்றன, அவற்றின் அளவுகள் என்ன எனச் சரிபார்த்தல் (எ.கா. A 3×4, B 4×5, C 4×4: AB 3×5; BA வரையறுக்கப்படவில்லை; AC 3×4; CA வரையறுக்கப்படவில்லை; BC வரையறுக்கப்படவில்லை; CB 4×5)
- AB ≠ BA காட்டுதல்
- இடமாற்று / சமச்சீர்
- சேர்வும் சந்திப்பும்
- Aʳ அடுக்குகள்
- படிமுறை 1-இல் செயல்பாடுகளை எண்ணுதல்
- 2 × 2, 3 × 3 அணிகளின் **துணிகோவையும் (determinant) நேர்மாறும்**; BX = 2X + C போன்ற அணிச் சமன்பாடுகளைத் தீர்த்தல் (ஜனவரி 2023)
:::

## விரைவு மீளாய்வுத் தாள்

| கருத்து | இவ்வாறு நினைவில் கொள்ளவும் |
|---|---|
| m × n | நிரைகள் × நிரல்கள்; m = n எனில் சதுரம் |
| aᵢⱼ | நிரை i, நிரல் j |
| சமம் | ஒரே அளவு + ஒரே உறுப்புகள் |
| A + B | ஒரே அளவு; உறுப்புவாரியாகக் கூட்டவும் |
| AB | (m×k)(k×n) = m×n; c<sub>ij</sub> = நிரை i · நிரல் j |
| பரிமாற்றுப் பண்பா? | இல்லை: பொதுவாக AB ≠ BA |
| படிமுறை 1 | ஒன்றுக்குள் ஒன்றான மூன்று சுழல்கள்; n³ பெருக்கல்கள், n²(n−1) கூட்டல்கள் |
| சமனி | IₙA = AIₙ = A |
| அடுக்குகள் | A⁰ = Iₙ; Aʳ = A·…·A |
| இடமாற்று | நிரைகளையும் நிரல்களையும் மாற்று; (AB)ᵗ = BᵗAᵗ |
| சமச்சீர் | A = Aᵗ |
| சேர்வு / சந்திப்பு | 0–1 அணிகளுக்கு உறுப்புவாரி OR / AND |
| நேர்மாறு | det A ≠ 0; A⁻¹ = (1/det A) · adj A; adj A = இணைக்காரணிகளின் இடமாற்று (குறிகள் + − +) |
